# Cliente IBM Quantum Compute v0.46.0 {#ibm-quantum-compute-client-v0460}

## Abril de 2026 {#april-2026}

<span id="executor-primitive"></span>
- **Introducing the Executor primitive**: We're excited to announce the release of the new `Executor` primitive and a new version of the noise-learning helper class, `NoiseLearnerV3`, both of which were first previewed at QDC 2025.

  Junto con [Samplomatic](https://qiskit.github.io/samplomatic/index.html), conforman el [modelo de ejecución dirigida](/guides/directed-execution-model), que proporciona transparencia y control total para ajustar tu flujo de trabajo de mitigación de errores. El tutorial [Probabilistic error cancellation with shaded lightcones](https://qiskit.github.io/qiskit-addon-slc/tutorials/01_getting_started.html), por ejemplo, demuestra cómo se usa este modelo para combinar técnicas avanzadas, incluyendo shaded lightcones, cancelación probabilística de errores (PEC), Twirled Readout Error eXtinction (TREX), y [postselección basada en mediciones](/guides/post-selection), para mejorar aún más la calidad de los resultados.

  Si prefieres un nivel de abstracción más alto, [`EstimatorV2`](/guides/estimator-noise-management) en Qiskit Runtime sigue proporcionando varias técnicas integradas de mitigación y supresión de errores, que puedes ajustar fácilmente usando la opción [`resilience_level`](/guides/estimator-noise-management#resilience-level).

  Para obtener más información, consulta las siguientes guías:

    - [Inicio rápido del Executor](/guides/get-started-with-executor)

    - [Auxiliar de aprendizaje de ruido](/guides/noise-learning)


  Ambas funciones nuevas están actualmente en beta y requieren la versión 0.47.0 o posterior de `qiskit-ibm-runtime`.
