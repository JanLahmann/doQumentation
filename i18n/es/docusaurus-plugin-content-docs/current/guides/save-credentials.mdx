# Guardar tus credenciales de acceso {#save-your-login-credentials}
Si trabajas en un entorno Python de confianza (como tu laptop personal o una estación de trabajo), puedes usar el método `save_account()` para guardar tus credenciales localmente y luego usarlas para inicializar el servicio.

<Admonition type="note" title="Notas">
      * Si usas una computadora pública u otro entorno no confiable, sigue en su lugar las instrucciones de [Inicializar el servicio en un entorno no confiable](/guides/cloud-setup-untrusted).
      * Sigue [estas instrucciones](/guides/cloud-setup-rest-api) si quieres conectarte mediante la API REST en lugar de usar Qiskit.
      * Si es necesario, usa [esta información](/guides/quickstart-steps-org#firewall) para configurar tu firewall y habilitar el acceso a los endpoints de la API de IBM Quantum.
</Admonition>

## Antes de empezar {#before-you-begin}

1. Asegúrate de estar trabajando en un entorno Python activo con [`qiskit` y `qiskit-ibm-runtime` packages instalados](/guides/install-qiskit#local).

1. Activa el entorno virtual de Python y ejecuta Python dentro de ese entorno.

1. Inicia sesión en [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Encontrar tus credenciales de acceso {#find-your-access-credentials}

1. Asegúrate de que la cuenta y la región correctas estén seleccionadas en el selector de cuentas del encabezado.

1. Encuentra tu clave de API. Desde el [panel de control](https://quantum.cloud.ibm.com/), crea tu clave de API, luego cópiala en un lugar seguro para poder usarla en la autenticación. Ten en cuenta que puedes usar la misma clave de API para conectarte a cualquier región.

1. Opcional: Encuentra la instancia que quieres usar desde la página [Instances](https://quantum.cloud.ibm.com/instances). Pasa el cursor sobre su CRN, haz clic en el ícono para copiarlo y guárdalo en un lugar seguro para poder identificar la instancia.


<span id="cloud-save"></span>

## Guardar tus credenciales de acceso {#save-your-access-credentials}

Guarda tus credenciales ejecutando el código apropiado una vez por cada cuenta que quieras guardar. Después de guardarlas, cárgalas siguiendo los pasos en [Inicializar IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Guardar credenciales que acceden a una instancia específica: {#save-credentials-that-access-a-specific-instance}
Si tienes varias instancias y quieres indicarle fácilmente a Quantum Compute cuál usar, guarda credenciales que incluyan el CRN de una instancia.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Guardar credenciales para la selección automática de instancia: {#save-credentials-for-automatic-instance-selection}
Si no proporcionas un CRN de instancia y pasas estas credenciales a Quantum Compute, se elegirá automáticamente una instancia adecuada según las opciones especificadas.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Ejemplo 2 {#example-2}
Este ejemplo guarda credenciales para la selección automática de instancia. Quantum Compute solo considerará las instancias premium en la región de la UE disponibles para la cuenta. Estas credenciales se convierten en las nuevas predeterminadas.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Ver las credenciales guardadas {#view-saved-credentials}

Para ver todas las credenciales que has guardado, ejecuta `service.saved_accounts()`. Ten en cuenta que si guardaste credenciales predeterminadas sin asignarles un nombre, se llamarán `default-ibm-quantum-platform`. Si les asignaste un nombre, verás `"is_default_account": true` en la salida.

## Consideraciones {#considerations}

* Si vas a guardar varias cuentas, usa el parámetro `name` para diferenciarlas.

* Las credenciales se guardan en `$HOME/.qiskit/qiskit-ibm.json`. No edites este archivo manualmente.

* Si no guardas tus credenciales, deberás especificarlas cada vez que inicies una nueva sesión (al instanciar IBM Quantum Compute Service).

* Si especificas tus credenciales manualmente, no se usará ninguna cuenta guardada.
