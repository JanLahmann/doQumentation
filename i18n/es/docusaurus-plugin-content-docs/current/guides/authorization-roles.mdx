# Roles de autorización {#authorization-roles}

Revisa los roles disponibles y las acciones asignadas a cada uno para ayudarte a asignar el acceso. Consulta [Roles y acciones de IAM](https://cloud.ibm.com/docs/iam?topic=iam-iam-service-roles-actions#service-roles-table155) en IBM Cloud&reg; para obtener más información.

## IBM Quantum Compute Service {#ibm-quantum-compute-service}

| Permiso | Requerido por |
| -- | -- |
| `quantum-computing.account-analytics-filters.read` | Obtener filtros de analíticas (`GET /v1/analytics/filters`) |
| `quantum-computing.account-analytics-usage.read` | Obtener analíticas de uso (`GET /v1/analytics/usage`) |
| `quantum-computing.account-analytics-usage.read` | Obtener analíticas de uso agrupadas (`GET /v1/analytics/usage_grouped`) |
| `quantum-computing.account-analytics-usage.read` | Obtener analíticas de uso agrupadas por fecha (`GET /v1/analytics/usage_grouped_by_date`) |
| `quantum-computing.account-configuration.read` | Obtener la configuración de la cuenta (`GET /v1/accounts/{id}`) |
| `quantum-computing.device.read` | Obtener la configuración del backend (`GET /v1/backends/{id}/configuration`) |
| `quantum-computing.device.read` | Obtener la configuración predeterminada del backend (`GET /v1/backends/{id}/defaults`) |
| `quantum-computing.device.read` | Obtener las propiedades del backend (`GET /v1/backends/{id}/properties`) |
| `quantum-computing.device.read` | Obtener el estado del backend (`GET /v1/backends/{id}/status`) |
| `quantum-computing.device.read` | Listar tus backends (`GET /v1/backends`) |
| `quantum-computing.instance-usage.read` | Obtener el uso de la instancia (`GET /v1/instances/usage`) |
| `quantum-computing.instance.configuration.read` | Obtener la configuración de la instancia (`GET /v1/instances/configuration`) |
| `quantum-computing.instance.read` | Obtener los detalles de la instancia actual (`GET /v1/instance`) |
| `quantum-computing.job.cancel` | Cancelar un trabajo (`POST /v1/jobs/{id}/cancel`) |
| `quantum-computing.job.create` | Ejecutar un trabajo (`POST /v1/jobs`) |
| `quantum-computing.job.delete` | Eliminar un trabajo (`DELETE /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Obtener las métricas del trabajo (`GET /v1/jobs/{id}/metrics`) |
| `quantum-computing.job.read` | Listar los detalles del trabajo (`GET /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Listar los registros del trabajo (`GET /v1/jobs/{id}/logs`) |
| `quantum-computing.job.read` | Listar los resultados del trabajo (`GET /v1/jobs/{id}/results`) |
| `quantum-computing.job.read` | Listar trabajos (`GET /v1/jobs`) |
| `quantum-computing.job.read` | Listar etiquetas (`GET /v1/tags`) |
| `quantum-computing.session.create` | Crear una sesión (`POST /v1/sessions`) |
| `quantum-computing.session.read` | Obtener una sesión (`GET /v1/sessions/{id}`) |
| `quantum-computing.session.update` | Cerrar la sesión del trabajo (`DELETE /v1/sessions/{id}/close`) |
| `quantum-computing.session.update` | Actualizar una sesión (`PATCH /v1/sessions/{id}`) |
| `quantum-computing.workload.list` | Listar las cargas de trabajo de la instancia del usuario (`GET /v1/workloads`) |

## IBM Quantum System Service {#ibm-quantum-system-service}

| Permiso | Requerido por |
| -- | -- |
| `quantum-computing.direct-access-backend-configuration.read` | Obtener la configuración del backend (`GET /v1/backends/{backend-name}/configuration`) |
| `quantum-computing.direct-access-backend-properties.read` | Obtener las propiedades del backend (`GET /v1/backends/{backend-name}/properties`) |
| `quantum-computing.direct-access-backend.list` | Obtener la lista de backends (`GET /v1/backends`) |
| `quantum-computing.direct-access-backend.read` | Obtener los detalles del backend (`GET /v1/backends/{backend-name}`) |
| `quantum-computing.direct-access-job.cancel` | Cancelar un trabajo (`POST /v1/jobs/{job-id}/cancel`) |
| `quantum-computing.direct-access-job.create` | Ejecutar un trabajo (`POST /v1/jobs`) |
| `quantum-computing.direct-access-job.delete` | Eliminar un trabajo (`DELETE /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-job.list` | Obtener trabajos (`GET /v1/jobs`) |
| `quantum-computing.direct-access-job.read` | Obtener un trabajo por ID (`GET /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-lane-configuration.list` | Obtener la configuración de los carriles del backend (`GET /v1/backends/{backend-name}/lanes`) |
