# Qiskit Code Assistant {#qiskit-code-assistant}

<span id="qca-sunset"></span>

## 29 de mayo de 2026 {#29-may-2026}
- **Servicio de Qiskit Code Assistant descontinuado** - El servicio de vista previa se ha descontinuado y las extensiones de Visual Studio Code y JupyterLab se han archivado.


  Según los comentarios y patrones de uso, cada vez más usuarios ejecutan los modelos de Qiskit Code Assistant localmente y trabajan en integraciones de editor que ya forman parte de su flujo de trabajo de desarrollo.

  Los modelos de Qiskit Code Assistant siguen disponibles para uso local. Consulta la documentación de [Qiskit Code Assistant](/guides/qiskit-code-assistant) para obtener más información.
