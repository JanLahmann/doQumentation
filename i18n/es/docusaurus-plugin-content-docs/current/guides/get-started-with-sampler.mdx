## Pasos para usar el primitivo Sampler {#steps-to-use-the-sampler-primitive}

### 1. Inicializar la cuenta {#1-initialize-the-account}

Primero necesitas inicializar tu cuenta. Luego puedes seleccionar la QPU que quieres usar para calcular el valor de expectación.

Sigue los pasos del tema [Configurar tu cuenta de IBM Cloud](/guides/cloud-setup) si aún no tienes una cuenta configurada.

:::note[Gates fraccionales]


Para usar los [gates fraccionales](/guides/fractional-gates) recientemente admitidos, establece `use_fractional_gates=True` al solicitar un backend a una instancia de `QiskitRuntimeService`. Por ejemplo:

```python
service = QiskitRuntimeService()
fractional_gate_backend = service.least_busy(use_fractional_gates=True)
```

Esta es una función experimental y podría cambiar en el futuro.

:::


```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()
backend = service.least_busy(
    operational=True, simulator=False, min_num_qubits=127
)
```

### 2. Crear un circuit {#2-create-a-circuit}

Necesitas al menos un circuit como entrada para el primitivo Sampler.

```python
import numpy as np
from qiskit.circuit.library import efficient_su2

circuit = efficient_su2(127, entanglement="linear")
circuit.measure_all()
# The circuit is parametrized, so we will define the parameter values for execution
param_values = np.random.rand(circuit.num_parameters)
```

El circuit y el observable deben transformarse para usar solo instrucciones admitidas por la QPU (denominadas circuits de *arquitectura de conjunto de instrucciones (ISA)*). Usa el transpilador para hacer esto.

```python
from qiskit.transpiler import generate_preset_pass_manager

pm = generate_preset_pass_manager(optimization_level=1, backend=backend)
isa_circuit = pm.run(circuit)
print(f">>> Circuit ops (ISA): {isa_circuit.count_ops()}")
```

```text
>>> Circuit ops (ISA): OrderedDict([('rz', 3036), ('sx', 1769), ('cz', 378), ('measure', 127), ('barrier', 1)])
```

### 3. Inicializar el Sampler de IBM Quantum {#3-initialize-the-ibm-quantum-sampler}

Cuando inicializas Sampler, usa el parámetro `mode` para especificar el modo en que quieres que se ejecute. Los valores posibles son objetos `batch`, `session` o `backend` para el modo de ejecución por lote, sesión y trabajo, respectivamente. Para más información, consulta [Introducción a los modos de ejecución de IBM Quantum Compute Service](/guides/execution-modes). Ten en cuenta que los usuarios del Plan Open no pueden enviar trabajos de sesión.

```python
from qiskit_ibm_runtime import SamplerV2 as Sampler

sampler = Sampler(mode=backend)
```

### 4. Invocar Sampler y obtener resultados {#4-invoke-sampler-and-get-results}

A continuación, invoca el método `run()` para generar la salida. El circuit y los conjuntos opcionales de valores de parámetros se ingresan como tuplas de *bloque unificado primitivo* (PUB).

```python
job = sampler.run([(isa_circuit, param_values)])
print(f">>> Job ID: {job.job_id()}")
print(f">>> Job Status: {job.status()}")
```

```text
>>> Job ID: dab7lb6rrl7c7386gjgg
```

```text
>>> Job Status: QUEUED
```

```python
result = job.result()

# Get results for the first (and only) PUB
pub_result = result[0]
print(
    f"First ten results for the 'meas' output register: "
    f"{pub_result.data.meas.get_bitstrings()[:10]}"
)
```
