# Usar endpoints privados virtuales para VPC y conectarse de forma privada a IBM Quantum Platform {#use-virtual-private-endpoints-for-vpc-to-privately-connect-to-ibm-quantum-platform}

Usa Endpoints Privados Virtuales (VPE) para [Virtual Private Cloud (VPC)](https://cloud.ibm.com/docs/vpc) para conectarte a IBM Quantum&reg; desde tu red VPC. La conexión usa la dirección IP que especifiques, asignada desde una subred dentro de tu VPC.

Los VPE son interfaces IP virtuales que están vinculadas a un gateway de endpoint creado por servicio. El gateway de endpoint es una función virtualizada que escala horizontalmente, es redundante y de alta disponibilidad, y abarca todas las zonas de disponibilidad de tu VPC. Los gateways de endpoint permiten las comunicaciones entre las instancias de servidor virtual dentro de tu VPC y el servicio IBM Cloud&reg; sobre la red troncal privada. VPE para VPC te permite controlar todo el direccionamiento privado dentro de tu nube. Para obtener más información, consulta [Acerca de los gateways de endpoint privado virtual](https://cloud.ibm.com/docs/vpc?topic=vpc-about-vpe).

Independientemente de si usas VPEs, toda la comunicación interna dentro de la red de IBM Quantum Platform siempre usa conexiones privadas en lugar de la internet pública.

Si tu conexión a IBM Quantum Platform en sí es pública o privada depende de si usas un VPE. Conectarte a través de los endpoints públicos transmite todos los datos de solicitud y respuesta a través de la internet pública. Conectarte a través de un VPE mantiene ese tráfico en la red privada en su lugar.

Los VPEs solo son compatibles con la API y el SDK de IBM Quantum Platform, como se describe en las siguientes secciones. El sitio web de IBM Quantum Platform no admite VPEs y solo se puede acceder a él a través de la red pública.

## Antes de comenzar {#before-you-begin}

Antes de apuntar a un VPE para IBM Quantum Platform, completa los siguientes pasos:

* [Crea una nube privada virtual](https://cloud.ibm.com/docs/vpc?topic=vpc-getting-started).

* [Planifica la topología de red](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-planning-considerations) para conectarte a los VPE.

* [Configura los controles de acceso](https://cloud.ibm.com/docs/vpc?topic=vpc-configure-acls-sgs-endpoint-gateways) para tu VPE.

* Comprende las [restricciones del servicio](https://cloud.ibm.com/docs/vpc?topic=vpc-limitations).

* Aprende a [ver los detalles del VPE](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-viewing-details-of-an-endpoint-gateway).


## Configurar un VPE para IBM Quantum Platform {#set-up-a-vpe-for-ibm-quantum-platform}

Hay varias formas de crear un gateway VPE. Si usas la [CLI](https://cloud.ibm.com/docs/vpc?topic=vpc-vpc-reference&interface=cli#vpe-clis) o la [API](https://cloud.ibm.com/apidocs/vpc/latest#create-endpoint-gateway), debes especificar el [Nombre de recurso en la nube (CRN)](https://cloud.ibm.com/docs/account?topic=account-crn) de la región en la que deseas conectarte a IBM Quantum Platform. Consulta la siguiente tabla para ver las regiones y CRN disponibles.

| Región | Planes   | Nombre de dominio completamente calificado (FQDN) | Nombre de recurso en la nube (CRN) |
|-----------------|-----------------|-----------------|-----------------|
| `us-east` | `Standard` | `private.us-east.quantum.cloud.ibm.com` | `crn:v1:bluemix:public:quantum-computing:us-east:::endpoint:private.us-east.quantum.cloud.ibm.com` |
| `eu-de` | `Standard` | `private.eu-de.quantum.cloud.ibm.com` | `crn:v1:bluemix:public:quantum-computing:eu-de:::endpoint:private.eu-de.quantum.cloud.ibm.com` |

### Configurar un gateway de endpoint {#configuring-an-endpoint-gateway}

Para configurar un gateway VPE, sigue estos pasos:

1. Lista los servicios disponibles, incluidos los servicios de infraestructura de IBM Cloud disponibles (de forma predeterminada) para todos los usuarios de VPC.

1. [Crea un gateway de endpoint](https://cloud.ibm.com/docs/vpc?topic=vpc-ordering-endpoint-gateway) para IBM Quantum Platform que desees que esté disponible de forma privada en la VPC.

1. [Vincula una dirección IP reservada](https://cloud.ibm.com/docs/vpc?topic=vpc-bind-unbind-reserved-ip) al gateway de endpoint.

1. [Consulta los gateways VPE creados](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-viewing-details-of-an-endpoint-gateway) asociados con IBM Quantum Platform.


Ahora las instancias de servidor virtual en la VPC pueden acceder a tu instancia de IBM Quantum Platform de forma privada.

## Usar tu VPE para IBM Quantum Platform {#use-your-vpe-for-ibm-quantum-platform}

Después de crear un gateway de endpoint para IBM Quantum Platform, sigue estos pasos:

### Usar el VPE con `qiskit-ibm-runtime` (SDK de Python) {#use-the-vpe-with-qiskit-ibm-runtime-python-sdk}

<Admonition type="note">
La compatibilidad con VPE requiere `qiskit-ibm-runtime` v0.24.0 o posterior.
</Admonition>

Al instanciar `QiskitRuntimeService`, especifica `private_endpoint=True`.

```python
# For `token`, use the 44-character API_KEY you created 
# and saved from the IBM Quantum Platform Home dashboard
service = QiskitRuntimeService(token="your-API_KEY", 
                              instance="INSTANCE_CRN",
                              channel="ibm_cloud",
                              private_endpoint=True)
```

### Usar el VPE con la API de IBM Quantum {#use-the-vpe-with-the-ibm-quantum-api}

Después de crear un gateway de endpoint para IBM Quantum Platform, usa el nombre de dominio completamente calificado (FQDN) del endpoint del servicio para la región de destino de [la tabla anterior](#set-up-a-vpe-for-ibm-quantum-platform).

```bash
  curl -X POST \
  https://private.us-east.quantum.cloud.ibm.com/api/v1/jobs \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Service-CRN: $SERVICE_INSTANCE_CRN" \
  -d '{
    "backend": "backend",
    "program_id": "sampler"
  }'
```
