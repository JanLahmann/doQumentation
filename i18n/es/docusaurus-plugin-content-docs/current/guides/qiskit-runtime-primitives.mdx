# Introducción a los primitivos de IBM Quantum {#introduction-to-ibm-quantum-primitives}

Los primitivos se crearon para simplificar las tareas más comunes de las computadoras cuánticas: concretamente, el muestreo de estados cuánticos y el cálculo de valores de expectación. Los primeros primitivos de IBM Quantum ([`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) y [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)) son implementaciones de las [clases base de primitivos](/guides/primitives) de Qiskit. Proporcionan una implementación más sofisticada (por ejemplo, con mitigación de errores incluida) como servicio en la nube y se utilizan para acceder al hardware de IBM Quantum&reg;.

El primitivo más nuevo de IBM Quantum, [Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor) (que está en beta), proporciona una interfaz de nivel más bajo que ofrece mayor visibilidad y control sin sacrificar el rendimiento. 
`Executor` también expone **capacidades adicionales que Sampler no ofrece**, como grupos de twirling adicionales y twirling para circuitos con puertas fraccionarias. Consulta [Migrate from Sampler to Executor](/guides/migrate-from-sampler-to-executor) para obtener más información sobre si migrar a `Executor`.
