## Encuesta posterior al curso {#post-course-survey}

¡Felicidades por completar el curso "Usa una computadora cuántica hoy" de IBM&reg;!

## Pon a prueba tu conocimiento {#test-your-knowledge}

Después de completar la lectura y las actividades de este curso, haz clic en el botón de abajo para navegar a IBM Training, donde puedes tomar el examen de insignia para Usa una computadora cuántica hoy.

El examen consta de 20 preguntas, y debes responder correctamente al menos 16 para aprobar. Al obtener una calificación aprobatoria, tu insignia se enviará automáticamente al correo electrónico que usaste para registrarte en IBM Training.

Asegúrate de estar listo para tomar el examen. Si no obtienes una calificación aprobatoria en dos intentos, el examen se bloqueará temporalmente.
