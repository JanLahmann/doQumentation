## Antecedentes {#background}

Este tutorial demuestra cómo implementar el algoritmo de diagonalización cuántica de Krylov (KQD) dentro del contexto de los patrones de Qiskit. Primero aprenderás la teoría detrás del algoritmo y luego verás una demostración de su ejecución en una QPU.

Estimar las propiedades de baja energía de Hamiltonianos de muchos cuerpos es una tarea central en la simulación cuántica.
Por ejemplo, las energías del estado fundamental y las excitaciones de baja energía están directamente relacionadas con la estabilidad química, el ordenamiento magnético, las transiciones de fase cuánticas y la respuesta del material.
En un ordenador clásico, la dimensión del espacio de Hilbert crece exponencialmente con el número de orbitales o espines, por lo que la diagonalización directa rápidamente se vuelve impracticable.

Existen varios enfoques de computación cuántica para este problema.
Los métodos variacionales a corto plazo, como el [eigensolucionador cuántico variacional (VQE)](/tutorials/spin-chain-vqe), utilizan circuitos parametrizados relativamente poco profundos, pero requieren un bucle de optimización clásica no lineal con muchas evaluaciones de circuitos cuánticos.
En el otro extremo, la [estimación de fase cuántica (QPE)](https://arxiv.org/abs/quant-ph/0604193) proporciona una ruta más directa a la estimación de autovalores con garantías rigurosas, pero la QPE estándar requiere circuitos coherentes largos y es principalmente adecuada para ordenadores cuánticos tolerantes a fallos.
KQD se sitúa entre estos dos enfoques: utiliza la evolución del Hamiltoniano en tiempo real, como en los algoritmos basados en estimación de fase, pero reemplaza la estimación de fase completa por un problema de autovalores proyectado compacto que puede resolverse clásicamente.

Considera un Hamiltoniano $H$ de $n$ Qubits y un estado de referencia $\lvert \psi_{0}\rangle$.
El método KQD construye un subespacio de Krylov a partir de estados evolucionados en tiempo real,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

donde $r$ es la dimensión de Krylov y $\Delta t$ es el paso de tiempo.
Cualquier estado en el subespacio de Krylov se representa entonces como una combinación lineal de estos estados base,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
where the denominator normalizes the state.

Con álgebra simple, podemos ver que la energía correspondiente se escribe como el cociente de Rayleigh,

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

Aquí, las matrices $\mathcal{S}$ y $\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

definen las matrices proyectadas de solapamiento y Hamiltoniano.
Sus elementos se estiman utilizando mediciones de circuitos cuánticos.

Nuestro objetivo es encontrar el coeficiente $\mathbf{c}$ que da el mínimo $E(\mathbf{c})$:

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

Según el teorema de Rayleigh-Ritz, esta minimización es equivalente a resolver el problema de autovalores generalizado (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

Ten en cuenta que la dimensión $r$ puede ser lo suficientemente pequeña como para que un ordenador clásico resuelva el GEVP.

Este es el mismo principio variacional utilizado en la diagonalización de subespacios clásica, pero aquí los estados base se generan mediante evolución temporal cuántica.
En comparación con VQE, KQD generalmente requiere circuitos más profundos porque depende de la evolución en tiempo real.
A cambio, KQD evita la optimización de parámetros no lineal y la ejecución iterativa en hardware cuántico, y mejora sistemáticamente a medida que se amplía el subespacio proyectado.
El algoritmo se ha demostrado a gran escala en hardware cuántico existente [\[2\]](#references), y su rendimiento puede analizarse con garantías demostrables [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.primitives import StatevectorEstimator
from qiskit.quantum_info import Operator, SparsePauliOp
from qiskit.synthesis import LieTrotter, SuzukiTrotter
from qiskit.transpiler import PassManager, Layout
from qiskit.transpiler.passes import CommutativeOptimization
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### Establecer los parámetros del algoritmo {#set-the-parameters-for-the-algorithm}

Basándose en las cotas superiores de la norma del Hamiltoniano, la Ref. [\[1\]](#references) sugiere heurísticamente el paso de tiempo $\Delta t$ como $\pi/\|H\|$.
Dado que la norma espectral $\|H\|$ es difícil de calcular, utilizamos en su lugar su cota superior:

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ matrix, easy to calculate the norm}} = 3(n-1).
\end{equation*}
$$

Establecemos la dimensión de Krylov en $r=10$ y el número de pasos de Trotter por paso de tiempo en $5$: un espacio de Krylov lo suficientemente grande como para resolver el espectro de baja energía manteniendo asequible el circuito más profundo ($t_{\max}=(r-1)\Delta t$), y suficientes pasos de Trotter para mantener pequeño el error de discretización en ese circuito más profundo.

#### Construir circuito {#build-circuit}

Aquí, construimos los circuitos para estimar los elementos de matriz $\mathcal{H}_{k\ell}$ y $\mathcal{S}_{k\ell}$.
Dado que todas las potencias de $H$ conmutan, tenemos
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Such matrices where the elements depend on the index differences in this manner are called *Toeplitz* and can be reconstructed from first-row elements indexed by $d=\ell-k$.

Aquí, presentamos el circuito, llamado **prueba de intercambio extendida**, que prepara
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
donde $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$.

#### Circuito de prueba de intercambio extendida [\[3\]](#references) {#extended-swap-test-circuit-3references}

El circuito primero prepara el estado de referencia en el registro del sistema mientras el ancilla permanece en $|0\rangle$:

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

Luego, al aplicar una puerta Hadamard al ancilla se crea una superposición coherente de dos ramas:

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Finalmente, se aplica la puerta de evolución temporal controlada:

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

solo cuando el ancilla está en la rama $|1\rangle$. Por lo tanto,

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

En el siguiente bloque de código, implementamos:
$$
\begin{equation*}
|\Psi(t)\rangle = \frac{|0\rangle|\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}},
\end{equation*}
$$
que se asignará como $t=d\Delta t$ para $d=1,\cdots r-1$ en el paso de ejecución.

```python
ancilla = 0
system_qubits = list(range(1, num_qubits + 1))

extended_swap_test = QuantumCircuit(num_qubits + 1)

# Append state preparation part
extended_swap_test = extended_swap_test.compose(qc_ref, system_qubits)

# Prepare the coherent branch label, (|0> + |1>) / sqrt(2).
extended_swap_test.h(ancilla)

# Apply U(t) only to the |1> branch of the ancilla.
extended_swap_test.append(
    controlled_evolution_gate, [ancilla] + system_qubits
)

# Decompose once more for visualization so that control bullets are visible.
display(extended_swap_test.draw("mpl", fold=-1))
```

#### Observables {#observables}

Para cualquier observable hermítico del sistema $O$, aquí establecemos los observables a calcular:

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Esto es porque $O=I$ da el elemento de solapamiento $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$, mientras que $O=H$ da el elemento del Hamiltoniano $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$.

Usando $X=|0\rangle\langle 1|+|1\rangle\langle 0|$, tenemos

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

De manera similar, usando $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

Por lo tanto, tenemos
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Finalmente, para cada estado $|\Psi_{0d}\rangle$, necesitamos medir:
$$
\begin{align*}
X \otimes I \text{ for } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ for } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ for } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ for } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

Para la estimación de los elementos de matriz de $\mathcal{H}$, el número de términos de Pauli es mucho mayor que para los elementos de matriz de $\mathcal{S}$.

Ahora podemos reducir el número de términos del Hamiltoniano medidos utilizando una técnica de desplazamiento [\[4\]](#references).
Dividimos el Hamiltoniano como:

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

donde $T$ se elige de manera que el estado de referencia sea su autoestado,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Then,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Here,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

es el elemento de matriz del Hamiltoniano desplazado.
Por lo tanto, solo necesitamos medir $X\otimes (H-T)$ y $Y\otimes (H-T)$.
La contribución de $T$ se reconstruye clásicamente utilizando el elemento de matriz de solapamiento ya medido $\mathcal{S}_{0d}$.

En este ejemplo, una elección natural es la parte diagonal del Hamiltoniano de Heisenberg,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

Dado que el estado de referencia es un estado de la base computacional, es un autoestado de cada término $Z_iZ_{i+1}$.

Sin embargo, una elección más ventajosa es incluir no solo los términos diagonales $ZZ$, sino también los términos $XX+YY$ que anulan el estado de referencia.

Para cada par de vecinos, el operador $XX+YY$ satisface

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

and

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

Por lo tanto, el término $XX+YY$ contribuye solo cuando los dos Qubits vecinos tienen ocupaciones diferentes en la cadena de bits de referencia.
Si ambos Qubits son $0$ o ambos son $1$, el término anula el estado de referencia y también puede desplazarse.

Sea $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, donde $z_i \in \{0,1\}$.
Así, podemos elegir
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Este operador todavía satisface

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

porque los términos $ZZ$ actúan diagonalmente sobre $|\psi_0\rangle$, mientras que los términos desplazados $XX+YY$ dan cero.
El autovalor correspondiente está por lo tanto determinado únicamente por los términos $ZZ$,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

Con esta elección, el Hamiltoniano desplazado se convierte en:
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Como resultado, solo es necesario medir los bordes con ocupaciones diferentes en el estado de referencia.
Todos los términos $ZZ$ y todos los términos $XX+YY$ inactivos se reconstruyen a través de la contribución de solapamiento $\tau \mathcal{S}_{0d}$, o dan una contribución cero por construcción.

Esto da un observable más pequeño que desplazar solo la parte diagonal.
En particular, para un estado de referencia de la base computacional con una excitación localizada, solo los bordes adyacentes a la excitación permanecen en $H-T$.
Por lo tanto, el número de términos de Pauli en $X\otimes(H-T)$ y $Y\otimes(H-T)$ puede reducirse sustancialmente, mientras que el elemento de matriz reconstruido
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

permanece exactamente igual.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau
```

### Paso 2: Optimizar el problema para la ejecución en hardware cuántico {#step-2-optimize-problem-for-quantum-hardware-execution}

Ahora convertimos el circuito abstracto de prueba de intercambio extendida en una plantilla orientada al hardware.
Antes de eso, optimizamos aún más el circuito primero a nivel abstracto.

#### Comparar el ordenamiento de términos del Hamiltoniano {#compare-hamiltonian-term-ordering}

Primero, comparamos diferentes ordenamientos de los términos de Pauli en el Hamiltoniano de Heisenberg para la simulación del Hamiltoniano.
El Hamiltoniano en sí no cambia, pero el ordenamiento afecta cómo se genera el circuito de fórmula de producto y cuánto se puede paralelizar la estructura en el circuito.
Por ejemplo, el ordenamiento ingenuo enumera todos los términos $XX$ de vecinos más cercanos, luego todos los términos $YY$, luego todos los términos $ZZ$.
Esto coloca bordes adyacentes como $(0,1)$ y $(1,2)$ uno al lado del otro, por lo que no pueden ejecutarse en paralelo.
El ordenamiento par-luego-impar visita primero los bordes pares disjuntos, seguidos de los bordes impares, lo que expone capas paralelas de dos Qubits.
El ordenamiento agrupado por bordes par-impar va un paso más allá: para cada borde, mantiene juntos los términos locales $XX$, $YY$ y $ZZ$, mientras sigue visitando los bordes pares antes que los impares.
Esperamos que los ordenamientos par-luego-impar y agrupado por bordes par-impar reduzcan la profundidad del circuito al exponer capas paralelas de dos Qubits, y que el ordenamiento agrupado por bordes reduzca adicionalmente el error de Trotter porque la interacción local de dos Qubits en el mismo borde se maneja como un bloque compacto.

![Pauli evolutions with different term ordering](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

El ordenamiento del Hamiltoniano también afecta al error de Trotter.
Si colocamos términos que no conmutan uno al lado del otro, las transiciones de base ocurren con más frecuencia, lo que induce más error de Trotter.
Al agrupar términos que requieren la misma transformación de base de Pauli, se pueden evitar cambios de base redundantes.

Aquí, la comparación utiliza el tiempo de evolución más grande que aparece en las estimaciones de Krylov de la primera fila,
$t_{\max} = (r-1)\Delta t,$
utilizando la misma condición de transpilación.

Para medir el error de Trotter, utilizamos la **infidelidad de proceso** entre el circuito trotterizado y la evolución exacta del Hamiltoniano,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
where $d=2^n$ is the dimension of the Hilbert space.

Este diagnóstico utiliza matrices densas, por lo que es adecuado para este pequeño ejemplo de 12 Qubits, pero no está diseñado como una subrutina escalable.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

def build_numeric_evolution_circuit(
    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:
    """Build a numeric circuit for exp(-i H t) with a chosen synthesis rule."""
    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### Eliminar la puerta de evolución temporal controlada {#remove-the-controlled-time-evolution-gate}

En la prueba de intercambio extendida, controlar la evolución temporal con un único Qubit ancilla requiere que el ancilla controle muchas puertas a través del sistema.
Esto puede introducir una sobrecarga de enrutamiento sustancial y, en el peor de los casos, requerir efectivamente conectividad de todos-a-uno.
Para evitar esto, es posible una optimización adicional al reemplazar la puerta de evolución temporal controlada por una versión sin control, aprovechando la simetría del Hamiltoniano.
Observemos el siguiente circuito.

![circuit optimization](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

Aquí, $B_{\rm ref}$ prepara el estado de referencia, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

En lugar de preparar primero $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$ y luego aplicar $U(t)$ solo en la rama $|1\rangle$, el circuito prepara directamente las dos ramas como

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

where

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

El circuito primero aplica una puerta Hadamard al ancilla y prepara el estado de referencia solo en la rama $|1\rangle$:

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Luego se aplica el operador de evolución temporal no controlado a ambas ramas:

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Dado que el Hamiltoniano conserva el número de excitación, podemos ver que $|0^n\rangle$ es su autoestado, y por lo tanto
el operador de evolución solo acumula una fase bajo el Hamiltoniano:
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Therefore,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

A continuación, $B_{\rm ref}$ se aplica solo en la rama $|0\rangle$.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

En este punto, las dos ramas tienen una fase relativa adicional. Para eliminarla, aplicamos la puerta de fase del ancilla

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

Esto transforma el estado como

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Así, salvo una fase global irrelevante, finalmente preparamos

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

En el siguiente bloque de código, implementamos este circuito sin control.


### Paso 3: Ejecutar utilizando primitivas de Qiskit {#step-3-execute-using-qiskit-primitives}

El siguiente paso es enviar el mismo circuito parametrizado para varios valores de $d$. Para cada $d$, estimamos cuatro valores esperados: $X\otimes I$, $Y\otimes I$, $X\otimes (H-T)$ y $Y\otimes (H-T)$. Estos cuatro números se combinan luego en los elementos complejos de la primera fila $\mathcal{S}_{0d}$ y $\mathcal{H}_{0d}$.

### Paso 4: Post-procesar y devolver el resultado en el formato clásico deseado {#step-4-post-process-and-return-result-in-desired-classical-format}
Después de estimar las matrices proyectadas, regularizamos y resolvemos el GEVP
$$
\begin{equation*}
\mathcal{H}\mathbf{c} = E\mathcal{S}\mathbf{c}.
\end{equation*}
$$
El autovalor generalizado más pequeño da la estimación KQD de la energía del estado fundamental.


## Apéndice: La perspectiva de la función hamiltoniana (filtro espectral) {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

El flujo de trabajo principal presentó KQD de forma operacional: construir una base de Krylov a partir de estados evolucionados en tiempo real, estimar las matrices proyectadas $\mathcal{H}$ y $\mathcal{S}$, y resolver el GEVP.
Este apéndice revisita el *mismo* cálculo desde un ángulo complementario que explica **por qué** funciona KQD: la perspectiva de la *función hamiltoniana*, o *filtro espectral* [\[3\]](#references), [\[5\]](#references).
Reutiliza el modelo de 12 qubits, el paso de tiempo $\Delta t$, y la solución de Krylov ya obtenida anteriormente; no se requiere ninguna ejecución de circuito nueva.

### El estado de referencia como una distribución de energía {#the-reference-state-as-an-energy-distribution}

Sea la descomposición en autovalores del hamiltoniano

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

con autoestados de energía $|E_m\rangle$.
Cualquier estado de referencia se puede expandir en esta base propia,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

por lo que lleva un **peso espectral** $p_m=|a_m|^2$ en cada energía $E_m$.
La energía de referencia es la media de esta distribución, $\langle H\rangle_{0}=\sum_m p_m E_m$.

La descomposición en autovalores de un hamiltoniano general de $n$ qubits es exponencialmente costosa, por lo que esta imagen es solo una herramienta de diagnóstico, que *no* forma parte del algoritmo.
Sin embargo, aquí podemos calcularla de forma económica para el *mismo* problema de $n=12$: el hamiltoniano de Heisenberg conserva el número total de excitaciones, y la referencia $|000001000000\rangle$ lleva una única excitación, por lo que todo su contenido espectral reside en el subespacio de una sola excitación, cuya dimensión crece solo linealmente con $n$.
Por lo tanto, reutilizamos el bloque exacto de una sola excitación (ya usado anteriormente como referencia comparativa) y extraemos la distribución de referencia $\{(E_m, p_m)\}$ dentro de ese subespacio.

```python
# Exact single-excitation-subspace decomposition of the reference state.
# This reuses make_heisenberg_hamiltonian / _basis_state_transition_amplitude_sparse
# and the n=12 `hamiltonian` and `ref_bitstring` defined in the small-scale example.
single_excitation_states = [1 << k for k in range(num_qubits)]

h_single = np.array(
    [
        [
            _basis_state_transition_amplitude_sparse(hamiltonian, bra, ket)
            for ket in single_excitation_states
        ]
        for bra in single_excitation_states
    ]
)
h_single = 0.5 * (h_single + h_single.conj().T)

subspace_evals, subspace_evecs = la.eigh(h_single)
subspace_evals = np.real(subspace_evals)

# Reference-state coordinates inside the single-excitation subspace.
ref_position = single_excitation_states.index(int(ref_bitstring, 2))
ref_in_subspace = np.zeros(num_qubits, dtype=complex)
ref_in_subspace[ref_position] = 1.0

# Amplitudes and spectral weights of the reference in the energy eigenbasis.
ref_eigen_amplitudes = subspace_evecs.conj().T @ ref_in_subspace
ref_spectral_weights = np.abs(ref_eigen_amplitudes) ** 2

print(f"Single-excitation subspace dimension: {num_qubits}")
print(f"Subspace ground-state energy:         {subspace_evals[0]:.6f}")
print(
    f"Reference energy (sum p_m E_m):       {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(f"Reference weight on subspace ground:  {ref_spectral_weights[0]:.6f}")
```

### KQD aprende un filtro que reestructura esta distribución {#kqd-learns-a-filter-that-reshapes-this-distribution}

Una **función hamiltoniana** $f(H)$ se define mediante cálculo espectral,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

o en otras palabras, una suma ponderada de proyectores propios.
Aplicarla a la referencia reestructura cada amplitud espectral, $a_m \to a_m f(E_m)$:

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

Si $f$ estuviera marcadamente concentrada en la energía más baja ($f(E_0)=1$ y $f(E_m)\approx 0$ en cualquier otro caso), entonces $f(H)$ actuaría como un proyector del estado fundamental, y la salida normalizada sería (cercana a) el estado fundamental.
Por lo tanto, un buen **filtro espectral** de paso bajo en energía es exactamente lo que queremos.

KQD no prescribe $f$ de antemano. En su lugar, expande el filtro en la base de evolución temporal real,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

una función *trigonométrica* de la energía cuyos coeficientes $\{c_\ell\}$ son precisamente el autovector del GEVP resuelto anteriormente.
Minimizar el cociente de Rayleigh $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ equivale, por lo tanto, a *aprender* el filtro que mejor suprime el peso del estado excitado de la referencia.
Una dimensión de Krylov $r$ mayor le da al filtro más grados de libertad y un pico más agudo en la energía del estado fundamental.

La función auxiliar a continuación evalúa este filtro aprendido en un eje de energía; luego lo aplicamos a la distribución de referencia obtenida anteriormente.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### Aumentar la dimensión de Krylov: flexibilidad de la función aprendida {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

Recuerda que el filtro aprendido es un polinomio trigonométrico en la energía con $r$ coeficientes,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

La dimensión de Krylov $r$ es exactamente el número de coeficientes libres, por lo que controla la **flexibilidad** de la función.
Un $r$ pequeño solo puede producir un filtro amplio y de variación suave que deja fugar peso hacia estados excitados de baja energía; cuando $r$ aumenta, el filtro puede formar un pico más estrecho en la energía objetivo y suprimir de forma más agresiva el peso restante del estado excitado.
Esta es la contraparte del filtro espectral a la convergencia de energía observada en el ejemplo a pequeña escala: a medida que $r$ crece, la distribución filtrada colapsa hacia el estado fundamental del subespacio y la energía estimada disminuye hacia él.

Reutilizamos las matrices proyectadas ya estimadas anteriormente y simplemente resolvemos el GEVP en cada bloque principal $r\times r$, y luego evaluamos y graficamos el filtro correspondiente.

```python
    filtered_energy_r = float(np.sum(filtered_weights_r * subspace_evals))

    sweep_cases.append((r, coeffs_r, filtered_weights_r))
    print(
        f"{r:2d}    {retained_r:8d}    {filtered_weights_r[0]:14.4f}    {filtered_energy_r:15.6f}"
    )

print(f"\nSubspace ground-state energy (target): {subspace_evals[0]:.6f}")

# One panel per Krylov dimension: filtered spectrum (bars) + filter intensity (curve).
fig, axes = plt.subplots(
    len(sweep_cases),
    1,
    figsize=(8, 2.1 * len(sweep_cases)),
    sharex=True,
)
axes = np.atleast_1d(axes)

for idx, (ax, (r, coeffs_r, filtered_weights_r)) in enumerate(
    zip(axes, sweep_cases)
):
    visible = (ref_spectral_weights > 1e-4) | (filtered_weights_r > 1e-4)
    ax.bar(
        subspace_evals[visible],
        ref_spectral_weights[visible],
        width=0.18,
        alpha=0.35,
        color="C0",
        label="reference $p_m$" if idx == 0 else None,
    )
    ax.bar(
        subspace_evals[visible],
        filtered_weights_r[visible],
        width=0.14,
        alpha=0.9,
        color="C1",
        label="filtered weights" if idx == 0 else None,
    )

    filter_intensity_r = (
        np.abs(trigonometric_krylov_filter(coeffs_r, energy_grid, dt)) ** 2
    )
    filter_intensity_r /= filter_intensity_r.max()
    ax.plot(energy_grid, filter_intensity_r, color="k", linewidth=2)

    ax.axvline(subspace_evals[0], color="C3", linestyle="--", linewidth=1)
    ax.set_ylim(0, 1)
    ax.set_ylabel("weight")
    ax.legend(loc="upper right", title=f"$r={r}$")

axes[-1].set_xlabel("Energy eigenvalue $E_m$")
fig.suptitle(
    r"KQD-learned filter $|f_{\rm KQD}(E)|^2$ sharpening with Krylov dimension $r$",
    y=1.0,
)
fig.tight_layout()
plt.show()
```
