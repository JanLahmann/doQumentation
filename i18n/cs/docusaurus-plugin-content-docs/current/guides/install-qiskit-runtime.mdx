# Instalace klienta IBM Quantum Compute {#install-the-ibm-quantum-compute-client}

IBM Quantum Compute Service je cloudová služba pro provádění kvantových výpočtů na hardwaru IBM Quantum&reg;. Tento průvodce ti ukáže, jak nainstalovat `qiskit-ibm-runtime`, což je klientský balíček pro přístup ke službě IBM Quantum Compute Service.

Před instalací `qiskit-ibm-runtime` postupuj podle pokynů v těchto průvodcích:

1. [Instalace Qiskit](/guides/install-qiskit).

2. [Nastavení účtu IBM Cloud](cloud-setup).


Spusť tento příkaz pro instalaci klienta IBM Quantum Compute:

```shell
pip install qiskit-ibm-runtime
```

<Admonition type="note" title="Udržuj se aktuální s nejnovějšími verzemi">
Pravidelně kontroluj [poznámky k vydání `qiskit-ibm-runtime`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/release-notes), abys viděl nová vydání. Doporučujeme často aktualizovat své požadavky pro `qiskit-ibm-runtime` spuštěním `pip install -U qiskit-ibm-runtime`.
</Admonition>
