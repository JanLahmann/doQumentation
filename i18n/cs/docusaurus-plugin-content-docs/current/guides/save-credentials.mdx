# Ulož své přihlašovací údaje {#save-your-login-credentials}
Pokud pracuješ v důvěryhodném prostředí Pythonu (například na osobním laptopu nebo pracovní stanici), můžeš použít metodu `save_account()` k uložení svých přihlašovacích údajů lokálně a poté je použít k inicializaci služby.

<Admonition type="note" title="Poznámky">
      * Pokud používáš veřejný počítač nebo jiné nedůvěryhodné prostředí, postupuj místo toho podle pokynů v části [Inicializace služby v nedůvěryhodném prostředí](/guides/cloud-setup-untrusted).
      * Postupuj podle [těchto pokynů](/guides/cloud-setup-rest-api), pokud se chceš připojit pomocí REST API místo Qiskit.
      * V případě potřeby použij [tyto informace](/guides/quickstart-steps-org#firewall) ke konfiguraci firewallu a povolení přístupu k API koncovým bodům IBM Quantum.
</Admonition>

## Než začneš {#before-you-begin}

1. Ujisti se, že pracuješ v aktivním prostředí Pythonu s nainstalovanými [balíčky `qiskit` a `qiskit-ibm-runtime`](/guides/install-qiskit#local).

1. Aktivuj virtuální prostředí Pythonu a spusť Python ve svém virtuálním prostředí.

1. Přihlas se na [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Najdi své přístupové údaje {#find-your-access-credentials}

1. Ujisti se, že v přepínači účtů v záhlaví je vybrán správný účet a region.

1. Najdi svůj API klíč. Na [nástěnce](https://quantum.cloud.ibm.com/) vytvoř svůj API klíč a zkopíruj jej na bezpečné místo, abys jej mohl/a použít k ověření. Všimni si, že stejný API klíč můžeš použít pro připojení k libovolnému regionu.

1. Volitelné: Najdi instanci, kterou chceš použít, na stránce [Instance](https://quantum.cloud.ibm.com/instances). Najeď myší na její CRN, klikni na ikonu pro kopírování a ulož ji na bezpečné místo, abys ji mohl/a použít k identifikaci instance.


<span id="cloud-save"></span>

## Ulož své přístupové údaje {#save-your-access-credentials}

Ulož své přihlašovací údaje spuštěním příslušného kódu jednou pro každý účet, který chceš uložit. Po uložení přihlašovacích údajů je načti podle kroků v části [Inicializace IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Ulož přihlašovací údaje pro přístup ke konkrétní instanci: {#save-credentials-that-access-a-specific-instance}
Pokud máš více instancí a chceš Quantum Compute snadno říct, kterou instanci použít, ulož přihlašovací údaje, které obsahují CRN instance.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Ulož přihlašovací údaje pro automatický výběr instance: {#save-credentials-for-automatic-instance-selection}
Pokud nezadáš CRN instance a předáš tyto přihlašovací údaje Quantum Compute, bude za tebe vybrána vhodná instance na základě zadaných možností.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Příklad 2 {#example-2}
Tento příklad uloží přihlašovací údaje pro automatický výběr instance. Quantum Compute bude hledat pouze prémiové instance v regionu EU, které jsou dostupné pro daný účet. Tyto přihlašovací údaje se stanou novými výchozími.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Zobrazení uložených přihlašovacích údajů {#view-saved-credentials}

Chceš-li zobrazit všechny uložené přihlašovací údaje, spusť `service.saved_accounts()`. Všimni si, že pokud jsi uložil/a výchozí přihlašovací údaje bez pojmenování, budou pojmenovány `default-ibm-quantum-platform`. Pokud jsi výchozí přihlašovací údaje pojmenoval/a, uvidíš ve výstupu `"is_default_account": true`.

## Důležité poznámky {#considerations}

* Pokud ukládáš více účtů, použij parametr `name` k jejich rozlišení.

* Přihlašovací údaje se ukládají do `$HOME/.qiskit/qiskit-ibm.json`. Tento soubor ručně neupravuj.

* Pokud neuložíš své přihlašovací údaje, musíš je zadávat pokaždé, když zahájíš novou session (vytvoříš instanci IBM Quantum Compute Service).

* Pokud zadáš přihlašovací údaje ručně, uložený účet nebude použit.
