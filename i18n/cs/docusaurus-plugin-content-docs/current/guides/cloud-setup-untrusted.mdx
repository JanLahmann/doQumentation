# Inicializace služby v nedůvěryhodném prostředí {#initialize-the-service-in-an-untrusted-environment}

Postupuj podle těchto pokynů, pokud pracuješ s IBM Cloud nebo REST API IBM Quantum Compute Service v nedůvěryhodném prostředí, například na veřejném počítači.

**Vyhni se spouštění kódu na nedůvěryhodném počítači nebo v externím cloudovém prostředí Python, abys minimalizoval/a bezpečnostní rizika.** Pokud musíš nedůvěryhodné prostředí použít (například na sdíleném nebo veřejném počítači), po každém použití změň svůj API klíč – smaž ho na [stránce API klíčů](https://cloud.ibm.com/iam/apikeys) a vytvoř nový.

    <Admonition type="caution">
      **Chraň svůj API klíč!** Nikdy ho nezahrnuj do zdrojového kódu, skriptu Python ani souboru notebooku. Při sdílení kódu s ostatními se ujisti, že tvůj API klíč není přímo vložen do skriptu Python. Místo toho sdílej skript bez tokenu a přilož pokyny, jak ho bezpečně nastavit.

      Pokud svůj klíč omylem sdílíš s někým jiným nebo ho zahrnuješ do verzovacího systému jako Git, okamžitě ho zneplatni podle tématu [Odstranění API klíče](https://cloud.ibm.com/docs/account?topic=account-userapikey&interface=ui#delete_user_key) v dokumentaci IBM Cloud.
    </Admonition>

<span id="access-credentials"></span>

## Najdi své přístupové přihlašovací údaje {#find-your-access-credentials}

1. Najdi svůj API klíč (označovaný také jako _API token_). Z [řídicího panelu](https://quantum.cloud.ibm.com/) vytvoř svůj API klíč, poté ho zkopíruj na bezpečné místo, abys ho mohl/a použít k ověření. Token nebude znovu zobrazen. Jeden API klíč lze použít pro připojení do libovolné oblasti.

2. Volitelně: Najdi instanci, kterou chceš použít, na stránce [Instance](https://quantum.cloud.ibm.com/instances). Přejeď myší přes její CRN, klikni na ikonu pro zkopírování a ulož ho na bezpečné místo, abys ho mohl/a použít k identifikaci instance.


## Ověření v IBM Cloud v nedůvěryhodném prostředí {#authenticate-to-ibm-cloud-in-an-untrusted-environment}

Pro inicializaci služby v této situaci použij kód podobný následujícímu:

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    # The credentials you enter will override any saved
    # account credentials that might be available locally.
    service = QiskitRuntimeService(
      # Use the 44-character API_KEY you created and saved from
      # the IBM Quantum Platform dashboard, and then delete
      # the key on the API keys page after entering this code:
      token="<your-API-key>", 
      
      # Optionally specify an instance to use
      instance="<IBM Cloud CRN or instance name>"
      )
    ```

<span id="rest-untrusted"></span>

## Ověření v REST API v nedůvěryhodném prostředí {#authenticate-to-the-rest-api-in-an-untrusted-environment}

Postupuj podle těchto kroků a použij svůj API klíč přímo k ověření v REST API IBM Quantum Compute Service, kde `<your_API_KEY>` je 44znakový API_KEY, který jsi vytvořil/a a uložil/a z domovského řídicího panelu IBM Quantum Platform.

1. Pomocí svého API klíče vygeneruj [bearer token](https://docs.quantum.ibm.com/api/qiskit-runtime-rest#authentication). _Bearer token_ je dočasné pověření, které vyprší po maximálně jedné hodině. Po vypršení platnosti získaného tokenu musíš vygenerovat nový, abys mohl/a nadále volat IBM Cloud nebo jiná servisní API. :


    ```bash
    curl -X POST 'https://iam.cloud.ibm.com/identity/token' \
    -H 'Content-Type: application/x-www-form-urlencoded' \
    -d 'grant_type=urn:ibm:params:oauth:grant-type:apikey&apikey=your_API_KEY'
    ```
    Copy and save the returned bearer token:  `"access_token": "<NEW_BEARER_TOKEN>"`
  1. Authenticate requests to the IBM Quantum Compute Service REST API by including the CRN and bearer token in the request's headers.

      ```bash
      curl -X 'GET' \
        'https://quantum.cloud.ibm.com/api/v1/usage' \
        '-H accept: application/json' \
        '-H authorization: Bearer <BEARER_TOKEN>' \
        '-H Service-CRN: <INSTANCE_CRN>'
      ```

1. Po každém použití změň svůj API klíč tak, že [odstraníš svůj existující API klíč](https://cloud.ibm.com/docs/account?topic=account-userapikey&interface=ui#delete_user_key) a vygeneruješ nový API klíč na domovské stránce [IBM Quantum Platform](https://quantum.cloud.ibm.com/).
