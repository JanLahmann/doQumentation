# IBM Quantum プリミティブの概要 {#introduction-to-ibm-quantum-primitives}

プリミティブは、量子コンピューターの最も一般的なタスク、すなわち量子状態のサンプリングと期待値の計算を簡略化するために作成されました。最初の IBM Quantum プリミティブ（[`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) および [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)）は、Qiskit [プリミティブ基底クラス](/guides/primitives)の実装です。これらはより洗練された実装（例えばエラー緩和を含む）をクラウドベースのサービスとして提供し、IBM Quantum&reg; ハードウェアへのアクセスに使用されます。

最新のIBM Quantumプリミティブである[Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor)（ベータ版）は、パフォーマンスを犠牲にすることなく、より高い可視性と制御を提供する低レベルのインターフェースです。
`Executor`は、追加のツイリンググループやフラクショナルゲートを含む回路のツイリングなど、**Samplerでは提供されない追加機能**も公開しています。`Executor`に移行すべきかどうかの詳細については、[SamplerからExecutorへの移行](/guides/migrate-from-sampler-to-executor)を参照してください。
