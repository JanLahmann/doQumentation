## 1. Qiskitをインストールする {#1-install-qiskit}

お好みのパッケージマネージャー（`pip`など）で以下をインストールしてください。

- [`qiskit`](/guides/install-qiskit)

- [`matplotlib`](https://matplotlib.org/stable/users/explain/quick_start.html)

- [`qiskit[visualization]`](https://docs.quantum.ibm.com/api/qiskit/visualization)


## 2. 回路を構築する {#2-build-your-circuit}

Pythonの実行環境を開き、次のコードを実行してBell状態（量子もつれ状態にある2つの量子ビット）を構築します。

```python
from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)
qc.measure_all()

sampler = StatevectorSampler()
result = sampler.run([qc], shots=1024).result()
print(result[0].data.meas.get_counts())
```

```text
{'00': 486, '11': 538}
```

期待される出力は、'00' と '11' がほぼ均等に分かれたものです。

## 3. 結果を可視化する {#3-visualize-your-results}

結果のヒストグラムを取得するには、プログラムに次のコードを追加します。

```python
# Uncomment lines 2 and 8 if you are not using Python in a Jupyter notebook
# import matplotlib.pyplot as plt
from qiskit.visualization import plot_histogram

counts = result[0].data.meas.get_counts()
plot_histogram(counts)

# plt.show()
```

この結果は量子もつれの明確な証拠です。

## 4. 変化を確認する {#4-see-what-happens}

コードを変更して結果にどのような影響があるか試してみましょう。例えば：

- `QuantumCircuit(3)` に変更して3番目の量子ビットを追加し、`qc.cx(1,2)` で2番目のCXゲートを追加します。測定結果は000と111に変わり、これら3つの量子ビットすべてが量子もつれ状態にあることを意味します。


- 回路の末尾に `qc.x(1)` を追加することで、結果がシフトする様子を確認できます。
