Use [QPY serialization](https://docs.quantum.ibm.com/api/qiskit/qpy) to save your circuit to file. QPY files store the full Qiskit circuit object and will be compatible with newer versions of Qiskit (although not necessarily with older versions of Qiskit).

実演として、以下のセルはシンプルな量子回路を作成します。

```python
# Added by doQumentation — required packages for this notebook
!pip install -q qiskit
```

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)
qc.measure_all()
```

このファイルをディスクに保存するには、`qpy.dump`関数を使用します。回路のリストを保存することもできます。

```python
from qiskit import qpy

with open("test.qpy", "wb") as file:
    qpy.dump(qc, file)
```

この回路は現在、`test.qpy`ファイルに保存されています。Pythonカーネルを再起動した場合、`qpy.load`関数を使って回路を再度ロードできます。これは、1つの回路しかシリアライズしていなくても、常に回路のリストを返すことに注意してください。

```python
with open("test.qpy", "rb") as handle:
    qc = qpy.load(handle)

qc[0].draw("mpl")
```
