# ジョブの実行時間を最小化する {#minimize-job-run-time}

ジョブの処理と実行に費やす時間を制限する方法はいくつかあります：

- **必要なショット数だけを実行する**：ジョブのQPU消費量（およびそのコスト）はショット数に比例してスケールします。そのため、必要なショット数だけを実行することでコストを管理できます。Estimator ジョブでは、精度を低くすると一般的にショット数が増え、実行時間も長くなります。


- 実行時間に制限を設ける：各ジョブ、バッチ、またはセッションの実行時間を制限できます。詳細については、[最大実行時間](/guides/max-execution-time)ガイドを参照してください。


- **エラー抑制とエラー軽減に必要な設定のみを使用する**：値を高く設定するとジョブの実行時間が長くなる場合があります。詳細については、[オプションの概要](/guides/runtime-options-overview)、[エラー抑制の設定](/guides/error-mitigation-and-suppression-techniques)、および[エラー軽減の設定](error-mitigation-and-suppression-techniques)を参照してください。


- PEA や PEC など、ノイズモデルを必要とするエラー緩和方法を使用しながら、同じ（おそらくパラメータ化された）Circuit を含む複数のジョブを実行している場合は、`NoiseLearner` の使用を検討してください。このヘルパープログラムを使用すると、Circuit のノイズモデルを一度学習し、以降の Estimator クエリでそのモデルを再利用できます。ノイズモデルは一定時間が経過すると古くなるため、これはジョブ間に長い遅延がない場合（たとえばセッション内）にのみ実用的であることに注意してください。詳細については、[ノイズ学習ヘルパー
](/guides/noise-learning) を参照してください。
