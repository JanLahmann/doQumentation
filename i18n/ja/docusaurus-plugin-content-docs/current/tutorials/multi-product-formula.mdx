## 背景 {#background}

### 多積公式とは？ {#what-are-multi-product-formulas}

量子コンピュータ上で量子系をシミュレートする際、中心となる課題は、ハミルトニアン $H$ に対する時間発展演算子 $e^{-iHt}$ を近似することです。標準的なアプローチでは、トロッター・鈴木分解としても知られる*積公式*（PF）を使用します。これらは $H = \sum_{a=1}^d F_a$ を、個々のユニタリ $e^{-iF_a t}$ が効率的に実装できる項に分解し、それらの単純なユニタリの順序付き積として完全な発展を近似します。

1次積公式（Lie-Trotter）は以下のようになります：

$$
S_1(t) := \prod_{a=1}^d e^{-i F_a t},
$$

これは2次の誤差を伴います：$S_1(t) = e^{-iHt} + \mathcal{O}(t^2)$。より高次の対称公式 $S_{2\chi}(t)$（$\chi$ は対称積公式の次数を表す。参考文献 [\[1\]](#references) を参照）は、$e^{-iHt} + \mathcal{O}(t^{2\chi+1})$ としてより速く収束しますが、ステップあたりの回路がより深くなるという代償があります。

*固定された*次数 $\chi$ で誤差を減らすために、通常は全発展時間 $t$ を $k$ 個のより小さなトロッター・ステップに分割します。各ステップは積公式によって $e^{-iHt/k}$ を近似し、それらのステップを連結します：

$$
e^{-iHt} \approx \left[S_{2\chi}(t/k)\right]^k.
$$

$2\chi$次の対称公式の場合、残留トロッター誤差は $\mathcal{O}\!\left(t^{2\chi+1} / k^{2\chi}\right)$ としてスケールします。したがって、$k$ を増やすとトロッター誤差は急速に抑制されます &mdash; しかし同時に回路の深さも線形に増加し、ノイズのあるハードウェアでは蓄積されるゲートノイズも増えることを意味します。**トロッター誤差（大きな $k$ を好む）**と**ハードウェアノイズ（小さな $k$ を好む）**の間のこの緊張関係こそ、多積公式がまさに解決しようとしているものです。MPF は、固定された次数 $\chi$ における*異なる $k$ の選択*からの結果を組み合わせるものであり、基礎となる積公式の次数を変えるものではないことに注意してください。

**多積公式（MPF）** [\[1\]](#references) は、それぞれ異なるトロッター・ステップ数 $k_1, k_2, \ldots, k_r$（$r$ 個のステップ数の集合）を使用する、複数のより浅いトロッター回路から得られた期待値の*重み付き線形結合*を構築します：

$$
\langle A \rangle_{\text{MPF}}(t) = \sum_{j=1}^r x_j \, \langle A \rangle_{k_j}(t),
$$

ここで、$\langle A \rangle_{k_j}(t)$ は、$k_j$ ステップのトロッター回路から推定された時刻 $t$ における観測量 $A$ の期待値であり、係数 $\{x_j\}_{j=1}^r$ は、組み合わせにおける主要なトロッター誤差項が打ち消し合うように選ばれます。この表現には [ステップ4](#small-scale-step-4) で再び触れ、トロッター結果を組み合わせるために明示的に評価します。実用上の重要な点は、MPF の中で最も深い回路が必要とするのは $k_{\max}$ ステップのみであり、これは同じ有効トロッター誤差に直接到達するために必要となる単一の $k$ よりもはるかに小さいということです。より浅い回路であることにより、MPF アプローチはノイズのあるハードウェアにより適したものになります。

### 係数はどのように決定されるか？ {#how-are-the-coefficients-determined}

MPF 係数には2つのファミリーがあります：

**静的係数**は、ハミルトニアン、初期状態、発展時間に依存しません。これらは、主要なトロッター誤差項の打ち消しを強制する線形系 $Ax = b$ を解くことで求められます。$2\chi$次の対称積公式で使用されるトロッター・ステップの集合 $\{k_j\}_{j=1}^r$ について、トロッター誤差を $k_j$ の逆べきで展開すると、次の形の制約方程式が得られます：

$$
\sum_{j=1}^r x_j = 1, \quad \sum_{j=1}^r \frac{x_j}{k_j^{\eta_n}} = 0 \quad (n = 0, \ldots, r-2),
$$

ここで、整数指数 $\{\eta_n\}$ は、選択した積公式に対する連続するトロッター誤差項の次数です。*対称的な* $2\chi$次の PF の場合、$\left[S_{2\chi}(t/k)\right]^k$ における主要な誤差は $1/k^{2\chi}$ としてスケールし、以降の補正は $1/k^{2\chi+2}, 1/k^{2\chi+4}, \ldots$ となります &mdash; したがって指数は $\eta_n = 2\chi + 2n$ です。非対称な PF の場合、奇数べきと偶数べきの両方が寄与し、$\eta_n = 2\chi + n$ となります。完全な導出については参考文献 [\[1\]](#references) を参照してください。上記の系の最初の方程式は不偏性を保証し（MPF は $k_j \to \infty$ の極限で厳密な期待値を再現します）、残りの $r-1$ 個の方程式は最初の $r-1$ 個のトロッター誤差項を順次打ち消します。結果として得られる $L_1$ ノルム $\|x\|_1$ が大きすぎる場合（サンプリングノイズを増幅させる）、代わりに $\|x\|_1$ に上限を設けながら $\|Ax - b\|$ を最小化する近似最適化を解くことができます。

**動的係数** [\[2\]](#references)、[\[3\]](#references) は、さらにハミルトニアン、初期状態、発展時間 $t$ に依存します。これらは、真の時間発展状態と MPF 近似との間のフロベニウス・ノルム距離を最小化します：

$$
\|\rho(t) - \mu^D(t)\|_F^2 = 1 + \sum_{i,j} M_{ij}(t)\, x_i(t)\, x_j(t) - 2\sum_i L_i(t)\, x_i(t),
$$

ここで、$M_{ij}(t) = \mathrm{Tr}[\rho_{k_i}(t)\,\rho_{k_j}(t)]$ は、異なるステップ数 $k_i, k_j$ に対するトロッター発展状態間の重なりのグラム行列であり、$L_i(t) = \mathrm{Tr}[\rho(t)\,\rho_{k_i}(t)]$ は（近似的な）厳密状態との重なりを測定します。このチュートリアルでは、これらの量はテンソルネットワーク法、具体的には `qiskit_addon_mpf` における TeNPy ベースのバックエンドを使用して効率的に計算されます。

### MPF をいつ使用するか {#when-to-use-mpfs}

MPFが特に有益なのは、次のような場合です。

- **回路の深さがボトルネックとなる場合。** ハードウェアノイズによって実行可能な深さが制限されている場合、MPFを使用することで、より浅い回路からより高い実効トロッター精度を達成できます。

- **フル状態準備ではなく、正確な期待値が必要な場合。** MPFは期待値のレベルで動作します &mdash; 量子状態ではなく、古典的な数値を組み合わせます。そのため、Estimatorプリミティブを使用したオブザーバブル推定に理想的です。

- **中程度の数のトロッターステップ数を組み合わせる場合。** 通常、$r = 3$&ndash;$5$個の異なるステップ数$k_j$を組み合わせれば、$\|x\|_1$を管理可能な範囲に保ちながら、いくつかの主要なトロッター誤差項を打ち消すのに十分です。


### MPFが役立たない場合 {#when-mpfs-might-not-help}

- **非常に短い時間発展の場合。** $t$が十分に小さく、単一の低次トロッター公式ですでに十分な精度がある場合、複数の回路を実行するオーバーヘッドは不要です。

- **状態準備タスクの場合。** MPFは補正された*期待値*を生成しますが、補正された量子状態は生成しません。実際の時間発展した状態が必要な場合（たとえば、別の量子サブルーチンへの入力として）、MPFは適用できません。

- **収束領域に違反するトロッターステップ数の場合。** 静的係数の導出では、各$\left[S_{2\chi}(t/k_j)\right]^{k_j}$を$t/k_j$の級数として展開します。この展開は$t/k_{\min} \lesssim 1$の場合にのみうまく収束します。$k_{\min}$が与えられた$t$に対して小さすぎる場合、最も浅い回路は摂動領域から大きく外れ、MPFが打ち消せない高次の誤差項が大きくなり、打ち消しには大きな係数が必要になる場合があります。$L_1$ノルム$\|x\|_1$は実用的な診断指標です。$\|x\|_1 \gg 1$の場合、サンプリングオーバーヘッド$\propto \|x\|_1^2$がトロッター誤差の削減効果を上回る可能性があります。詳細は[トロッターステップの選択に関するガイド](https://qiskit.github.io/qiskit-addon-mpf/how_tos/choose_trotter_steps.html)を参照してください。

#### トロッター回路の構築 {#build-trotter-circuits}

各時間点と各トロッターステップ数について、近似的なトロッター時間発展を実装する回路を作成します。セットアップセクションで定義した`CollectAndCollapse`パスは、XX回転とYY回転を単一のXX+YYゲートに収集し、後でより効率的なテンソルネットワークシミュレーションを行う準備をします。

        mpf_trotter_circs

    mpf_circuits = [
        initial_state_circ.compose(circuit) for circuit in mpf_trotter_circs
    ]
    all_circs.append(mpf_circuits)

### ステップ 3: Qiskitプリミティブを使用した実行 {#step-3-execute-using-qiskit-primitives}

小規模な例では、ISAに変換されたトロッター回路を、Aerを利用した`EstimatorV2`プリミティブで実行します。これにより、各$(k_j, t)$の組み合わせに対する*ノイズのない*参照値が得られます &mdash; これらは、ステップ4でMPFが組み合わせる$\langle A \rangle_{k_j}(t)$の値です。時間発展の時間をスイープすることで、後で個々のプロダクト公式とMPFそれぞれの完全な時系列曲線をプロットできるようにします。

```python
estimator = Estimator(mode=aer_sim)

mpf_expvals_all_times, mpf_stds_all_times = [], []
for isa_circuits in isa_circs_all_times:
    result = estimator.run(
        [(circuit, observable) for circuit in isa_circuits], precision=0.005
    ).result()
    mpf_expvals_all_times.append([res.data.evs for res in result])
    mpf_stds_all_times.append([res.data.stds for res in result])
```

### ステップ 4: 後処理と所望の古典形式での結果の返却 {#step-4-post-process-and-return-result-in-desired-classical-format}

ステップ4では、実際にMPFを構築します。係数$x_j$はここで*計算*されます（動的変種では、この計算は負荷が高くなる場合があります）が、概念的にはこれらは、ステップ3の量子測定結果を単一の補正済み期待値に組み合わせるための古典的なレシピです &mdash; そのため、係数と組み合わせのワークフロー全体を後処理として扱います。

MPFが真のダイナミクスをどれだけ正確に追跡できているかを評価するために、まずハミルトニアンを直接指数化して、厳密な時間発展した期待値を計算します。これは$L = 10$であるためにのみ扱いやすく、以下の大規模なハードウェアの例では、代わりにテンソルネットワークによる推定に頼る必要があります。

```python
exact_expvals = []
for t in exact_evolution_times:
    exp_H = expm(-1j * t * hamiltonian.to_matrix())
    initial_state = Statevector(initial_state_circ).data
    time_evolved_state = exp_H @ initial_state

    exact_obs = (
        time_evolved_state.conj()
        @ observable.to_matrix()
        @ time_evolved_state
    ).real
    exact_expvals.append(exact_obs)
```

#### 静的MPF係数 {#static-mpf-coefficients}

静的MPFは、時間発展の時間、ハミルトニアン、初期状態に依存しない係数$x_j$を使用します。背景セクションで説明した線形システム$Ax = b$を設定し、係数を解きます。行列$A$は、トロッターステップ数$k_j$、プロダクト公式の次数$\chi$、および公式が対称かどうか（指数$\eta_n$を決定します）によって決まります。

この小規模な例では、$k_j = [1, 2, 4]$と非対称な次数$2\chi=2$の鈴木・トロッター公式を使用します（つまり$\chi=1$、$\eta_n = 2 + n$となり、$\eta_0 = 2,\, \eta_1 = 3$）。システムは次のようになります。

$$
A =
\begin{bmatrix}
1 & 1 & 1\\
1 & \frac{1}{2^2} & \frac{1}{4^2}  \\
1 & \frac{1}{2^3} & \frac{1}{4^3}  \\
\end{bmatrix}, \quad
b =
\begin{bmatrix}
1 \\
0 \\
0
\end{bmatrix}.
$$

1行目は不偏性を保証します（$\sum_j x_j = 1$）。2行目と3行目は、それぞれ主要な$1/k^2$項と次の$1/k^3$トロッター誤差項を打ち消します。

##### LSEの設定 {#set-up-the-lse}

上記の行列$A$と右辺のベクトル$b$を組み立てるために、`qiskit_addon_mpf.static`の`setup_static_lse`を使用します。行列$A$は$k_j$だけでなく、選択したプロダクト公式にも依存します &mdash; 特にその*次数*$\chi$と*対称*かどうかです。`symmetric`フラグは、指数パターン$\eta_n$を制御します（対称な公式は偶数次のトロッター誤差項のみを生成します。参考文献[\[1\]](#references)を参照）。参考文献[\[2\]](#references)に示されているように、基礎となるPFが対称であっても、`symmetric=True`に設定することは厳密には必要ではないことに注意してください &mdash; 非対称のLSEは依然として有効です（余分な不要な制約を課すことになります）。

この例では、ステップ1ですでに`order = 2`と`symmetric = False`を設定しています。

```python
lse = setup_static_lse(mpf_trotter_steps, order=order, symmetric=symmetric)
```

#### 動的MPF係数 {#dynamic-mpf-coefficients}

静的MPFは、ハミルトニアンや状態に依存しない方法でトロッター誤差項を打ち消すため、特定のハミルトニアンと初期状態に対して必ずしも最小の近似誤差を生成するわけではありません。動的MPF（参考文献[\[2\]](#references)、[\[3\]](#references)）は代わりに、各時刻$t$においてフロベニウスノルム距離$\|\rho(t) - \mu^D(t)\|_F^2$を最小化する時間依存係数$x_i(t)$を求めます。背景セクションで示したように、これにはトロッター発展した状態間のオーバーラップ行列$M_{ij}(t)$と、厳密な状態とのオーバーラップ$L_i(t)$が必要です &mdash; どちらも`qiskit_addon_mpf`内のテンソルネットワーク（TeNPy）バックエンドを使用して推定します。

動的LSEを設定するには、3つの要素が必要です。

1. アドオンが各$k_j$に対して実行し、$\rho_{k_j}(t)$をMPS/MPOとして生成する**近似発展因子**。これは、2次トロッター回路の層構造から構築します（`slice_by_depth`ごとに1層）。TeNPyの切り捨てパラメーターを持つ`LayerwiseEvolver`としてラップします。

2. 高精度な参照$\rho(t)$を生成する**厳密発展因子**。厳密な発展の代理として、小さな時間ステップの4次鈴木・トロッター回路（`dt=0.1`、`order=4`）を使用します。

3. TeNPyシミュレーションのシードとなる**恒等因子**と**初期状態MPS**。


以下のセルは、近似発展因子を構築します。

```python
# Create approximate time-evolution circuits
single_2nd_order_circ = generate_time_evolution_circuit(
    hamiltonian, time=1.0, synthesis=SuzukiTrotter(reps=1, order=order)
)
single_2nd_order_circ = pm.run(single_2nd_order_circ)  # collect XX and YY

# Find layers in the circuit
layers = slice_by_depth(single_2nd_order_circ, max_slice_depth=1)

# Create tensor network models
models = [
    LayerModel.from_quantum_circuit(layer, conserve="Sz") for layer in layers
]

# Create the time-evolution object
approx_factory = partial(
    LayerwiseEvolver,
    layers=models,
    options={
        "preserve_norm": False,
        "trunc_params": {
            "chi_max": 64,
            "svd_min": 1e-8,
            "trunc_cut": None,
        },
        "max_delta_t": 2,
    },
)
```

最後に、初期MPO状態を生成する`identity_factory`を定義し、層状トロッターモデルで使用される格子に一致するMPSとしてネール初期状態を準備します。

因子が揃ったら、各時間発展の時刻において動的係数を計算します。各$t$について、`setup_dynamic_lse`がTeNPyを介して関連するオーバーラップ行列を構築し、`setup_frobenius_problem`がフロベニウスノルムコストを最小化する`cvxpy.Problem`を返します。ソルバーはその時刻に合わせた係数$x_j(t)$を返し、それを`mpf_dynamic_coeffs_list`に収集します。特定の$t$でソルバーが失敗した場合は、ゼロ係数にフォールバックしてループを続行します。

#### トロッター期待値とMPF係数の組み合わせ {#combine-trotter-expectation-values-with-the-mpf-coefficients}

次に、各係数の組み合わせ（静的厳密、静的近似、動的）について$\langle A \rangle_{\text{MPF}}(t) = \sum_j x_j \, \langle A \rangle_{k_j}(t)$を評価し、回路ごとの標準誤差を伝播させ、得られた時系列を厳密対角化の曲線と比較してプロットします。

上記のプロットは、トロッター誤差とサンプリング誤差の相互作用を示しています。

- **トロッター誤差。** 個々のプロダクト公式（灰色のマーカー）は、時間が経つにつれて厳密な曲線からますます逸脱していきます。$k=1$回路は最も浅く、逸脱が最も大きいですが、それはすでに$t/k \gtrsim 1$の領域にあり、主要な$1/k^{2}$誤差項が大きくなっているためです。MPFの組み合わせ（色付きマーカー）は、これらの主要なトロッター誤差項のいくつかを打ち消すため、単一の$k_j$回路よりもはるかに厳密な曲線に近づきます。残るギャップは、MPFが打ち消さ*ない*高次のトロッター項を反映しています。次数$2$、$r=3$の静的MPFは最初の2つの誤差次数しか除去せず、大きな$t/k_{\min}$では、打ち消されなかったテール項がやがて支配的になります &mdash; そのため、MPFは非常に浅い回路が任意の時刻で正確であり続けることを保証するものではありません。


- **サンプリング誤差。** MPF曲線でエラーバーが広くなるのは、線形結合の直接的な帰結です。独立した回路ごとの標準誤差$\sigma_{k_j}$を伝播させると、合計分散は$\sigma_{\text{MPF}}^2 = \sum_j x_j^2 \, \sigma_{k_j}^2$になります。したがって、$\|x\|_2$（実際には制御対象である$\|x\|_1$）が大きいほど、目標とする不確かさに到達するために必要なショット数が多くなります。これが背景セクションで説明した近似ソルバーの選択肢の背後にあるトレードオフです。私たちは、このオーバーヘッドを管理可能な範囲に保つために$\|x\|_1$を制限します。重要なのは、トロッター誤差とは異なり、サンプリング誤差は$1/\sqrt{N_{\text{shots}}}$で縮小するため、ショット数を増やせば常に減らせるという点です。


以下の大規模なハードウェアの例では、ハードウェアノイズが各$\langle A \rangle_{k_j}$に追加の誤差源として加わり、同様にMPF係数によって増幅されます。そのセクションでは、エラー緩和がMPFとどのように相互作用するかを見ていきます。

## 大規模なハードウェアの例 {#large-scale-hardware-example}

このセクションでは、厳密にシミュレーションできる範囲を超えて問題を拡大します。参考文献[\[3\]](#references)に示された結果のいくつかを、時刻$t = 3$の50量子ビットXXZ鎖を用いて再現します。小規模な例と同じ4ステップのワークフローに従いますが、今度はエラー緩和を用いて実際の量子ハードウェアを対象とします。テンプレートと同様に、各ステップはコード内にインラインで示されており、中間出力を確認する価値がある場合、1つのステップが複数のセルにまたがることがあります。
このマッピングは、小規模な例を反映しています。ハミルトニアンを定義し、トロッターパラメーターを選択し、MPF係数（静的および動的）を計算し、回路を構築します。主な違いは以下のとおりです。

- $\mathcal{U}(0.5, 1.5)$からランダムに抽出された結合を持つ、50サイト上の**XXZハミルトニアン**（参考文献[\[3\]](#references)）。

- $k_j = [3, 4, 6]$を持つ**対称な**2次トロッター公式（つまり$\chi=1$、`symmetric=True`）。

- 単一の固定された時間発展の時刻$t = 3$。$k_{\min}=3$では$t/k_{\min}=1$となり、浅い構成要素がトロッター収束領域内に留まり、MPFが依存する主要誤差モデルが有効であることが保証されます。

- ベースラインとして使用される、追加の**単一回路比較実行（$k = 10$トロッターステップ）**。$k = 10$を選んだのは、ハードウェア上での2量子ビット深度が、最も深いMPF構成要素（$k_{\max}=6$）に複数のMPF回路を実行するオーバーヘッドを加えたものよりも深いためです。これは、MPFの組み合わせが単一回路のベースラインを上回ることが期待される領域である、ノイズが制限要因となるほど十分に深いものです。これは、MPFの実効トロッター誤差を目標とする回路（そのためにはさらに多くのステップが必要になります）ではなく、MPFの組み合わせと比較する「単一の深い回路」の比較です。


ここではまだステップ1（マッピングと回路構築）の段階ですが、このセルで静的係数とともに動的係数も事前に計算していることに注意してください。動的係数は$H$と$t$に依存しますが、量子測定には依存しないため、ステップ4より前であればいつでも計算できます。MPF固有のセットアップを一箇所にまとめるために、ここで計算を行います。

```python
# -------------------------Step 1-------------------------
L = 50
coupling_map = CouplingMap.from_line(L, bidirectional=False)

# XXZ Hamiltonian with random couplings (Ref. [3])
np.random.seed(0)
even_edges = list(coupling_map.get_edges())[::2]
odd_edges = list(coupling_map.get_edges())[1::2]

Js = np.random.uniform(0.5, 1.5, size=L)
hamiltonian = SparsePauliOp(Pauli("I" * L))
for i, edge in enumerate(even_edges + odd_edges):
    hamiltonian += SparsePauliOp.from_sparse_list(
        [
            ("XX", (edge), 2 * Js[i]),
            ("YY", (edge), 2 * Js[i]),
            ("ZZ", (edge), 4 * Js[i]),
        ],
        num_qubits=L,
    )

observable = SparsePauliOp.from_sparse_list(
    [("ZZ", (L // 2 - 1, L // 2), 1.0)], num_qubits=L
)

total_time = 3
mpf_trotter_steps = [3, 4, 6]
order = 2
symmetric = True

# Static coefficients
lse = setup_static_lse(mpf_trotter_steps, order=order, symmetric=symmetric)
mpf_coeffs = lse.solve()
print(f"Static coefficients: {mpf_coeffs}")
print(f"L1 norm: {np.linalg.norm(mpf_coeffs, ord=1)}")

model_approx, coeffs_approx = setup_sum_of_squares_problem(
    lse, max_l1_norm=2.0
)
model_approx.solve()
print(f"Approximate coefficients: {coeffs_approx.value}")
print(f"L1 norm (approx): {np.linalg.norm(coeffs_approx.value, ord=1)}")

# -------------------------Dynamic coefficients-------------------------
single_2nd_order_circ = generate_time_evolution_circuit(
    hamiltonian, time=1.0, synthesis=SuzukiTrotter(reps=1, order=order)
)
single_2nd_order_circ = pm.run(single_2nd_order_circ)

layers = slice_by_depth(single_2nd_order_circ, max_slice_depth=1)
models = [
    LayerModel.from_quantum_circuit(layer, conserve="Sz") for layer in layers
]

approx_factory = partial(
    LayerwiseEvolver,
    layers=models,
    options={
        "preserve_norm": False,
        "trunc_params": {"chi_max": 64, "svd_min": 1e-8, "trunc_cut": None},
        "max_delta_t": 4,
    },
)

single_4th_order_circ = generate_time_evolution_circuit(
    hamiltonian, time=1.0, synthesis=SuzukiTrotter(reps=1, order=4)
)
single_4th_order_circ = pm.run(single_4th_order_circ)
exact_model_layers = [
    LayerModel.from_quantum_circuit(layer, conserve="Sz")
    for layer in slice_by_depth(single_4th_order_circ, max_slice_depth=1)
]

exact_factory = partial(
    LayerwiseEvolver,
    layers=exact_model_layers,
    dt=0.1,
    options={
        "preserve_norm": False,
        "trunc_params": {"chi_max": 64, "svd_min": 1e-8, "trunc_cut": None},
        "max_delta_t": 3,
    },
)

def identity_factory():
    return MPOState.initialize_from_lattice(models[0].lat, conserve=True)

mps_initial_state = MPS_neel_state(models[0].lat)

print(f"Computing dynamic coefficients for time={total_time}")
lse_dyn = setup_dynamic_lse(
    mpf_trotter_steps,
    total_time,
    identity_factory,
    exact_factory,
    approx_factory,
    mps_initial_state,
)
problem, coeffs_dyn = setup_frobenius_problem(lse_dyn)
try:
    problem.solve()
    mpf_dynamic_coeffs = coeffs_dyn.value
except Exception as error:
    mpf_dynamic_coeffs = np.zeros(len(mpf_trotter_steps))
    print(error, "Calculation Failed")

# -------------------------Step 1 (cont): Build circuits-------------------------
mpf_circuits = []
for k in mpf_trotter_steps:
    circuit = QuantumCircuit(L)
    circuit.x([i for i in range(L) if i % 2])
    trotter_circ = generate_time_evolution_circuit(
        hamiltonian,
        synthesis=SuzukiTrotter(reps=k, order=order),
        time=total_time,
    )
    circuit.compose(trotter_circ, qubits=range(L), inplace=True)
    mpf_circuits.append(circuit)

# Baseline "single deep circuit" comparison run with k=10 Trotter steps.
# Its two-qubit depth is deeper than the deepest MPF constituent (k_max=6) plus
# the overhead of running multiple circuits, pushing it into the noise-limited
# regime where MPF is expected to outperform. It does NOT target the MPF's effective
# Trotter error (which would require many more steps).
comp_circuit = QuantumCircuit(L)
comp_circuit.x([i for i in range(L) if i % 2])
trotter_circ = generate_time_evolution_circuit(
    hamiltonian,
    synthesis=SuzukiTrotter(reps=10, order=order),
    time=total_time,
)
comp_circuit.compose(trotter_circ, qubits=range(L), inplace=True)
mpf_circuits.append(comp_circuit)
```

上記のハードウェア結果について、いくつかの観察事項があります。

- **ハードウェア上では、より深くすることは無料ではありません。** 単一回路のベースラインが直接それを物語っています。$k = 6$回路は本質的に厳密です（参照値$-0.244$に対して$-0.256$）が、より深い$k = 10$のベースラインはより良いのではなく*悪く*なっています（$-0.061$で、約$0.18$の誤差）。トロッター誤差がすでに小さい場合、ステップを追加することは主に回路を深くし、より多くのゲートノイズとデコヒーレンスを蓄積するだけです。これはまさに、MPFが構築された領域です。浅い構成要素のみを使用して、深い回路の精度を達成することです。


- **ノルムの小さいMPFは、深い単一回路を上回ります。** 近似静的MPF（$\|x\|_1 \approx 2$に制限）は$-0.259$に到達し、参照値からの誤差は約$0.015$と、$k = 10$のベースラインよりもはるかに近い値です。動的MPF（$-0.127$）も、そのベースラインを楽に上回ります。どちらも浅い$k_j = [3, 4, 6]$回路のみを組み合わせているにもかかわらず、深い単一回路では得られなかった答えを回復しています。


- **係数ノルムは数学的最適性よりも重要です。** 厳密静的MPFは$\|x\|_1 = 4.66$であり、すべての推定量の中で*最悪*です（$-0.567$で、誤差は$0.3$を超えます）。大きな係数ノルムは、各$\langle A \rangle_{k_j}$に残る残留ゲートノイズ、デコヒーレンス、ZNE誤差をほぼ同じ係数で増幅し、それによって得られるトロッター誤差の打ち消し効果を圧倒してしまいます。ノルムを制限すること（近似静的ソルバー、$\|x\|_1 \approx 2$）で、この圧倒的な影響が取り除かれ、最良の推定値が得られます &mdash; ただし、その係数はもはや主要なトロッター誤差を厳密には打ち消しません。


- **個々の浅い回路も依然として競争力を持つ場合があります。** 単独の$k = 6$構成要素（$-0.256$）自体も、ここでは本質的に厳密です &mdash; この実行では、近似静的MPFよりもわずかに近いくらいです。問題は、「収束しているがまだノイズに制限されていない」という最適な領域に、どの単一の$k$が位置するかを事前に知ることができないという点であり、トロッター収束を保証するために単に深くする（$k = 10$）という一見安全に見える選択こそが、まさに失敗する選択なのです。MPFは、正しい深さを推測する必要のない、浅い回路の原理に基づいた組み合わせを提供します。


実用的な教訓は、ハードウェア上ではMPFを各個別の$\langle A \rangle_{k_j}$に対する強力なエラー緩和と組み合わせるべきであり、係数の$L_1$ノルムは控えめに保つべきであり（近似ソルバーまたは動的MPFを使用）、トロッターステップ$k_j$は$t/k_{\min} \lesssim 1$となるように選択すべきだということです &mdash; ここでは、$t = 3$における$k_{\min} = 3$により$t/k_{\min} = 1$となり、構成要素が、静的MPFが依存する主要誤差モデルが有効な収束領域内に留まっています。これらの選択により、ここでのノルムの小さいMPFは収束した単一回路に匹敵する一方で、単純に「もっと深くする」という素朴なベースラインはそうならず、参考文献[\[3\]](#references)に示された深さと精度のトレードオフの利点が再現されています。また、個々の実行にはノイズがあることにも注意してください &mdash; 同じジョブの別の送信（または別のバックエンド）では、正確な順序が変わる可能性があります。堅牢な傾向としては、小さな$\|x\|_1$のMPFはうまく機能し、大きな$\|x\|_1$の厳密静的MPFはハードウェアノイズによって増幅され、深すぎる単一回路はノイズに制限されるという点です。
