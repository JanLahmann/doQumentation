# Salve suas credenciais de acesso {#save-your-login-credentials}
Se você está trabalhando em um ambiente Python confiável (como em um laptop pessoal ou estação de trabalho), pode usar o método `save_account()` para salvar suas credenciais localmente e depois utilizá-las para inicializar o serviço.

<Admonition type="note" title="Notas">
      * Se você estiver usando um computador público ou outro ambiente não confiável, siga as instruções em [Inicializar o serviço em um ambiente não confiável](/guides/cloud-setup-untrusted).
      * Siga [estas instruções](/guides/cloud-setup-rest-api) se quiser se conectar usando a REST API em vez do Qiskit.
      * Se necessário, use [estas informações](/guides/quickstart-steps-org#firewall) para configurar seu firewall e permitir o acesso aos endpoints da API do IBM Quantum.
</Admonition>

## Antes de começar {#before-you-begin}

1. Certifique-se de estar trabalhando em um ambiente Python ativo com os [pacotes `qiskit` e `qiskit-ibm-runtime` instalados](/guides/install-qiskit#local).

1. Ative o ambiente virtual Python e execute o Python nesse ambiente.

1. Faça login na [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Encontre suas credenciais de acesso {#find-your-access-credentials}

1. Verifique se a conta e a região corretas estão selecionadas no seletor de conta no cabeçalho.

1. Encontre sua chave de API. No [painel](https://quantum.cloud.ibm.com/), crie sua chave de API, copie-a para um local seguro para usá-la na autenticação. Observe que você pode usar a mesma chave de API para se conectar a qualquer região.

1. Opcional: Encontre a instância que deseja usar na página [Instâncias](https://quantum.cloud.ibm.com/instances). Passe o cursor sobre o CRN, clique no ícone para copiá-lo e salve-o em um local seguro para usá-lo para identificar a instância.


<span id="cloud-save"></span>

## Salve suas credenciais de acesso {#save-your-access-credentials}

Salve suas credenciais executando o código apropriado uma vez para cada conta que deseja salvar. Após salvar suas credenciais, carregue-as seguindo as etapas em [Inicializar IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Salvar credenciais que acessam uma instância específica: {#save-credentials-that-access-a-specific-instance}
Se você tem várias instâncias e quer informar facilmente ao Quantum Compute qual instância usar, salve credenciais que incluam um CRN de instância.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Salvar credenciais para seleção automática de instância: {#save-credentials-for-automatic-instance-selection}
Se você não fornecer um CRN de instância e passar essas credenciais ao Quantum Compute, uma instância adequada será escolhida automaticamente com base nas opções especificadas.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Exemplo 2 {#example-2}
Este exemplo salva credenciais para seleção automática de instância. Quantum Compute buscará apenas instâncias premium na região da UE disponíveis para a conta. Essas credenciais se tornam o novo padrão.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Visualizar credenciais salvas {#view-saved-credentials}

Para visualizar todas as credenciais que você salvou, execute `service.saved_accounts()`. Observe que, se você salvou credenciais padrão sem nomeá-las, elas recebem o nome `default-ibm-quantum-platform`. Se você nomeou suas credenciais padrão, verá `"is_default_account": true` na saída.

## Considerações {#considerations}

* Se você está salvando várias contas, use o parâmetro `name` para diferenciá-las.

* As credenciais são salvas em `$HOME/.qiskit/qiskit-ibm.json`. Não edite este arquivo manualmente.

* Se você não salvar suas credenciais, precisará especificá-las toda vez que iniciar uma nova sessão (instanciar IBM Quantum Compute Service).

* Se você especificar suas credenciais manualmente, uma conta salva não será usada.
