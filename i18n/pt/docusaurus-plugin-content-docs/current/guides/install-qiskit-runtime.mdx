# Instalar o cliente IBM Quantum Compute {#install-the-ibm-quantum-compute-client}

O IBM Quantum Compute Service é o serviço baseado em nuvem para executar computações quânticas no hardware IBM Quantum&reg;. Este guia mostra como instalar o `qiskit-ibm-runtime`, que é o pacote cliente para acessar o IBM Quantum Compute Service.

Antes de instalar o `qiskit-ibm-runtime`, siga as instruções nestes guias:

1. [Instalar o Qiskit](/guides/install-qiskit).

2. [Configurar sua conta IBM Cloud](cloud-setup).


Execute este comando para instalar o cliente IBM Quantum Compute:

```shell
pip install qiskit-ibm-runtime
```

<Admonition type="note" title="Mantenha-se atualizado com as versões mais recentes">
Verifique periodicamente as [notas de lançamento do `qiskit-ibm-runtime`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/release-notes) para ver novos lançamentos. Recomendamos atualizar frequentemente seus requisitos para `qiskit-ibm-runtime` executando `pip install -U qiskit-ibm-runtime`.
</Admonition>
