# Introdução às primitivas do IBM Quantum {#introduction-to-ibm-quantum-primitives}

As primitivas foram criadas para simplificar as tarefas mais comuns em computadores quânticos: nomeadamente, amostrar estados quânticos e calcular valores esperados. As primeiras primitivas do IBM Quantum ([`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) e [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)) são implementações das [classes base de primitivas](/guides/primitives) do Qiskit. Elas oferecem uma implementação mais sofisticada (por exemplo, incluindo mitigação de erros) como serviço baseado em nuvem e são usadas para acessar o hardware IBM Quantum&reg;.

A mais nova primitiva do IBM Quantum, [Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor) (que está em beta), fornece uma interface de nível mais baixo que oferece mais visibilidade e controle sem sacrificar o desempenho. 
`Executor` também expõe **capacidades adicionais que o Sampler não oferece**, como grupos de twirling adicionais e twirling para circuitos com portas fracionárias. Consulte [Migrar do Sampler para o Executor](/guides/migrate-from-sampler-to-executor) para mais informações sobre se deve migrar para o `Executor`.
