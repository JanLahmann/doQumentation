# Use endpoints privados virtuais para VPC para se conectar de forma privada à IBM Quantum Platform {#use-virtual-private-endpoints-for-vpc-to-privately-connect-to-ibm-quantum-platform}

Use Virtual Private Endpoints (VPE) para [Virtual Private Cloud (VPC)](https://cloud.ibm.com/docs/vpc) para se conectar à IBM Quantum&reg; a partir da sua rede VPC. A conexão usa o endereço IP que você especifica, alocado a partir de uma sub-rede dentro da sua VPC.

Os VPEs são interfaces IP virtuais vinculadas a um gateway de endpoint criado por serviço. O gateway de endpoint é uma função virtualizada que escala horizontalmente, é redundante e altamente disponível, e abrange todas as zonas de disponibilidade da sua VPC. Os gateways de endpoint habilitam a comunicação entre instâncias de servidor virtual dentro da sua VPC e o serviço IBM Cloud&reg; no backbone privado. O VPE para VPC permite que você controle todo o endereçamento privado dentro da sua nuvem. Para mais informações, consulte [About virtual private endpoint gateways](https://cloud.ibm.com/docs/vpc?topic=vpc-about-vpe).

Independentemente de você usar VPEs, toda a comunicação interna dentro da rede da IBM Quantum Platform sempre usa conexões privadas em vez da internet pública.

Se a sua conexão com a própria IBM Quantum Platform é pública ou privada depende se você usa um VPE. Conectar-se por meio dos endpoints públicos transmite todos os dados de solicitação e resposta pela internet pública. Conectar-se por meio de um VPE mantém esse tráfego na rede privada.

VPEs são suportados apenas para a API e o SDK da IBM Quantum Platform, conforme descrito nas seções a seguir. O site da IBM Quantum Platform não oferece suporte a VPEs e só pode ser acessado pela rede pública.

## Antes de começar {#before-you-begin}

Antes de direcionar um VPE para a IBM Quantum Platform, complete as seguintes etapas:

* [Crie uma Virtual Private Cloud](https://cloud.ibm.com/docs/vpc?topic=vpc-getting-started).

* [Planeje a topologia de rede](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-planning-considerations) para se conectar aos VPEs.

* [Defina os controles de acesso](https://cloud.ibm.com/docs/vpc?topic=vpc-configure-acls-sgs-endpoint-gateways) para o seu VPE.

* Entenda as [restrições de serviço](https://cloud.ibm.com/docs/vpc?topic=vpc-limitations).

* Entenda como [visualizar os detalhes do VPE](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-viewing-details-of-an-endpoint-gateway).


## Configurar um VPE para a IBM Quantum Platform {#set-up-a-vpe-for-ibm-quantum-platform}

Existem várias maneiras de criar um gateway VPE. Se você usar a [CLI](https://cloud.ibm.com/docs/vpc?topic=vpc-vpc-reference&interface=cli#vpe-clis) ou a [API](https://cloud.ibm.com/apidocs/vpc/latest#create-endpoint-gateway), deverá especificar o [Cloud Resource Name (CRN)](https://cloud.ibm.com/docs/account?topic=account-crn) da região à qual deseja se conectar à IBM Quantum Platform. Consulte a tabela a seguir para ver as regiões e CRNs disponíveis.

| Região | Planos   | Nome de Domínio Totalmente Qualificado (FQDN) | Cloud Resource Name (CRN) |
|-----------------|-----------------|-----------------|-----------------|
| `us-east` | `Standard` | `private.us-east.quantum.cloud.ibm.com` | `crn:v1:bluemix:public:quantum-computing:us-east:::endpoint:private.us-east.quantum.cloud.ibm.com` |
| `eu-de` | `Standard` | `private.eu-de.quantum.cloud.ibm.com` | `crn:v1:bluemix:public:quantum-computing:eu-de:::endpoint:private.eu-de.quantum.cloud.ibm.com` |

### Configurando um gateway de endpoint {#configuring-an-endpoint-gateway}

Para configurar um gateway VPE, siga estas etapas:

1. Liste os serviços disponíveis, incluindo os serviços de infraestrutura do IBM Cloud disponíveis (por padrão) para todos os usuários VPC.

1. [Crie um gateway de endpoint](https://cloud.ibm.com/docs/vpc?topic=vpc-ordering-endpoint-gateway) para a IBM Quantum Platform que você deseja que fique disponível de forma privada para a VPC.

1. [Vincule um endereço IP reservado](https://cloud.ibm.com/docs/vpc?topic=vpc-bind-unbind-reserved-ip) ao gateway de endpoint.

1. [Visualize os gateways VPE criados](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-viewing-details-of-an-endpoint-gateway) associados à IBM Quantum Platform.


Agora suas instâncias de servidor virtual na VPC podem acessar sua instância da IBM Quantum Platform de forma privada.

## Use seu VPE para a IBM Quantum Platform {#use-your-vpe-for-ibm-quantum-platform}

Depois de criar um gateway de endpoint para a IBM Quantum Platform, siga estas etapas:

### Use o VPE com `qiskit-ibm-runtime` (SDK Python) {#use-the-vpe-with-qiskit-ibm-runtime-python-sdk}

<Admonition type="note">
O suporte a VPE requer `qiskit-ibm-runtime` v0.24.0 ou superior.
</Admonition>

Ao instanciar `QiskitRuntimeService`, especifique `private_endpoint=True`.

```python
# For `token`, use the 44-character API_KEY you created 
# and saved from the IBM Quantum Platform Home dashboard
service = QiskitRuntimeService(token="your-API_KEY", 
                              instance="INSTANCE_CRN",
                              channel="ibm_cloud",
                              private_endpoint=True)
```

### Use o VPE com a API IBM Quantum {#use-the-vpe-with-the-ibm-quantum-api}

Depois de criar um gateway de endpoint para a IBM Quantum Platform, use o nome de domínio totalmente qualificado (FQDN) do endpoint de serviço para a região de destino a partir [da tabela anterior](#set-up-a-vpe-for-ibm-quantum-platform).

```bash
  curl -X POST \
  https://private.us-east.quantum.cloud.ibm.com/api/v1/jobs \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Service-CRN: $SERVICE_INSTANCE_CRN" \
  -d '{
    "backend": "backend",
    "program_id": "sampler"
  }'
```
