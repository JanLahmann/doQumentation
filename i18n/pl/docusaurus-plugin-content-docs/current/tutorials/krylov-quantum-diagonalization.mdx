## Podstawy teoretyczne {#background}

Ten samouczek pokazuje, jak zaimplementować algorytm kwantowej diagonalizacji Krylova (KQD) w kontekście wzorców Qiskit. Najpierw poznasz teorię stojącą za algorytmem, a następnie zobaczysz demonstrację jego wykonania na QPU.

Szacowanie własności niskoenergetycznych hamiltonianów wielociałowych jest centralnym zadaniem w symulacji kwantowej.
Na przykład energie stanu podstawowego i niskie wzbudzenia są bezpośrednio powiązane ze stabilnością chemiczną, uporządkowaniem magnetycznym, przejściami fazowymi kwantowymi i odpowiedzią materiału.
Na komputerze klasycznym wymiar przestrzeni Hilberta rośnie wykładniczo wraz z liczbą orbitali lub spinów, więc bezpośrednia diagonalizacja szybko staje się niepraktyczna.

Istnieje kilka podejść obliczeń kwantowych do tego problemu.
Metody wariacyjne bliskiego zasięgu, takie jak [wariacyjny solver wartości własnych (VQE)](/tutorials/spin-chain-vqe), wykorzystują stosunkowo płytkie sparametryzowane obwody, ale wymagają nieliniowej pętli optymalizacji klasycznej z wieloma ocenami obwodów kwantowych.
Z drugiej strony, [estymacja fazy kwantowej (QPE)](https://arxiv.org/abs/quant-ph/0604193) zapewnia bardziej bezpośrednią drogę do szacowania wartości własnych z rygorystycznymi gwarancjami, ale standardowa QPE wymaga długich koherentnych obwodów i jest przeznaczona głównie dla komputerów kwantowych odpornych na błędy.
KQD znajduje się pomiędzy tymi dwoma podejściami: wykorzystuje ewolucję hamiltonianu w czasie rzeczywistym, tak jak w algorytmach opartych na estymacji fazy, ale zastępuje pełną estymację fazy zwartym rzutowanym problemem wartości własnych, który można rozwiązać klasycznie.

Rozważmy hamiltonian $H$ na $n$ kubitach oraz stan referencyjny $\lvert \psi_{0}\rangle$.
Metoda KQD buduje podprzestrzeń Kryłowa ze stanów ewoluujących w czasie rzeczywistym,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

gdzie $r$ to wymiar Kryłowa, a $\Delta t$ to krok czasowy.
Każdy stan w podprzestrzeni Kryłowa jest wtedy reprezentowany jako kombinacja liniowa tych stanów bazowych,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
where the denominator normalizes the state.

Przy pomocy prostej algebry widzimy, że odpowiadająca energia jest zapisana jako iloraz Rayleigha,

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

Tutaj macierze $\mathcal{S}$ i $\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

definiują rzutowane macierze pokrycia i hamiltonianu.
Ich elementy są szacowane za pomocą pomiarów obwodów kwantowych.

Naszym celem jest znalezienie współczynnika $\mathbf{c}$, który daje minimalne $E(\mathbf{c})$:

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

Zgodnie z twierdzeniem Rayleigha-Ritza minimalizacja ta jest równoważna rozwiązaniu uogólnionego problemu wartości własnych (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

Zauważ, że wymiar $r$ może być wystarczająco mały, aby komputer klasyczny mógł rozwiązać GEVP.

Jest to ta sama zasada wariacyjna używana w klasycznej diagonalizacji podprzestrzeni, ale tutaj stany bazowe są generowane przez kwantową ewolucję czasową.
W porównaniu z VQE, KQD zazwyczaj wymaga głębszych obwodów, ponieważ opiera się na ewolucji w czasie rzeczywistym.
W zamian KQD unika nieliniowej optymalizacji parametrów i iteracyjnego wykonywania na sprzęcie kwantowym, a jego dokładność systematycznie się poprawia w miarę powiększania rzutowanej podprzestrzeni.
Algorytm został zademonstrowany na dużą skalę na istniejącym sprzęcie kwantowym [\[2\]](#references), a jego wydajność można analizować z możliwymi do udowodnienia gwarancjami [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.primitives import StatevectorEstimator
from qiskit.quantum_info import Operator, SparsePauliOp
from qiskit.synthesis import LieTrotter, SuzukiTrotter
from qiskit.transpiler import PassManager, Layout
from qiskit.transpiler.passes import CommutativeOptimization
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### Ustawianie parametrów algorytmu {#set-the-parameters-for-the-algorithm}

Na podstawie górnych ograniczeń normy hamiltonianu, [\[1\]](#references) heurystycznie sugeruje krok czasowy $\Delta t$ jako $\pi/\|H\|$.
Ponieważ norma spektralna $\|H\|$ jest trudna do obliczenia, zamiast tego używamy jej górnego ograniczenia:

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ matrix, easy to calculate the norm}} = 3(n-1).
\end{equation*}
$$

Ustawiamy wymiar Kryłowa na $r=10$, a liczbę kroków Trottera na krok czasowy na $5$: wystarczająco duża przestrzeń Kryłowa, aby rozwiązać niskoenergetyczne widmo, przy jednoczesnym utrzymaniu przystępnego kosztu najgłębszego obwodu ($t_{\max}=(r-1)\Delta t$), oraz wystarczająco dużo kroków Trottera, aby utrzymać mały błąd dyskretyzacji przy tym najgłębszym obwodzie.

#### Budowa obwodu {#build-circuit}

Tutaj budujemy obwody do oszacowania elementów macierzowych $\mathcal{H}_{k\ell}$ i $\mathcal{S}_{k\ell}$.
Ponieważ wszystkie potęgi $H$ komutują, mamy
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Such matrices where the elements depend on the index differences in this manner are called *Toeplitz* and can be reconstructed from first-row elements indexed by $d=\ell-k$.

Tutaj przedstawiamy obwód, zwany **rozszerzonym testem swap**, który przygotowuje
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
gdzie $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$.

#### Obwód testu rozszerzonego swap [\[3\]](#references) {#extended-swap-test-circuit-3references}

Obwód najpierw przygotowuje stan referencyjny w rejestrze systemowym, podczas gdy ancilla pozostaje w stanie $|0\rangle$:

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

Następnie zastosowanie bramki Hadamarda do ancilli tworzy koherentną superpozycję dwóch gałęzi:

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Na koniec stosowana jest kontrolowana bramka ewolucji czasowej:

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

tylko wtedy, gdy ancilla znajduje się w gałęzi $|1\rangle$. Dlatego,

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

W następnym bloku kodu implementujemy:
$$
\begin{equation*}

\end{equation*}
$$
co zostanie przypisane jako $t=d\Delta t$ dla $d=1,\cdots r-1$ w kroku wykonania.

#### Obserwable {#observables}

Dla dowolnej hermitowskiej obserwabli systemu $O$, ustawiamy tutaj obserwable do obliczenia:

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Wynika to z faktu, że $O=I$ daje element przekrywania $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$, podczas gdy $O=H$ daje element hamiltonianu $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$.

Używając $X=|0\rangle\langle 1|+|1\rangle\langle 0|$, mamy

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

Podobnie, używając $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

Zatem mamy
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Na koniec, dla każdego stanu $|\Psi_{0d}\rangle$, musimy zmierzyć:
$$
\begin{align*}
X \otimes I \text{ for } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ for } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ for } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ for } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

Dla estymacji elementów macierzy $\mathcal{H}$, liczba wyrazów Pauliego jest znacznie większa niż dla elementów macierzy $\mathcal{S}$.

Możemy teraz zmniejszyć liczbę mierzonych wyrazów hamiltonianu, stosując technikę przesunięcia [\[4\]](#references).
Dzielimy hamiltonian jako:

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

gdzie $T$ jest wybrane tak, aby stan referencyjny był jego stanem własnym,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Then,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Here,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

jest przesuniętym elementem macierzy hamiltonianu.
Dlatego musimy mierzyć jedynie $X\otimes (H-T)$ i $Y\otimes (H-T)$.
Wkład od $T$ jest odtwarzany klasycznie przy użyciu już zmierzonego elementu macierzy przekrywania $\mathcal{S}_{0d}$.

W tym przykładzie naturalnym wyborem jest diagonalna część hamiltonianu Heisenberga,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

Ponieważ stan referencyjny jest stanem bazy obliczeniowej, jest on stanem własnym każdego wyrazu $Z_iZ_{i+1}$.

Jednak bardziej korzystny wybór obejmuje nie tylko diagonalne wyrazy $ZZ$, ale także wyrazy $XX+YY$, które anihilują stan referencyjny.

Dla każdej sąsiedniej pary operator $XX+YY$ spełnia

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

and

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

Dlatego wyraz $XX+YY$ wnosi wkład tylko wtedy, gdy dwa sąsiednie kubity mają różne obsadzenia w referencyjnym ciągu bitów.
Jeśli oba kubity są $0$ albo oba są $1$, wyraz anihiluje stan referencyjny i również może zostać przesunięty na zewnątrz.

Niech $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, gdzie $z_i \in \{0,1\}$.
Możemy zatem wybrać
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Ten operator nadal spełnia

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

ponieważ wyrazy $ZZ$ działają diagonalnie na $|\psi_0\rangle$, podczas gdy przesunięte wyrazy $XX+YY$ dają zero.
Odpowiadająca wartość własna jest zatem wyznaczona wyłącznie przez wyrazy $ZZ$,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

Przy tym wyborze przesunięty hamiltonian staje się:
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

W rezultacie mierzone muszą być jedynie krawędzie o różnych obsadzeniach w stanie referencyjnym.
Wszystkie wyrazy $ZZ$ oraz wszystkie nieaktywne wyrazy $XX+YY$ są odtwarzane poprzez wkład przekrywania $\tau \mathcal{S}_{0d}$, albo dają zerowy wkład z konstrukcji.

Daje to mniejszą obserwablę niż przesunięcie samej części diagonalnej.
W szczególności, dla stanu referencyjnego bazy obliczeniowej ze zlokalizowanym wzbudzeniem, w $H-T$ pozostają jedynie krawędzie sąsiadujące ze wzbudzeniem.
Dlatego liczbę wyrazów Pauliego w $X\otimes(H-T)$ i $Y\otimes(H-T)$ można znacznie zmniejszyć, podczas gdy odtworzony element macierzy
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

pozostaje dokładnie taki sam.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau

obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, shift_tau = (
    make_reduced_heisenberg_observables(ref_bitstring)
)
```

#### Porównanie kolejności wyrazów hamiltonianu {#compare-hamiltonian-term-ordering}

Najpierw porównujemy różne kolejności wyrazów Pauliego w hamiltonianie Heisenberga dla symulacji hamiltonianu.
Sam hamiltonian pozostaje niezmieniony, ale kolejność wpływa na sposób generowania obwodu formuły produktowej oraz na to, jak bardzo struktura może być zrównoleglona w obwodzie.
Na przykład naiwna kolejność wymienia najpierw wszystkie wyrazy $XX$ dla najbliższych sąsiadów, następnie wszystkie wyrazy $YY$, a na końcu wszystkie wyrazy $ZZ$.
Umieszcza to sąsiadujące krawędzie, takie jak $(0,1)$ i $(1,2)$, obok siebie, więc nie mogą być wykonane równolegle.
Kolejność parzyste-potem-nieparzyste odwiedza najpierw rozłączne parzyste krawędzie, a następnie nieparzyste, co odsłania równoległe warstwy dwukubitowe.
Kolejność parzysto-nieparzysta z grupowaniem krawędzi idzie o krok dalej: dla każdej krawędzi utrzymuje razem lokalne wyrazy $XX$, $YY$ i $ZZ$, wciąż odwiedzając parzyste krawędzie przed nieparzystymi.
Spodziewamy się, że kolejności parzyste-potem-nieparzyste oraz parzysto-nieparzysta z grupowaniem krawędzi zmniejszą głębokość obwodu poprzez odsłonięcie równoległych warstw dwukubitowych, a kolejność z grupowaniem krawędzi dodatkowo zmniejszy błąd Trottera, ponieważ lokalna interakcja dwukubitowa na tej samej krawędzi jest obsługiwana jako zwarty blok.

![Pauli evolutions with different term ordering](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

Kolejność hamiltonianu wpływa również na błąd Trottera.
Jeśli umieścimy niekomutujące wyrazy obok siebie, przejścia bazowe następują częściej, co powoduje większy błąd Trottera.
Grupując wyrazy wymagające tej samej transformacji bazy Pauliego, można uniknąć zbędnych zmian bazy.

Tutaj porównanie wykorzystuje największy czas ewolucji, który pojawia się w estymacjach Kryłowa pierwszego wiersza,
$t_{\max} = (r-1)\Delta t,$
przy użyciu tego samego warunku transpilacji.

Aby zmierzyć błąd Trottera, używamy **nieporzeczności procesu** (process infidelity) między obwodem Trotterowskim a dokładną ewolucją hamiltonianu w czasie rzeczywistym,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
where $d=2^n$ is the dimension of the Hilbert space.

Ten diagnostyk wykorzystuje macierze gęste, więc jest odpowiedni dla tego małego 12-kubitowego przykładu, ale nie jest przeznaczony jako skalowalna podprocedura.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

def build_numeric_evolution_circuit(
    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:
    """Build a numeric circuit for exp(-i H t) with a chosen synthesis rule."""
    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

print("Precomputing the exact evolution operator... ", end="")
exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### Usunięcie kontrolowanej bramki ewolucji w czasie {#remove-the-controlled-time-evolution-gate}

W rozszerzonym teście swap, kontrolowanie ewolucji w czasie za pomocą pojedynczego kubitu pomocniczego wymaga, aby kubit pomocniczy kontrolował wiele bramek w całym systemie.
Może to wprowadzić znaczny narzut trasowania, a w najgorszym przypadku efektywnie wymagać łączności wszystko-z-jednym.
Aby tego uniknąć, możliwa jest dalsza optymalizacja poprzez zastąpienie kontrolowanej bramki ewolucji w czasie wersją bezkontrolną, wykorzystującą symetrię hamiltonianu.
Przyjrzyjmy się poniższemu obwodowi.

![circuit optimization](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

Tutaj $B_{\rm ref}$ przygotowuje stan referencyjny, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

Zamiast najpierw przygotować $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$, a następnie zastosować $U(t)$ jedynie na gałęzi $|1\rangle$, obwód bezpośrednio przygotowuje obie gałęzie jako

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

where

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

Obwód najpierw stosuje bramkę Hadamarda na kubicie pomocniczym i przygotowuje stan referencyjny jedynie na gałęzi $|1\rangle$:

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Następnie niekontrolowany operator ewolucji w czasie jest stosowany do obu gałęzi:

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Ponieważ hamiltonian zachowuje liczbę wzbudzeń, widzimy, że $|0^n\rangle$ jest jego stanem własnym, a zatem operator ewolucji jedynie gromadzi fazę pod wpływem hamiltonianu:
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Therefore,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Następnie $B_{\rm ref}$ jest stosowane jedynie na gałęzi $|0\rangle$.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

W tym momencie obie gałęzie mają dodatkową fazę względną. Aby ją usunąć, stosujemy bramkę fazy kubitu pomocniczego

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

Przekształca to stan jako

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Zatem, z dokładnością do nieistotnej globalnej fazy, w końcu przygotowaliśmy

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

W kolejnym bloku kodu implementujemy ten bezkontrolny obwód.

### Krok 3: Wykonanie przy użyciu prymitywów Qiskit {#step-3-execute-using-qiskit-primitives}

Kolejnym krokiem jest przesłanie tego samego sparametryzowanego obwodu dla kilku wartości $d$. Dla każdego $d$ estymujemy cztery wartości oczekiwane: $X\otimes I$, $Y\otimes I$, $X\otimes (H-T)$ i $Y\otimes (H-T)$. Te cztery liczby są następnie łączone w zespolone elementy pierwszego wiersza $\mathcal{S}_{0d}$ i $\mathcal{H}_{0d}$.

Tutaj $\mathcal{S}_{00}=1$ i $\mathcal{H}_{00}=\langle\psi_{0}|(H-T)|\psi_{0}\rangle=\langle\psi_{0}|H|\psi_{0}\rangle-\tau$ można obliczyć klasycznie, ponieważ $\lvert\psi_0\rangle$ jest rzadki, więc pomijamy przypadek $d=0$.

Po oszacowaniu zrzutowanych macierzy regularyzujemy je i rozwiązujemy GEVP
$$
\begin{equation*}
\mathcal{H}\mathbf{c} = E\mathcal{S}\mathbf{c}.
\end{equation*}
$$
Najmniejsza uogólniona wartość własna daje estymatę KQD energii stanu podstawowego.

```python
s_row_est[0] = 1.0
```

## Dodatek: Perspektywa funkcji hamiltonianu (filtru spektralnego) {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

Ten dodatek powraca do *tego samego* obliczenia z komplementarnej perspektywy, która wyjaśnia **dlaczego** KQD działa: perspektywa *funkcji hamiltonianu*, czyli *filtru spektralnego* [\[3\]](#references), [\[5\]](#references).
Wykorzystuje ponownie model 12-kubitowy, krok czasowy $\Delta t$ oraz rozwiązanie Kryłowa uzyskane już powyżej; nie jest wymagane żadne nowe wykonanie obwodu.

### Stan referencyjny jako rozkład energii {#the-reference-state-as-an-energy-distribution}

Niech hamiltonian ma rozkład na wartości własne

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

ze stanami własnymi energii $|E_m\rangle$.
Każdy stan referencyjny można rozwinąć w tej bazie własnej,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

więc niesie ze sobą **wagę spektralną** $p_m=|a_m|^2$ przy każdej energii $E_m$. Energia referencyjna to średnia tego rozkładu, $\langle H\rangle_{0}=\sum_m p_m E_m$.

Rozkład na wartości własne ogólnego $n$-kubitowego hamiltonianu jest kosztowny wykładniczo, więc ten obraz stanowi jedynie diagnostykę, która *nie* jest częścią algorytmu.
Tutaj jednak możemy obliczyć go tanio dla *tego samego* problemu $n=12$: hamiltonian Heisenberga zachowuje całkowitą liczbę wzbudzeń, a stan referencyjny $|000001000000\rangle$ niesie pojedyncze wzbudzenie, więc cała jego zawartość spektralna mieści się w podprzestrzeni pojedynczego wzbudzenia, której wymiar rośnie tylko liniowo z $n$.
Dlatego ponownie wykorzystujemy dokładny blok pojedynczego wzbudzenia (już użyty powyżej jako punkt odniesienia) i odczytujemy rozkład referencyjny $\{(E_m, p_m)\}$ w tej podprzestrzeni.

```python
# Exact single-excitation-subspace decomposition of the reference state.
# This reuses make_heisenberg_hamiltonian / _basis_state_transition_amplitude_sparse
# and the n=12 `hamiltonian` and `ref_bitstring` defined in the small-scale example.
single_excitation_states = [1 << k for k in range(num_qubits)]

h_single = np.array(
    [
        [
            _basis_state_transition_amplitude_sparse(hamiltonian, bra, ket)
            for ket in single_excitation_states
        ]
        for bra in single_excitation_states
    ]
)
```

### KQD uczy się filtru, który przekształca ten rozkład {#kqd-learns-a-filter-that-reshapes-this-distribution}

**Funkcja hamiltonianu** $f(H)$ jest zdefiniowana poprzez rachunek spektralny,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

innymi słowy, ważoną sumę projektorów własnych.
Zastosowanie jej do stanu referencyjnego przekształca każdą amplitudę spektralną, $a_m \to a_m f(E_m)$:

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

Gdyby $f$ było ostro skupione przy najniższej energii ($f(E_0)=1$ i $f(E_m)\approx 0$ w pozostałych przypadkach), wówczas $f(H)$ działałoby jako projektor stanu podstawowego, a znormalizowany wynik byłby (blisko) stanem podstawowym.
Dlatego dobry dolnoprzepustowy **filtr spektralny** w energii jest dokładnie tym, czego potrzebujemy.

KQD nie ustala $f$ z góry. Zamiast tego rozwija filtr w bazie ewolucji w czasie rzeczywistym,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

*trygonometryczną* funkcję energii, której współczynniki $\{c_\ell\}$ są dokładnie wektorem własnym GEVP rozwiązanym powyżej.
Minimalizacja ilorazu Rayleigha $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ jest zatem tym samym, co *uczenie się* filtru, który najlepiej tłumi wagę stanów wzbudzonych w stanie referencyjnym.
Większy wymiar Kryłowa $r$ daje filtrowi więcej stopni swobody i ostrzejszy pik przy energii stanu podstawowego.

Poniższa funkcja pomocnicza oblicza ten wyuczony filtr na osi energii; następnie stosujemy go do rozkładu referencyjnego uzyskanego powyżej.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### Wizualizacja filtru i jego elastyczności {#visualize-the-filter-and-its-flexibility}

Najpierw pokazujemy wyuczony filtr przy pełnym wymiarze Kryłowa użytym powyżej, a następnie śledzimy, jak się on wyostrza w miarę wzrostu wymiaru $r$.

Słupki pokazują referencyjne wagi spektralne $p_m$ (przed) i przefiltrowane wagi $p_m|f_{\rm KQD}(E_m)|^2$ (po), wraz z wyuczoną intensywnością filtru $|f_{\rm KQD}(E)|^2$ na ciągłej osi energii.
Filtr koncentruje wagę na najniższej energii podprzestrzeni pojedynczego wzbudzenia &mdash; tej samej energii, do której zbiegła estymata KQD w przykładzie o małej skali.
Zauważ, że jest to stan podstawowy *w obrębie sektora pojedynczego wzbudzenia*, który jest odpowiednim celem dla tego zachowującego wzbudzenie stanu referencyjnego, a nie globalny stan podstawowy.

### Zwiększanie wymiaru Kryłowa: elastyczność wyuczonej funkcji {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

Przypomnijmy, że wyuczony filtr jest wielomianem trygonometrycznym energii z $r$ współczynnikami,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

Wymiar Kryłowa $r$ jest dokładnie liczbą wolnych współczynników, więc kontroluje on **elastyczność** funkcji.
Mały $r$ może wytworzyć jedynie szeroki, łagodnie zmieniający się filtr, który przecieka wagę do nisko leżących stanów wzbudzonych; gdy $r$ rośnie, filtr może utworzyć węższy pik przy docelowej energii i bardziej agresywnie tłumić pozostałą wagę stanów wzbudzonych.
Jest to spektralny odpowiednik zbieżności energii obserwowanej w przykładzie o małej skali: w miarę wzrostu $r$ przefiltrowany rozkład zapada się do stanu podstawowego podprzestrzeni, a estymowana energia maleje w jego kierunku.

Ponownie wykorzystujemy zrzutowane macierze już oszacowane powyżej i po prostu rozwiązujemy GEVP dla każdego wiodącego bloku $r\times r$, a następnie obliczamy i wykreślamy odpowiadający filtr.

```python
# Sweep the Krylov dimension using the leading r x r blocks of the estimated matrices.
sweep_dims = [r for r in (2, 4, 6, 8, krylov_dim) if r <= krylov_dim]
sweep_dims = sorted(set(sweep_dims))

energy_grid = np.linspace(
    subspace_evals.min() - 0.5, subspace_evals.max() + 0.5, 800
)

sweep_cases = []
print(" r    retained    ground overlap    filtered energy")
print("--    --------    --------------    ---------------")
for r in sweep_dims:
    _, coeffs_r, retained_r = solve_thresholded_gevp(
        h_matrix_est[:r, :r],
        s_matrix_est[:r, :r],
        threshold=1e-12,
    )
    filter_on_spectrum_r = trigonometric_krylov_filter(
        coeffs_r, subspace_evals, dt
    )
    filtered_weights_r = filtered_spectral_weights(
        ref_spectral_weights, filter_on_spectrum_r
    )
    filtered_energy_r = float(np.sum(filtered_weights_r * subspace_evals))

    sweep_cases.append((r, coeffs_r, filtered_weights_r))
    print(
        f"{r:2d}    {retained_r:8d}    {filtered_weights_r[0]:14.4f}    {filtered_energy_r:15.6f}"
    )

print(f"\nSubspace ground-state energy (target): {subspace_evals[0]:.6f}")

# One panel per Krylov dimension: filtered spectrum (bars) + filter intensity (curve).
fig, axes = plt.subplots(
    len(sweep_cases),
    1,
    figsize=(8, 2.1 * len(sweep_cases)),
    sharex=True,
)
axes = np.atleast_1d(axes)

for idx, (ax, (r, coeffs_r, filtered_weights_r)) in enumerate(
    zip(axes, sweep_cases)
):
    visible = (ref_spectral_weights > 1e-4) | (filtered_weights_r > 1e-4)
    ax.bar(
        subspace_evals[visible],
        ref_spectral_weights[visible],
        width=0.18,
        alpha=0.35,
        color="C0",
        label="reference $p_m$" if idx == 0 else None,
    )
    ax.bar(
        subspace_evals[visible],
        filtered_weights_r[visible],
        width=0.14,
        alpha=0.9,
        color="C1",
        label="filtered weights" if idx == 0 else None,
    )

    filter_intensity_r = (
        np.abs(trigonometric_krylov_filter(coeffs_r, energy_grid, dt)) ** 2
    )
    filter_intensity_r /= filter_intensity_r.max()
    ax.plot(energy_grid, filter_intensity_r, color="k", linewidth=2)

    ax.axvline(subspace_evals[0], color="C3", linestyle="--", linewidth=1)
    ax.set_ylim(0, 1)
    ax.set_ylabel("weight")
    ax.legend(loc="upper right", title=f"$r={r}$")

axes[-1].set_xlabel("Energy eigenvalue $E_m$")
fig.suptitle(
    r"KQD-learned filter $|f_{\rm KQD}(E)|^2$ sharpening with Krylov dimension $r$",
    y=1.0,
)
fig.tight_layout()
plt.show()
```
