# Qiskit Code Assistant {#qiskit-code-assistant}

<span id="qca-sunset"></span>

## 29 maja 2026 {#29-may-2026}
- **Usługa Qiskit Code Assistant została wycofana** - Usługa w wersji podglądowej została wycofana, a rozszerzenia Visual Studio Code i JupyterLab zostały zarchiwizowane.


  Na podstawie opinii i wzorców użytkowania coraz więcej użytkowników uruchamia modele Qiskit Code Assistant lokalnie i pracuje w integracjach z edytorem, które są już częścią ich przepływu pracy programistycznej.

  Modele Qiskit Code Assistant pozostają dostępne do użytku lokalnego. Zobacz dokumentację [Qiskit Code Assistant](/guides/qiskit-code-assistant), aby uzyskać więcej informacji.
