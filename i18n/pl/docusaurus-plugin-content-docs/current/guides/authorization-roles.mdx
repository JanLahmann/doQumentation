# Role autoryzacji {#authorization-roles}

Przejrzyj dostępne role i działania przypisane do każdej z nich, aby ułatwić sobie przyznawanie dostępu. Zobacz [role i działania IAM](https://cloud.ibm.com/docs/iam?topic=iam-iam-service-roles-actions#service-roles-table155) w IBM Cloud&reg;, aby uzyskać więcej informacji.

## IBM Quantum Compute Service {#ibm-quantum-compute-service}

| Uprawnienie | Wymagane przez |
| -- | -- |
| `quantum-computing.account-analytics-filters.read` | Pobierz filtry analityczne (`GET /v1/analytics/filters`) |
| `quantum-computing.account-analytics-usage.read` | Pobierz analitykę użytkowania (`GET /v1/analytics/usage`) |
| `quantum-computing.account-analytics-usage.read` | Pobierz analitykę użytkowania zgrupowaną (`GET /v1/analytics/usage_grouped`) |
| `quantum-computing.account-analytics-usage.read` | Pobierz analitykę użytkowania zgrupowaną według daty (`GET /v1/analytics/usage_grouped_by_date`) |
| `quantum-computing.account-configuration.read` | Pobierz konfigurację konta (`GET /v1/accounts/{id}`) |
| `quantum-computing.device.read` | Pobierz konfigurację Backend'u (`GET /v1/backends/{id}/configuration`) |
| `quantum-computing.device.read` | Pobierz domyślne ustawienia Backend'u (`GET /v1/backends/{id}/defaults`) |
| `quantum-computing.device.read` | Pobierz właściwości Backend'u (`GET /v1/backends/{id}/properties`) |
| `quantum-computing.device.read` | Pobierz status Backend'u (`GET /v1/backends/{id}/status`) |
| `quantum-computing.device.read` | Wyświetl listę swoich Backend'ów (`GET /v1/backends`) |
| `quantum-computing.instance-usage.read` | Pobierz użytkowanie instancji (`GET /v1/instances/usage`) |
| `quantum-computing.instance.configuration.read` | Pobierz konfigurację instancji (`GET /v1/instances/configuration`) |
| `quantum-computing.instance.read` | Pobierz szczegóły bieżącej instancji (`GET /v1/instance`) |
| `quantum-computing.job.cancel` | Anuluj zadanie (`POST /v1/jobs/{id}/cancel`) |
| `quantum-computing.job.create` | Uruchom zadanie (`POST /v1/jobs`) |
| `quantum-computing.job.delete` | Usuń zadanie (`DELETE /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Pobierz metryki zadania (`GET /v1/jobs/{id}/metrics`) |
| `quantum-computing.job.read` | Wyświetl szczegóły zadania (`GET /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Wyświetl logi zadania (`GET /v1/jobs/{id}/logs`) |
| `quantum-computing.job.read` | Wyświetl wyniki zadania (`GET /v1/jobs/{id}/results`) |
| `quantum-computing.job.read` | Wyświetl listę zadań (`GET /v1/jobs`) |
| `quantum-computing.job.read` | Wyświetl listę tagów (`GET /v1/tags`) |
| `quantum-computing.session.create` | Utwórz Session (`POST /v1/sessions`) |
| `quantum-computing.session.read` | Pobierz Session (`GET /v1/sessions/{id}`) |
| `quantum-computing.session.update` | Zamknij Session zadania (`DELETE /v1/sessions/{id}/close`) |
| `quantum-computing.session.update` | Zaktualizuj Session (`PATCH /v1/sessions/{id}`) |
| `quantum-computing.workload.list` | Wyświetl listę obciążeń instancji użytkownika (`GET /v1/workloads`) |

## IBM Quantum System Service {#ibm-quantum-system-service}

| Uprawnienie | Wymagane przez |
| -- | -- |
| `quantum-computing.direct-access-backend-configuration.read` | Pobierz konfigurację Backend'u (`GET /v1/backends/{backend-name}/configuration`) |
| `quantum-computing.direct-access-backend-properties.read` | Pobierz właściwości Backend'u (`GET /v1/backends/{backend-name}/properties`) |
| `quantum-computing.direct-access-backend.list` | Pobierz listę Backend'ów (`GET /v1/backends`) |
| `quantum-computing.direct-access-backend.read` | Pobierz szczegóły Backend'u (`GET /v1/backends/{backend-name}`) |
| `quantum-computing.direct-access-job.cancel` | Anuluj zadanie (`POST /v1/jobs/{job-id}/cancel`) |
| `quantum-computing.direct-access-job.create` | Uruchom zadanie (`POST /v1/jobs`) |
| `quantum-computing.direct-access-job.delete` | Usuń zadanie (`DELETE /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-job.list` | Pobierz zadania (`GET /v1/jobs`) |
| `quantum-computing.direct-access-job.read` | Pobierz zadanie według ID (`GET /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-lane-configuration.list` | Pobierz konfigurację ścieżek Backend'u (`GET /v1/backends/{backend-name}/lanes`) |
