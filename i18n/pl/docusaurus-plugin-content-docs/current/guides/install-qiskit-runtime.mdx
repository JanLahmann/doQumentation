# Instalacja klienta IBM Quantum Compute {#install-the-ibm-quantum-compute-client}

IBM Quantum Compute Service to usługa chmurowa do wykonywania obliczeń kwantowych na sprzęcie IBM Quantum&reg;. Ten przewodnik pokazuje, jak zainstalować `qiskit-ibm-runtime` — pakiet kliencki umożliwiający dostęp do usługi IBM Quantum Compute Service.

Przed instalacją `qiskit-ibm-runtime` wykonaj instrukcje zawarte w tych przewodnikach:

1. [Zainstaluj Qiskit](/guides/install-qiskit).

2. [Skonfiguruj konto IBM Cloud](cloud-setup).


Uruchom to polecenie, aby zainstalować klienta IBM Quantum Compute:

```shell
pip install qiskit-ibm-runtime
```

<Admonition type="note" title="Bądź na bieżąco z najnowszymi wersjami">
Regularnie sprawdzaj [informacje o wydaniach `qiskit-ibm-runtime`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/release-notes), aby śledzić nowe wersje. Zalecamy częste aktualizowanie wymagań dla `qiskit-ibm-runtime` poprzez uruchomienie `pip install -U qiskit-ibm-runtime`.
</Admonition>
