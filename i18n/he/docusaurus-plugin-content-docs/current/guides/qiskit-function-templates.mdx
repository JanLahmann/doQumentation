# מבוא לתבניות פונקציות Qiskit {#introduction-to-qiskit-function-templates}

[תבניות פונקציות Qiskit](https://github.com/qiskit-community/qiskit-function-templates) הן אוסף קוד פתוח של דוגמאות קוד מציאותיות המעניקות לך גישה לחלק מתהליכי המחקר העדכניים ביותר המנצלים כלים כמו Qiskit SDK ו-[תוספי Qiskit](/guides/addons). תהליכי עבודה מוכנים אלו לוקחים מידע מניסויים מעשיים ואורזים אותו בצורה שתוכל להתאים אישית ולעשות בה שימוש חוזר במחקר שלך, כך שלא תצטרך לבנות הכל מאפס. כל התבניות ניתנות לפריסה מיידית ב-[Qiskit Serverless](/guides/serverless) שם תוכל לנצל בקלות משאבי מחשוב קלאסיים כחלק מתהליך העבודה שלך.

ישנם שני סוגים של תבניות:

- *מימושי תבניות*: דוגמאות קוד מתמחות המיישמות טכניקות מתקדמות מניסויים בעולם האמיתי בתחומים כמו כימיה ופיזיקה.

- *תבניות בסיס*: מקורות עזר לפיתוח פונקציית Qiskit מקורית משלך. תבניות אלו מדגישות שיטות עבודה מומלצות בפיתוח ממשקים, עיצוב קוד, בדיקות יחידה ועוד.


## מימושי תבניות {#template-implementations}

מימושי תבניות פונקציות Qiskit מאורגנים לפי תחום יישום. כרגע הכולל בקולקציה הן שתי תבניות פיזיקה שמשתמשות ב[תוסף AQC-Tensor של Qiskit](https://qiskit.github.io/qiskit-addon-aqc-tensor/) (אחת לסימולציית המילטוניאן ואחת לדינמיקת המילטוניאן מסוג AQC + Trotter) ותבנית כימיה לסימולציית מבנה אלקטרוני עם מודל ממס משתמע באמצעות [תוסף SQD של Qiskit](https://docs.quantum.ibm.com/addons/qiskit-addon-sqd).
משאבים להתחלה עם תבניות אלו זמינים בקישורים הבאים:

- סימולציית מבנה אלקטרוני עם מודל ממס משתמע: [קבצי מקור התבנית](https://github.com/qiskit-community/qiskit-function-templates/tree/main/chemistry/sqd_pcm) ו[מדריך](/guides/function-template-chemistry-workflow)

- סימולציית המילטוניאן: [קבצי מקור התבנית](https://github.com/qiskit-community/qiskit-function-templates/tree/main/physics/hamiltonian_simulation) ו[מדריך](/guides/function-template-hamiltonian-simulation)

- דינמיקת המילטוניאן מסוג AQC + Trotter: [קבצי מקור התבנית](https://github.com/qiskit-community/qiskit-function-templates/tree/main/physics/aqc_trotter) ו[מדריך](/guides/function-template-aqc-trotter)


## תבניות בסיס {#base-templates}

*תבניות הבסיס* הן מקורות עזר לפיתוח פונקציית Qiskit מקורית משלך. הן מתוכננות לעזור לך להתניע את תהליך הפיתוח על ידי המחשה של שיטות עבודה מומלצות בפיתוח ממשקים, עיצוב קוד, טיפול בקלט/פלט, הודעות שגיאה, נקודות ביקורת, בדיקות יחידה ועוד. המאגר חשוף כ-[תבנית GitHub](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository) כך שניתן להרחיב בקלות את מימוש ה-CI/CD.

כרגע ישנן שתי תבניות: [תבנית פונקציית Circuit](https://github.com/qiskit-community/qiskit-function-templates/blob/main/base_templates/circuit_function_template.py) ו[תבנית פונקציית אפליקציה](https://github.com/qiskit-community/qiskit-function-templates/blob/main/base_templates/application_function_template.py).
