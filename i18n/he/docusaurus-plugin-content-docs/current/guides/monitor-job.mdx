## ניטור עבודה {#monitor-a-job}

השתמש בשיטות אלה כדי לבדוק את הסטטוס של העבודות שהגשת, לאחזר תוצאות, ולצפות בפרטים הקשורים לעבודה ולביצועה.

<Tabs>
    <TabItem value="Qiskit" label="מעקב אחר עבודה עם Qiskit">
        מופע העבודה מספק כמה שיטות למעקב:

        | Method | Description |
        | --- | --- |
        | `job.status()` | בדוק את הסטטוס הנוכחי של העבודה |
        | `job.job_id()` | קבל את מזהה העבודה הייחודי |
        | `job.result()` | אחזר את תוצאות העבודה (קריאה חוסמת עד להשלמה) |
        | `job.wait_for_final_state()` | חסום עד שהעבודה מגיעה למצב סופי |

        
    </TabItem>

### מדוע עבודה נשארת "בתהליך" {#why-a-job-stays-in-progress}

ייתכן שתשים לב שעבודה (בין אם במצב job או מצב batch) שאתה מצפה שתיקח רק כמה שניות נשארת בסטטוס **בתהליך** (הנקרא `RUNNING` ב-Qiskit) הרבה יותר זמן. זה נורמלי, וזה לא אומר שהעבודה צורכת את כל אותו הזמן כשימוש. זה קורה בגלל האופן שבו עבודות מתוזמנות על QPU:

- כל עבודה דורשת עיבוד מקדים קלאסי לפני שהיא יכולה לפעול על ה-QPU. עבודה עוברת ל-**בתהליך** (`RUNNING`) ברגע שהעיבוד הקלאסי הזה מתחיל — לא כאשר היא מתחילה לפעול על ה-QPU.

- רוב העיבוד הקלאסי הזה פועל במקביל, כך שעבודות מרובות יכולות להיות **בתהליך** באותו הזמן.

- עם זאת, רק עבודה אחת בכל פעם יכולה לפעול על ה-QPU. כאשר מספר עבודות מסיימות את העיבוד הקלאסי שלהן ומוכנות לביצוע, עליהן להמתין לתורן ל-QPU. זה ידוע כ*תחרות QPU*. כאשר התחרות גבוהה, עבודה יכולה להישאר **בתהליך** זמן ניכר יותר מכמה שניות זמן ה-QPU שהיא באמת זקוקה להן.

- תחרות יכולה גם להתרחש כאשר משימת תחזוקת מערכת, כגון כיול, פועלת על ה-QPU. העבודה שלך נשארת **בתהליך** עד שמשימת התחזוקה מסתיימת וה-QPU הופך לזמין.


בגלל זה, זמן השעון שחלף שעבודה מבלה **בתהליך** אינו זהה לשימוש שלה. גם [השימוש המוערך](/guides/estimate-job-run-time) וגם [זמן הביצוע המקסימלי](/guides/max-execution-time) מבוססים רק על הזמן שבו ה-QPU נעול כדי לבצע את העבודה שלך, ולכן אינם כוללים את העיבוד הקלאסי הרב-שרשורי המתואר לעיל. זמן ארוך של **בתהליך** לא מגדיל את השימוש או העלות המדווחים שלך.

#### מצב סשן שונה {#session-mode-is-different}

ההתנהגות הקודמת חלה על [מצב job](/guides/execution-modes#job-mode) ו-[מצב batch](/guides/execution-modes#batch-mode). ב-[מצב session](/guides/execution-modes#session-mode), במהלך חלון הפעילות של הסשן, למשתמש יש גישה בלעדית ל-Backend ואף עבודה אחרת לא יכולה לפעול, כולל עבודות כיול. לכן, כל תחרות QPU מתרחשת רק בין עבודות הסשן שלך עצמך. בנוסף, מכיוון שקיבולת ה-QPU שמורה למשך הסשן, שימוש הסשן נמדד כזמן שחלף בזמן שהסשן נשאר פעיל, ללא קשר לכך שעבודות פועלות באופן פעיל. ראה [שימוש בעומס עבודה](/guides/estimate-job-run-time#usage) למידע נוסף.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()

# Retrieve a job by ID
job = service.job("<job_id>")

# Get job ID (useful for saving for later retrieval)
print(f"Job ID: {job.job_id()}")

# Check current status
print(f"Status: {job.status()}")

# Wait for job to complete (blocking call)
job.wait_for_final_state()
print("Job completed")

# Get results
results = job.result()
print(results)
```

## צפייה במדדי עבודה {#view-job-metrics}

קבל סקירה כללית של הגשות העבודה שלך, כולל מדדי עומסי עבודה של אצווה וסשן.

<Tabs>
    <TabItem value="Qiskit" label="קבלת מדדי עבודה עם Qiskit">
        השתמש בשיטה [`service.jobs()`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/qiskit-runtime-service#jobs) עם מסננים כדי לאחזר מידע על העבודות שהגשת, כגון כמה הוגשו, מה הסטטוסים שלהן, ומתי נוצרו. הדוגמה הבאה מאחזרת את כל העבודות שהוגשו בשבעת הימים האחרונים ומחשבת את השימוש הכולל מעבודות אלה.

        
    </TabItem>
    <TabItem value="IQP" label="צפייה במדדי עבודה בפלטפורמת IBM Quantum">
        נווט לדף [Analytics](https://quantum.cloud.ibm.com/analytics) כדי לראות ולהוריד נתונים, כגון הבאים:
        - שימוש כולל
        - שימוש מסונן לפי מופע, מחשב קוונטי, ומשתמש
        - ספירת עומסי עבודה של job, batch, ו-session

        **הערה**: תוכל לגשת לדף Analytics רק עבור חשבונות שבבעלותך או שאתה מנהל.
    </TabItem>
</Tabs>

```python
from datetime import datetime, timedelta
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()

# Retrieve all jobs in the last 7 days
seven_days_ago = datetime.now() - timedelta(days=7)
jobs = service.jobs(limit=None, created_after=seven_days_ago)

# To retrieve all jobs in a Session or Batch, use the session_id filter
# jobs = service.jobs(session_id="<session id>")

total_usage = 0
for job in jobs:
    total_usage += job.usage()

print(f"{len(jobs)} jobs were submitted in the last 7 days.")
print(f"Total usage was {total_usage} seconds")
```

## אחזור תכונות Backend {#retrieve-backend-properties}

<Tabs>
    <TabItem value="Qiskit" label="אחזור תכונות Backend עם Qiskit">
        תוכל להשתמש ב-`job.properties()` כדי לאחזר תכונות Backend, כולל שיעורי שגיאה, בזמן ביצוע העבודה.

        דוגמה זו מדגימה כיצד לאחזר תכונות Backend שהיו נוכחיות בזמן שעבודה בוצעה, כולל זמני $T_1$/$T_2$ ושיעורי שגיאה עבור קיוביט ספציפי (0).

        

        <Admonition type="note" title="חבילות ספק מיושנות">
            `service.jobs()` גם מחזיר עבודות שהורצו מחבילת `qiskit-ibm-provider` המיושנת. עבודות שהוגשו על ידי חבילת `qiskit-ibmq-provider` הישנה (גם היא מיושנת) אינן זמינות עוד.
        </Admonition>
    </TabItem>
    <TabItem value="IQP" label="אחזור תכונות Backend בפלטפורמת IBM Quantum">
        תוכל לראות נתוני כיול עבור ה-Backend בזמן ביצוע העבודה, כמו גם בזמן יצירתה.
        1. עבור לדף [עומסי העבודה](https://quantum.cloud.ibm.com/workloads)
        2. לחץ על עומס עבודה כדי לפתוח את דף הפרטים שלו
        3. תחת מחשב קוונטי, לחץ על צפה בהיסטוריית כיול
        4. השתמש בתפריט הנפתח כדי לשנות בין צפייה בנתונים "בתחילת ביצוע העבודה" ל-"ביצירת העבודה"
    </TabItem>
</Tabs>

```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()

# Uncomment the next line to retrieve a specific job by ID
# job = service.job("<job_id>")

# Optionally retrieve multiple jobs with filters
# Use `limit` to retrieve a specific number of jobs. The default `limit` is 10.
my_backend = "<your-backend>"
recent_jobs = service.jobs(backend_name=my_backend, limit=10)

print(f"Retrieved {len(recent_jobs)} recent jobs from {my_backend}\n")

# Get results from all jobs
for job in recent_jobs:
    print(f"Job ID: {job.job_id()}")
    print(f"Status: {job.status()}")

    # Retrieve results if the job is complete
    if str(job.status()) == "DONE":
        try:
            results = job.result()
            print(f"Results: {results}")
        except Exception as e:
            print(f"Error retrieving results: {e}")
    else:
        print("Results: Not available (job still running or failed)")
    print()
```

```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()

# Retrieve a specific job by ID
job = service.job("<job_id>")

print(f"Job ID: {job.job_id()}")
print(f"Backend: {job.backend}\n")

# Fetch backend properties at the time of job execution
properties = job.properties()

if properties:
    print("Backend Properties at Job Execution Time:")
    print("=" * 60)

    # Get T1 (relaxation time) for qubit 0
    t1 = properties.t1(0)
    print(f"Qubit 0 T1 (relaxation time): {t1}")

    # Get T2 (dephasing time) for qubit 0
    t2 = properties.t2(0)
    print(f"Qubit 0 T2 (dephasing time): {t2}")

    # Get readout error for qubit 0
    readout_error = properties.readout_error(0)
    print(f"Qubit 0 readout error: {readout_error}")

    # Get all properties for a specific qubit
    print("All properties for qubit 0:")
    qubit_props = properties.qubit_property(0)
    for prop_name, prop_value in qubit_props.items():
        print(f"  {prop_name}: {prop_value}")
else:
    print("No properties available for this job")
```

## ביטול עבודה {#cancel-a-job}

בטל עבודה שנמצאת בתור או פועלת. ברגע שעבודה מבוטלת, לא ניתן להמשיך אותה.

<Tabs>
    <TabItem value="Qiskit" label="ביטול עם Qiskit">
        השתמש בשיטה `job.cancel()` כדי לבטל עבודה באופן תכנותי.

        
    </TabItem>
    <TabItem value="IQP" label="ביטול בפלטפורמת IBM Quantum">
        1. **מטבלת עומסי העבודה**: לחץ על תפריט הגלישה בקצה השורה של עומס העבודה שברצונך לבטל, ובחר **ביטול**.
        2. **מדף פרטי העבודה**: לחץ על עומס העבודה כדי לפתוח את דף הפרטים שלו, השתמש בתפריט הנפתח **פעולות** בראש הדף, ובחר **ביטול**.
    </TabItem>
</Tabs>

```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()

# Retrieve the job
job = service.job("<job_id>")

# Cancel the job
job.cancel()

print(f"Job {job.job_id()} has been canceled")
```
