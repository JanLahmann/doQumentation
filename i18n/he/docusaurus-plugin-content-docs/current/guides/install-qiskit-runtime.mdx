# התקנת לקוח IBM Quantum Compute {#install-the-ibm-quantum-compute-client}

IBM Quantum Compute Service הוא שירות מבוסס ענן להרצת חישובים קוונטיים על חומרת IBM Quantum&reg;. המדריך הזה מראה לך איך להתקין את `qiskit-ibm-runtime`, שהוא חבילת הלקוח לגישה ל-IBM Quantum Compute Service.

לפני שמתקינים את `qiskit-ibm-runtime`, יש לבצע את ההוראות במדריכים הבאים:

1. [התקן את Qiskit](/guides/install-qiskit).

2. [הגדר את חשבון IBM Cloud שלך](cloud-setup).


הרץ את הפקודה הבאה כדי להתקין את לקוח IBM Quantum Compute:

```shell
pip install qiskit-ibm-runtime
```

<Admonition type="note" title="שמור על גרסאות עדכניות">
בדוק מדי פעם את [הערות הגרסה של `qiskit-ibm-runtime`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/release-notes) כדי לראות גרסאות חדשות. אנחנו ממליצים לעדכן את הדרישות של `qiskit-ibm-runtime` לעיתים קרובות על ידי הרצת `pip install -U qiskit-ibm-runtime`.
</Admonition>
