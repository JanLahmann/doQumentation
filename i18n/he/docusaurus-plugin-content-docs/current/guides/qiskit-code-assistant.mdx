# Qiskit Code Assistant {#qiskit-code-assistant}

מודלי ה-LLM של Qiskit Code Assistant שואפים להפוך את המחשוב הקוונטי לנגיש יותר למאמצים חדשים של Qiskit ולשפר את חוויית הקידוד עבור משתמשים קיימים. הוא מאומן באמצעות מיליוני אסימוני טקסט מ-SDK של Qiskit, שנים של דוגמאות קוד Qiskit, ותכונות IBM Quantum&reg;. Qiskit Code Assistant יכול לסייע בתהליך פיתוח הקוד הקוונטי שלך על ידי הצעת הצעות שנוצרו על ידי LLM המבוססות על [IBM Granite ומודלי קוד פתוח אחרים](https://huggingface.co/Qiskit) הכוללות את התכונות והפונקציונליות העדכניות ביותר מ-IBM&reg;.

<Admonition type="note" title="הערות">
- **רוצה לדלג ישירות להוראות ההתקנה? עבור לסעיף [התקנת Qiskit Code Assistant](#install).**
- אם יש לך משוב או שתרצה לפנות לצוות המפתחים, השתמש ב[ערוץ Qiskit Slack Workspace](https://qiskit.enterprise.slack.com/archives/C07LYA6PL83) או במאגרי GitHub הציבוריים הרלוונטיים.
</Admonition>

## מודל השפה הגדול (LLM) מאחורי Qiskit Code Assistant {#the-large-language-model-llm-behind-qiskit-code-assistant}

כדי לספק הצעות קוד, Qiskit Code Assistant משתמש במודל שפה גדול (LLM). במקרה זה, Qiskit Code Assistant מסתמך כרגע על המודל `mistral-small-3.2-24b-qiskit`, הבנוי על [מודל Mistral-Small-3.2-24B-Qiskit](https://huggingface.co/Qiskit/mistral-small-3.2-24b-qiskit). המודל `mistral-small-3.2-24b-qiskit` משפר את יכולות יצירת הקוד של מודל `Mistral-Small-3.2-24B-Instruct-2506` עבור Qiskit באמצעות אימון מקדים מורחב וכוונון עדין על נתוני Qiskit באיכות גבוהה, כמו גם commit-ים של Python ושיחות. למידע נוסף על משפחת מודלי Mistral AI, ראה ב[תיעוד Mistral AI](https://docs.mistral.ai/getting-started/models). לפרטים נוספים על מודלי `.*-qiskit`, ראה [Qiskit Code Assistant: Training LLMs for generating Quantum Computing Code](https://arxiv.org/abs/2405.19495).

ה-LLMs המתמחים שלנו ב-Qiskit זמינים גם כמודלים בקוד פתוח. בדוק את כל המודלים הזמינים בכתובת https://huggingface.co/Qiskit.

## ה-Benchmarks של Qiskit HumanEval ו-Qiskit HumanEval Hard {#the-qiskit-humaneval-and-qiskit-humaneval-hard-benchmarks}

כדי לבדוק את `mistral-small-3.2-24b-qiskit` ומודלים אחרים, שיתפנו פעולה עם Advocates ומומחים של Qiskit ליצירת ה-benchmarks המבוססים על ביצוע בשם Qiskit HumanEval (QHE) ו-Qiskit HumanEval Hard (QHE Hard), והרצנו אותם על המודלים. ה-benchmarks הללו דומים ל-[HumanEval](https://arxiv.org/abs/2107.03374), כולל מספר בעיות קוד מאתגרות לפתרון, כולן מבוססות על ספריות Qiskit הרשמיות.

ה-benchmarks מורכבים מכ-150 בדיקות, כל אחת עשויה מהגדרת פונקציה, ואחריה docstring המפרט את המשימה שהמודל נדרש לפתור. כל דוגמה כוללת גם פתרון קנוני ייחוסי, וכן בדיקות יחידה, להערכת נכונות הפתרונות שנוצרו. ישנן שלוש רמות קושי לבדיקות: בסיסי, ביניים וקשה. ה-benchmark של Qiskit HumanEval Hard הוא וריאציה של זה של Qiskit HumanEval, אך מסיר מידע הקשור ל-import של קוד, כך שה-LLM צריך להבין את ה-import הנכון של המתודה או המחלקה. שינוי זה הופך את מערך הנתונים לאתגרתי הרבה יותר עבור LLMs, לפי הבדיקות והתוצאות הראשוניות שלנו.

מערכי הנתונים של Qiskit HumanEval ו-Qiskit HumanEval Hard זמינים באתרים הבאים: [Qiskit HumanEval](https://huggingface.co/datasets/Qiskit/qiskit_humaneval) ו-[Qiskit HumanEval](https://huggingface.co/datasets/Qiskit/qiskit_humaneval_hard). ניתן לתרום לפיתוח של ה-benchmarks הללו ב[מאגר GitHub](https://github.com/qiskit-community/qiskit-human-eval).

<AccordionItem title="Manually deploy the Qiskit Code Assistant models in local through Ollama">

ישנן מספר דרכים לפרוס ולקיים אינטראקציה עם מודל Qiskit Code Assistant שהורד. מדריך זה מדגים שימוש ב-[Ollama](https://ollama.com) כדלקמן: באמצעות [אפליקציית Ollama](#using-the-ollama-application) דרך שילוב Hugging Face Hub או מודל מקומי, או עם [חבילת `llama-cpp-python`](#use-llama-cpp-python).

#### שימוש באפליקציית Ollama {#using-the-ollama-application}

אפליקציית Ollama מספקת פתרון פשוט להרצת ה-LLMs מקומית. קל לשימוש, עם CLI שהופך את כל תהליך ההגדרה, ניהול המודלים והאינטראקציה לפשוט למדי. הוא אידיאלי לניסויים מהירים ולמשתמשים שרוצים לטפל בפחות פרטים טכניים.

##### התקנת Ollama {#install-ollama}

1. הורד את [אפליקציית Ollama](https://ollama.com/download)

1. התקן את הקובץ שהורדת

1. הפעל את אפליקציית Ollama המותקנת


    <Admonition type="info">
        האפליקציה פועלת בהצלחה כאשר סמל Ollama מופיע בשורת התפריטים של שולחן העבודה. ניתן גם לאמת שהשירות פועל על ידי גלישה לכתובת `http://localhost:11434/`.
    </Admonition>

1. נסה את Ollama בטרמינל שלך והתחל להריץ מודלים. לדוגמה:


    ```
    ollama run hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit
    ```

##### הגדרת Ollama באמצעות שילוב Hugging Face Hub {#set-up-ollama-using-the-hugging-face-hub-integration}

[שילוב Ollama/Hugging Face Hub](https://huggingface.co/docs/hub/ollama) מספק דרך לקיים אינטראקציה עם מודלים המתארחים ב-Hugging Face Hub מבלי לצורך ליצור modelfile חדש או להוריד ידנית את קבצי GGUF או safetensors. קבצי ה-`template` וה-`params` המוגדרים כברירת מחדל כבר כלולים עבור המודל ב-Hugging Face Hub.

1. ודא שאפליקציית Ollama פועלת.


1. עבור לדף המודל הרצוי והעתק את ה-URL. לדוגמה, https://huggingface.co/Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF.


1. מהטרמינל שלך, הרץ את הפקודה:


    ```
    ollama run hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit
    ```

ניתן להשתמש במודל `hf.co/Qiskit/Qwen2.5-Coder-14B-Qiskit` או בכל אחד מהמודלים הרשמיים GGUF המומלצים הנוכחיים `hf.co/Qiskit/mistral-small-3.2-24b-qiskit-GGUF` או `hf.co/Qiskit/granite-3.3-8b-qiskit-GGUF`.

##### הגדרת Ollama עם מודל GGUF של Qiskit Code Assistant שהורד ידנית {#set-up-ollama-with-a-manually-downloaded-qiskit-code-assistant-gguf-model}

אם הורדת ידנית מודל GGUF כגון https://huggingface.co/Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF ואתה רוצה לנסות תבניות ופרמטרים שונים, ניתן לעקוב אחר השלבים הבאים כדי לטעון אותו לאפליקציית Ollama המקומית שלך.

1. צור `Modelfile` עם התוכן הבא וודא לעדכן את `<PATH-TO-GGUF-FILE>` לנתיב בפועל של המודל שהורדת.


    ```
    FROM <PATH-TO-GGUF-FILE>
    TEMPLATE """{{ if .System }}
    System:
    {{ .System }}

    {{ end }}{{ if .Prompt }}Question:
    {{ .Prompt }}

    {{ end }}Answer:
    ```python{{ .Response }}
    """

    PARAMETER stop "Question:"
    PARAMETER stop "Answer:"
    PARAMETER stop "System:"
    PARAMETER stop "```"

    PARAMETER temperature 0
    PARAMETER top_k 1

    ```

1. הרץ את הפקודה הבאה כדי ליצור מופע מודל מותאם אישית המבוסס על `Modelfile`.


    ```
    ollama create Qwen2.5-Coder-14B-Qiskit -f ./path-to-model-file

    ```

    <Admonition type="note">
        תהליך זה עשוי לקחת זמן עד ש-Ollama יקרא את קובץ המודל, יאתחל את מופע המודל ויגדיר אותו בהתאם למפרט שסופק.
    </Admonition>

##### הרץ את מודל Qiskit Code Assistant שהורדת ידנית ב-Ollama

לאחר שמודל `Qwen2.5-Coder-14B-Qiskit` הוגדר ב-Ollama, הרץ את הפקודה הבאה כדי להפעיל את המודל ולקיים אינטראקציה איתו בטרמינל (במצב שיחה).

```
ollama run Qwen2.5-Coder-14B-Qiskit

```

כמה פקודות שימושיות:

- `ollama list` - הצג רשימת מודלים על המחשב שלך

- `ollama rm Qwen2.5-Coder-14B-Qiskit` - מחק את המודל

- `ollama show Qwen2.5-Coder-14B-Qiskit` - הצג מידע על המודל

- `ollama stop Qwen2.5-Coder-14B-Qiskit` - עצור מודל שרץ כרגע

- `ollama ps` - הצג אילו מודלים טעונים כרגע

<AccordionItem title="פרוס ידנית את מודלי Qiskit Code Assistant מקומית באמצעות חבילת `llama-cpp-python`">

<span id="use-llama-cpp-python"></span>
An alternative to the Ollama application is the `llama-cpp-python` package, which is a Python binding for `llama.cpp`. It gives you more control and flexibility to run the GGUF model locally, and is ideal for users who wish to integrate the local model in their workflows and Python applications.

1. התקן את [`llama-cpp-python`](https://pypi.org/project/llama-cpp-python/)

2. תקשר עם המודל מתוך היישום שלך באמצעות `llama_cpp`. לדוגמה:


```python
from llama_cpp import Llama

model_path = <PATH-TO-GGUF-FILE>

model = Llama(
        model_path,
        seed=17,
        n_ctx=10000,
        n_gpu_layers=37, # to offload in gpu, but put 0 if all in cpu
    )

input = 'Generate a quantum circuit with 2 qubits'
raw_pred = model(input)["choices"][0]["text"]

```

אפשר גם להוסיף פרמטרים ליצירת טקסט למודל כדי להתאים אישית את ההסקה:

```python
generation_kwargs = {
        "max_tokens": 512,
        "echo": False, # Echo the prompt in the output
        "top_k": 1
    }

raw_pred = model(input, **generation_kwargs)["choices"][0]["text"]

```

</AccordionItem>

<AccordionItem title="Manually deploy the Qiskit Code Assistant models in local through llama.cpp">
#### השתמש בספריית `llama.cpp`

אלטרנטיבה נוספת היא להשתמש ב-`llama.cpp`, ספרייה בקוד פתוח לביצוע הסקת LLM על CPU עם הגדרה מינימלית.
היא מספקת שליטה ברמה נמוכה על הרצת המודל ובדרך כלל מריצים אותה משורת הפקודה, תוך הפניה לקובץ מודל GGUF מקומי.

ישנן כמה דרכים להתקין את `llama.cpp` על המחשב שלך:

- התקן את llama.cpp באמצעות [brew, nix, או winget](https://github.com/ggml-org/llama.cpp/blob/master/docs/install.md)

- הרץ עם Docker: ראה את [תיעוד ה-Docker מצוות `llama.cpp`](https://github.com/ggml-org/llama.cpp/blob/master/docs/docker.md)

- הורד קבצים בינאריים מוכנים מראש מ[דף ההוצאות](https://github.com/ggml-org/llama.cpp/releases)

- בנה מהמקור על ידי [שכפול המאגר הזה](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md)


לאחר ההתקנה, תוכל להשתמש ב-`llama.cpp` כדי לתקשר עם מודלי GGUF במצב שיחה כך:
```bash

# Use a local model file {#use-a-local-model-file}
llama-cli -m my_model.gguf -cnv

# Or download and run a model directly from Hugging Face {#or-download-and-run-a-model-directly-from-hugging-face}
llama-cli -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF -cnv

```

אפשר גם להפעיל שרת API תואם OpenAI עבור המודל בדרך הבאה:
```bash
llama-server -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF

```

##### פרמטרים מתקדמים
עם התוכנה `llama-cli`, אפשר לשלוט ביצירת המודל באמצעות אפשרויות שורת פקודה. לדוגמה, אפשר לספק פרומפט התחלתי של "מערכת" באמצעות הדגל `-p/--prompt`. במצב שיחה (`-cnv`), פרומפט התחלתי זה פועל כהודעת המערכת. אחרת, פשוט אפשר להוסיף בתחילת טקסט הפרומפט שלך כל הוראה רצויה. אפשר גם לכוונן פרמטרי דגימה - למשל: טמפרטורה (`--temp`), top-k (`--top-k`), top-p (`--top-p`), עונש חזרתיות (`--repeat-penalty`), והזרע לשימוש (`--seed`). להלן דוגמה להפעלה באמצעות אפשרויות אלו:

```bash
llama-cli -hf Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF \
  -p "You are a friendly assistant." -cnv \
  --temp 0.7 \
  --top-k 50 \
  --top-p 0.95 \
  --repeat-penalty 1.1 \
  --seed 42

```

כדי להבטיח את התפקוד התקין של מודלי Qiskit שלנו, אנו ממליצים להשתמש בפרומפט המערכת שמסופק במאגרי ה-HF GGUF שלנו: פרומפט מערכת עבור [mistral-small-3.2-24b-qiskit-GGUF](https://huggingface.co/Qiskit/mistral-small-3.2-24b-qiskit-GGUF/blob/main/system), [Qwen2.5-Coder-14B-Qiskit-GGUF](https://huggingface.co/Qiskit/Qwen2.5-Coder-14B-Qiskit-GGUF/blob/main/system), [granite-3.3-8b-qiskit-GGUF](https://huggingface.co/Qiskit/granite-3.3-8b-qiskit-GGUF/blob/main/system), ו-[granite-3.2-8b-qiskit-GGUF](https://huggingface.co/Qiskit/granite-3.2-8b-qiskit-GGUF/blob/main/system).

<AccordionItem title="התחבר ידנית ל-Continue (VS Code)">

#### [Continue](https://marketplace.visualstudio.com/items?itemName=Continue.continue) (VS Code)

##### 1. התקן את התוסף

פתח את VS Code, עבור להרחבות (`Cmd+Shift+X`), חפש **Continue**, והתקן אותו.

##### 2. פתח את התצורה

לחץ על סמל Continue בסרגל הצד, ואז לחץ על סמל גלגל השיניים, או פתח את פלטת הפקודות (`Cmd+Shift+P`) והרץ **Continue: Open Config File**.

פעולה זו פותחת את `~/.continue/config.yaml` (או `config.json` בגרסאות ישנות יותר).

##### 3. הגדר את המודל

הוסף את הבא ל-`config.yaml`:

```yaml
models:
  - name: Qiskit Code Assistant
    provider: ollama
    model: mistral-small-3.2-24b-qiskit
    apiBase: http://localhost:11434

```

פעולה זו הופכת את מודל Qiskit לזמין ב**פאנל הצ'אט** (שיחות בסרגל הצד, שאלות ותשובות מוטבעות) ולפקודות **עריכה מוטבעת**.

##### 4. Test it

- **צ'אט:** פתח את פאנל Continue בסרגל הצד ושאל שאלה (למשל, "איך אני יוצר מעגל פרמטרי ב-Qiskit?")

- **עריכה מוטבעת:** בחר בלוק קוד, לחץ `Cmd+I` (Mac) או `Ctrl+I` (Linux/Windows)

  
  
  
  
  
</AccordionItem>

<AccordionItem title="התחבר ידנית ל-Jupyter AI (JupyterLab)">

#### [Jupyter AI](https://jupyter-ai.readthedocs.io/en/v3/index.html) (JupyterLab)

**הערה:** הוראות אלו מכסות את Jupyter AI v2.x.

##### 1. התקן את Jupyter AI ואת ספק Ollama

```bash
pip install "jupyter-ai<3" langchain-ollama

```

ה-pin `"jupyter-ai<3"` מבטיח שתקבל v2.x. חבילת `langchain-ollama` נדרשת כדי ש-Jupyter AI יזהה את Ollama כספק. בלעדיה, Ollama לא יופיע בפאנל ההגדרות.

לאחר מכן הפעל מחדש את JupyterLab.

##### 2. הגדר את מודל הצ'אט

פתח את JupyterLab ולחץ על **סמל הצ'אט** בסרגל הצד השמאלי. בפאנל ההגדרות:

1. תחת **Language model**, בחר ב-**Ollama** כספק.

2. הזן `mistral-small-3.2-24b-qiskit` כשם המודל.

3. אין צורך במפתח API עבור Ollama (השאר את השדה ריק).

4. לחץ על חץ החזרה כדי להתחיל בשיחה.


##### 3. השתמש בפקודת הקסם `%%ai`

פקודת הקסם `%%ai` מאפשרת לך לשאול את המודל ישירות בתאי המחברת.

```python
%load_ext jupyter_ai_magics

```

ואז בתא:

```python
%%ai ollama:mistral-small-3.2-24b-qiskit
Write a function that implements Grover's algorithm using Qiskit

```

##### 4. מארח Ollama מותאם אישית (אופציונלי)

כברירת מחדל, Jupyter AI מתחבר ל-`http://127.0.0.1:11434`. אם שרת ה-Ollama שלך רץ בכתובת או יציאה אחרת:

**בממשק הצ'אט:** הגדר את השדה "Base API URL" בפאנל הגדרות ה-AI.

</AccordionItem>

<AccordionItem title="התחבר ידנית ל-OpenCode (Terminal)">

#### [OpenCode](https://opencode.ai/) (Terminal)

##### 1. התקן את OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash

```

##### 2. הגדר את מודל Qiskit

צור קובץ `opencode.json` בשורש הפרויקט שלך (או `~/.config/opencode/opencode.json` עבור תצורה גלובלית):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": {
        "baseURL": "http://localhost:11434/v1"
      },
      "models": {
        "mistral-small-3.2-24b-qiskit": {
          "name": "Qiskit Code Assistant"
        }
      }
    }
  }
}

```

##### 3. בחר את המודל

הפעל את OpenCode בספריית הפרויקט שלך:

```bash
opencode

```

בתוך ה-TUI, הרץ את הפקודה `/models` ובחר ב-**Qiskit Code Assistant** מהרשימה.

##### 4. Test it

שאל שאלה ישירות בצ'אט, לדוגמה: "הגדר מעגל בל והרץ אותו באמצעות QiskitRuntimeService"
