## רקע {#background}

מדריך זה מדגים כיצד ליישם את אלגוריתם האלכסון הקוונטי קרילוב (KQD) בהקשר של תבניות Qiskit. תחילה תלמד את התיאוריה מאחורי האלגוריתם ולאחר מכן תראה הדגמה של ביצועו על QPU.

הערכת התכונות באנרגיה נמוכה של המילטוניאנים מרובי-גופים היא משימה מרכזית בסימולציה קוונטית.
לדוגמה, אנרגיות מצב יסוד והתעוררויות נמוכות קשורות ישירות ליציבות כימית, סדר מגנטי, מעברי פאזה קוונטיים, ותגובת החומר.
במחשב קלאסי, ממד מרחב הילברט גדל באופן אקספוננציאלי עם מספר האורביטלים או הספינים, כך שאלכסון ישיר הופך במהירות ללא מעשי.

קיימות מספר גישות מחשוב קוונטי לבעיה זו.
שיטות וריאציוניות לטווח קרוב, כגון [פותר הערכים העצמיים הוריאציוני הקוונטי (VQE)](/tutorials/spin-chain-vqe), משתמשות ב-Circuits פרמטריים רדודים יחסית, אך הן דורשות לולאת אופטימיזציה קלאסית לא-לינארית עם הערכות Circuit קוונטי רבות.
בקצה השני, [הערכת פאזה קוונטית (QPE)](https://arxiv.org/abs/quant-ph/0604193) מספקת דרך ישירה יותר להערכת ערכים עצמיים עם הבטחות קפדניות, אך QPE הסטנדרטי דורש Circuits קוהרנטיים ארוכים ומתאים בעיקר למחשבים קוונטיים סובלניים לתקלות.
KQD ממוקם בין שתי הגישות הללו: הוא משתמש באבולוציית המילטוניאן בזמן אמת, כמו באלגוריתמים מבוססי הערכת פאזה, אך מחליף הערכת פאזה מלאה בבעיית ערכים עצמיים מוקרנת קומפקטית שניתן לפתור באופן קלאסי.

נתבונן בהמילטוניאן $H$ בן $n$ Qubit ובמצב ייחוס $\lvert \psi_{0}\rangle$.
שיטת KQD בונה תת-מרחב קרילוב ממצבים שהתפתחו בזמן אמת,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

כאשר $r$ הוא ממד קרילוב ו-$\Delta t$ הוא צעד הזמן.
כל מצב בתת-מרחב קרילוב מיוצג אז כצירוף לינארי של מצבי הבסיס הללו,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
where the denominator normalizes the state.

באמצעות אלגברה פשוטה, אנו יכולים לראות שהאנרגיה המתאימה נכתבת כמנת ריילי (Rayleigh quotient),

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

כאן, המטריצות $\mathcal{S}$ ו-$\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

מגדירות את מטריצות החפיפה וההמילטוניאן המוקרנות.
הערכים שלהן מוערכים באמצעות מדידות Circuit קוונטי.

אנו שואפים למצוא את המקדם $\mathbf{c}$ שנותן את המינימום של $E(\mathbf{c})$:

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

לפי משפט ריילי-ריץ (Rayleigh-Ritz), מזעור זה שקול לפתרון בעיית הערכים העצמיים המוכללת (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

שים לב שהממד $r$ יכול להיות קטן מספיק כדי שמחשב קלאסי יוכל לפתור את ה-GEVP.

זהו אותו עקרון וריאציוני המשמש באלכסון תת-מרחב קלאסי, אך כאן מצבי הבסיס נוצרים על ידי אבולוציית זמן קוונטית.
בהשוואה ל-VQE, KQD בדרך כלל דורש Circuits עמוקים יותר מכיוון שהוא מסתמך על אבולוציה בזמן אמת.
בתמורה, KQD נמנע מאופטימיזציית פרמטרים לא-לינארית וביצוע איטרטיבי על חומרה קוונטית, והוא משתפר באופן שיטתי ככל שתת-המרחב המוקרן מוגדל.
האלגוריתם הודגם בקנה מידה גדול על חומרה קוונטית קיימת [\[2\]](#references), וניתן לנתח את הביצועים שלו עם הבטחות ניתנות להוכחה [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.primitives import StatevectorEstimator
from qiskit.quantum_info import Operator, SparsePauliOp
from qiskit.synthesis import LieTrotter, SuzukiTrotter
from qiskit.transpiler import PassManager, Layout
from qiskit.transpiler.passes import CommutativeOptimization
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### הגדרת פרמטרים לאלגוריתם {#set-the-parameters-for-the-algorithm}

בהתבסס על הגבולות העליונים על נורמת ההמילטוניאן, מקור [\[1\]](#references) מציע באופן היוריסטי את צעד הזמן $\Delta t$ כ-$\pi/\|H\|$.
מכיוון שקשה לחשב את הנורמה הספקטרלית $\|H\|$, אנו משתמשים במקום זאת בגבול העליון שלה:

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ matrix, easy to calculate the norm}} = 3(n-1).
\end{equation*}
$$

אנו קובעים את ממד קרילוב ל-$r=10$ ואת מספר צעדי Trotter לכל צעד זמן ל-$5$: מרחב קרילוב גדול מספיק כדי לפתור את הספקטרום הנמוך תוך שמירה על ה-Circuit העמוק ביותר ($t_{\max}=(r-1)\Delta t$) במחיר סביר, ומספיק צעדי Trotter כדי לשמור על שגיאת הדיסקרטיזציה קטנה באותו Circuit עמוק ביותר.

#### בניית Circuit {#build-circuit}

כאן, אנו בונים את ה-Circuits להערכת איברי המטריצה $\mathcal{H}_{k\ell}$ ו-$\mathcal{S}_{k\ell}$.
מכיוון שכל החזקות של $H$ מתחלפות (commute), יש לנו
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Such matrices where the elements depend on the index differences in this manner are called *Toeplitz* and can be reconstructed from first-row elements indexed by $d=\ell-k$.

כאן, אנו מציגים את ה-Circuit, הנקרא **extended-swap-test**, שמכין
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
כאשר $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$.

#### Circuit של extended swap test [\[3\]](#references) {#extended-swap-test-circuit-3references}

ה-Circuit תחילה מכין את מצב הייחוס על רגיסטר המערכת בעוד האנסילה (ancilla) נשארת ב-$|0\rangle$:

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

לאחר מכן, הפעלת Gate של הדמר (Hadamard) על האנסילה יוצרת סופרפוזיציה קוהרנטית של שני ענפים:

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

לבסוף, ה-Gate של אבולוציית הזמן המבוקרת מפעיל:

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

רק כאשר האנסילה נמצאת בענף $|1\rangle$. לכן,

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

בבלוק הקוד הבא, אנו מיישמים:
$$
\begin{equation*}
|\Psi(t)\rangle = \frac{|0\rangle|\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}},
\end{equation*}
$$
אשר יוקצה כ-$t=d\Delta t$ עבור $d=1,\cdots r-1$ בשלב הביצוע.

#### אובזרבלים {#observables}

עבור כל אובזרבל הרמיטי של המערכת $O$, כאן אנו קובעים את האובזרבלים לחישוב:

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

זאת מכיוון ש-$O=I$ נותן את איבר החפיפה $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$, בעוד ש-$O=H$ נותן את איבר ההמילטוניאן $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$.

באמצעות $X=|0\rangle\langle 1|+|1\rangle\langle 0|$, יש לנו

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

באופן דומה, באמצעות $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

לכן, יש לנו
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

לבסוף, עבור כל מצב $|\Psi_{0d}\rangle$, עלינו למדוד:
$$
\begin{align*}
X \otimes I \text{ עבור } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ עבור } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ עבור } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ עבור } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

עבור הערכת איברי המטריצה $\mathcal{H}$, מספר איברי פאולי גדול הרבה יותר מזה של איברי המטריצה $\mathcal{S}$.

כעת אנו יכולים להפחית את מספר איברי ההמילטוניאן הנמדדים באמצעות טכניקת הזזה (shifting) [\[4\]](#references).
אנו מפצלים את ההמילטוניאן כך:

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

כאשר $T$ נבחר כך שמצב הייחוס הוא הווקטור העצמי שלו,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Then,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Here,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

הוא איבר המטריצה של ההמילטוניאן המוזז.
לכן, עלינו למדוד רק את $X\otimes (H-T)$ ו-$Y\otimes (H-T)$.
התרומה מ-$T$ משוחזרת באופן קלאסי באמצעות איבר מטריצת החפיפה שכבר נמדד $\mathcal{S}_{0d}$.

בדוגמה זו, בחירה טבעית היא החלק האלכסוני של המילטוניאן הייזנברג,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

מכיוון שמצב הייחוס הוא מצב בסיס חישובי, הוא וקטור עצמי של כל איבר $Z_iZ_{i+1}$.

עם זאת, בחירה מועילה יותר היא לכלול לא רק את איברי $ZZ$ האלכסוניים, אלא גם את איברי $XX+YY$ שמאפסים (annihilate) את מצב הייחוס.

עבור כל זוג שכנים, האופרטור $XX+YY$ מקיים

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

and

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

לכן, איבר $XX+YY$ תורם רק כאשר לשני ה-Qubit השכנים יש אכלוסים שונים במחרוזת הביטים של הייחוס. אם שני ה-Qubit הם שניהם $0$ או שניהם $1$, האיבר מאפס את מצב הייחוס וניתן גם להזיז אותו החוצה.

נהיה $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, כאשר $z_i \in \{0,1\}$.
לכן, אנו יכולים לבחור
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

אופרטור זה עדיין מקיים

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

מכיוון שאיברי $ZZ$ פועלים באופן אלכסוני על $|\psi_0\rangle$, בעוד שאיברי $XX+YY$ המוזזים נותנים אפס.
הערך העצמי המתאים נקבע אם כן רק על ידי איברי $ZZ$,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

עם בחירה זו, ההמילטוניאן המוזז הופך ל:
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

כתוצאה מכך, רק הקשתות (edges) עם אכלוסים שונים במצב הייחוס צריכות להימדד.
כל איברי $ZZ$ וכל איברי $XX+YY$ הלא-פעילים משוחזרים דרך תרומת החפיפה $\tau \mathcal{S}_{0d}$, או נותנים תרומה אפסית מעצם הבנייה.

זה נותן אובזרבל קטן יותר מהזזת החלק האלכסוני בלבד.
בפרט, עבור מצב ייחוס בבסיס חישובי עם התעוררות ממוקמת, רק הקשתות הסמוכות להתעוררות נשארות ב-$H-T$.
לכן, ניתן להפחית משמעותית את מספר איברי פאולי ב-$X\otimes(H-T)$ וב-$Y\otimes(H-T)$, בעוד שאיבר המטריצה המשוחזר
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

נשאר בדיוק זהה.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau

obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, shift_tau = (
    make_reduced_heisenberg_observables(ref_bitstring)
)

print("Observable: Re shifted H_0d")
print(obs_x_shifted_hamiltonian)
print()

print("Observable: Im shifted H_0d")
print(obs_y_shifted_hamiltonian)
print()

print("tau =", shift_tau)

]

    "Im shifted H_0d",
]
```

### שלב 2: אופטימיזציה של הבעיה לביצוע על חומרה קוונטית {#step-2-optimize-problem-for-quantum-hardware-execution}

#### השוואת סידור איברי ההמילטוניאן {#compare-hamiltonian-term-ordering}

ראשית, אנו משווים סידורים שונים של איברי פאולי בהמילטוניאן הייזנברג עבור סימולציית ההמילטוניאן.
ההמילטוניאן עצמו אינו משתנה, אך הסידור משפיע על אופן היצירה של Circuit נוסחת המכפלה (product-formula) ועד כמה ניתן להריץ את המבנה במקביל ב-Circuit.
לדוגמה, הסידור הנאיבי מפרט את כל איברי $XX$ של השכנים הקרובים ביותר, ואז את כל איברי $YY$, ואז את כל איברי $ZZ$.
זה ממקם קשתות סמוכות כמו $(0,1)$ ו-$(1,2)$ זו לצד זו, כך שלא ניתן להריץ אותן במקביל.
הסידור זוגי-ואז-אי-זוגי (even-then-odd) מבקר תחילה בקשתות זוגיות זרות, ולאחר מכן בקשתות אי-זוגיות, מה שחושף שכבות דו-Qubit מקבילות.
הסידור המקובץ-לפי-קשתות זוגי-אי-זוגי הולך צעד אחד קדימה: עבור כל קשת, הוא שומר את איברי $XX$, $YY$ ו-$ZZ$ המקומיים יחד, תוך שהוא עדיין מבקר בקשתות זוגיות לפני קשתות אי-זוגיות.
אנו מצפים שהסידורים זוגי-ואז-אי-זוגי והמקובץ-לפי-קשתות זוגי-אי-זוגי יפחיתו את עומק ה-Circuit על ידי חשיפת שכבות דו-Qubit מקבילות, ושהסידור המקובץ-לפי-קשתות יפחית בנוסף את שגיאת Trotter מכיוון שהאינטראקציה הדו-Qubit המקומית על אותה קשת מטופלת כבלוק קומפקטי.

![Pauli evolutions with different term ordering](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

סידור ההמילטוניאן משפיע גם על שגיאת Trotter.
אם אנו ממקמים איברים שאינם מתחלפים (noncommuting) זה לצד זה, מעברי הבסיס מתרחשים לעיתים קרובות יותר, מה שגורם ליותר שגיאת Trotter.
על ידי קיבוץ איברים הדורשים את אותה טרנספורמציית בסיס-פאולי, ניתן להימנע משינויי בסיס מיותרים.

כאן, ההשוואה משתמשת בזמן האבולוציה הגדול ביותר שמופיע בהערכות קרילוב של השורה הראשונה,
$t_{\max} = (r-1)\Delta t,$
תוך שימוש באותו תנאי טרנספילציה (transpilation).

על מנת למדוד את שגיאת Trotter, אנו משתמשים ב-**אי-נאמנות תהליך** (process infidelity) בין ה-Circuit המבוסס-Trotter (Trotterized) לבין אבולוציית ההמילטוניאן המדויקת,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
where $d=2^n$ is the dimension of the Hilbert space.

אבחון זה משתמש במטריצות צפופות, ולכן הוא מתאים לדוגמה הקטנה הזו בת 12 Qubit אך אינו מיועד כתת-שגרה הניתנת להרחבה.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

def build_numeric_evolution_circuit(
    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:
    """Build a numeric circuit for exp(-i H t) with a chosen synthesis rule."""
    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

print("Precomputing the exact evolution operator... ", end="")
exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### הסרת שער אבולוציית הזמן המבוקר {#remove-the-controlled-time-evolution-gate}

במבחן ה-swap המורחב, שליטה על אבולוציית הזמן באמצעות קיוביט עזר (ancilla) בודד דורשת מהעזר לשלוט בשערים רבים ברחבי המערכת.
זה יכול להוביל לתקורת ניתוב משמעותית, ובמקרה הגרוע ביותר לדרוש בפועל קישוריות של כולם-לאחד.
כדי להימנע מכך, ניתן לבצע אופטימיזציה נוספת על ידי החלפת שער אבולוציית הזמן המבוקר בגרסה חופשית משליטה, תוך ניצול הסימטריה של ההמילטוניאן.
בואו נסתכל על המעגל הבא.

![circuit optimization](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

כאן, $B_{\rm ref}$ מכין את מצב הייחוס, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

במקום להכין תחילה את $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$ ולאחר מכן להפעיל $U(t)$ רק על ענף $|1\rangle$, המעגל מכין ישירות את שני הענפים כך

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

where

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

המעגל מפעיל תחילה שער Hadamard על העזר ומכין את מצב הייחוס רק על ענף $|1\rangle$:

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

לאחר מכן מפעילים את אופרטור אבולוציית הזמן הלא-מבוקר על שני הענפים:

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

מכיוון שההמילטוניאן משמר את מספר העירור, אנחנו יכולים לראות ש-$|0^n\rangle$ הוא מצב עצמי שלו, ולכן
אופרטור האבולוציה רק צובר פאזה תחת ההמילטוניאן:
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Therefore,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

לאחר מכן, $B_{\rm ref}$ מופעל רק על ענף $|0\rangle$.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

בשלב זה, לשני הענפים יש פאזה יחסית נוספת. כדי להסיר אותה, אנחנו מפעילים את שער הפאזה של העזר

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

זה משנה את המצב ל-

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

לכן, עד לפאזה גלובלית לא רלוונטית, הכנו לבסוף

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

בבלוק הקוד הבא, אנחנו מיישמים את המעגל החופשי-משליטה הזה.


### שלב 4: עיבוד לאחר והחזרת תוצאה בפורמט קלאסי רצוי {#step-4-post-process-and-return-result-in-desired-classical-format}
לאחר הערכת המטריצות המוקרנות, אנחנו מרגלרזים ופותרים את ה-GEVP
$$
\begin{equation*}

\end{equation*}
$$
הערך העצמי המוכלל הקטן ביותר נותן את הערכת KQD לאנרגיית מצב היסוד.

```python
            options=large_estimator_options,
        )
        # Krylov quantum diagonalization of lattice Hamiltonians -> TUT_KQDOLH.
        large_estimator.options.environment.job_tags = ["TUT_KQDOLH"]

        for d in large_d_values:
            parameter_values = [d * large_dt]
            pubs_for_d = [
                (large_isa_circuit, observable, parameter_values)
                for observable in large_isa_observables
            ]
            job = large_estimator.run(pubs_for_d)
            large_jobs.append(job)
            print(
                f"Submitted d={d}: job_id={job.job_id()}, "

    d: job.job_id() for d, job in zip(large_d_values, large_jobs)
}

# Post-process the quantum results and solve the classical GEVP.
# Reconstruct the first rows of S and the shifted Hamiltonian matrix.
large_s_row_est = np.zeros(large_krylov_dim, dtype=complex)
large_h_shifted_row_est = np.zeros(large_krylov_dim, dtype=complex)
large_s_row_est[0] = 1.0
large_h_shifted_row_est[0] = large_ref_energy - large_shift_tau

        )

        np.asarray(pub_result.data.evs).reshape(-1)[0]
        for pub_result in job_result
    ]

    large_s_row_est[d] = expectation_values[0] + 1j * expectation_values[1]
    large_h_shifted_row_est[d] = (
        expectation_values[2] + 1j * expectation_values[3]

large_h_row_est = large_h_shifted_row_est + large_shift_tau * large_s_row_est

    large_s_row_est.conj(),
    large_s_row_est,
)
large_h_matrix_est = la.toeplitz(
    large_h_row_est.conj(),
    large_h_row_est,
)
```

## נספח: נקודת המבט של פונקציית-ההמילטוניאן (מסנן-ספקטרלי) {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

זרימת העבודה העיקרית הציגה את KQD באופן אופרטיבי: לבנות בסיס קרילוב ממצבים שעברו אבולוציית זמן-אמת, להעריך את המטריצות המוקרנות $\mathcal{H}$ ו-$\mathcal{S}$, ולפתור את ה-GEVP.
הנספח הזה חוזר אל *אותו* חישוב מזווית משלימה שמסבירה **מדוע** KQD עובד: נקודת המבט של *פונקציית-ההמילטוניאן*, או *מסנן-ספקטרלי* [\[3\]](#references), [\[5\]](#references).
הוא משתמש שוב במודל בן 12 הקיוביטים, בצעד הזמן $\Delta t$, ובפתרון קרילוב שכבר התקבל למעלה; לא נדרשת הרצת מעגל חדשה.

### מצב הייחוס כהתפלגות אנרגיה {#the-reference-state-as-an-energy-distribution}

נניח שלהמילטוניאן יש את הפירוק העצמי

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

עם מצבים עצמיים של אנרגיה $|E_m\rangle$.
כל מצב ייחוס אפשר להרחיב בבסיס העצמי הזה,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

כך שהוא נושא **משקל ספקטרלי** $p_m=|a_m|^2$ בכל אנרגיה $E_m$.
אנרגיית הייחוס היא הממוצע של ההתפלגות הזו, $\langle H\rangle_{0}=\sum_m p_m E_m$.

הפירוק העצמי של המילטוניאן כללי בן $n$ קיוביטים יקר באופן אקספוננציאלי, כך שתמונה זו היא רק כלי אבחון, שהוא *לא* חלק מהאלגוריתם.
כאן, לעומת זאת, אנחנו יכולים לחשב אותה בזול עבור *אותה* בעיה עם $n=12$: המילטוניאן הייזנברג משמר את מספר העירור הכולל, ומצב הייחוס $|000001000000\rangle$ נושא עירור בודד, כך שכל התוכן הספקטרלי שלו חי בתת-המרחב של עירור בודד שהממד שלו גדל באופן ליניארי בלבד עם $n$.
לכן אנחנו משתמשים שוב בבלוק העירור-הבודד המדויק (שכבר שימש למעלה כמדד השוואה) וקוראים את התפלגות הייחוס $\{(E_m, p_m)\}$ בתוך תת-המרחב הזה.

```python
# Exact single-excitation-subspace decomposition of the reference state.
# This reuses make_heisenberg_hamiltonian / _basis_state_transition_amplitude_sparse
# and the n=12 `hamiltonian` and `ref_bitstring` defined in the small-scale example.
single_excitation_states = [1 << k for k in range(num_qubits)]

h_single = np.array(
    [
        [
            _basis_state_transition_amplitude_sparse(hamiltonian, bra, ket)
            for ket in single_excitation_states
        ]
        for bra in single_excitation_states
    ]
)
h_single = 0.5 * (h_single + h_single.conj().T)

subspace_evals, subspace_evecs = la.eigh(h_single)
subspace_evals = np.real(subspace_evals)

# Reference-state coordinates inside the single-excitation subspace.
ref_position = single_excitation_states.index(int(ref_bitstring, 2))
ref_in_subspace = np.zeros(num_qubits, dtype=complex)
ref_in_subspace[ref_position] = 1.0

# Amplitudes and spectral weights of the reference in the energy eigenbasis.
ref_eigen_amplitudes = subspace_evecs.conj().T @ ref_in_subspace
ref_spectral_weights = np.abs(ref_eigen_amplitudes) ** 2

print(f"Single-excitation subspace dimension: {num_qubits}")
print(f"Subspace ground-state energy:         {subspace_evals[0]:.6f}")
print(
    f"Reference energy (sum p_m E_m):       {np.sum(ref_spectral_weights * subspace_evals):.6f}"

print(f"Reference weight on subspace ground:  {ref_spectral_weights[0]:.6f}")
```

### KQD לומד מסנן שמעצב מחדש את ההתפלגות הזו {#kqd-learns-a-filter-that-reshapes-this-distribution}

**פונקציית המילטוניאן** $f(H)$ מוגדרת דרך חשבון ספקטרלי,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

או במילים אחרות, סכום משוקלל של מקרינים עצמיים.
הפעלתה על הייחוס מעצבת מחדש כל אמפליטודה ספקטרלית, $a_m \to a_m f(E_m)$:

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

אילו $f$ הייתה ממוקדת בחדות באנרגיה הנמוכה ביותר ($f(E_0)=1$ ו-$f(E_m)\approx 0$ אחרת) אז $f(H)$ הייתה פועלת כמקרין מצב-יסוד, והפלט המנורמל היה (קרוב ל)מצב היסוד.
לכן, **מסנן ספקטרלי** תת-מעבירי טוב באנרגיה הוא בדיוק מה שאנחנו רוצים.

KQD לא קובע מראש את $f$. במקום זאת הוא מרחיב את המסנן בבסיס אבולוציית זמן-האמת,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

פונקציה *טריגונומטרית* של האנרגיה שהמקדמים שלה $\{c_\ell\}$ הם בדיוק וקטור העצמי של ה-GEVP שנפתר למעלה.
מזעור מנת Rayleigh $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ הוא לכן זהה ל*למידת* המסנן שמדכא בצורה הטובה ביותר את המשקל של המצב הנרגש בייחוס.
ממד קרילוב גדול יותר $r$ נותן למסנן יותר דרגות חופש ופסגה חדה יותר באנרגיית מצב היסוד.

הפונקציה העזר להלן מעריכה את המסנן הנלמד הזה על ציר אנרגיה; אנחנו מיישמים אותו לאחר מכן על התפלגות הייחוס שהתקבלה למעלה.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### הגדלת ממד קרילוב: גמישות הפונקציה הנלמדת {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

נזכיר שהמסנן הנלמד הוא פולינום טריגונומטרי באנרגיה עם $r$ מקדמים,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

ממד קרילוב $r$ הוא בדיוק מספר המקדמים החופשיים, ולכן הוא שולט ב**גמישות** של הפונקציה.
$r$ קטן יכול לייצר רק מסנן רחב ומשתנה בעדינות שדולף משקל למצבים נרגשים נמוכים; כאשר $r$ גדל, המסנן יכול ליצור פסגה צרה יותר באנרגיית היעד ולדכא את משקל המצב הנרגש הנותר בצורה אגרסיבית יותר.
זהו המקבילה של מסנן-ספקטרלי להתכנסות האנרגיה שנצפתה בדוגמה בקנה מידה קטן: ככל ש-$r$ גדל, ההתפלגות המסוננת קורסת לתוך מצב היסוד של תת-המרחב והאנרגיה המוערכת יורדת לעברו.

אנחנו משתמשים שוב במטריצות המוקרנות שכבר הוערכו למעלה ופשוט פותרים את ה-GEVP בכל בלוק $r\times r$ מוביל, ולאחר מכן מעריכים ומציירים את המסנן המתאים.
