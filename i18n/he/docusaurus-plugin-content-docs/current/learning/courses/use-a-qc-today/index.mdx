# סקירה כללית {#overview}

!["תמונת Hero"](/learning/images/courses/use-a-qc-today/hero.svg)

ברוכים הבאים ל-*השתמש במחשב קוונטי היום*! בקורס הזה, תתחיל להשתמש במחשב קוונטי ישר מהדלת, ותלמד בדרך את העקרונות הבסיסיים של חישוב קוונטי.

הקורס הזה מיועד לסקרנים ולעסוקים. אין צורך בתואר בפיזיקה או שנים של ניסיון בתכנות. אם אתה יכול לעקוב אחרי notebook וללחוץ "Run," אתה מוכן.

## מבחן {#exam}

כדי להשיג את ה-badge שלך עבור הקורס "שימוש במחשב קוונטי", גש למבחן ב-IBM&reg; Training. מבחן זה נועד להתבצע לאחר קריאת השיעורים בקורס הזה. לאחר שתעבור את המבחן, תקבל הודעה מ-Credly שהשגת badge.
