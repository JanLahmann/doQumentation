# Pasang Qiskit {#install-qiskit}

Sama ada anda bekerja secara tempatan atau dalam persekitaran awan, langkah pertama bagi semua pengguna ialah memasang Qiskit.

<span id="local"></span>

## Pasang Qiskit SDK {#install-the-qiskit-sdk}

1. Pasang Python. Semak bahagian "Programming Language" di [halaman projek Qiskit PyPI](https://pypi.org/project/qiskit/) untuk menentukan versi Python yang disokong oleh keluaran terkini. Untuk arahan muat turun, lihat [Panduan Pemula Python.](https://wiki.python.org/moin/BeginnersGuide/Download)


    Adalah disyorkan supaya kamu menggunakan [persekitaran maya Python](https://docs.python.org/3.10/tutorial/venv.html) untuk mengasingkan Qiskit daripada aplikasi lain.

    <Admonition type="note">
    These instructions use the standard Python distribution from [pypi.org](https://pypi.org/). However, you can use other Python distributions, such as [Anaconda](https://docs.anaconda.com/anaconda/) or [miniconda](https://docs.anaconda.com/miniconda/), along with other dependency management workflows like [Poetry](https://python-poetry.org/docs/).
    </Admonition>

    <Accordion>
    <AccordionItem title="Jika kamu baharu dengan persekitaran maya, klik untuk kembangkan maklumat lanjut.">
    Persekitaran maya Python ialah ruang terasing untuk bekerja dengan Python bagi tujuan tertentu — supaya kamu boleh memasang pakej apa sahaja yang kamu mahu, dan menyediakan pustaka, kebergantungan, dan sebagainya, tanpa menjejaskan persekitaran Python "base" pada mesin kamu.

    Pilih lokasi pilihan untuk menyimpan maklumat tentang persekitaran maya anda. Biasanya ia disimpan dalam direktori bernama `.venv` dalam setiap direktori projek yang anda kerjakan.

    Pilih lokasi pilihan untuk menyimpan maklumat tentang persekitaran maya kamu. Biasanya ia disimpan dalam direktori bernama `.venv` dalam setiap direktori projek yang kamu bekerja di dalamnya.
    </AccordionItem>
    </Accordion>

    Pertama, navigasi ke direktori projek anda dan cipta persekitaran minimal yang hanya mengandungi Python.

        <OperatingSystemTabs>
          <TabItem value="mac" label="macOS">

            ```shell
            python3 -m venv .venv
            ```
          </TabItem>

          <TabItem value="linux" label="Linux">

            ```shell
            python3 -m venv .venv
            ```
          </TabItem>

          <TabItem value="win" label="Windows">

            ```text
            python -m venv .venv
            ```
          </TabItem>
         </OperatingSystemTabs>

    Seterusnya, aktifkan persekitaran baharu anda.

         <OperatingSystemTabs>
           <TabItem value="mac" label="macOS">

             ```shell
             source .venv/bin/activate
             ```
           </TabItem>

           <TabItem value="linux" label="Linux">

             ```shell
             source .venv/bin/activate
             ```
           </TabItem>

           <TabItem value="win" label="Windows">
              Jika menggunakan PowerShell:

             ```text
             .venv\Scripts\Activate.ps1
             ```
             Jika menggunakan Git Bash:

             ```text
             source .venv/scripts/activate
             ```
              Jika menggunakan command prompt:

             ```text
             .venv\Scripts\activate
             ```
           </TabItem>
         </OperatingSystemTabs>

1. [Pasang pip](https://pip.pypa.io/en/stable/installation/) jika ia belum dipasang dalam persekitaran anda. Pip ialah pengurus pakej Python yang anda gunakan untuk memasang Qiskit dan pakej Python lain. Gunakan `pip list` untuk melihat apa yang ada dalam persekitaran maya anda. Dalam kebanyakan persekitaran Python, pip sudah dipasang.


1. Pasang Qiskit SDK.


      ```shell
      pip install qiskit
      ```

      <Admonition type="tip" title="Tambah sokongan visualisasi">
      Jika anda ingin menggunakan fungsi visualisasi atau buku nota Jupyter, pasang juga modul `qiskit.visualization`. Lihat [rujukan API Visualisasi](https://docs.quantum.ibm.com/api/qiskit/visualization) untuk maklumat lanjut.
      </Admonition>

<span id="local-jupyter"></span>
1. Jika anda ingin menjalankan buku nota Jupyter dengan pakej Qiskit yang baru dipasang, anda perlu memasang Jupyter dalam persekitaran anda.

      ```shell
      pip install jupyter
      ```
    Kemudian buka buku nota anda seperti berikut:

      ```shell
      jupyter notebook <path/to/notebook.ipynb>
      ```

Jika anda merancang untuk bekerja secara tempatan dan menggunakan simulator yang dibina dalam Qiskit, maka pemasangan anda sudah selesai. Jika anda ingin menjalankan kerja pada QPU IBM, teruskan ke [sediakan akaun IBM Cloud anda](cloud-setup).

<Admonition type="note" title="Kekal terkini dengan versi terbaharu">
Semak secara berkala [nota keluaran Qiskit](https://docs.quantum.ibm.com/api/qiskit/release-notes) untuk melihat keluaran baharu. Kami mengesyorkan anda kerap mengemaskini keperluan untuk `qiskit` dengan menjalankan `pip install -U qiskit`.
</Admonition>

## Penyelesaian masalah {#troubleshooting}

<Accordion>
<AccordionItem title="`No Module 'qiskit'` error with Jupyter Notebook">
  Jika kamu menggunakan ``pip install qiskit`` dan menyediakan persekitaran maya kamu dalam
  Anaconda, maka kamu mungkin mendapat ralat ``No Module 'qiskit'`` apabila kamu menjalankan tutorial
  dalam Jupyter Notebook. Jika kamu belum memasang Qiskit atau menyediakan
  persekitaran maya kamu, kamu boleh ikut langkah [pemasangan](#qiskit-install).

  Ralat ini disebabkan apabila cuba mengimport pakej Qiskit dalam
  persekitaran di mana Qiskit tidak dipasang. Jika kamu melancarkan Jupyter Notebook
  dari Anaconda-Navigator, berkemungkinan Jupyter Notebook sedang berjalan
  dalam persekitaran base (root), bukannya dalam persekitaran maya
  kamu. Pilih persekitaran maya dalam Anaconda-Navigator dari menu dropdown
  **Applications on**. Dalam menu ini, kamu boleh melihat
  semua persekitaran maya dalam Anaconda, dan kamu boleh
  memilih persekitaran di mana kamu telah memasang Qiskit untuk melancarkan Jupyter
  Notebook.
</AccordionItem>

<AccordionItem title="Compilation errors during installation">
  Qiskit bergantung kepada beberapa pakej Python sumber terbuka lain, yang
  dipasang secara automatik apabila menjalankan ``pip install qiskit``. Bergantung pada
  platform sistem kamu dan versi Python, adalah mungkin bahawa pakej tertentu
  tidak menyediakan binari pra-bina untuk sistem kamu. Kamu boleh rujuk
  kepada [Sokongan sistem pengendalian](#operating-system-support) untuk senarai platform yang disokong oleh Qiskit, sesetengah
  daripadanya mungkin memerlukan kompiler tambahan. Dalam kes di mana tiada
  binari pra-kompil tersedia, ``pip`` akan cuba mengkompil pakej
  dari sumber, yang seterusnya mungkin memerlukan beberapa kebergantungan tambahan yang perlu
  dipasang secara manual.

  Jika output ``pip install qiskit`` mengandungi baris yang serupa dengan:

  ```
  Failed building wheel for SOME_PACKAGE
  ...
  build/temp.linux-x86_64-3.5/_openssl.c:498:30: fatal error
  compilation terminated.
  error: command 'x86_64-linux-gnu-gcc' failed with exit status 1
  ```

  sila semak dokumentasi pakej yang gagal dipasang (dalam
  kod contoh, ``SOME_PACKAGE``) untuk maklumat tentang cara memasang pustaka
  yang diperlukan untuk mengkompil dari sumber.
</AccordionItem>
</Accordion>

## Sokongan sistem pengendalian {#operating-system-support}

Qiskit berusaha untuk menyokong sebanyak mungkin sistem pengendalian, tetapi disebabkan keterbatasan dalam sumber ujian yang tersedia dan ketersediaan sistem pengendalian, tidak semua sistem pengendalian boleh disokong. Sokongan sistem pengendalian untuk Qiskit dibahagikan kepada tiga peringkat dengan tahap sokongan yang berbeza untuk setiap peringkat. Untuk platform di luar ini, seperti FreeBSD atau WebAssembly (WASI), Qiskit mungkin masih boleh dipasang, tetapi ia tidak diuji dan anda perlu membina Qiskit (dan kemungkinan pergantungan Qiskit) dari sumber.

Selain itu, Qiskit hanya menyokong implementasi CPython bahasa Python. Menjalankan dengan penterjemah Python lain seperti PyPy tidak disokong.

### Qiskit v2.x {#qiskit-v2x}

Dalam siri keluaran Qiskit v2.x, platform yang disokong adalah:

<Accordion>
<AccordionItem title="Tier 1">
  Sistem pengendalian Tier 1 diuji sepenuhnya sebagai sebahagian daripada proses pembangunan untuk memastikan sebarang perubahan yang dicadangkan berfungsi dengan betul. Binari pra-kompil dibina, diuji, dan diterbitkan ke PyPI sebagai sebahagian daripada proses keluaran. Biasanya, selagi ada persekitaran Python yang berfungsi dipasang, Qiskit boleh dipasang pada sistem pengendalian ini tanpa perlu memasang kebergantungan lanjut.

  Sistem pengendalian Peringkat 1 diuji sepenuhnya sebagai sebahagian daripada proses pembangunan untuk memastikan sebarang perubahan yang dicadangkan akan berfungsi dengan betul. Binari pra-kompil dibina, diuji, dan diterbitkan ke PyPI sebagai sebahagian daripada proses keluaran. Biasanya, selagi ada persekitaran Python yang berfungsi dipasang, Qiskit boleh dipasang pada sistem pengendalian ini tanpa perlu memasang pergantungan lanjutan.

  - Linux x86_64 (pengedaran yang serasi dengan spesifikasi pembungkusan [manylinux 2014](https://www.python.org/dev/peps/pep-0599/)).

  - Windows 64-bit (Windows 10 dan ke atas disokong)

  - Windows 64-bit (Windows 10 dan ke atas disokong)

  - Linux AArch64 (pengedaran yang serasi dengan spesifikasi pembungkusan [manylinux 2014](https://www.python.org/dev/peps/pep-0599/))
</AccordionItem>
<AccordionItem title="Tier 2">
  Sistem pengendalian Tier 2 tidak diuji sebagai sebahagian daripada proses pembangunan. Walau bagaimanapun, binari pra-kompil dibina, diuji, dan diterbitkan ke PyPI sebagai sebahagian daripada proses keluaran, dan pakej ini boleh dijangka boleh dipasang hanya dengan persekitaran Python yang berfungsi.
  Mungkin terdapat kelewatan dalam mengeluarkan pakej untuk sistem ini, kerana kegagalan ujian mungkin tidak dikesan sehingga jauh kemudian, dan kegagalan semasa penerbitan tidak akan menyekat penerbitan pakej untuk sistem Tier 1.

  Sistem pengendalian Peringkat 2 tidak diuji sebagai sebahagian daripada proses pembangunan. Walau bagaimanapun, binari pra-kompil dibina, diuji, dan diterbitkan ke PyPI sebagai sebahagian daripada proses keluaran, dan pakej ini boleh dijangka dipasang dengan hanya persekitaran Python yang berfungsi.
  Mungkin ada kelewatan dalam mengeluarkan pakej untuk sistem ini, kerana kegagalan ujian mungkin tidak dikesan sehingga jauh kemudian, dan kegagalan semasa penerbitan tidak akan menghalang penerbitan pakej untuk sistem Peringkat 1.

  - macOS x86_64 (10.12 atau lebih baharu)
</AccordionItem>
<AccordionItem title="Tier 3">
  Sistem pengendalian Tier 3 tidak diuji sebagai sebahagian daripada proses pembangunan. Binari pra-kompil dibina dan diterbitkan ke PyPI sebagai sebahagian daripada proses keluaran tetapi tidak diuji. Ia mungkin tidak boleh dipasang hanya dengan persekitaran Python yang berfungsi dan mungkin memerlukan kompiler C/C++ atau program tambahan untuk membina kebergantungan dari sumber sebagai sebahagian daripada proses pemasangan. Sokongan untuk sistem pengendalian ini adalah usaha terbaik sahaja.

  Sistem pengendalian Tier 3:

  - Linux ppc64le (pengedaran yang serasi dengan spesifikasi pembungkusan [manylinux 2014](https://www.python.org/dev/peps/pep-0599/))

  - Linux s390x (pengedaran yang serasi dengan spesifikasi pembungkusan [manylinux 2014](https://www.python.org/dev/peps/pep-0599/))
</AccordionItem>
</Accordion>

Bermula dengan Qiskit v2.0.0, hanya platform 64-bit disokong dan platform 32-bit tidak disokong. Kamu tidak akan dapat membina dari sumber
pada platform 32-bit juga, kerana secara dalaman kod Rust Qiskit mengandaikan lebar penunjuk 64-bit.
