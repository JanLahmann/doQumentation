# Pengenalan kepada primitif IBM Quantum {#introduction-to-ibm-quantum-primitives}

Primitif dicipta untuk memudahkan tugas paling biasa dalam komputer kuantum: iaitu, pensampelan keadaan kuantum dan pengiraan nilai jangkaan. Primitif IBM Quantum pertama ([`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) dan [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)) adalah implementasi kelas asas [primitif](/guides/primitives) Qiskit. Ia menyediakan implementasi yang lebih canggih (contohnya, dengan memasukkan pengurangan ralat) sebagai perkhidmatan berasaskan awan dan digunakan untuk mengakses perkakasan IBM Quantum&reg;.

Primitif IBM Quantum terbaharu, [Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor) (yang berada dalam beta), menyediakan antara muka peringkat lebih rendah yang memberikan lebih ketara dan kawalan tanpa mengorbankan prestasi. 
`Executor` juga mendedahkan **keupayaan tambahan yang tidak ditawarkan oleh Sampler**, seperti kumpulan twirling tambahan dan twirling untuk litar dengan get pecahan. Rujuk [Migrate from Sampler to Executor](/guides/migrate-from-sampler-to-executor) untuk maklumat lanjut tentang sama ada untuk berpindah ke `Executor`.

## Langkah seterusnya {#next-steps}

<Admonition type="tip" title="Cadangan">
- Ketahui tentang [kelas asas primitif](/guides/primitives) yang menjadi asas primitif IBM Quantum.
- Semak contoh terperinci [Estimator](/guides/estimator-examples), [Sampler](/guides/sampler-examples), atau [Executor](/guides/executor-examples).
- Lihat butiran input dan output untuk [Estimator](/guides/estimator-input-output), [Executor](/guides/executor-input-output), dan [Sampler](/guides/sampler-input-output).
- Amalkan penggunaan primitif melalui [pelajaran Fungsi kos](/learning/courses/variational-algorithm-design/cost-functions) dalam IBM Quantum Learning.
- Lihat [rujukan API EstimatorV2](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2), [rujukan API SamplerV2](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2), dan [rujukan API Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor).
</Admonition>
