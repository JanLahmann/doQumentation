## Langkah-langkah untuk menggunakan primitif Sampler {#steps-to-use-the-sampler-primitive}

### 1. Mulakan akaun {#1-initialize-the-account}

Anda perlu memulakan akaun anda terlebih dahulu. Anda kemudian boleh memilih QPU yang ingin anda gunakan untuk mengira nilai jangkaan.

Ikuti langkah-langkah dalam topik [Sediakan akaun IBM Cloud anda](/guides/cloud-setup) jika anda belum menyediakan akaun.

:::note[gate pecahan]


Untuk menggunakan [gate pecahan](/guides/fractional-gates) yang baru disokong, tetapkan `use_fractional_gates=True` apabila meminta Backend dari instans `QiskitRuntimeService`. Contohnya:

```python
service = QiskitRuntimeService()
fractional_gate_backend = service.least_busy(use_fractional_gates=True)
```

Ini adalah ciri eksperimen dan mungkin berubah pada masa depan.

:::


```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()
backend = service.least_busy(
    operational=True, simulator=False, min_num_qubits=127
)
```

### 2. Cipta Circuit {#2-create-a-circuit}

Anda memerlukan sekurang-kurangnya satu Circuit sebagai input kepada primitif Sampler.

```python
import numpy as np
from qiskit.circuit.library import efficient_su2

circuit = efficient_su2(127, entanglement="linear")
circuit.measure_all()
# The circuit is parametrized, so we will define the parameter values for execution
param_values = np.random.rand(circuit.num_parameters)
```

Circuit dan observable perlu ditransformasi untuk hanya menggunakan arahan yang disokong oleh QPU (dirujuk sebagai Circuit *set seni bina arahan (ISA)*). Gunakan Transpiler untuk melakukan ini.

```python
from qiskit.transpiler import generate_preset_pass_manager

pm = generate_preset_pass_manager(optimization_level=1, backend=backend)
isa_circuit = pm.run(circuit)
print(f">>> Circuit ops (ISA): {isa_circuit.count_ops()}")
```

```text
>>> Circuit ops (ISA): OrderedDict([('rz', 3036), ('sx', 1769), ('cz', 378), ('measure', 127), ('barrier', 1)])
```

### 3. Mulakan IBM Quantum Sampler {#3-initialize-the-ibm-quantum-sampler}

Apabila anda memulakan Sampler, gunakan parameter `mode` untuk menentukan mod yang anda mahu ia jalankan. Nilai yang mungkin adalah objek `batch`, `session`, atau `backend` untuk mod pelaksanaan kumpulan, session, dan kerja masing-masing. Untuk maklumat lanjut, lihat [Pengenalan kepada mod pelaksanaan IBM Quantum Compute Service](/guides/execution-modes). Perhatikan bahawa pengguna Pelan Terbuka tidak boleh menghantar kerja session.

```python
from qiskit_ibm_runtime import SamplerV2 as Sampler

sampler = Sampler(mode=backend)
```

### 4. Panggil Sampler dan dapatkan keputusan {#4-invoke-sampler-and-get-results}

Seterusnya, panggil kaedah `run()` untuk menjana output. Circuit dan set nilai parameter pilihan dimasukkan sebagai tupel *blok bersatu primitif* (PUB).

```python
job = sampler.run([(isa_circuit, param_values)])
print(f">>> Job ID: {job.job_id()}")
print(f">>> Job Status: {job.status()}")
```

```text
>>> Job ID: dab7lb6rrl7c7386gjgg
```

```text
>>> Job Status: QUEUED
```

```python
result = job.result()

# Get results for the first (and only) PUB
pub_result = result[0]
print(
    f"First ten results for the 'meas' output register: "
    f"{pub_result.data.meas.get_bitstrings()[:10]}"
)
```
