# Simpan kelayakan log masuk anda {#save-your-login-credentials}
Jika anda bekerja dalam persekitaran Python yang dipercayai (seperti pada komputer riba atau stesen kerja peribadi), anda boleh menggunakan kaedah `save_account()` untuk menyimpan kelayakan anda secara tempatan, kemudian menggunakannya untuk memulakan perkhidmatan.

<Admonition type="note" title="Nota">
      * Jika anda menggunakan komputer awam atau persekitaran yang tidak dipercayai, ikuti arahan dalam [Mulakan perkhidmatan dalam persekitaran yang tidak dipercayai](/guides/cloud-setup-untrusted) sebaliknya.
      * Ikuti [arahan ini](/guides/cloud-setup-rest-api) jika anda mahu menyambung menggunakan REST API dan bukannya menggunakan Qiskit.
      * Jika perlu, gunakan [maklumat ini](/guides/quickstart-steps-org#firewall) untuk mengkonfigurasi tembok api anda bagi membolehkan akses ke titik akhir API IBM Quantum.
</Admonition>

## Sebelum anda mulakan {#before-you-begin}

1. Pastikan anda bekerja dalam persekitaran Python aktif dengan [`qiskit` dan `qiskit-ibm-runtime` packages](/guides/install-qiskit#local) dipasang.

1. Aktifkan persekitaran maya Python dan jalankan Python dalam persekitaran maya anda.

1. Log masuk ke [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Cari kelayakan akses anda {#find-your-access-credentials}

1. Pastikan akaun dan rantau yang betul dipilih dalam pemilih akaun di header.

1. Cari kunci API anda. Dari [papan pemuka](https://quantum.cloud.ibm.com/), cipta kunci API anda, kemudian salinnya ke lokasi yang selamat supaya anda boleh menggunakannya untuk pengesahan. Perhatikan bahawa anda boleh menggunakan kunci API yang sama untuk menyambung ke mana-mana rantau.

1. Pilihan: Cari instans yang ingin anda gunakan dari halaman [Instans](https://quantum.cloud.ibm.com/instances). Arahkan kursor ke atas CRN-nya, klik ikon untuk menyalinnya, kemudian simpan di lokasi yang selamat supaya anda boleh menggunakannya untuk mengenal pasti instans.


<span id="cloud-save"></span>

## Simpan kelayakan akses anda {#save-your-access-credentials}

Simpan kelayakan anda dengan menjalankan kod yang sesuai sekali bagi setiap akaun yang ingin anda simpan. Selepas menyimpan kelayakan anda, muatkannya dengan mengikuti langkah dalam [Mulakan IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Simpan kelayakan yang mengakses instans tertentu: {#save-credentials-that-access-a-specific-instance}
Jika anda mempunyai berbilang instans dan mahu Quantum Compute mengetahui instans mana yang hendak digunakan, simpan kelayakan yang menyertakan CRN instans.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Simpan kelayakan untuk pemilihan instans automatik: {#save-credentials-for-automatic-instance-selection}
Jika anda tidak menyediakan CRN instans dan menghantar kelayakan ini ke Quantum Compute, instans yang sesuai akan dipilih untuk anda, berdasarkan pilihan yang dinyatakan.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Contoh 2 {#example-2}
Contoh ini menyimpan kelayakan untuk pemilihan instans automatik. Quantum Compute hanya akan melihat instans premium di rantau EU yang tersedia untuk akaun. Kelayakan ini menjadi lalai baharu.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Lihat kelayakan yang disimpan {#view-saved-credentials}

Untuk melihat semua kelayakan yang telah anda simpan, jalankan `service.saved_accounts()`. Perhatikan bahawa jika anda menyimpan kelayakan lalai dan tidak menamainya, ia dinamakan `default-ibm-quantum-platform`. Jika anda menamakan kelayakan lalai anda, anda akan melihat `"is_default_account": true` dalam output.

## Pertimbangan {#considerations}

* Jika anda menyimpan berbilang akaun, gunakan parameter `name` untuk membezakannya.

* Kelayakan disimpan ke `$HOME/.qiskit/qiskit-ibm.json`. Jangan edit fail ini secara manual.

* Jika anda tidak menyimpan kelayakan anda, anda mesti menyatakannya setiap kali anda memulakan Session baharu (memulakan IBM Quantum Compute Service).

* Jika anda menyatakan kelayakan secara manual, akaun yang tersimpan tidak akan digunakan.
