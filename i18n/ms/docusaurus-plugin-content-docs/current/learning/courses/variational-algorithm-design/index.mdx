# Gambaran Keseluruhan {#overview}

!["Hero image"](/learning/images/courses/variational-algorithm-design/hero.avif)

Kursus ini ditujukan kepada individu yang mempunyai sedikit pengalaman dengan pengkomputeran kuantum dan ingin belajar cara menulis algoritma variasi menggunakan primitif IBM Quantum. Ia juga sesuai untuk profesional pengkomputeran kuantum yang ingin mengembangkan pengetahuan dan kemahiran mereka dalam bidang algoritma variasi.

## Peperiksaan {#exam}

Untuk mendapatkan lencana Variational algorithm design anda, ambil peperiksaan di IBM&reg; Training. Peperiksaan ini bertujuan untuk diambil selepas membaca pelajaran dalam kursus ini. Selepas anda lulus peperiksaan, anda akan dimaklumkan oleh Credly bahawa anda telah mendapat lencana.
