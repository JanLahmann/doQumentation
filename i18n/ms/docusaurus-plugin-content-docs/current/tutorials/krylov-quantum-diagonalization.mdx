## Latar Belakang {#background}

Tutorial ini menunjukkan cara melaksanakan algoritma penyepelasan kuantum Krylov (KQD) dalam konteks corak Qiskit.
Anda akan belajar teori di sebalik algoritma ini terlebih dahulu, kemudian melihat demonstrasi pelaksanaannya pada QPU.

Menganggarkan sifat tenaga-rendah Hamiltonian banyak-jasad adalah tugas utama dalam simulasi kuantum.
Sebagai contoh, tenaga keadaan-dasar dan pengujaan rendah berkait secara langsung dengan kestabilan kimia, susunan magnet, peralihan fasa kuantum, dan tindak balas bahan.
Pada komputer klasik, dimensi ruang-Hilbert berkembang secara eksponen dengan bilangan orbital atau spin, jadi pepenjuruan langsung menjadi tidak praktikal dengan cepat.

Terdapat beberapa pendekatan pengkomputeran kuantum untuk masalah ini.
Kaedah variasi jangka pendek, seperti [variational quantum eigensolver (VQE)](/tutorials/spin-chain-vqe), menggunakan Circuit berparameter yang agak cetek, tetapi ia memerlukan gelung pengoptimuman klasik tak linear dengan banyak penilaian Circuit kuantum.
Di hujung yang lain, [quantum phase estimation (QPE)](https://arxiv.org/abs/quant-ph/0604193) menyediakan laluan yang lebih langsung untuk anggaran nilai eigen dengan jaminan yang tegas, tetapi QPE piawai memerlukan Circuit koheren yang panjang dan hanya sesuai untuk komputer kuantum toleran-kesalahan.
KQD berada di antara kedua-dua pendekatan ini: ia menggunakan evolusi Hamiltonian masa-nyata, seperti dalam algoritma berasaskan anggaran-fasa, tetapi menggantikan anggaran fasa penuh dengan masalah nilai eigen terunjur yang padat yang boleh diselesaikan secara klasik.

Pertimbangkan Hamiltonian $n$-Qubit $H$ dan keadaan rujukan $\lvert \psi_{0}\rangle$.
Kaedah KQD membina subruang Krylov daripada keadaan yang berevolusi secara masa-nyata,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

dengan $r$ ialah dimensi Krylov dan $\Delta t$ ialah langkah masa.
Sebarang keadaan dalam subruang Krylov kemudian diwakili sebagai gabungan linear keadaan asas ini,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
where the denominator normalizes the state.

Dengan algebra ringkas, kita boleh melihat bahawa tenaga yang sepadan ditulis sebagai kadar hasil bagi Rayleigh,

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

Di sini, matriks $\mathcal{S}$ dan $\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

mentakrifkan matriks pertindihan dan Hamiltonian terunjur.
Entrinya dianggarkan menggunakan pengukuran Circuit kuantum.

Kami bertujuan mencari pekali $\mathbf{c}$ yang memberikan $E(\mathbf{c})$ minimum:

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

Berdasarkan teorem Rayleigh-Ritz, peminimuman ini setara dengan menyelesaikan masalah nilai eigen teritlak (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

Ambil perhatian bahawa dimensi $r$ boleh cukup kecil untuk komputer klasik menyelesaikan GEVP.

Ini adalah prinsip variasi yang sama yang digunakan dalam pepenjuruan subruang klasik, tetapi di sini keadaan asas dihasilkan oleh evolusi masa kuantum.
Berbanding VQE, KQD biasanya memerlukan Circuit yang lebih dalam kerana ia bergantung pada evolusi masa-nyata.
Sebagai balasan, KQD mengelakkan pengoptimuman parameter tak linear dan pelaksanaan perkakasan kuantum berulang, dan ia bertambah baik secara sistematik apabila subruang terunjur diperbesarkan.
Algoritma ini telah ditunjukkan pada skala besar pada perkakasan kuantum sedia ada [\[2\]](#references), dan prestasinya boleh dianalisis dengan jaminan yang boleh dibuktikan [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.primitives import StatevectorEstimator

from qiskit.synthesis import LieTrotter, SuzukiTrotter
from qiskit.transpiler import PassManager, Layout
from qiskit.transpiler.passes import CommutativeOptimization
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### Tetapkan parameter untuk algoritma {#set-the-parameters-for-the-algorithm}

Berdasarkan sempadan-atas norma Hamiltonian, Rujukan [\[1\]](#references) secara heuristik mencadangkan langkah masa $\Delta t$ sebagai $\pi/\|H\|$.
Oleh kerana norma spektrum $\|H\|$ sukar dikira, kami sebaliknya menggunakan sempadan atasnya:

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ matrix, easy to calculate the norm}} = 3(n-1).
\end{equation*}
$$

Kami menetapkan dimensi Krylov kepada $r=10$ dan bilangan langkah Trotter setiap langkah masa kepada $5$: ruang Krylov yang cukup besar untuk menyelesaikan spektrum tenaga-rendah sambil mengekalkan Circuit paling dalam ($t_{\max}=(r-1)\Delta t$) berpatutan, dan langkah Trotter yang cukup untuk mengekalkan ralat pendiskretan kecil pada Circuit paling dalam tersebut.

#### Bina Circuit {#build-circuit}

Di sini, kami membina Circuit untuk menganggarkan unsur matriks $\mathcal{H}_{k\ell}$ dan $\mathcal{S}_{k\ell}$.
Oleh kerana semua kuasa $H$ berkomut, kita ada
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Such matrices where the elements depend on the index differences in this manner are called *Toeplitz* and can be reconstructed from first-row elements indexed by $d=\ell-k$.

Di sini, kami mempersembahkan Circuit, dipanggil **extended-swap-test**, yang menyediakan
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
dengan $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$.

#### Circuit ujian-tukar lanjutan [\[3\]](#references) {#extended-swap-test-circuit-3references}

Circuit terlebih dahulu menyediakan keadaan rujukan pada daftar sistem sementara ancilla kekal pada $|0\rangle$:

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

Kemudian, mengenakan gate Hadamard kepada ancilla mencipta superposisi koheren bagi dua cabang:

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Akhirnya, gate evolusi masa terkawal dikenakan:

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

hanya apabila ancilla berada dalam cabang $|1\rangle$. Oleh itu,

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Dalam blok kod seterusnya, kami melaksanakan:
$$
\begin{equation*}
|\Psi(t)\rangle = \frac{|0\rangle|\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}},
\end{equation*}
$$
yang akan ditetapkan sebagai $t=d\Delta t$ untuk $d=1,\cdots r-1$ dalam langkah pelaksanaan.

```python
ancilla = 0
system_qubits = list(range(1, num_qubits + 1))

extended_swap_test = QuantumCircuit(num_qubits + 1)

# Append state preparation part

extended_swap_test.h(ancilla)
```

#### Boleh diperhatikan {#observables}

Untuk sebarang boleh diperhatikan sistem Hermitan $O$, di sini kami menetapkan boleh diperhatikan untuk dikira:

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Ini kerana $O=I$ memberikan unsur pertindihan $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$, manakala $O=H$ memberikan unsur Hamiltonian $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$.

Menggunakan $X=|0\rangle\langle 1|+|1\rangle\langle 0|$, kita ada

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

Begitu juga, menggunakan $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

Oleh itu, kita ada
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Akhirnya, untuk setiap keadaan $|\Psi_{0d}\rangle$, kita perlu mengukur:
$$
\begin{align*}
X \otimes I \text{ for } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ for } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ for } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ for } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

Untuk anggaran unsur matriks $\mathcal{H}$, bilangan sebutan Pauli jauh lebih besar daripada unsur matriks $\mathcal{S}$.

Kita kini boleh mengurangkan bilangan sebutan Hamiltonian yang diukur dengan menggunakan teknik anjakan [\[4\]](#references).
Kita membahagikan Hamiltonian sebagai:

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

dengan $T$ dipilih sedemikian rupa sehingga keadaan rujukan adalah keadaan eigennya,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Then,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Here,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

ialah unsur matriks Hamiltonian teranjak.
Oleh itu, kita hanya perlu mengukur $X\otimes (H-T)$ dan $Y\otimes (H-T)$.
Sumbangan daripada $T$ dibina semula secara klasik menggunakan unsur matriks pertindihan $\mathcal{S}_{0d}$ yang telah diukur.

Dalam contoh ini, pilihan semula jadi adalah bahagian pepenjuru Hamiltonian Heisenberg,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

Oleh kerana keadaan rujukan adalah keadaan asas-pengiraan, ia adalah keadaan eigen bagi setiap sebutan $Z_iZ_{i+1}$.

Walau bagaimanapun, pilihan yang lebih menguntungkan adalah dengan menyertakan bukan sahaja sebutan pepenjuru $ZZ$, tetapi juga sebutan $XX+YY$ yang memusnahkan keadaan rujukan.

Untuk setiap pasangan bersebelahan, operator $XX+YY$ memenuhi

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

and

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

Oleh itu, sebutan $XX+YY$ hanya menyumbang apabila dua Qubit bersebelahan mempunyai penghunian berbeza dalam bitstring rujukan.
Jika kedua-dua Qubit adalah $0$ atau kedua-duanya $1$, sebutan itu memusnahkan keadaan rujukan dan juga boleh dianjakkan keluar.

Biar $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, dengan $z_i \in \{0,1\}$.
Oleh itu, kita boleh memilih
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Operator ini masih memenuhi

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

kerana sebutan $ZZ$ bertindak secara pepenjuru pada $|\psi_0\rangle$, manakala sebutan $XX+YY$ teranjak memberikan sifar.
Nilai eigen yang sepadan oleh itu ditentukan hanya oleh sebutan $ZZ$,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

Dengan pilihan ini, Hamiltonian teranjak menjadi:
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Hasilnya, hanya tepi dengan penghunian berbeza dalam keadaan rujukan yang perlu diukur.
Semua sebutan $ZZ$ dan semua sebutan $XX+YY$ tidak aktif dibina semula melalui sumbangan pertindihan $\tau \mathcal{S}_{0d}$, atau memberikan sumbangan sifar mengikut binaan.

Ini memberikan boleh diperhatikan yang lebih kecil daripada menganjak hanya bahagian pepenjuru.
Secara khusus, untuk keadaan rujukan asas-pengiraan dengan pengujaan tersetempat, hanya tepi bersebelahan dengan pengujaan tersebut kekal dalam $H-T$.
Oleh itu, bilangan sebutan Pauli dalam $X\otimes(H-T)$ dan $Y\otimes(H-T)$ boleh dikurangkan dengan ketara, sementara unsur matriks yang dibina semula
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

kekal sama sepenuhnya.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau

obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, shift_tau = (
    make_reduced_heisenberg_observables(ref_bitstring)
)
```

### Langkah 2: Optimumkan masalah untuk pelaksanaan perkakasan kuantum {#step-2-optimize-problem-for-quantum-hardware-execution}

Kini kita mengubah Circuit ujian-tukar lanjutan abstrak menjadi templat berorientasikan perkakasan.
Sebelum itu, kita terlebih dahulu mengoptimumkan lagi Circuit di peringkat abstrak.

#### Bandingkan susunan sebutan Hamiltonian {#compare-hamiltonian-term-ordering}

Pertama, kita bandingkan susunan berbeza sebutan Pauli dalam Hamiltonian Heisenberg untuk simulasi Hamiltonian.
Hamiltonian itu sendiri tidak berubah, tetapi susunan mempengaruhi cara Circuit formula-produk dijana dan sejauh mana struktur boleh diselaraskan dalam Circuit.
Sebagai contoh, susunan naif menyenaraikan semua sebutan $XX$ jiran-terdekat, kemudian semua sebutan $YY$, kemudian semua sebutan $ZZ$.
Ini meletakkan tepi bersebelahan seperti $(0,1)$ dan $(1,2)$ bersebelahan antara satu sama lain, jadi ia tidak boleh dilaksanakan secara selari.
Susunan genap-kemudian-ganjil melawati tepi genap yang saling terpisah dahulu, diikuti tepi ganjil, yang mendedahkan lapisan dwi-Qubit selari.
Susunan tepi-berkumpulan genap-ganjil pergi selangkah lebih jauh: untuk setiap tepi, ia mengekalkan sebutan tempatan $XX$, $YY$, dan $ZZ$ bersama-sama, sambil masih melawati tepi genap sebelum tepi ganjil.
Kita menjangkakan susunan genap-kemudian-ganjil dan tepi-berkumpulan genap-ganjil mengurangkan kedalaman Circuit dengan mendedahkan lapisan dwi-Qubit selari, dan susunan tepi-berkumpulan tambahan mengurangkan ralat Trotter kerana interaksi dwi-Qubit tempatan pada tepi yang sama dikendalikan sebagai blok padat.

![Pauli evolutions with different term ordering](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

Susunan Hamiltonian juga mempengaruhi ralat Trotter.
Jika kita meletakkan sebutan tidak berkomut bersebelahan antara satu sama lain, peralihan asas berlaku lebih kerap, yang menyebabkan lebih banyak ralat Trotter.
Dengan mengumpulkan sebutan yang memerlukan transformasi asas-Pauli yang sama, perubahan asas yang berlebihan boleh dielakkan.

Di sini, perbandingan menggunakan masa evolusi terbesar yang muncul dalam anggaran Krylov baris-pertama,
$t_{\max} = (r-1)\Delta t,$
menggunakan keadaan transpilasi yang sama.

Untuk mengukur ralat Trotter, kita menggunakan **ketidaksetiaan proses** antara Circuit Trotter dan evolusi Hamiltonian tepat,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
where $d=2^n$ is the dimension of the Hilbert space.

Diagnostik ini menggunakan matriks padat, jadi ia sesuai untuk contoh 12-Qubit kecil ini tetapi tidak dimaksudkan sebagai subrutin boleh skala.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

def build_numeric_evolution_circuit(
    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:
    """Build a numeric circuit for exp(-i H t) with a chosen synthesis rule."""
    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

print("Precomputing the exact evolution operator... ", end="")
exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### Buang gate evolusi masa terkawal {#remove-the-controlled-time-evolution-gate}

Dalam ujian-tukar lanjutan, mengawal evolusi masa dengan satu Qubit ancilla memerlukan ancilla mengawal banyak gate merentasi sistem.
Ini boleh memperkenalkan overhead penghalaan yang besar dan, dalam kes terburuk, secara berkesan memerlukan kesambungan semua-kepada-satu.
Untuk mengelakkan ini, pengoptimuman lanjut boleh dilakukan dengan menggantikan gate evolusi masa terkawal dengan versi bebas-kawalan, mengeksploitasi simetri Hamiltonian.
Mari kita perhatikan Circuit berikut.

![circuit optimization](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

Di sini, $B_{\rm ref}$ menyediakan keadaan rujukan, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

Berbanding menyediakan $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$ dahulu dan kemudian mengenakan $U(t)$ hanya pada cabang $|1\rangle$, Circuit terus menyediakan dua cabang sebagai

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

where

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

Circuit terlebih dahulu mengenakan gate Hadamard kepada ancilla dan menyediakan keadaan rujukan hanya pada cabang $|1\rangle$:

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Kemudian operator evolusi masa tanpa-kawalan dikenakan pada kedua-dua cabang:

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Oleh kerana Hamiltonian mengekalkan bilangan pengujaan, kita boleh lihat bahawa $|0^n\rangle$ adalah keadaan eigennya, dan oleh itu
operator evolusi hanya mengumpul fasa di bawah Hamiltonian:
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Therefore,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Seterusnya, $B_{\rm ref}$ dikenakan hanya pada cabang $|0\rangle$.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Pada titik ini, kedua-dua cabang mempunyai fasa relatif tambahan. Untuk mengeluarkannya, kita mengaplikasikan gate fasa ancilla

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

Ini mentransformasikan keadaan sebagai

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Oleh itu, sehingga fasa global yang tidak relevan, kita akhirnya menyediakan

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

Dalam blok kod seterusnya, kita mengimplementasikan Circuit bebas kawalan ini.


### Langkah 3: Laksanakan menggunakan primitif Qiskit {#step-3-execute-using-qiskit-primitives}

Langkah seterusnya ialah menghantar Circuit berparameter yang sama untuk beberapa nilai $d$. Untuk setiap $d$, kita menganggarkan empat nilai jangkaan: $X\otimes I$, $Y\otimes I$, $X\otimes (H-T)$, dan $Y\otimes (H-T)$. Keempat-empat nombor ini kemudian digabungkan menjadi elemen baris pertama kompleks $\mathcal{S}_{0d}$ dan $\mathcal{H}_{0d}$.

Di sini, $\mathcal{S}_{00}=1$ dan $\mathcal{H}_{00}=\langle\psi_{0}|(H-T)|\psi_{0}\rangle=\langle\psi_{0}|H|\psi_{0}\rangle-\tau$ boleh dikira secara klasik kerana $\lvert\psi_0\rangle$ adalah jarang, jadi kita langkau kes $d=0$.

### Langkah 4: Pascaproses dan kembalikan hasil dalam format klasik yang dikehendaki {#step-4-post-process-and-return-result-in-desired-classical-format}
Selepas menganggarkan matriks terunjur, kita menormalkan dan menyelesaikan GEVP
$$
\begin{equation*}
\mathcal{H}\mathbf{c} = E\mathcal{S}\mathbf{c}.
\end{equation*}
$$
Nilai eigen umum yang terkecil memberikan anggaran KQD bagi tenaga keadaan asas.

```python
h_shifted_row_est = np.zeros(krylov_dim, dtype=complex)
s_row_est = np.zeros(krylov_dim, dtype=complex)

h_shifted_row_est[0] = ref_energy - shift_tau
s_row_est[0] = 1.0

for idx, (pub_input, pub_result) in enumerate(zip(inputs, result)):
    d_index, obs_index = divmod(idx, len(observables))
    ev = np.asarray(pub_result.data.evs).reshape(-1)[0]
    std = np.asarray(pub_result.data.stds).reshape(-1)[0]

    if obs_index == 0:
        s_row_est[d_index + 1] = ev
    elif obs_index == 1:
        s_row_est[d_index + 1] += 1j * ev
    elif obs_index == 2:
        h_shifted_row_est[d_index + 1] = ev
    elif obs_index == 3:
        h_shifted_row_est[d_index + 1] += 1j * ev

# H_0d = shifted_H_0d + tau * S_0d.
h_row_est = h_shifted_row_est + shift_tau * s_row_est

h_matrix_est = la.toeplitz(h_row_est.conj(), h_row_est)
s_matrix_est = la.toeplitz(s_row_est.conj(), s_row_est)

positive_s_eigvals = s_eigvals[s_eigvals > 1e-12]
s_condition_number = (
    positive_s_eigvals[-1] / positive_s_eigvals[0]
    if len(positive_s_eigvals) > 0
    else np.inf
)

with np.printoptions(precision=3, suppress=True):
    print("Estimated first row of S:")
    print(s_row_est)
    print()
    print("Estimated first row of H:")
    print(h_row_est)
    print()
    print("Eigenvalues of the estimated overlap matrix S:")
    print(s_eigvals)
```

## Appendix: The Hamiltonian-function (spectral-filter) viewpoint {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

Aliran kerja utama membentangkan KQD secara operasi: membina asas Krylov daripada keadaan yang berevolusi dalam masa nyata, menganggarkan matriks terunjur $\mathcal{H}$ dan $\mathcal{S}$, dan menyelesaikan GEVP.
Lampiran ini mengunjungi semula pengiraan yang *sama* daripada sudut pandangan pelengkap yang menerangkan **mengapa** KQD berfungsi: sudut pandangan *fungsi-Hamiltonian*, atau *penapis-spektrum* [\[3\]](#references), [\[5\]](#references).
Ia menggunakan semula model 12-qubit, langkah masa $\Delta t$, dan penyelesaian Krylov yang telah diperoleh di atas; tiada pelaksanaan Circuit baharu diperlukan.

### The reference state as an energy distribution {#the-reference-state-as-an-energy-distribution}

Biarkan Hamiltonian mempunyai penguraian eigen

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

dengan keadaan eigen tenaga $|E_m\rangle$.
Mana-mana keadaan rujukan boleh dikembangkan dalam asas eigen ini,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

jadi ia membawa **berat spektrum** $p_m=|a_m|^2$ pada setiap tenaga $E_m$.
Tenaga rujukan ialah min bagi taburan ini, $\langle H\rangle_{0}=\sum_m p_m E_m$.

Penguraian eigen bagi Hamiltonian $n$-qubit am adalah mahal secara eksponen, jadi gambaran ini hanyalah diagnostik, yang *bukan* sebahagian daripada algoritma.
Di sini, bagaimanapun, kita boleh mengiranya dengan murah untuk masalah $n=12$ yang *sama*: Hamiltonian Heisenberg mengekalkan jumlah nombor pengujaan, dan rujukan $|000001000000\rangle$ membawa satu pengujaan tunggal, jadi seluruh kandungan spektrumnya berada dalam subruang pengujaan tunggal yang dimensinya hanya berkembang secara linear dengan $n$.
Oleh itu kita menggunakan semula blok pengujaan tunggal yang tepat (yang telah digunakan di atas sebagai penanda aras) dan membaca taburan rujukan $\{(E_m, p_m)\}$ dalam subruang tersebut.

```python
# Exact single-excitation-subspace decomposition of the reference state.
# This reuses make_heisenberg_hamiltonian / _basis_state_transition_amplitude_sparse
# and the n=12 `hamiltonian` and `ref_bitstring` defined in the small-scale example.
single_excitation_states = [1 << k for k in range(num_qubits)]

    [
        [
            _basis_state_transition_amplitude_sparse(hamiltonian, bra, ket)
            for ket in single_excitation_states

        for bra in single_excitation_states
```

### KQD learns a filter that reshapes this distribution {#kqd-learns-a-filter-that-reshapes-this-distribution}

Satu **fungsi Hamiltonian** $f(H)$ ditakrifkan melalui kalkulus spektrum,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

atau dengan kata lain, satu jumlah berpemberat bagi eigen-projektor.
Mengaplikasikannya kepada rujukan membentuk semula setiap amplitud spektrum, $a_m \to a_m f(E_m)$:

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

Jika $f$ dipuncak dengan tajam pada tenaga terendah ($f(E_0)=1$ dan $f(E_m)\approx 0$ selainnya) maka $f(H)$ akan bertindak sebagai projektor keadaan asas, dan output ternormal akan menjadi (hampir) keadaan asas.
Oleh itu, satu **penapis spektrum** laluan-rendah yang baik dalam tenaga adalah tepat apa yang kita mahukan.

KQD tidak menetapkan $f$ terlebih dahulu. Sebaliknya ia mengembangkan penapis dalam asas evolusi masa nyata,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

satu fungsi *trigonometri* bagi tenaga yang pekalinya $\{c_\ell\}$ adalah tepat vektor eigen GEVP yang diselesaikan di atas.
Meminimumkan hasil bagi Rayleigh $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ oleh itu adalah sama seperti *mempelajari* penapis yang paling baik menekan berat keadaan teruja bagi rujukan.
Dimensi Krylov $r$ yang lebih besar memberikan penapis lebih darjah kebebasan dan puncak yang lebih tajam pada tenaga keadaan asas.

Pembantu di bawah menilai penapis yang dipelajari ini pada paksi tenaga; kita kemudian mengaplikasikannya kepada taburan rujukan yang diperoleh di atas.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### Visualize the filter and its flexibility {#visualize-the-filter-and-its-flexibility}

Kita mula-mula menunjukkan penapis yang dipelajari pada dimensi Krylov penuh yang digunakan di atas, kemudian menjejaki bagaimana ia menajamkan apabila dimensi $r$ berkembang.

Bar menunjukkan berat spektrum rujukan $p_m$ (sebelum) dan berat tertapis $p_m|f_{\rm KQD}(E_m)|^2$ (selepas), bersama dengan keamatan penapis yang dipelajari $|f_{\rm KQD}(E)|^2$ pada paksi tenaga berterusan.
Penapis menumpukan berat kepada tenaga terendah subruang pengujaan tunggal &mdash; tenaga yang sama yang anggaran KQD menumpu kepadanya dalam contoh skala kecil.
Perhatikan bahawa ini adalah keadaan asas *dalam sektor pengujaan tunggal*, yang merupakan sasaran relevan bagi keadaan rujukan pengekalan pengujaan ini, bukan keadaan asas global.

```python
fig, ax = plt.subplots(figsize=(8, 4))
```

### Increasing the Krylov dimension: flexibility of the learned function {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

Ingat bahawa penapis yang dipelajari adalah polinomial trigonometri dalam tenaga dengan $r$ pekali,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

Dimensi Krylov $r$ adalah tepat bilangan pekali bebas, jadi ia mengawal **fleksibiliti** fungsi.
$r$ yang kecil hanya boleh menghasilkan penapis luas yang berubah secara perlahan yang membocorkan berat ke dalam keadaan teruja yang rendah; apabila $r$ meningkat, penapis boleh membentuk puncak yang lebih sempit pada tenaga sasaran dan menekan baki berat keadaan teruja dengan lebih agresif.
Ini adalah rakan sepadan penapis-spektrum bagi penumpuan tenaga yang diperhatikan dalam contoh skala kecil: apabila $r$ berkembang, taburan tertapis runtuh kepada keadaan asas subruang dan tenaga yang dianggarkan menurun ke arahnya.

Kita menggunakan semula matriks terunjur yang telah dianggarkan di atas dan hanya menyelesaikan GEVP pada setiap blok $r\times r$ terdepan, kemudian menilai dan memplot penapis yang sepadan.

```python
# Sweep the Krylov dimension using the leading r x r blocks of the estimated matrices.
sweep_dims = [r for r in (2, 4, 6, 8, krylov_dim) if r <= krylov_dim]
sweep_dims = sorted(set(sweep_dims))

energy_grid = np.linspace(
    subspace_evals.min() - 0.5, subspace_evals.max() + 0.5, 800
)

sweep_cases = []
print(" r    retained    ground overlap    filtered energy")
print("--    --------    --------------    ---------------")
for r in sweep_dims:
    _, coeffs_r, retained_r = solve_thresholded_gevp(
        h_matrix_est[:r, :r],
        s_matrix_est[:r, :r],
        threshold=1e-12,
    )
    filter_on_spectrum_r = trigonometric_krylov_filter(
        coeffs_r, subspace_evals, dt
    )
    filtered_weights_r = filtered_spectral_weights(
        ref_spectral_weights, filter_on_spectrum_r
    )
    filtered_energy_r = float(np.sum(filtered_weights_r * subspace_evals))

    sweep_cases.append((r, coeffs_r, filtered_weights_r))
    print(
        f"{r:2d}    {retained_r:8d}    {filtered_weights_r[0]:14.4f}    {filtered_energy_r:15.6f}"
    )

print(f"\nSubspace ground-state energy (target): {subspace_evals[0]:.6f}")

# One panel per Krylov dimension: filtered spectrum (bars) + filter intensity (curve).
fig, axes = plt.subplots(
    len(sweep_cases),
    1,
    figsize=(8, 2.1 * len(sweep_cases)),
    sharex=True,
)
axes = np.atleast_1d(axes)

for idx, (ax, (r, coeffs_r, filtered_weights_r)) in enumerate(
    zip(axes, sweep_cases)
):
    visible = (ref_spectral_weights > 1e-4) | (filtered_weights_r > 1e-4)
    ax.bar(
        subspace_evals[visible],
        ref_spectral_weights[visible],
        width=0.18,
        alpha=0.35,
        color="C0",
        label="reference $p_m$" if idx == 0 else None,
    )
    ax.bar(
        subspace_evals[visible],
        filtered_weights_r[visible],
        width=0.14,
        alpha=0.9,
        color="C1",
        label="filtered weights" if idx == 0 else None,
    )

    filter_intensity_r = (
        np.abs(trigonometric_krylov_filter(coeffs_r, energy_grid, dt)) ** 2
    )
    filter_intensity_r /= filter_intensity_r.max()
    ax.plot(energy_grid, filter_intensity_r, color="k", linewidth=2)

    ax.axvline(subspace_evals[0], color="C3", linestyle="--", linewidth=1)
    ax.set_ylim(0, 1)
    ax.set_ylabel("weight")
    ax.legend(loc="upper right", title=f"$r={r}$")

axes[-1].set_xlabel("Energy eigenvalue $E_m$")
fig.suptitle(
    r"KQD-learned filter $|f_{\rm KQD}(E)|^2$ sharpening with Krylov dimension $r$",
    y=1.0,
)
fig.tight_layout()
plt.show()
```
