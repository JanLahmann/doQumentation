## نظرة عامة {#overview}

حلّال المعادلات التفاضلية الجزئية (PDE) المقدَّم هنا جزء من منصة Quantum Innovative Computing Kit (QUICK) الخاصة بنا (QUICK-PDE)، وهو مغلَّف كدالة Qiskit. بواسطة دالة QUICK-PDE، يمكنك حل المعادلات التفاضلية الجزئية المتخصصة بمجالات محددة على وحدات معالجة الكم (QPUs) من IBM Quantum. تستند هذه الدالة إلى الخوارزمية الموصوفة في [ورقة H-DES من ColibriTD](https://arxiv.org/abs/2410.01130). وتستطيع هذه الخوارزمية حل مسائل الفيزياء المتعددة المعقدة، بدءًا من ديناميكيات الموائع الحسابية (CFD) وتشوه المواد (MD)، مع حالات استخدام أخرى قيد التطوير.

للتعامل مع المعادلات التفاضلية، تُرمَّز الحلول التجريبية على شكل تركيبات خطية من الدوال المتعامدة (عادةً كثيرات حدود شيبيشيف، وتحديدًا $2^n$ منها، حيث $n$ هو عدد الـ qubits التي ترمّز دالتك)، ومُعامَلة بزوايا دائرة كمية متغيرة (VQC). ينتج الـ ansatz حالة ترمّز الدالة، ويُقيَّم عبر مرصودات تتيح مجموعاتها تقييم الدالة عند جميع النقاط. يمكنك بعد ذلك تقييم دالة الخسارة التي تُرمَّز فيها المعادلات التفاضلية، وضبط الزوايا في حلقة هجينة كما هو موضح أدناه. تقترب الحلول التجريبية تدريجيًا من الحلول الفعلية حتى تصل إلى نتيجة مُرضية.

![مسار عمل دالة QUICK-PDE](/docs/images/guides/colibritd-equation-solver/diagram.svg)

إضافةً إلى هذه الحلقة الهجينة، يمكنك أيضًا تسلسل محسِّنات مختلفة. يفيد هذا عندما تريد محسِّنًا شاملًا للعثور على مجموعة جيدة من الزوايا، ثم محسِّنًا أدق لاتباع التدرج نحو أفضل مجموعة من الزوايا المجاورة. في حالة ديناميكيات الموائع الحسابية (CFD)، يُعطي تسلسل التحسين الافتراضي أفضل النتائج - أما في حالة تشوه المواد (MD)، فبينما يُعطي الافتراضي نتائج جيدة، يمكنك ضبطه أكثر للحصول على فوائد خاصة بالمسألة.

لاحظ أنه لكل متغير من متغيرات الدالة، نحدد عدد الـ qubits (يمكنك تجربتها). بتكديس 10 دوائر متطابقة وتقييم 10 مرصودات متطابقة على qubits مختلفة عبر دائرة كبيرة واحدة، يمكنك تخفيف الضوضاء ضمن عملية تحسين CMA معتمدًا على طريقة تعلم الضوضاء، وتقليل عدد القياسات المطلوبة بشكل ملحوظ.

### ديناميكيات الموائع الحسابية {#computational-fluid-dynamics}

**معادلة Burgers' غير اللزجة** تُنمذج الموائع غير اللزجة المتدفقة كما يلي:

$$\frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} = 0,$$

$u$ يُمثّل حقل سرعة الموائع. لهذه الحالة شرط حدودي زمني: يمكنك اختيار الشرط الابتدائي ثم السماح للنظام بالاسترخاء. حاليًا، الشروط الابتدائية الوحيدة المقبولة هي الدوال الخطية: $ax + b$. الحل التحليلي هو:

$$u(t, x) = \frac{ax + b}{at + 1}.$$

**معادلات أويلر عديمة الضغط** تُمثّل تدفق مائع غير قابل للانضغاط لزج بالتخميد كما يلي:

$$\frac{\partial g}{\partial t} + u\frac{\partial g}{\partial x} + g\frac{\partial u}{\partial x} = 0,$$

$$u\frac{\partial g}{\partial t} + g\frac{\partial u}{\partial t} + u^2\frac{\partial g}{\partial x} + 2gu\frac{\partial u}{\partial x} + \frac{\mu}{(1+t)^{\lambda}} g u = 0,$$

$g$ يمثل حقل الكثافة، $u$ حقل السرعة، و$\mu$ معامل التخميد. في صياغتنا، نضع $\lambda = 1$، لذا لن يُستخدم كمعامل فيما يلي. تحتوي حالة الاستخدام هذه على شروط حدية زمنية: $g(0, x) = e^{-x}$ و$u(0, x) = x$. الحل التحليلي هو:

$$g(t, x) = \frac{1-\mu}{(1+t)^{1-\mu} - \mu} \exp\!\left(\frac{(\mu-1)\, x}{(1+t)^{1-\mu} - \mu}\right),$$

$$u(t, x) = \frac{(1-\mu)\, x}{\left((1+t)^{1-\mu} - \mu\right)(1+t)^{\mu}}.$$

وسيطات المعادلات التفاضلية لـ CFD تقع على شبكة ثابتة كما يلي:

- $t$ يقع بين 0 و0.95 بـ 41 نقطة عينة. $x$ يقع بين 0 و0.95 بـ 41 نقطة عينة.


### تشوه المواد {#material-deformation}

تركّز هذه الحالة على التشوه شبه المرن أحادي البعد (اختبار الشد)، حيث يُثبَّت قضيب في الفضاء ويُسحب من طرفه الآخر. نصف المسألة كما يلي:

$$u' - \frac{\sigma}{3K} - \frac{2}{\sqrt{3}}\epsilon_0\left(\frac{\sigma'}{\sigma_0\sqrt{3}}\right)^n = 0,$$

$$\sigma' - b = 0,$$

$K$ يمثّل معامل الحجم للمادة المُشدَّدة، $n$ الأُس في قانون القوى، $b$ القوة لكل وحدة كتلة، $\epsilon_0$ حد الإجهاد التناسبي، $\sigma_0$ حد الانفعال التناسبي، $u$ دالة الإجهاد، و$\sigma$ دالة الانفعال. الحل التحليلي هو:

$$\sigma(x) = \sigma_0 - bx,$$

$$u(x) = -\frac{3^{-(3+n)/2}}{2bK(1+n)\,\sigma_0^{n}}\Biggl[3^{(1+n)/2}b^2\sigma_0^n(1+n)x^2 - 2\cdot 3^{(1+n)/2}b\sigma_0^n(1+n)\sigma_0 x - 12\epsilon_0 K\sigma_0^{1+n}$$
$$- 12b\epsilon_0 K\sigma_0^n x\left(\frac{-bx+\sigma_0}{\sigma_0}\right)^n + 12\epsilon_0 K\sigma_0^{n+1}\left(\frac{-bx+\sigma_0}{\sigma_0}\right)^n - 12\epsilon_0 K \sigma_0^{1+n}\Biggr],$$

حيث $\sigma_0 = g(0)$ هو الشرط الحدي على الإجهاد عند $x=0$.

القضيب المدروس له طول وحدوي. لهذه الحالة شرط حدودي لإجهاد السطح $t$، أي مقدار الشغل اللازم لشد القضيب.

وسيطات المعادلات التفاضلية لـ MD تقع على شبكة ثابتة كما يلي:

- $x$ يقع بين 0 و1 بـ 30 نقطة عينة.

## أمثلة {#examples}

للبدء، جرّب أحد الأمثلة التالية:

### معادلة Burgers' غير اللزجة (CFD) {#inviscid-burgers-equation-cfd}

بالنسبة لمعادلة Burgers'، عند ضبط الشروط الابتدائية على $u(0,x) = x$، تكون النتائج كما يلي:

```python
# launch the simulation with initial conditions u(0,x) = a*x + b
job = quick.run(
    use_case="CFD_BURGER", physical_parameters={"a": 1.0, "b": 0.0}
)
```

تحقق من [حالة](/guides/functions-get-started#check-job-status) عبء عمل دالة Qiskit أو استرجع [النتائج](/guides/functions-get-started#retrieve-results) كما يلي:

```python
# Print the ID so you can use it later, if necessary
print(job.job_id)
print(job.status())
solution = job.result()
```

```python
import numpy as np
import matplotlib.pyplot as plt

def plot_result_3d(result):
    fig = plt.figure()
    ax = fig.add_subplot(projection="3d")

    t, x = np.meshgrid(result["samples"]["t"], result["samples"]["x"])

    ax.plot_surface(
        t,
        x,
        result["functions"]["u"],
        edgecolor="royalblue",
        lw=0.25,
        rstride=26,
        cstride=26,
        alpha=0.3,
    )
    ax.scatter(t, x, result["functions"]["u"], marker=".")
    ax.set(xlabel="t", ylabel="x", zlabel="u(t,x)")

    plt.show()

# Call
plot_result_3d(solution)
```

### معادلة أويلر عديمة الضغط (CFD) {#pressureless-eulers-equation-cfd}

بالنسبة لمعادلة أويلر، عند ضبط الشروط الابتدائية على $g(0, x) = e^{-x}$ و$u(0, x) = x$، من أجل $\mu$ معطى (هنا، $\mu = 0.1$) و$\lambda = 1$، تكون النتائج كما يلي:

```python
# Launches the solving for an arbitrary mu
job = quick.run(use_case="CFD_EULER", physical_parameters={"mu": 0.1})

solution = job.result()

# Colorplot function
def plot_result_2d(result):
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    configs = {
        "g": {"cmap": "viridis", "title": "g(t, x)"},
        "u": {"cmap": "plasma", "title": "u(t, x)"},
    }

    t = result["samples"]["t"]
    x = result["samples"]["x"]

    for ax, (field, cfg) in zip(axes, configs.items()):
        v = result["functions"][field]

        im = ax.contourf(t, x, v, levels=50, cmap=cfg["cmap"])
        fig.colorbar(im, ax=ax, label=cfg["title"])

        ax.set_xlabel("t")
        ax.set_ylabel("x")
        ax.set_title(cfg["title"], fontsize=13, fontweight="bold")

    plt.tight_layout()
    plt.show()

plot_result_2d(solution)
```

### تشوه المواد {#material-deformation-1}

تتطلب حالة تشوه المواد المعاملات الفيزيائية للمادة والقوة المطبّقة، كما يلي:

```python
# Select the properties of your material
job = quick.run(
    use_case="MD",
    physical_parameters={
        "t": 12.0,
        "K": 100.0,
        "n": 4.0,
        "b": 10.0,
        "epsilon_0": 0.1,

# Plot the result
solution = job.result()

_ = plt.figure()
stress_plot = plt.subplot(211)
plt.plot(solution["samples"]["x"], solution["functions"]["u"])
strain_plot = plt.subplot(212)
plt.plot(solution["samples"]["x"], solution["functions"]["sigma"])

plt.show()
```

## استرجاع رسائل الخطأ {#fetch-error-messages}

إذا كانت حالة عبء عملك `ERROR`، استخدم `job.error_message()` لاسترجاع رسالة الخطأ للمساعدة في تصحيح الأخطاء، كما يلي:

```python
job = quick.run(use_case="MD", physical_params={})

print(job.error_message())

# A wrapper can also be used for a more human readable version
def pprint_error(job):
    print("".join(eval(job.error_message())["error"]))

print("___")
pprint_error(job)
```
