## خطوات استخدام Sampler primitive {#steps-to-use-the-sampler-primitive}

### 1. تهيئة الحساب {#1-initialize-the-account}

تحتاج أولاً إلى تهيئة حسابك. يمكنك بعد ذلك اختيار وحدة المعالجة الكمية (QPU) التي تريد استخدامها لحساب قيمة التوقع.

اتبع الخطوات في موضوع [إعداد حساب IBM Cloud الخاص بك](/guides/cloud-setup) إن لم يكن لديك حساب مُعدٌّ بالفعل.

:::note[البوابات الكسرية]


لاستخدام [البوابات الكسرية](/guides/fractional-gates) المدعومة حديثًا، اضبط `use_fractional_gates=True` عند طلب Backend من نسخة `QiskitRuntimeService`. على سبيل المثال:

```python
service = QiskitRuntimeService()
fractional_gate_backend = service.least_busy(use_fractional_gates=True)
```

هذه ميزة تجريبية وقد تتغير في المستقبل.

:::


```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()
backend = service.least_busy(
    operational=True, simulator=False, min_num_qubits=127
)
```

### 2. إنشاء دائرة {#2-create-a-circuit}

تحتاج إلى دائرة واحدة على الأقل كمدخل لـ Sampler primitive.

```python
import numpy as np
from qiskit.circuit.library import efficient_su2

circuit = efficient_su2(127, entanglement="linear")
circuit.measure_all()
# The circuit is parametrized, so we will define the parameter values for execution
param_values = np.random.rand(circuit.num_parameters)
```

يجب تحويل الدائرة والمراقب ليستخدما فقط التعليمات المدعومة من قِبَل وحدة المعالجة الكمية (المُشار إليها بـ *دوائر مجموعة تعليمات المعمارية (ISA)*). استخدم الـ Transpiler للقيام بذلك.

```python
from qiskit.transpiler import generate_preset_pass_manager

pm = generate_preset_pass_manager(optimization_level=1, backend=backend)
isa_circuit = pm.run(circuit)
print(f">>> Circuit ops (ISA): {isa_circuit.count_ops()}")
```

```text
>>> Circuit ops (ISA): OrderedDict([('rz', 3036), ('sx', 1769), ('cz', 378), ('measure', 127), ('barrier', 1)])
```

### 3. تهيئة IBM Quantum Sampler {#3-initialize-the-ibm-quantum-sampler}

عند تهيئة Sampler، استخدم المعامل `mode` لتحديد الوضع الذي تريده أن يعمل فيه. القيم الممكنة هي `batch` أو `session` أو كائنات `backend` لأوضاع تنفيذ الدُّفعة والجلسة والمهمة على التوالي. لمزيد من المعلومات، راجع [مقدمة إلى أوضاع تنفيذ IBM Quantum Compute Service](/guides/execution-modes). لاحظ أن مستخدمي الخطة المجانية لا يمكنهم إرسال مهام جلسات.

```python
from qiskit_ibm_runtime import SamplerV2 as Sampler

sampler = Sampler(mode=backend)
```

### 4. استدعاء Sampler والحصول على النتائج {#4-invoke-sampler-and-get-results}

بعد ذلك، استدعِ الطريقة `run()` لتوليد الإخراج. تُدخَل الدائرة ومجموعات قيم المعاملات الاختيارية كصفوف *كتلة موحدة للـ Primitive* (PUB).

```python
job = sampler.run([(isa_circuit, param_values)])
print(f">>> Job ID: {job.job_id()}")
print(f">>> Job Status: {job.status()}")
```

```text
>>> Job ID: dab7lb6rrl7c7386gjgg
```

```text
>>> Job Status: QUEUED
```

```python
result = job.result()

# Get results for the first (and only) PUB
pub_result = result[0]
print(
    f"First ten results for the 'meas' output register: "
    f"{pub_result.data.meas.get_bitstrings()[:10]}"
)
```
