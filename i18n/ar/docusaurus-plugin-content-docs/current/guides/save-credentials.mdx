# احفظ بيانات تسجيل الدخول {#save-your-login-credentials}
إذا كنت تعمل في بيئة Python موثوقة (مثل حاسوبك الشخصي أو محطة العمل الخاصة بك)، فيمكنك استخدام طريقة `save_account()` لحفظ بيانات اعتمادك محلياً، ثم استخدامها لتهيئة الخدمة.

<Admonition type="note" title="ملاحظات">
      * إذا كنت تستخدم حاسوباً عاماً أو أي بيئة غير موثوقة، فاتبع التعليمات الموجودة في [تهيئة الخدمة في بيئة غير موثوقة](/guides/cloud-setup-untrusted) عوضاً عن ذلك.
      * اتبع [هذه التعليمات](/guides/cloud-setup-rest-api) إذا أردت الاتصال عبر REST API بدلاً من استخدام Qiskit.
      * إذا لزم الأمر، استخدم [هذه المعلومات](/guides/quickstart-steps-org#firewall) لضبط جدار الحماية الخاص بك وتمكين الوصول إلى نقاط نهاية IBM Quantum API.
</Admonition>

## قبل أن تبدأ {#before-you-begin}

1. تأكد من أنك تعمل في بيئة Python نشطة مع تثبيت [`qiskit` و `qiskit-ibm-runtime` packages](/guides/install-qiskit#local).

1. فعِّل البيئة الافتراضية لـ Python وشغِّل Python داخلها.

1. سجّل الدخول إلى [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## ابحث عن بيانات اعتمادك {#find-your-access-credentials}

1. تأكد من اختيار الحساب والمنطقة الصحيحين في مبدِّل الحساب الموجود في الرأس.

1. ابحث عن مفتاح API الخاص بك. من لوحة [التحكم](https://quantum.cloud.ibm.com/)، أنشئ مفتاح API ثم انسخه إلى مكان آمن لتتمكن من استخدامه في المصادقة. لاحظ أنه يمكنك استخدام نفس مفتاح API للاتصال بأي منطقة.

1. اختياري: ابحث عن النسخة التي تريد استخدامها من صفحة [Instances](https://quantum.cloud.ibm.com/instances). مرِّر المؤشر فوق CRN الخاص بها، وانقر على الأيقونة لنسخه، ثم احفظه في مكان آمن لتتمكن من استخدامه لتحديد النسخة.


<span id="cloud-save"></span>

## احفظ بيانات اعتمادك {#save-your-access-credentials}

احفظ بيانات اعتمادك بتشغيل الكود المناسب مرةً واحدة لكل حساب تريد حفظه. بعد حفظ بيانات اعتمادك، حمِّلها باتباع الخطوات الموجودة في [تهيئة IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### احفظ بيانات اعتماد للوصول إلى نسخة محددة: {#save-credentials-that-access-a-specific-instance}
إذا كان لديك نسخ متعددة وتريد إخبار Quantum Compute بسهولة أيَّ نسخة تستخدم، فاحفظ بيانات اعتماد تتضمن CRN الخاص بالنسخة.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### احفظ بيانات اعتماد لاختيار النسخة تلقائياً: {#save-credentials-for-automatic-instance-selection}
إذا لم تُقدِّم CRN نسخة وأرسلت هذه البيانات إلى Quantum Compute، فسيتم اختيار نسخة مناسبة لك بناءً على الخيارات المحددة.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### مثال 2 {#example-2}
يحفظ هذا المثال بيانات اعتماد لاختيار النسخة تلقائياً. لن ينظر Quantum Compute إلا في النسخ المتميزة في منطقة الاتحاد الأوروبي المتاحة للحساب. تصبح هذه البيانات الافتراضية الجديدة.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## اعرض بيانات الاعتماد المحفوظة {#view-saved-credentials}

لعرض جميع بيانات الاعتماد التي حفظتها، شغِّل `service.saved_accounts()`. لاحظ أنه إذا حفظت بيانات اعتماد افتراضية ولم تُسمِّها، فستُسمَّى `default-ibm-quantum-platform`. وإذا أعطيت بيانات اعتمادك الافتراضية اسماً، فسترى `"is_default_account": true` في المخرجات.

## اعتبارات {#considerations}

* إذا كنت تحفظ حسابات متعددة، استخدم المعامل `name` للتمييز بينها.

* تُحفظ بيانات الاعتماد في `$HOME/.qiskit/qiskit-ibm.json`. لا تُعدِّل هذا الملف يدوياً.

* إذا لم تحفظ بيانات اعتمادك، فيجب عليك تحديدها في كل مرة تبدأ فيها جلسة جديدة (عند إنشاء نسخة من IBM Quantum Compute Service).

* إذا حددت بيانات اعتمادك يدوياً، فلن يُستخدم الحساب المحفوظ.
