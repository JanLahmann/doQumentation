# Instalarea clientului IBM Quantum Compute {#install-the-ibm-quantum-compute-client}

IBM Quantum Compute Service este serviciul bazat pe cloud pentru executarea calculelor cuantice pe hardware IBM Quantum&reg;. Acest ghid îți arată cum să instalezi `qiskit-ibm-runtime`, care este pachetul client pentru accesarea IBM Quantum Compute Service.

Înainte de a instala `qiskit-ibm-runtime`, urmează instrucțiunile din aceste ghiduri:

1. [Instalare Qiskit](/guides/install-qiskit).

2. [Configurare cont IBM Cloud](cloud-setup).


Rulează această comandă pentru a instala clientul IBM Quantum Compute:

```shell
pip install qiskit-ibm-runtime
```

<Admonition type="note" title="Rămâi la curent cu cele mai recente versiuni">
Verifică periodic [notele de lansare `qiskit-ibm-runtime`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/release-notes) pentru a vedea noile versiuni. Recomandăm actualizarea frecventă a cerințelor pentru `qiskit-ibm-runtime` prin rularea `pip install -U qiskit-ibm-runtime`.
</Admonition>
