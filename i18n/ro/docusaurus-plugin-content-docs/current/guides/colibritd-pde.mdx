## Prezentare generală {#overview}

Rezolvatorul de Ecuații cu Derivate Parțiale (PDE) prezentat aici face parte din platforma noastră Quantum Innovative Computing Kit (QUICK) (QUICK-PDE) și este ambalat ca o Funcție Qiskit. Cu funcția QUICK-PDE, poți rezolva ecuații cu derivate parțiale specifice unui domeniu pe QPU-urile IBM Quantum. Această funcție se bazează pe algoritmul descris în [lucrarea de prezentare H-DES a ColibriTD](https://arxiv.org/abs/2410.01130) Acest algoritm poate rezolva probleme complexe de multi-fizică, începând cu Dinamica Computațională a Fluidelor (CFD) și Deformarea Materialelor (MD), urmând să fie adăugate și alte cazuri de utilizare în curând.

Pentru a aborda ecuațiile diferențiale, soluțiile de test sunt codificate ca combinații liniare de funcții ortogonale (de obicei polinoame Chebyshev, și mai specific $2^n$ dintre ele, unde $n$ este numărul de qubiți care codifică funcția ta), parametrizate prin unghiurile unui Circuit Cuantic Variabil (VQC). Ansatz-ul generează o stare care codifică funcția, evaluată prin observabile ale căror combinații permit evaluarea funcției în toate punctele. Poți apoi evalua funcția de pierdere în care sunt codificate ecuațiile diferențiale și ajusta fin unghiurile într-un ciclu hibrid, după cum este prezentat în continuare. Soluțiile de test se apropie treptat de soluțiile reale până când obții un rezultat satisfăcător.

![Fluxul de lucru al funcției QUICK-PDE](/docs/images/guides/colibritd-equation-solver/diagram.svg)

Pe lângă acest ciclu hibrid, poți de asemenea înlănțui diferiți optimizatori. Acest lucru este util atunci când dorești ca un optimizator global să găsească un set bun de unghiuri, iar apoi un optimizator mai fin să urmeze un gradient către cel mai bun set de unghiuri vecine. În cazul dinamicii computaționale a fluidelor (CFD), secvența de optimizare implicită produce cele mai bune rezultate — dar în cazul deformării materialelor (MD), deși valorile implicite oferă rezultate bune, le poți configura mai detaliat pentru beneficii specifice problemei.

Reține că, pentru fiecare variabilă a funcției, specificăm numărul de qubiți (cu care poți experimenta). Prin stivuirea a 10 circuite identice și evaluarea celor 10 observabile identice pe qubiți diferiți de-a lungul unui circuit mare, poți aplica atenuarea zgomotului în cadrul procesului de optimizare CMA, bazându-te pe metoda de învățare a zgomotului, și reduce semnificativ numărul de shot-uri necesare.

### Dinamica computațională a fluidelor {#computational-fluid-dynamics}

**Ecuația Burgers fără vâscozitate** modelează curgerea fluidelor nevâscoase după cum urmează:

$$\frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} = 0,$$

$u$ reprezintă câmpul vitezei fluidului. Acest caz de utilizare are o condiție la limită temporală: poți selecta condiția inițială și apoi permite sistemului să se relaxeze. În prezent, singurele condiții inițiale acceptate sunt funcțiile liniare: $ax + b$. Soluția analitică este:

$$u(t, x) = \frac{ax + b}{at + 1}.$$

**Ecuațiile Euler fără presiune** modelează curgerea fluidului compresibil neviscoz cu amortizare, după cum urmează:

$$\frac{\partial g}{\partial t} + u\frac{\partial g}{\partial x} + g\frac{\partial u}{\partial x} = 0,$$

$$u\frac{\partial g}{\partial t} + g\frac{\partial u}{\partial t} + u^2\frac{\partial g}{\partial x} + 2gu\frac{\partial u}{\partial x} + \frac{\mu}{(1+t)^{\lambda}} g u = 0,$$

$g$ reprezintă câmpul densității, $u$ câmpul vitezei și $\mu$ un coeficient de amortizare. În formularea noastră, stabilim $\lambda = 1$, deci nu va fi folosit ca parametru în continuare. Acest caz de utilizare are condiții la limită temporale: $g(0, x) = e^{-x}$ și $u(0, x) = x$. Soluția analitică este:

$$g(t, x) = \frac{1-\mu}{(1+t)^{1-\mu} - \mu} \exp\!\left(\frac{(\mu-1)\, x}{(1+t)^{1-\mu} - \mu}\right),$$

$$u(t, x) = \frac{(1-\mu)\, x}{\left((1+t)^{1-\mu} - \mu\right)(1+t)^{\mu}}.$$

Argumentele pentru ecuațiile diferențiale ale CFD se află pe o grilă fixă, după cum urmează:

- $t$ este între 0 și 0.95 cu 41 de puncte de eșantionare. $x$ este între 0 și 0.95 cu 41 de puncte de eșantionare.


### Deformarea Materialelor {#material-deformation}

Acest caz de utilizare se concentrează pe deformarea hipoelastică cu testul de tracțiune unidimensional, în care o bară fixată în spațiu este trasă la celălalt capăt. Descriem problema după cum urmează:

$$u' - \frac{\sigma}{3K} - \frac{2}{\sqrt{3}}\epsilon_0\left(\frac{\sigma'}{\sigma_0\sqrt{3}}\right)^n = 0,$$

$$\sigma' - b = 0,$$

$K$ reprezintă modulul de compresibilitate al materialului întins, $n$ exponentul unei legi de putere, $b$ forța pe unitate de masă, $\epsilon_0$ limita de stres proporțional, $\sigma_0$ limita de deformare proporțională, $u$ funcția de stres și $\sigma$ funcția de deformare. Soluția analitică este:

$$\sigma(x) = \sigma_0 - bx,$$

$$u(x) = -\frac{3^{-(3+n)/2}}{2bK(1+n)\,\sigma_0^{n}}\Biggl[3^{(1+n)/2}b^2\sigma_0^n(1+n)x^2 - 2\cdot 3^{(1+n)/2}b\sigma_0^n(1+n)\sigma_0 x - 12\epsilon_0 K\sigma_0^{1+n}$$
$$- 12b\epsilon_0 K\sigma_0^n x\left(\frac{-bx+\sigma_0}{\sigma_0}\right)^n + 12\epsilon_0 K\sigma_0^{n+1}\left(\frac{-bx+\sigma_0}{\sigma_0}\right)^n - 12\epsilon_0 K \sigma_0^{1+n}\Biggr],$$

unde $\sigma_0 = g(0)$ este condiția la limită pentru deformație la $x=0$.

Bara considerată are lungime unitară. Acest caz de utilizare are o condiție la limită pentru stresul de suprafață $t$, adică cantitatea de lucru necesară pentru a întinde bara.

Argumentele pentru ecuațiile diferențiale ale MD se află pe o grilă fixă, după cum urmează:

- $x$ este între 0 și 1 cu 30 de puncte de eșantionare.

## Exemple {#examples}

Pentru a începe, încearcă unul dintre următoarele exemple:

### Ecuația Burgers fără vâscozitate (CFD) {#inviscid-burgers-equation-cfd}

Pentru ecuația Burgers, când condițiile inițiale sunt setate la $u(0,x) = x$, rezultatele sunt după cum urmează:

```python
# launch the simulation with initial conditions u(0,x) = a*x + b
job = quick.run(
    use_case="CFD_BURGER", physical_parameters={"a": 1.0, "b": 0.0}
)
```

Verifică [statusul](/guides/functions-get-started#check-job-status) sarcinii de lucru a Funcției Qiskit sau returnează [rezultatele](/guides/functions-get-started#retrieve-results) după cum urmează:

```python
# Print the ID so you can use it later, if necessary
print(job.job_id)
print(job.status())
solution = job.result()
```

```python
import numpy as np
import matplotlib.pyplot as plt

def plot_result_3d(result):
    fig = plt.figure()
    ax = fig.add_subplot(projection="3d")

    t, x = np.meshgrid(result["samples"]["t"], result["samples"]["x"])

    ax.plot_surface(
        t,
        x,
        result["functions"]["u"],
        edgecolor="royalblue",
        lw=0.25,
        rstride=26,
        cstride=26,
        alpha=0.3,
    )
    ax.scatter(t, x, result["functions"]["u"], marker=".")
    ax.set(xlabel="t", ylabel="x", zlabel="u(t,x)")

    plt.show()

# Call
plot_result_3d(solution)
```

### Ecuația Euler fără presiune (CFD) {#pressureless-eulers-equation-cfd}

Pentru ecuația Euler, când condițiile inițiale sunt setate la $g(0, x) = e^{-x}$ și $u(0, x) = x$, pentru un $\mu$ dat (aici, $\mu = 0.1$) și $\lambda = 1$, rezultatele sunt după cum urmează:

```python
# Launches the solving for an arbitrary mu
job = quick.run(use_case="CFD_EULER", physical_parameters={"mu": 0.1})

solution = job.result()

# Colorplot function
def plot_result_2d(result):
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    configs = {
        "g": {"cmap": "viridis", "title": "g(t, x)"},
        "u": {"cmap": "plasma", "title": "u(t, x)"},
    }

    t = result["samples"]["t"]
    x = result["samples"]["x"]

    for ax, (field, cfg) in zip(axes, configs.items()):
        v = result["functions"][field]

        im = ax.contourf(t, x, v, levels=50, cmap=cfg["cmap"])
        fig.colorbar(im, ax=ax, label=cfg["title"])

        ax.set_xlabel("t")
        ax.set_ylabel("x")
        ax.set_title(cfg["title"], fontsize=13, fontweight="bold")

    plt.tight_layout()
    plt.show()

plot_result_2d(solution)
```

### Deformarea Materialelor {#material-deformation-1}

Cazul de utilizare al deformării materialelor necesită parametrii fizici ai materialului tău și forța aplicată, după cum urmează:

```python
# Select the properties of your material
job = quick.run(
    use_case="MD",
    physical_parameters={
        "t": 12.0,
        "K": 100.0,
        "n": 4.0,
        "b": 10.0,
        "epsilon_0": 0.1,
        "sigma_0": 5.0,

# Plot the result
solution = job.result()

_ = plt.figure()
stress_plot = plt.subplot(211)
plt.plot(solution["samples"]["x"], solution["functions"]["u"])
strain_plot = plt.subplot(212)
plt.plot(solution["samples"]["x"], solution["functions"]["sigma"])

plt.show()
```

## Obține mesaje de eroare {#fetch-error-messages}

Dacă statusul sarcinii tale de lucru este `ERROR`, folosește `job.error_message()` pentru a obține mesajul de eroare care te ajută la depanare, după cum urmează:

```python
job = quick.run(use_case="MD", physical_params={})

print(job.error_message())

# A wrapper can also be used for a more human readable version
def pprint_error(job):
    print("".join(eval(job.error_message())["error"]))

print("___")
pprint_error(job)
```
