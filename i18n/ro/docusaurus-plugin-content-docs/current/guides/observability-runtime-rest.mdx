# Evenimente de urmărire a activității pentru IBM Quantum Compute Service {#activity-tracking-events-for-ibm-quantum-compute-service}

Serviciile IBM Cloud&reg;, precum IBM Quantum&reg; Compute Service, generează evenimente de urmărire a activității.

Evenimentele de urmărire a activității raportează activitățile care modifică starea unui serviciu în IBM Cloud. Poți folosi evenimentele pentru a investiga activități anormale și acțiuni critice, precum și pentru a respecta cerințele de audit de reglementare.

Poți folosi IBM Cloud Activity Tracker Event Routing, un serviciu de platformă, pentru a direcționa evenimentele de auditare din contul tău către destinații la alegere, configurând ținte și rute care definesc unde sunt trimise evenimentele de urmărire a activității. Pentru mai multe informații, consultă [Despre IBM Cloud Activity Tracker Events Routing.](https://cloud.ibm.com/docs/atracker?topic=atracker-about)

Poți folosi IBM Cloud Logs pentru a vizualiza și a primi alerte privind evenimentele generate în contul tău și direcționate de IBM Cloud Activity Tracker Event Routing către o instanță IBM Cloud Logs.

## Locații unde sunt generate evenimentele de urmărire a activității {#locations-where-activity-tracking-events-are-generated}

IBM Quantum Compute Service trimite evenimente de urmărire a activității în următoarele regiuni:

- Washington ("us-east")

- Frankfurt ("eu-de")
