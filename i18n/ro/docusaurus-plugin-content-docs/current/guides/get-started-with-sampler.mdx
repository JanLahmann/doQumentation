## Pași pentru utilizarea primitivei Sampler {#steps-to-use-the-sampler-primitive}

### 1. Inițializarea contului {#1-initialize-the-account}

Trebuie mai întâi să îți inițializezi contul. Poți selecta apoi QPU-ul pe care vrei să îl folosești pentru a calcula valoarea de așteptare.

Urmează pașii din subiectul [Configurarea contului IBM Cloud](/guides/cloud-setup) dacă nu ai deja un cont configurat.

:::note[Gate-uri fracționale]


Pentru a utiliza [gate-urile fracționale](/guides/fractional-gates) nou suportate, setează `use_fractional_gates=True` atunci când soliciți un backend dintr-o instanță `QiskitRuntimeService`. De exemplu:

```python
service = QiskitRuntimeService()
fractional_gate_backend = service.least_busy(use_fractional_gates=True)
```

Aceasta este o caracteristică experimentală și s-ar putea schimba în viitor.

:::


```python
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()
backend = service.least_busy(
    operational=True, simulator=False, min_num_qubits=127
)
```

### 2. Crearea unui circuit {#2-create-a-circuit}

Ai nevoie de cel puțin un circuit ca intrare pentru primitiva Sampler.

```python
import numpy as np
from qiskit.circuit.library import efficient_su2

circuit = efficient_su2(127, entanglement="linear")
circuit.measure_all()
# The circuit is parametrized, so we will define the parameter values for execution
param_values = np.random.rand(circuit.num_parameters)
```

Circuitul și observabilul trebuie transformate pentru a utiliza doar instrucțiunile suportate de QPU (denumite circuite de *arhitectură set de instrucțiuni (ISA)*). Folosește transpilerul pentru aceasta.

```python
from qiskit.transpiler import generate_preset_pass_manager

pm = generate_preset_pass_manager(optimization_level=1, backend=backend)
isa_circuit = pm.run(circuit)
print(f">>> Circuit ops (ISA): {isa_circuit.count_ops()}")
```

```text
>>> Circuit ops (ISA): OrderedDict([('rz', 3036), ('sx', 1769), ('cz', 378), ('measure', 127), ('barrier', 1)])
```

### 3. Inițializarea IBM Quantum Sampler {#3-initialize-the-ibm-quantum-sampler}

Când inițializezi Sampler, folosești parametrul `mode` pentru a specifica modul în care vrei să ruleze. Valorile posibile sunt obiecte `batch`, `session` sau `backend` pentru modul de execuție batch, session și respectiv job. Pentru mai multe informații, consultă [Introducere în modurile de execuție IBM Quantum Compute Service](/guides/execution-modes). Reține că utilizatorii planului Open nu pot trimite joburi de sesiune.

```python
from qiskit_ibm_runtime import SamplerV2 as Sampler

sampler = Sampler(mode=backend)
```

### 4. Invocarea Sampler și obținerea rezultatelor {#4-invoke-sampler-and-get-results}

Apoi, invocă metoda `run()` pentru a genera ieșirea. Circuitul și seturile opționale de valori de parametri sunt introduse ca tupluri *primitive unified bloc* (PUB).

```python
job = sampler.run([(isa_circuit, param_values)])
print(f">>> Job ID: {job.job_id()}")
print(f">>> Job Status: {job.status()}")
```

```text
>>> Job ID: dab7lb6rrl7c7386gjgg
```

```text
>>> Job Status: QUEUED
```

```python
result = job.result()

# Get results for the first (and only) PUB
pub_result = result[0]
print(
    f"First ten results for the 'meas' output register: "
    f"{pub_result.data.meas.get_bitstrings()[:10]}"
)
```
