# Salvează-ți datele de autentificare {#save-your-login-credentials}
Dacă lucrezi într-un mediu Python de încredere (cum ar fi un laptop personal sau o stație de lucru), poți folosi metoda `save_account()` pentru a-ți salva datele de autentificare local, apoi să le folosești pentru a inițializa serviciul.

<Admonition type="note" title="Note">
      * Dacă folosești un computer public sau un alt mediu neîncredibil, urmează instrucțiunile din [Inițializează serviciul într-un mediu neîncredibil](/guides/cloud-setup-untrusted).
      * Urmează [aceste instrucțiuni](/guides/cloud-setup-rest-api) dacă vrei să te conectezi folosind REST API în loc de Qiskit.
      * Dacă este necesar, folosește [aceste informații](/guides/quickstart-steps-org#firewall) pentru a configura firewall-ul și a permite accesul la endpoint-urile IBM Quantum API.
</Admonition>

## Înainte de a începe {#before-you-begin}

1. Asigură-te că lucrezi într-un mediu Python activ cu [pachetele `qiskit` și `qiskit-ibm-runtime` instalate](/guides/install-qiskit#local).

1. Activează mediul virtual Python și rulează Python în mediul tău virtual.

1. Autentifică-te pe [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Găsește-ți datele de acces {#find-your-access-credentials}

1. Asigură-te că în selectorul de conturi din antet sunt selectate contul și regiunea corecte.

1. Găsește-ți cheia API. Din [tabloul de bord](https://quantum.cloud.ibm.com/), creează cheia ta API, apoi copiaz-o într-un loc sigur pentru a o putea folosi la autentificare. Reține că poți folosi aceeași cheie API pentru a te conecta la orice regiune.

1. Opțional: Găsește instanța pe care vrei să o folosești din pagina [Instances](https://quantum.cloud.ibm.com/instances). Treci cu cursorul peste CRN-ul ei, fă clic pe pictogramă pentru a o copia, apoi salveaz-o într-un loc sigur pentru a o putea folosi la identificarea instanței.


<span id="cloud-save"></span>

## Salvează-ți datele de acces {#save-your-access-credentials}

Salvează-ți datele de autentificare rulând codul corespunzător o singură dată pentru fiecare cont pe care vrei să îl salvezi. După salvarea datelor de autentificare, încarcă-le urmând pașii din [Inițializează IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Salvează datele de autentificare pentru accesarea unei instanțe specifice: {#save-credentials-that-access-a-specific-instance}
Dacă ai mai multe instanțe și vrei să îi spui ușor serviciului Quantum Compute pe care instanță să o folosească, salvează datele de autentificare care includ un CRN de instanță.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Salvează datele de autentificare pentru selecția automată a instanței: {#save-credentials-for-automatic-instance-selection}
Dacă nu furnizezi un CRN de instanță și transmiți aceste date de autentificare către Quantum Compute, o instanță corespunzătoare va fi aleasă automat pentru tine, pe baza opțiunilor specificate.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Exemplul 2 {#example-2}
Acest exemplu salvează datele de autentificare pentru selecția automată a instanței. Quantum Compute va lua în considerare doar instanțele premium din regiunea EU care sunt disponibile pentru cont. Aceste date de autentificare devin noul implicit.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Vizualizează datele de autentificare salvate {#view-saved-credentials}

Pentru a vizualiza toate datele de autentificare pe care le-ai salvat, rulează `service.saved_accounts()`. Reține că, dacă ai salvat date de autentificare implicite fără să le denumești, acestea se numesc `default-ibm-quantum-platform`. Dacă ți-ai denumit datele de autentificare implicite, vei vedea `"is_default_account": true` în rezultat.

## Considerații {#considerations}

* Dacă salvezi mai multe conturi, folosește parametrul `name` pentru a le diferenția.

* Datele de autentificare sunt salvate în `$HOME/.qiskit/qiskit-ibm.json`. Nu edita manual acest fișier.

* Dacă nu îți salvezi datele de autentificare, trebuie să le specifici de fiecare dată când pornești o sesiune nouă (instanțiezi IBM Quantum Compute Service).

* Dacă îți specifici manual datele de autentificare, un cont salvat nu va fi folosit.
