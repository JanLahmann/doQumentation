In addition to [visualizing instructions on a circuit](/guides/visualize-circuits), you might want to visualize a circuit's scheduling by using the Qiskit [`timeline_drawer`](https://docs.quantum.ibm.com/api/qiskit/qiskit.visualization.timeline_drawer) method. To visualize dynamic circuit scheduling, use the `draw_circuit_schedule_timing` method, as described in the [Visualize circuit timing](/guides/qiskit-runtime-circuit-timing) guide.

## 예시 {#examples}

스케줄된 Circuit 프로그램을 시각화하려면, 일련의 제어 인수와 함께 이 함수를 호출할 수 있습니다. 출력 이미지 외관의 대부분은 스타일시트로 수정할 수 있지만, 반드시 필요한 것은 아닙니다.

### 기본 스타일시트로 그리기 {#draw-with-the-default-stylesheet}

```python
# Added by doQumentation — required packages for this notebook
!pip install -q qiskit
```

```python
from qiskit import QuantumCircuit
from qiskit.visualization.timeline import draw
from qiskit.providers.fake_provider import GenericBackendV2
from qiskit.transpiler import generate_preset_pass_manager

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)

backend = GenericBackendV2(5)

pm = generate_preset_pass_manager(backend=backend, optimization_level=1)
isa_circuit = pm.run(qc)

draw(isa_circuit, target=backend.target)
```

### 프로그램 디버깅에 적합한 스타일시트로 그리기 {#draw-with-a-stylesheet-suited-for-program-debugging}

```python
from qiskit import QuantumCircuit
from qiskit.visualization.timeline import draw, IQXDebugging
from qiskit.providers.fake_provider import GenericBackendV2
from qiskit.transpiler import generate_preset_pass_manager

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)
qc.measure_all()

backend = GenericBackendV2(5)
pm = generate_preset_pass_manager(backend=backend, optimization_level=1)
isa_circuit = pm.run(qc)
draw(isa_circuit, style=IQXDebugging(), target=backend.target)
```

![이전 코드 셀의 출력](/docs/images/guides/visualize-circuit-timing/extracted-outputs/907dc46c-0.svg)

사용자 정의 generator 또는 layout 함수를 만들고, 기존 스타일시트를 해당 함수로 업데이트할 수 있습니다. 이렇게 하면 스케줄된 Circuit drawer의 코드베이스를 수정하지 않고도 출력 이미지 외관의 대부분을 제어할 수 있습니다. 더 많은 예시는 [`timeline_drawer`](https://docs.quantum.ibm.com/api/qiskit/qiskit.visualization.timeline_drawer) API 레퍼런스를 참조하세요.
