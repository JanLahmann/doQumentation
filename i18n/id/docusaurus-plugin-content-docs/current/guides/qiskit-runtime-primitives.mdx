# Pengantar primitif IBM Quantum {#introduction-to-ibm-quantum-primitives}

Primitif dibuat untuk menyederhanakan tugas paling umum pada komputer kuantum: yaitu, sampling state kuantum dan menghitung nilai ekspektasi. Primitif IBM Quantum pertama ([`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) dan [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)) adalah implementasi dari [kelas dasar primitif](/guides/primitives) Qiskit. Keduanya menyediakan implementasi yang lebih canggih (misalnya, dengan menyertakan mitigasi error) sebagai layanan berbasis cloud dan digunakan untuk mengakses hardware IBM Quantum&reg;.

Primitif IBM Quantum terbaru, [Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor) (yang berstatus beta), menyediakan interface tingkat lebih rendah yang memberikan lebih banyak visibilitas dan kontrol tanpa mengorbankan performa. 
`Executor` juga mengekspos **kemampuan tambahan yang tidak ditawarkan Sampler**, seperti kelompok twirling tambahan dan twirling untuk circuit dengan fractional gate. Lihat [Migrasi dari Sampler ke Executor](/guides/migrate-from-sampler-to-executor) untuk informasi lebih lanjut tentang apakah perlu bermigrasi ke `Executor`.
