# Inisialisasi layanan di lingkungan yang tidak tepercaya {#initialize-the-service-in-an-untrusted-environment}

Ikuti petunjuk ini jika Anda bekerja dengan IBM Cloud atau IBM Quantum Compute Service REST API di lingkungan yang tidak tepercaya, seperti komputer umum.

**Hindari menjalankan kode di mesin yang tidak tepercaya atau lingkungan Python cloud eksternal untuk meminimalkan risiko keamanan.** Jika Anda harus menggunakan lingkungan yang tidak tepercaya (misalnya, di komputer bersama atau publik), ganti API key Anda setelah setiap penggunaan dengan menghapusnya di [halaman API keys](https://cloud.ibm.com/iam/apikeys) dan membuat yang baru.

    <Admonition type="caution">
      **Lindungi API key Anda!** Jangan pernah menyertakan kunci Anda di kode sumber, skrip Python, atau file notebook. Saat berbagi kode dengan orang lain, pastikan API key Anda tidak disematkan langsung di dalam skrip Python. Sebaliknya, bagikan skrip tanpa token dan berikan petunjuk untuk mengaturnya dengan aman.

      Jika Anda secara tidak sengaja berbagi kunci dengan seseorang atau menyertakannya di version control seperti Git, segera cabut kunci Anda dengan mengikuti topik [Menghapus API key](https://cloud.ibm.com/docs/account?topic=account-userapikey&interface=ui#delete_user_key) di IBM Cloud.
    </Admonition>

<span id="access-credentials"></span>

## Temukan kredensial akses Anda {#find-your-access-credentials}

1. Temukan API key Anda (juga disebut sebagai _API token_). Dari [dashboard](https://quantum.cloud.ibm.com/), buat API key Anda, lalu salin ke lokasi yang aman agar bisa digunakan untuk autentikasi. Token tidak akan terlihat lagi. Perlu diketahui bahwa Anda bisa menggunakan satu API key untuk terhubung ke region mana pun.

2. Opsional: Temukan instance yang ingin Anda gunakan dari halaman [Instances](https://quantum.cloud.ibm.com/instances). Arahkan kursor ke CRN-nya, klik ikon untuk menyalinnya, lalu simpan di lokasi yang aman agar bisa digunakan untuk mengidentifikasi instance.


## Autentikasi ke IBM Cloud di lingkungan yang tidak tepercaya {#authenticate-to-ibm-cloud-in-an-untrusted-environment}

Untuk menginisialisasi layanan dalam situasi ini, gunakan kode seperti berikut:

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    # The credentials you enter will override any saved
    # account credentials that might be available locally.
    service = QiskitRuntimeService(
      # Use the 44-character API_KEY you created and saved from
      # the IBM Quantum Platform dashboard, and then delete
      # the key on the API keys page after entering this code:
      token="<your-API-key>",
      
      # Optionally specify an instance to use
      instance="<IBM Cloud CRN or instance name>"
      )
    ```

<span id="rest-untrusted"></span>

## Autentikasi ke REST API di lingkungan yang tidak tepercaya {#authenticate-to-the-rest-api-in-an-untrusted-environment}

Ikuti langkah-langkah ini untuk menggunakan API key Anda secara langsung guna autentikasi ke IBM Quantum Compute Service REST API, di mana `<your_API_KEY>` adalah API_KEY 44 karakter yang Anda buat dan simpan dari dashboard Beranda IBM Quantum Platform.

1. Gunakan API key Anda untuk menghasilkan [bearer token](https://docs.quantum.ibm.com/api/qiskit-runtime-rest#authentication). _Bearer token_ adalah kredensial sementara yang kedaluwarsa setelah maksimal satu jam. Setelah token yang diperoleh kedaluwarsa, Anda harus membuat yang baru untuk terus memanggil IBM Cloud atau API layanan lainnya. :


    ```bash
    curl -X POST 'https://iam.cloud.ibm.com/identity/token' \
    -H 'Content-Type: application/x-www-form-urlencoded' \
    -d 'grant_type=urn:ibm:params:oauth:grant-type:apikey&apikey=your_API_KEY'
    ```
    Copy and save the returned bearer token:  `"access_token": "<NEW_BEARER_TOKEN>"`
  1. Authenticate requests to the IBM Quantum Compute Service REST API by including the CRN and bearer token in the request's headers.

      ```bash
      curl -X 'GET' \
        'https://quantum.cloud.ibm.com/api/v1/usage' \
        '-H accept: application/json' \
        '-H authorization: Bearer <BEARER_TOKEN>' \
        '-H Service-CRN: <INSTANCE_CRN>'
      ```

1. Ubah API key kamu setelah setiap penggunaan dengan [Menghapus API key kamu yang sudah ada](https://cloud.ibm.com/docs/account?topic=account-userapikey&interface=ui#delete_user_key) dan membuat API key baru pada halaman utama [IBM Quantum Platform](https://quantum.cloud.ibm.com/).
