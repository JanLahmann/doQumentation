# Simpan kredensial login kamu {#save-your-login-credentials}
Kalau kamu bekerja di lingkungan Python yang terpercaya (misalnya laptop atau workstation pribadi), kamu bisa menggunakan metode `save_account()` untuk menyimpan kredensial secara lokal, lalu menggunakannya untuk menginisialisasi layanan.

<Admonition type="note" title="Catatan">
      * Kalau kamu menggunakan komputer publik atau lingkungan yang tidak terpercaya, ikuti petunjuk di [Inisialisasi layanan di lingkungan yang tidak terpercaya](/guides/cloud-setup-untrusted).
      * Ikuti [petunjuk ini](/guides/cloud-setup-rest-api) jika kamu ingin terhubung menggunakan REST API alih-alih Qiskit.
      * Jika diperlukan, gunakan [informasi ini](/guides/quickstart-steps-org#firewall) untuk mengonfigurasi firewall agar bisa mengakses endpoint API IBM Quantum.
</Admonition>

## Sebelum mulai {#before-you-begin}

1. Pastikan kamu bekerja di lingkungan Python yang aktif dengan [`qiskit` dan `qiskit-ibm-runtime` packages terinstal](/guides/install-qiskit#local).

1. Aktifkan virtual environment Python dan jalankan Python di dalamnya.

1. Masuk ke [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Temukan kredensial akses kamu {#find-your-access-credentials}

1. Pastikan akun dan region yang benar sudah dipilih di account switcher di header.

1. Temukan API key kamu. Dari [dashboard](https://quantum.cloud.ibm.com/), buat API key kamu, lalu salin ke lokasi yang aman agar bisa digunakan untuk autentikasi. Perlu diketahui bahwa kamu bisa menggunakan API key yang sama untuk terhubung ke region mana pun.

1. Opsional: Temukan instance yang ingin kamu gunakan dari halaman [Instances](https://quantum.cloud.ibm.com/instances). Arahkan kursor ke CRN-nya, klik ikon untuk menyalinnya, lalu simpan di lokasi yang aman agar bisa digunakan untuk mengidentifikasi instance tersebut.


<span id="cloud-save"></span>

## Simpan kredensial akses kamu {#save-your-access-credentials}

Simpan kredensial kamu dengan menjalankan kode yang sesuai sekali per akun yang ingin kamu simpan. Setelah menyimpan kredensial, muat kredensial tersebut dengan mengikuti langkah-langkah di [Inisialisasi IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Simpan kredensial yang mengakses instance tertentu: {#save-credentials-that-access-a-specific-instance}
Kalau kamu punya beberapa instance dan ingin dengan mudah memberi tahu Quantum Compute instance mana yang harus digunakan, simpan kredensial yang menyertakan CRN instance.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Simpan kredensial untuk pemilihan instance otomatis: {#save-credentials-for-automatic-instance-selection}
Kalau kamu tidak menyertakan CRN instance dan meneruskan kredensial ini ke Quantum Compute, instance yang sesuai akan dipilihkan untukmu berdasarkan opsi yang ditentukan.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Contoh 2 {#example-2}
Contoh ini menyimpan kredensial untuk pemilihan instance otomatis. Quantum Compute hanya akan melihat instance premium di region EU yang tersedia untuk akun tersebut. Kredensial ini menjadi default yang baru.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Lihat kredensial yang tersimpan {#view-saved-credentials}

Untuk melihat semua kredensial yang sudah kamu simpan, jalankan `service.saved_accounts()`. Perlu diketahui bahwa jika kamu menyimpan kredensial default tanpa menamainya, kredensial tersebut akan diberi nama `default-ibm-quantum-platform`. Jika kamu menamakan kredensial default, kamu akan melihat `"is_default_account": true` di output.

## Pertimbangan {#considerations}

* Jika kamu menyimpan beberapa akun, gunakan parameter `name` untuk membedakannya.

* Kredensial disimpan di `$HOME/.qiskit/qiskit-ibm.json`. Jangan edit file ini secara manual.

* Jika kamu tidak menyimpan kredensial, kamu harus menentukannya setiap kali memulai sesi baru (menginstansiasi IBM Quantum Compute Service).

* Jika kamu menentukan kredensial secara manual, akun yang tersimpan tidak akan digunakan.
