# Instal IBM Quantum Compute client {#install-the-ibm-quantum-compute-client}

IBM Quantum Compute Service adalah layanan berbasis cloud untuk menjalankan komputasi kuantum di hardware IBM Quantum&reg;. Panduan ini menunjukkan cara menginstal `qiskit-ibm-runtime`, yaitu paket client untuk mengakses IBM Quantum Compute Service.

Sebelum menginstal `qiskit-ibm-runtime`, ikuti instruksi di panduan-panduan berikut:

1. [Instal Qiskit](/guides/install-qiskit).

2. [Atur akun IBM Cloud-mu](cloud-setup).


Jalankan perintah ini untuk menginstal IBM Quantum Compute client:

```shell
pip install qiskit-ibm-runtime
```

<Admonition type="note" title="Tetap update dengan versi terbaru">
Cek secara berkala [`qiskit-ibm-runtime` release notes](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/release-notes) untuk melihat rilis baru. Kami menyarankan untuk sering memperbarui kebutuhanmu untuk `qiskit-ibm-runtime` dengan menjalankan `pip install -U qiskit-ibm-runtime`.
</Admonition>
