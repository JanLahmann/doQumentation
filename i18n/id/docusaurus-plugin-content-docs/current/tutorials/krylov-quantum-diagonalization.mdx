## Latar Belakang {#background}

Tutorial ini mendemonstrasikan cara mengimplementasikan diagonalisasi kuantum Krylov (KQD) dalam konteks pola Qiskit. Kamu akan mempelajari teori di balik algoritma ini terlebih dahulu, lalu melihat demonstrasi eksekusinya di QPU.

Mengestimasi sifat energi rendah dari Hamiltonian banyak-benda adalah tugas utama dalam simulasi kuantum.
Sebagai contoh, energi keadaan dasar dan eksitasi tingkat rendah berkaitan langsung dengan stabilitas kimia, tata magnetik, transisi fase kuantum, dan respons material.
Pada komputer klasik, dimensi ruang Hilbert tumbuh secara eksponensial seiring bertambahnya jumlah orbital atau spin, sehingga diagonalisasi langsung dengan cepat menjadi tidak praktis.

Ada beberapa pendekatan komputasi kuantum untuk masalah ini.
Metode variasional jangka pendek, seperti [variational quantum eigensolver (VQE)](/tutorials/spin-chain-vqe), menggunakan circuit berparameter yang relatif dangkal, tetapi memerlukan loop optimasi klasik nonlinear dengan banyak evaluasi quantum circuit.
Di sisi lain, [quantum phase estimation (QPE)](https://arxiv.org/abs/quant-ph/0604193) memberikan rute yang lebih langsung untuk estimasi eigenvalue dengan jaminan yang ketat, tetapi QPE standar memerlukan circuit koheren yang panjang dan terutama cocok untuk komputer kuantum fault-tolerant.
KQD berada di antara kedua pendekatan ini: ia menggunakan evolusi Hamiltonian real-time, seperti pada algoritma berbasis phase-estimation, tetapi menggantikan phase estimation penuh dengan masalah eigenvalue terproyeksi yang ringkas yang bisa diselesaikan secara klasik.

Perhatikan Hamiltonian $n$-qubit $H$ dan keadaan referensi $\lvert \psi_{0}\rangle$.
Metode KQD membangun subruang Krylov dari keadaan yang berevolusi secara real-time,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

di mana $r$ adalah dimensi Krylov dan $\Delta t$ adalah langkah waktu.
Setiap keadaan dalam subruang Krylov kemudian direpresentasikan sebagai kombinasi linear dari keadaan basis ini,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
where the denominator normalizes the state.

Dengan aljabar sederhana, kita bisa melihat bahwa energi yang bersesuaian ditulis sebagai Rayleigh quotient,

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

Di sini, matriks $\mathcal{S}$ dan $\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

mendefinisikan matriks overlap dan Hamiltonian yang diproyeksikan.
Entrinya diestimasi menggunakan pengukuran quantum circuit.

Kita bertujuan menemukan koefisien $\mathbf{c}$ yang menghasilkan $E(\mathbf{c})$ minimum:

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

Menurut teorema Rayleigh-Ritz, minimisasi ini setara dengan menyelesaikan generalized eigenvalue problem (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

Perhatikan bahwa dimensi $r$ bisa cukup kecil sehingga komputer klasik bisa menyelesaikan GEVP.

Ini adalah prinsip variasional yang sama yang digunakan dalam diagonalisasi subruang klasik, tetapi di sini keadaan basisnya dihasilkan oleh evolusi waktu kuantum.
Dibandingkan dengan VQE, KQD biasanya memerlukan circuit yang lebih dalam karena bergantung pada evolusi real-time.
Sebagai imbalannya, KQD menghindari optimasi parameter nonlinear dan eksekusi perangkat keras kuantum iteratif, dan secara sistematis meningkat seiring diperbesarnya subruang yang diproyeksikan.
Algoritma ini telah didemonstrasikan dalam skala besar pada perangkat keras kuantum yang ada [\[2\]](#references), dan kinerjanya bisa dianalisis dengan jaminan yang bisa dibuktikan [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.primitives import StatevectorEstimator

from qiskit.synthesis import LieTrotter, SuzukiTrotter
from qiskit.transpiler import PassManager, Layout
from qiskit.transpiler.passes import CommutativeOptimization
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### Atur parameter untuk algoritma {#set-the-parameters-for-the-algorithm}

Berdasarkan batas atas pada norma Hamiltonian, Ref. [\[1\]](#references) secara heuristik menyarankan langkah waktu $\Delta t$ sebagai $\pi/\|H\|$.
Karena norma spektral $\|H\|$ sulit dihitung, kita malah menggunakan batas atasnya:

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ matrix, easy to calculate the norm}} = 3(n-1).
\end{equation*}
$$

#### Membangun circuit {#build-circuit}

Di sini, kita membangun circuit untuk mengestimasi elemen matriks $\mathcal{H}_{k\ell}$ dan $\mathcal{S}_{k\ell}$.
Karena semua pangkat dari $H$ berkomutasi, kita memperoleh
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Such matrices where the elements depend on the index differences in this manner are called *Toeplitz* and can be reconstructed from first-row elements indexed by $d=\ell-k$.

Di sini, kita menyajikan circuit, yang disebut **extended-swap-test**, yang menyiapkan
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
di mana $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$.

#### Circuit extended swap test [\[3\]](#references) {#extended-swap-test-circuit-3references}

Circuit pertama-tama menyiapkan keadaan referensi pada register sistem sementara ancilla tetap berada di $|0\rangle$:

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

Kemudian, menerapkan gate Hadamard pada ancilla menciptakan superposisi koheren dari dua cabang:

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Akhirnya, gate evolusi waktu terkontrol diterapkan:

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

hanya ketika ancilla berada di cabang $|1\rangle$. Oleh karena itu,

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Pada blok kode berikutnya, kita mengimplementasikan:
$$
\begin{equation*}
|\Psi(t)\rangle = \frac{|0\rangle|\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}},
\end{equation*}
$$
yang akan ditetapkan sebagai $t=d\Delta t$ untuk $d=1,\cdots r-1$ pada langkah eksekusi.

```python
ancilla = 0
system_qubits = list(range(1, num_qubits + 1))

extended_swap_test = QuantumCircuit(num_qubits + 1)

# Append state preparation part
extended_swap_test = extended_swap_test.compose(qc_ref, system_qubits)

# Prepare the coherent branch label, (|0> + |1>) / sqrt(2).
extended_swap_test.h(ancilla)

# Apply U(t) only to the |1> branch of the ancilla.
extended_swap_test.append(
    controlled_evolution_gate, [ancilla] + system_qubits

# Decompose once more for visualization so that control bullets are visible.
display(extended_swap_test.draw("mpl", fold=-1))
```

#### Observable {#observables}

Untuk observable sistem Hermitian $O$ apa pun, di sini kita menetapkan observable yang akan dihitung:

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Ini karena $O=I$ memberikan elemen overlap $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$, sementara $O=H$ memberikan elemen Hamiltonian $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$.

Dengan menggunakan $X=|0\rangle\langle 1|+|1\rangle\langle 0|$, kita memperoleh

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

Demikian pula, dengan menggunakan $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

Oleh karena itu, kita memperoleh
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Akhirnya, untuk setiap keadaan $|\Psi_{0d}\rangle$, kita perlu mengukur:
$$
\begin{align*}
X \otimes I \text{ untuk } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ untuk } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ untuk } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ untuk } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

Untuk estimasi elemen matriks $\mathcal{H}$, jumlah suku Pauli jauh lebih besar dibandingkan untuk elemen matriks $\mathcal{S}$.

Kita sekarang dapat mengurangi jumlah suku Hamiltonian yang diukur dengan menggunakan teknik pergeseran [\[4\]](#references).
Kita memisahkan Hamiltonian sebagai:

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

di mana $T$ dipilih sedemikian rupa sehingga keadaan referensi merupakan eigenstate-nya,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Then,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Here,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

adalah elemen matriks Hamiltonian yang telah digeser.
Oleh karena itu, kita hanya perlu mengukur $X\otimes (H-T)$ dan $Y\otimes (H-T)$.
Kontribusi dari $T$ direkonstruksi secara klasik dengan menggunakan elemen matriks overlap $\mathcal{S}_{0d}$ yang telah diukur.

Dalam contoh ini, pilihan yang alami adalah bagian diagonal dari Hamiltonian Heisenberg,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

Karena keadaan referensi adalah keadaan basis komputasi, ia merupakan eigenstate dari setiap suku $Z_iZ_{i+1}$.

Namun, pilihan yang lebih menguntungkan adalah menyertakan tidak hanya suku diagonal $ZZ$, tetapi juga suku $XX+YY$ yang menganihilasi keadaan referensi.

Untuk setiap pasangan tetangga, operator $XX+YY$ memenuhi

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

and

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

Oleh karena itu, suku $XX+YY$ berkontribusi hanya ketika dua qubit tetangga memiliki okupansi yang berbeda pada bitstring referensi.
Jika kedua qubit sama-sama $0$ atau sama-sama $1$, suku tersebut menganihilasi keadaan referensi dan juga dapat digeser keluar.

Misalkan $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, di mana $z_i \in \{0,1\}$.
Dengan demikian, kita dapat memilih
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Operator ini masih memenuhi

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

karena suku $ZZ$ bekerja secara diagonal pada $|\psi_0\rangle$, sementara suku $XX+YY$ yang telah digeser memberikan nol.
Eigenvalue yang bersesuaian oleh karena itu ditentukan hanya oleh suku $ZZ$,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

Dengan pilihan ini, Hamiltonian yang telah digeser menjadi:
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Sebagai hasilnya, hanya edge dengan okupansi yang berbeda pada keadaan referensi yang perlu diukur.
Semua suku $ZZ$ dan semua suku $XX+YY$ yang tidak aktif direkonstruksi melalui kontribusi overlap $\tau \mathcal{S}_{0d}$, atau memberikan kontribusi nol berdasarkan konstruksinya.

Ini menghasilkan observable yang lebih kecil dibandingkan hanya menggeser bagian diagonal.
Secara khusus, untuk keadaan referensi basis komputasi dengan eksitasi yang terlokalisasi, hanya edge yang berdekatan dengan eksitasi yang tersisa dalam $H-T$.
Oleh karena itu, jumlah suku Pauli dalam $X\otimes(H-T)$ dan $Y\otimes(H-T)$ dapat dikurangi secara substansial, sementara elemen matriks yang direkonstruksi
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

tetap sama persis.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau
```

### Langkah 2: Optimalkan masalah untuk eksekusi perangkat keras kuantum {#step-2-optimize-problem-for-quantum-hardware-execution}

Sekarang kita mengubah circuit extended-swap-test yang abstrak menjadi template yang berorientasi hardware.
Sebelum itu, kita terlebih dahulu mengoptimalkan lebih lanjut circuit tersebut pada level abstrak.

#### Membandingkan urutan suku Hamiltonian {#compare-hamiltonian-term-ordering}

Pertama, kita membandingkan berbagai urutan suku Pauli dalam Hamiltonian Heisenberg untuk simulasi Hamiltonian.
Hamiltonian itu sendiri tidak berubah, tetapi urutan tersebut memengaruhi bagaimana circuit product-formula dihasilkan dan seberapa besar strukturnya dapat diparalelkan dalam circuit.
Sebagai contoh, urutan naif mendaftarkan semua suku $XX$ tetangga terdekat, kemudian semua suku $YY$, lalu semua suku $ZZ$.
Hal ini menempatkan edge yang berdekatan seperti $(0,1)$ dan $(1,2)$ bersebelahan satu sama lain, sehingga tidak dapat dieksekusi secara paralel.
Urutan even-then-odd mengunjungi edge genap yang saling lepas terlebih dahulu, diikuti oleh edge ganjil, yang menyingkap layer dua-qubit paralel.
Urutan even-odd edge-grouped melangkah lebih jauh lagi: untuk setiap edge, ia menjaga suku $XX$, $YY$, dan $ZZ$ lokal tetap bersama, sambil tetap mengunjungi edge genap sebelum edge ganjil.
Kita mengharapkan urutan even-then-odd dan even-odd edge-grouped mengurangi kedalaman circuit dengan menyingkap layer dua-qubit paralel, dan urutan edge-grouped juga mengurangi error Trotter karena interaksi dua-qubit lokal pada edge yang sama ditangani sebagai blok yang kompak.

![Pauli evolutions with different term ordering](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

Urutan Hamiltonian juga memengaruhi error Trotter.
Jika kita menempatkan suku-suku yang tidak berkomutasi bersebelahan, transisi basis terjadi lebih sering, yang menyebabkan lebih banyak error Trotter.
Dengan mengelompokkan suku-suku yang memerlukan transformasi basis-Pauli yang sama, perubahan basis yang redundan dapat dihindari.

Di sini, perbandingan menggunakan waktu evolusi terbesar yang muncul dalam estimasi Krylov baris pertama,
$t_{\max} = (r-1)\Delta t,$
dengan menggunakan kondisi transpilasi yang sama.

Untuk mengukur error Trotter, kita menggunakan **process infidelity** antara circuit yang di-Trotterisasi dan evolusi Hamiltonian yang eksak,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
where $d=2^n$ is the dimension of the Hilbert space.

Diagnostik ini menggunakan matriks padat, sehingga cocok untuk contoh 12-qubit kecil ini tetapi tidak dimaksudkan sebagai subrutin yang scalable.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

def build_numeric_evolution_circuit(
    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:
    """Build a numeric circuit for exp(-i H t) with a chosen synthesis rule."""
    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

print("Precomputing the exact evolution operator... ", end="")
exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### Menghapus gate evolusi waktu terkontrol {#remove-the-controlled-time-evolution-gate}

Dalam extended swap test, mengontrol evolusi waktu dengan satu qubit ancilla mengharuskan ancilla untuk mengontrol banyak gate di seluruh sistem.
Hal ini dapat memperkenalkan overhead routing yang substansial dan, dalam kasus terburuk, secara efektif memerlukan konektivitas all-to-one.
Untuk menghindari hal ini, optimasi lebih lanjut dimungkinkan dengan menggantikan gate evolusi waktu terkontrol dengan versi bebas-kontrol, memanfaatkan simetri Hamiltonian.
Mari kita amati circuit berikut.

![circuit optimization](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

Di sini, $B_{\rm ref}$ menyiapkan keadaan referensi, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

Alih-alih terlebih dahulu menyiapkan $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$ dan kemudian menerapkan $U(t)$ hanya pada cabang $|1\rangle$, circuit secara langsung menyiapkan kedua cabang sebagai

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

where

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

Circuit pertama-tama menerapkan gate Hadamard pada ancilla dan menyiapkan keadaan referensi hanya pada cabang $|1\rangle$:

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Kemudian operator evolusi waktu yang tidak terkontrol diterapkan pada kedua cabang:

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Karena Hamiltonian mempertahankan jumlah eksitasi, kita dapat melihat bahwa $|0^n\rangle$ adalah eigenstate-nya, dan dengan demikian
operator evolusi hanya mengakumulasi fase di bawah Hamiltonian:
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Therefore,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Selanjutnya, $B_{\rm ref}$ diterapkan hanya pada cabang $|0\rangle$.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Pada titik ini, kedua cabang memiliki fase relatif tambahan. Untuk menghilangkannya, kita menerapkan gate fase ancilla

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

Ini mentransformasi keadaan sebagai

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Dengan demikian, hingga fase global yang tidak relevan, kita akhirnya menyiapkan

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

Pada blok kode berikutnya, kita mengimplementasikan circuit bebas-kontrol ini.


### Langkah 3: Eksekusi menggunakan Qiskit primitives {#step-3-execute-using-qiskit-primitives}

Langkah selanjutnya adalah mengirimkan circuit terparameterisasi yang sama untuk beberapa nilai $d$. Untuk setiap $d$, kita mengestimasi empat nilai ekspektasi: $X\otimes I$, $Y\otimes I$, $X\otimes (H-T)$, dan $Y\otimes (H-T)$. Keempat angka ini kemudian digabungkan menjadi elemen baris pertama kompleks $\mathcal{S}_{0d}$ dan $\mathcal{H}_{0d}$.

Di sini, $\mathcal{S}_{00}=1$ dan $\mathcal{H}_{00}=\langle\psi_{0}|(H-T)|\psi_{0}\rangle=\langle\psi_{0}|H|\psi_{0}\rangle-\tau$ dapat dihitung secara klasik karena $\lvert\psi_0\rangle$ bersifat sparse, sehingga kita melewatkan kasus $d=0$.

### Langkah 4: Pasca-proses dan kembalikan hasil dalam format klasik yang diinginkan {#step-4-post-process-and-return-result-in-desired-classical-format}
Setelah mengestimasi matriks yang terproyeksi, kita meregularisasi dan menyelesaikan GEVP
$$
\begin{equation*}
\mathcal{H}\mathbf{c} = E\mathcal{S}\mathbf{c}.
\end{equation*}
$$
Eigenvalue tergeneralisasi terkecil memberikan estimasi KQD dari energi keadaan dasar.


## Lampiran: Sudut pandang fungsi-Hamiltonian (filter-spektral) {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

Alur kerja utama menyajikan KQD secara operasional: membangun basis Krylov dari keadaan yang dievolusikan secara waktu-nyata, mengestimasi matriks terproyeksi $\mathcal{H}$ dan $\mathcal{S}$, dan menyelesaikan GEVP.
Lampiran ini meninjau kembali perhitungan yang *sama* dari sudut pandang komplementer yang menjelaskan **mengapa** KQD bekerja: sudut pandang *fungsi-Hamiltonian*, atau *filter-spektral* [\[3\]](#references), [\[5\]](#references).
Lampiran ini menggunakan kembali model 12-qubit, langkah waktu $\Delta t$, dan solusi Krylov yang sudah diperoleh di atas; tidak diperlukan eksekusi circuit baru.

### Keadaan referensi sebagai distribusi energi {#the-reference-state-as-an-energy-distribution}

Misalkan Hamiltonian memiliki dekomposisi eigen

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

dengan eigenstate energi $|E_m\rangle$.
Keadaan referensi apa pun dapat diekspansikan dalam basis eigen ini,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

sehingga ia membawa **bobot spektral** $p_m=|a_m|^2$ pada setiap energi $E_m$.
Energi referensi adalah rata-rata dari distribusi ini, $\langle H\rangle_{0}=\sum_m p_m E_m$.

Dekomposisi eigen dari Hamiltonian $n$-qubit yang umum berbiaya eksponensial, sehingga gambaran ini hanya merupakan diagnostik, yang *bukan* bagian dari algoritma.
Di sini, bagaimanapun, kita dapat menghitungnya dengan murah untuk masalah $n=12$ yang *sama*: Hamiltonian Heisenberg mengonservasi jumlah total eksitasi, dan referensi $|000001000000\rangle$ membawa satu eksitasi, sehingga seluruh konten spektralnya berada dalam subruang eksitasi tunggal yang dimensinya hanya bertumbuh secara linear terhadap $n$.
Oleh karena itu, kita menggunakan kembali blok eksitasi tunggal yang eksak (sudah digunakan di atas sebagai benchmark) dan membaca distribusi referensi $\{(E_m, p_m)\}$ di dalam subruang tersebut.

### KQD mempelajari filter yang membentuk ulang distribusi ini {#kqd-learns-a-filter-that-reshapes-this-distribution}

Sebuah **fungsi-Hamiltonian** $f(H)$ didefinisikan melalui kalkulus spektral,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

atau dengan kata lain, jumlah berbobot dari eigenprojector.
Menerapkannya pada referensi membentuk ulang setiap amplitudo spektral, $a_m \to a_m f(E_m)$:

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

Jika $f$ memiliki puncak yang tajam pada energi terendah ($f(E_0)=1$ dan $f(E_m)\approx 0$ selainnya) maka $f(H)$ akan bertindak sebagai proyektor keadaan-dasar, dan output yang dinormalisasi akan (mendekati) keadaan dasar.
Oleh karena itu, **filter spektral** low-pass yang baik dalam energi adalah tepat apa yang kita inginkan.

KQD tidak menentukan $f$ terlebih dahulu. Sebaliknya, ia mengekspansikan filter dalam basis evolusi waktu-nyata,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

sebuah fungsi *trigonometrik* dari energi yang koefisiennya $\{c_\ell\}$ tepatnya merupakan eigenvector GEVP yang diselesaikan di atas.
Meminimalkan quotient Rayleigh $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ oleh karena itu sama dengan *mempelajari* filter yang paling baik menekan bobot keadaan-tereksitasi dari referensi.
Dimensi Krylov $r$ yang lebih besar memberikan filter lebih banyak derajat kebebasan dan puncak yang lebih tajam pada energi keadaan-dasar.

Helper di bawah ini mengevaluasi filter yang telah dipelajari ini pada sumbu energi; kita kemudian menerapkannya pada distribusi referensi yang diperoleh di atas.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### Meningkatkan dimensi Krylov: fleksibilitas dari fungsi yang telah dipelajari {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

Ingat kembali bahwa filter yang telah dipelajari adalah polinomial trigonometrik dalam energi dengan $r$ koefisien,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

Dimensi Krylov $r$ persis merupakan jumlah koefisien bebas, sehingga ia mengontrol **fleksibilitas** dari fungsi tersebut.
$r$ yang kecil hanya dapat menghasilkan filter yang lebar dan bervariasi secara perlahan yang membocorkan bobot ke keadaan-keadaan tereksitasi berenergi rendah; ketika $r$ meningkat, filter dapat membentuk puncak yang lebih sempit pada energi target dan menekan sisa bobot keadaan-tereksitasi secara lebih agresif.
Ini adalah rekan filter-spektral dari konvergensi energi yang diamati pada contoh skala kecil: seiring bertambahnya $r$, distribusi yang telah difilter mengempis menuju keadaan dasar subruang dan energi yang diestimasi menurun mendekatinya.

Kita menggunakan kembali matriks terproyeksi yang sudah diestimasi di atas dan cukup menyelesaikan GEVP pada setiap blok $r\times r$ terdepan, kemudian mengevaluasi dan memplot filter yang bersesuaian.

```python
# Sweep the Krylov dimension using the leading r x r blocks of the estimated matrices.
sweep_dims = [r for r in (2, 4, 6, 8, krylov_dim) if r <= krylov_dim]
sweep_dims = sorted(set(sweep_dims))

energy_grid = np.linspace(
    subspace_evals.min() - 0.5, subspace_evals.max() + 0.5, 800
)

sweep_cases = []
print(" r    retained    ground overlap    filtered energy")
print("--    --------    --------------    ---------------")
for r in sweep_dims:
    _, coeffs_r, retained_r = solve_thresholded_gevp(
        h_matrix_est[:r, :r],
        s_matrix_est[:r, :r],
        threshold=1e-12,
    )
    filter_on_spectrum_r = trigonometric_krylov_filter(
        coeffs_r, subspace_evals, dt
    )
    filtered_weights_r = filtered_spectral_weights(
        ref_spectral_weights, filter_on_spectrum_r
    )
    filtered_energy_r = float(np.sum(filtered_weights_r * subspace_evals))

    sweep_cases.append((r, coeffs_r, filtered_weights_r))
    print(
        f"{r:2d}    {retained_r:8d}    {filtered_weights_r[0]:14.4f}    {filtered_energy_r:15.6f}"
    )

print(f"\nSubspace ground-state energy (target): {subspace_evals[0]:.6f}")

# One panel per Krylov dimension: filtered spectrum (bars) + filter intensity (curve).
fig, axes = plt.subplots(
    len(sweep_cases),
    1,
    figsize=(8, 2.1 * len(sweep_cases)),
    sharex=True,
)
axes = np.atleast_1d(axes)

for idx, (ax, (r, coeffs_r, filtered_weights_r)) in enumerate(
    zip(axes, sweep_cases)
):
    visible = (ref_spectral_weights > 1e-4) | (filtered_weights_r > 1e-4)
    ax.bar(
        subspace_evals[visible],
        ref_spectral_weights[visible],
        width=0.18,
        alpha=0.35,
        color="C0",
        label="reference $p_m$" if idx == 0 else None,
    )
    ax.bar(
        subspace_evals[visible],
        filtered_weights_r[visible],
        width=0.14,
        alpha=0.9,
        color="C1",
        label="filtered weights" if idx == 0 else None,
    )

    filter_intensity_r = (
        np.abs(trigonometric_krylov_filter(coeffs_r, energy_grid, dt)) ** 2
    )
    filter_intensity_r /= filter_intensity_r.max()
    ax.plot(energy_grid, filter_intensity_r, color="k", linewidth=2)

    ax.axvline(subspace_evals[0], color="C3", linestyle="--", linewidth=1)
    ax.set_ylim(0, 1)
    ax.set_ylabel("weight")
    ax.legend(loc="upper right", title=f"$r={r}$")

axes[-1].set_xlabel("Energy eigenvalue $E_m$")
fig.suptitle(
    r"KQD-learned filter $|f_{\rm KQD}(E)|^2$ sharpening with Krylov dimension $r$",
    y=1.0,
)
fig.tight_layout()
plt.show()
```
