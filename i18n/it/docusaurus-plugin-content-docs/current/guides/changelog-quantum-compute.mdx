# Client IBM Quantum Compute v0.46.0 {#ibm-quantum-compute-client-v0460}

## Aprile 2026 {#april-2026}

<span id="executor-primitive"></span>
- **Introducing the Executor primitive**: We're excited to announce the release of the new `Executor` primitive and a new version of the noise-learning helper class, `NoiseLearnerV3`, both of which were first previewed at QDC 2025.

  Insieme a [Samplomatic](https://qiskit.github.io/samplomatic/index.html), costituiscono il [modello di esecuzione diretta](/guides/directed-execution-model), che fornisce piena trasparenza e controllo per ottimizzare il tuo workflow di mitigazione degli errori. Il tutorial [Probabilistic error cancellation with shaded lightcones](https://qiskit.github.io/qiskit-addon-slc/tutorials/01_getting_started.html), ad esempio, mostra come questo modello venga usato per combinare tecniche avanzate, tra cui shaded lightcones, probabilistic error cancellation (PEC), Twirled Readout Error eXtinction (TREX) e [postselezione basata sulla misurazione](/guides/post-selection), per migliorare ulteriormente la qualità dei risultati.

  Se preferisci un livello di astrazione più alto, [`EstimatorV2`](/guides/estimator-noise-management) in Qiskit Runtime continua a fornire diverse tecniche integrate di mitigazione e soppressione degli errori, che puoi facilmente regolare usando l'opzione [`resilience_level`](/guides/estimator-noise-management#resilience-level).

  Per saperne di più, consulta le seguenti guide:

    - [Guida rapida a Executor](/guides/get-started-with-executor)

    - [Helper per l'apprendimento del rumore](/guides/noise-learning)


  Entrambe queste nuove funzionalità sono attualmente in beta e richiedono `qiskit-ibm-runtime` versione 0.47.0 o superiore.
