# Qiskit Code Assistant {#qiskit-code-assistant}

<span id="qca-sunset"></span>

## 29 maggio 2026 {#29-may-2026}
- **Servizio Qiskit Code Assistant interrotto** - Il servizio di anteprima è stato interrotto e le estensioni per Visual Studio Code e JupyterLab sono state archiviate.


  In base al feedback e ai modelli di utilizzo, sempre più utenti eseguono i modelli di Qiskit Code Assistant localmente e lavorano con integrazioni dell'editor già presenti nel loro workflow di sviluppo.

  I modelli di Qiskit Code Assistant rimangono disponibili per l'uso locale. Consulta la documentazione [Qiskit Code Assistant](/guides/qiskit-code-assistant) per maggiori informazioni.
