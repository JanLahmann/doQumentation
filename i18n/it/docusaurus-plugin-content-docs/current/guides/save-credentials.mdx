# Salvare le credenziali di accesso {#save-your-login-credentials}
Se stai lavorando in un ambiente Python attendibile (ad esempio su un laptop o una workstation personale), puoi usare il metodo `save_account()` per salvare le tue credenziali in locale e poi utilizzarle per inizializzare il servizio.

<Admonition type="note" title="Note">
      * Se stai usando un computer pubblico o un altro ambiente non attendibile, segui invece le istruzioni in [Inizializzare il servizio in un ambiente non attendibile](/guides/cloud-setup-untrusted).
      * Segui [queste istruzioni](/guides/cloud-setup-rest-api) se vuoi connetterti tramite l'API REST invece di usare Qiskit.
      * Se necessario, usa [queste informazioni](/guides/quickstart-steps-org#firewall) per configurare il firewall e abilitare l'accesso agli endpoint API di IBM Quantum.
</Admonition>

## Prima di iniziare {#before-you-begin}

1. Assicurati di lavorare in un ambiente Python attivo con i pacchetti [`qiskit` e `qiskit-ibm-runtime` installati](/guides/install-qiskit#local).

1. Attiva l'ambiente virtuale Python ed esegui Python al suo interno.

1. Accedi a [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Trovare le credenziali di accesso {#find-your-access-credentials}

1. Assicurati che l'account e la regione corretti siano selezionati nel selettore di account nell'intestazione.

1. Trova la tua chiave API. Dal [dashboard](https://quantum.cloud.ibm.com/), crea la tua chiave API, quindi copiala in una posizione sicura per poterla usare per l'autenticazione. Nota che puoi usare la stessa chiave API per connetterti a qualsiasi regione.

1. Facoltativo: trova l'istanza che desideri usare dalla pagina [Istanze](https://quantum.cloud.ibm.com/instances). Passa il cursore sul suo CRN, fai clic sull'icona per copiarlo, quindi salvalo in una posizione sicura per poterlo usare per identificare l'istanza.


<span id="cloud-save"></span>

## Salvare le credenziali di accesso {#save-your-access-credentials}

Salva le tue credenziali eseguendo il codice appropriato una volta per ogni account che vuoi salvare. Dopo aver salvato le credenziali, caricale seguendo i passaggi in [Inizializzare IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Salvare credenziali che accedono a un'istanza specifica: {#save-credentials-that-access-a-specific-instance}
Se hai più istanze e vuoi indicare facilmente a Quantum Compute quale usare, salva credenziali che includono un CRN di istanza.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Salvare credenziali per la selezione automatica dell'istanza: {#save-credentials-for-automatic-instance-selection}
Se non fornisci un CRN di istanza e passi queste credenziali a Quantum Compute, verrà scelta automaticamente un'istanza appropriata in base alle opzioni specificate.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Esempio 2 {#example-2}
Questo esempio salva le credenziali per la selezione automatica dell'istanza. Quantum Compute considererà solo le istanze premium nella regione EU disponibili per l'account. Queste credenziali diventano il nuovo predefinito.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Visualizzare le credenziali salvate {#view-saved-credentials}

Per visualizzare tutte le credenziali salvate, esegui `service.saved_accounts()`. Nota che se hai salvato le credenziali predefinite senza assegnare loro un nome, vengono denominate `default-ibm-quantum-platform`. Se hai assegnato un nome alle tue credenziali predefinite, vedrai `"is_default_account": true` nell'output.

## Considerazioni {#considerations}

* Se stai salvando più account, usa il parametro `name` per distinguerli.

* Le credenziali vengono salvate in `$HOME/.qiskit/qiskit-ibm.json`. Non modificare questo file manualmente.

* Se non salvi le credenziali, dovrai specificarle ogni volta che avvii una nuova sessione (istanziando IBM Quantum Compute Service).

* Se specifichi manualmente le tue credenziali, un account salvato non verrà utilizzato.
