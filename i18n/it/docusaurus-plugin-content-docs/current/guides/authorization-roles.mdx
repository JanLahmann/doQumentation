# Ruoli di autorizzazione {#authorization-roles}

Esamina i ruoli disponibili e le azioni associate a ciascuno per aiutarti ad assegnare l'accesso. Per maggiori informazioni, vedi [Ruoli e azioni IAM](https://cloud.ibm.com/docs/iam?topic=iam-iam-service-roles-actions#service-roles-table155) su IBM Cloud&reg;.

## IBM Quantum Compute Service {#ibm-quantum-compute-service}

| Permesso | Richiesto da |
| -- | -- |
| `quantum-computing.account-analytics-filters.read` | Ottenere i filtri di analisi (`GET /v1/analytics/filters`) |
| `quantum-computing.account-analytics-usage.read` | Ottenere l'analisi dell'utilizzo (`GET /v1/analytics/usage`) |
| `quantum-computing.account-analytics-usage.read` | Ottenere l'analisi dell'utilizzo raggruppata (`GET /v1/analytics/usage_grouped`) |
| `quantum-computing.account-analytics-usage.read` | Ottenere l'analisi dell'utilizzo raggruppata per data (`GET /v1/analytics/usage_grouped_by_date`) |
| `quantum-computing.account-configuration.read` | Ottenere la configurazione dell'account (`GET /v1/accounts/{id}`) |
| `quantum-computing.device.read` | Ottenere la configurazione del backend (`GET /v1/backends/{id}/configuration`) |
| `quantum-computing.device.read` | Ottenere le impostazioni predefinite del backend (`GET /v1/backends/{id}/defaults`) |
| `quantum-computing.device.read` | Ottenere le proprietà del backend (`GET /v1/backends/{id}/properties`) |
| `quantum-computing.device.read` | Ottenere lo stato del backend (`GET /v1/backends/{id}/status`) |
| `quantum-computing.device.read` | Elencare i tuoi backend (`GET /v1/backends`) |
| `quantum-computing.instance-usage.read` | Ottenere l'utilizzo dell'istanza (`GET /v1/instances/usage`) |
| `quantum-computing.instance.configuration.read` | Ottenere la configurazione dell'istanza (`GET /v1/instances/configuration`) |
| `quantum-computing.instance.read` | Ottenere i dettagli dell'istanza corrente (`GET /v1/instance`) |
| `quantum-computing.job.cancel` | Annullare un job (`POST /v1/jobs/{id}/cancel`) |
| `quantum-computing.job.create` | Eseguire un job (`POST /v1/jobs`) |
| `quantum-computing.job.delete` | Eliminare un job (`DELETE /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Ottenere le metriche del job (`GET /v1/jobs/{id}/metrics`) |
| `quantum-computing.job.read` | Elencare i dettagli del job (`GET /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Elencare i log del job (`GET /v1/jobs/{id}/logs`) |
| `quantum-computing.job.read` | Elencare i risultati del job (`GET /v1/jobs/{id}/results`) |
| `quantum-computing.job.read` | Elencare i job (`GET /v1/jobs`) |
| `quantum-computing.job.read` | Elencare i tag (`GET /v1/tags`) |
| `quantum-computing.session.create` | Creare una sessione (`POST /v1/sessions`) |
| `quantum-computing.session.read` | Ottenere una sessione (`GET /v1/sessions/{id}`) |
| `quantum-computing.session.update` | Chiudere la sessione del job (`DELETE /v1/sessions/{id}/close`) |
| `quantum-computing.session.update` | Aggiornare una sessione (`PATCH /v1/sessions/{id}`) |
| `quantum-computing.workload.list` | Elencare i carichi di lavoro dell'istanza utente (`GET /v1/workloads`) |

## IBM Quantum System Service {#ibm-quantum-system-service}

| Permesso | Richiesto da |
| -- | -- |
| `quantum-computing.direct-access-backend-configuration.read` | Ottenere la configurazione del backend (`GET /v1/backends/{backend-name}/configuration`) |
| `quantum-computing.direct-access-backend-properties.read` | Ottenere le proprietà del backend (`GET /v1/backends/{backend-name}/properties`) |
| `quantum-computing.direct-access-backend.list` | Ottenere l'elenco dei backend (`GET /v1/backends`) |
| `quantum-computing.direct-access-backend.read` | Ottenere i dettagli del backend (`GET /v1/backends/{backend-name}`) |
| `quantum-computing.direct-access-job.cancel` | Annullare un job (`POST /v1/jobs/{job-id}/cancel`) |
| `quantum-computing.direct-access-job.create` | Eseguire un job (`POST /v1/jobs`) |
| `quantum-computing.direct-access-job.delete` | Eliminare un job (`DELETE /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-job.list` | Ottenere i job (`GET /v1/jobs`) |
| `quantum-computing.direct-access-job.read` | Ottenere un job tramite ID (`GET /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-lane-configuration.list` | Ottenere la configurazione delle lane del backend (`GET /v1/backends/{backend-name}/lanes`) |
