To get information about a qubit's state, you can _measure_ it onto a [classical bit](https://docs.quantum.ibm.com/api/qiskit/circuit#qiskit.circuit.Clbit). In Qiskit, measurements are performed in the computational basis, that is, the single-qubit Pauli-$Z$ basis. Therefore, a measurement yields 0 or 1, depending on the overlap with the Pauli-$Z$ eigenstates $|0\rangle$ and $|1\rangle$:

$$
|q\rangle \xrightarrow{measure}\begin{cases}
      0 (\text{outcome}+1), \text{with probability } p_0=|\langle q|0\rangle|^{2}\text{,} \\
      1 (\text{outcome}-1), \text{with probability } p_1=|\langle q|1\rangle|^{2}\text{.}
    \end{cases}
$$

## Applicare una misurazione a un circuito {#apply-a-measurement-to-a-circuit}

Esistono diversi modi per applicare misurazioni a un circuito:

### Metodo `QuantumCircuit.measure` {#quantumcircuitmeasure-method}

Usa il metodo [`measure`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#measure) per misurare un [`QuantumCircuit`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#quantumcircuit-class).

Esempi:

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(5, 5)
qc.x(0)
qc.x(1)
qc.x(4)
qc.measure(
    range(5), range(5)
)  #  Measures all qubits into the corresponding clbit.
```

### Classe `Measure` {#measure-class}

La classe Qiskit [Measure](https://docs.quantum.ibm.com/api/qiskit/circuit#qiskit.circuit.Measure) misura i qubit specificati.

```python
from qiskit.circuit import Measure

qc = QuantumCircuit(3, 1)
qc.x([0, 1])
qc.append(Measure(), [0], [0])  # measure qubit 0 into clbit 0
```

### Metodo `QuantumCircuit.measure_all` {#quantumcircuitmeasure-all-method}

Per misurare tutti i qubit nei corrispondenti bit classici, usa il metodo [`measure_all`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#measure_all). Per impostazione predefinita, questo metodo aggiunge nuovi bit classici in un `ClassicalRegister` per memorizzare le misurazioni.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3, 1)
qc.x([0, 2])
qc.measure_all()  # Measure all qubits.
```

### Metodo `QuantumCircuit.measure_active` {#quantumcircuitmeasure-active-method}

Per misurare tutti i qubit che non sono inattivi, usa il metodo [`measure_active`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#measure_active). Questo metodo crea un nuovo `ClassicalRegister` con una dimensione pari al numero di qubit non inattivi da misurare.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3, 1)
qc.x([0, 2])
qc.measure_active()  # Measure qubits that are not idle, that is, qubits 0 and 2.
```
