## Contesto {#background}

Questo tutorial dimostra come implementare l'algoritmo di diagonalizzazione quantistica di Krylov (KQD) nel contesto dei pattern Qiskit. Imparerete prima la teoria alla base dell'algoritmo e poi vedrete una dimostrazione della sua esecuzione su una QPU.

Stimare le proprietà a bassa energia di Hamiltoniane a molti corpi è un compito centrale nella simulazione quantistica.
Ad esempio, le energie dello stato fondamentale e le eccitazioni a bassa energia sono direttamente correlate alla stabilità chimica, all'ordinamento magnetico, alle transizioni di fase quantistiche e alla risposta dei materiali.
Su un computer classico, la dimensione dello spazio di Hilbert cresce esponenzialmente con il numero di orbitali o spin, quindi la diagonalizzazione diretta diventa rapidamente impraticabile.

Esistono diversi approcci di calcolo quantistico a questo problema.
I metodi variazionali a breve termine, come l'[eigensolver variazionale quantistico (VQE)](/tutorials/spin-chain-vqe), utilizzano circuiti parametrizzati relativamente poco profondi, ma richiedono un ciclo di ottimizzazione classica non lineare con molte valutazioni del circuito quantistico.
All'altro estremo, la [stima di fase quantistica (QPE)](https://arxiv.org/abs/quant-ph/0604193) fornisce un percorso più diretto alla stima degli autovalori con garanzie rigorose, ma la QPE standard richiede circuiti coerenti lunghi ed è principalmente adatta a computer quantistici fault-tolerant.
La KQD si colloca tra questi due approcci: utilizza l'evoluzione Hamiltoniana in tempo reale, come negli algoritmi basati sulla stima di fase, ma sostituisce la stima di fase completa con un problema agli autovalori proiettato compatto che può essere risolto classicamente.

Consideriamo un'Hamiltoniana a $n$ qubit $H$ e uno stato di riferimento $\lvert \psi_{0}\rangle$.
Il metodo KQD costruisce un sottospazio di Krylov da stati evoluti in tempo reale,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

dove $r$ è la dimensione di Krylov e $\Delta t$ è il passo temporale.
Qualsiasi stato nel sottospazio di Krylov è quindi rappresentato come una combinazione lineare di questi stati di base,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
where the denominator normalizes the state.

Con una semplice algebra, possiamo vedere che l'energia corrispondente è scritta come il quoziente di Rayleigh,

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

Qui, le matrici $\mathcal{S}$ e $\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

definiscono le matrici di overlap e Hamiltoniana proiettate.
I loro elementi sono stimati utilizzando misurazioni di circuiti quantistici.

Miriamo a trovare il coefficiente $\mathbf{c}$ che fornisce il minimo $E(\mathbf{c})$:

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

Per il teorema di Rayleigh-Ritz, questa minimizzazione è equivalente a risolvere il problema agli autovalori generalizzato (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

Nota che la dimensione $r$ può essere abbastanza piccola da permettere a un computer classico di risolvere il GEVP.

Questo è lo stesso principio variazionale utilizzato nella diagonalizzazione classica dei sottospazi, ma qui gli stati di base sono generati dall'evoluzione temporale quantistica.
Rispetto al VQE, la KQD richiede solitamente circuiti più profondi perché si basa sull'evoluzione in tempo reale.
In cambio, la KQD evita l'ottimizzazione non lineare dei parametri e l'esecuzione iterativa su hardware quantistico, e migliora sistematicamente man mano che il sottospazio proiettato viene ampliato.
L'algoritmo è stato dimostrato su larga scala su hardware quantistico esistente [\[2\]](#references), e le sue prestazioni possono essere analizzate con garanzie dimostrabili [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.primitives import StatevectorEstimator
from qiskit.quantum_info import Operator, SparsePauliOp
from qiskit.synthesis import LieTrotter, SuzukiTrotter
from qiskit.transpiler import PassManager, Layout
from qiskit.transpiler.passes import CommutativeOptimization
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### Impostare i parametri per l'algoritmo {#set-the-parameters-for-the-algorithm}

Sulla base dei limiti superiori sulla norma dell'Hamiltoniana, il Rif. [\[1\]](#references) suggerisce euristicamente il passo temporale $\Delta t$ come $\pi/\|H\|$.
Poiché la norma spettrale $\|H\|$ è difficile da calcolare, utilizziamo invece il suo limite superiore:

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ matrix, easy to calculate the norm}} = 3(n-1).
\end{equation*}
$$

Impostiamo la dimensione di Krylov a $r=10$ e il numero di passi di Trotter per passo temporale a $5$: uno spazio di Krylov abbastanza grande da risolvere lo spettro a bassa energia mantenendo il circuito più profondo ($t_{\max}=(r-1)\Delta t$) accessibile, e abbastanza passi di Trotter da mantenere piccolo l'errore di discretizzazione a quel circuito più profondo.

#### Costruire il circuito {#build-circuit}

Qui, costruiamo i circuiti per stimare gli elementi della matrice $\mathcal{H}_{k\ell}$ e $\mathcal{S}_{k\ell}$.
Poiché tutte le potenze di $H$ commutano, abbiamo
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Such matrices where the elements depend on the index differences in this manner are called *Toeplitz* and can be reconstructed from first-row elements indexed by $d=\ell-k$.

Qui, presentiamo il circuito, chiamato **extended-swap-test**, che prepara
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
dove $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$.

#### Circuito di extended swap test [\[3\]](#references) {#extended-swap-test-circuit-3references}

Il circuito prepara prima lo stato di riferimento sul registro di sistema mentre l'ancilla rimane in $|0\rangle$:

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

Quindi, applicando una porta di Hadamard all'ancilla si crea una sovrapposizione coerente di due rami:

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Infine, la porta di evoluzione temporale controllata applica:

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

solo quando l'ancilla è nel ramo $|1\rangle$. Pertanto,

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Nel prossimo blocco di codice, implementiamo:
$$
\begin{equation*}
|\Psi(t)\rangle = \frac{|0\rangle|\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}},
\end{equation*}
$$
che sarà assegnato come $t=d\Delta t$ per $d=1,\cdots r-1$ nella fase di esecuzione.

```python
ancilla = 0
system_qubits = list(range(1, num_qubits + 1))

extended_swap_test = QuantumCircuit(num_qubits + 1)

# Append state preparation part
extended_swap_test = extended_swap_test.compose(qc_ref, system_qubits)

# Prepare the coherent branch label, (|0> + |1>) / sqrt(2).
extended_swap_test.h(ancilla)

# Apply U(t) only to the |1> branch of the ancilla.
extended_swap_test.append(
    controlled_evolution_gate, [ancilla] + system_qubits
)

# Decompose once more for visualization so that control bullets are visible.
display(extended_swap_test.draw("mpl", fold=-1))
```

#### Osservabili {#observables}

Per qualsiasi osservabile hermitiana di sistema $O$, qui impostiamo le osservabili da calcolare:

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Questo perché $O=I$ fornisce l'elemento di overlap $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$, mentre $O=H$ fornisce l'elemento Hamiltoniano $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$.

Utilizzando $X=|0\rangle\langle 1|+|1\rangle\langle 0|$, abbiamo

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

Analogamente, utilizzando $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

Pertanto, abbiamo
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Infine, per ciascuno stato $|\Psi_{0d}\rangle$, dobbiamo misurare:
$$
\begin{align*}
X \otimes I \text{ for } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ for } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ for } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ for } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

Per la stima degli elementi della matrice $\mathcal{H}$, il numero di termini di Pauli è molto maggiore rispetto a quello per gli elementi della matrice $\mathcal{S}$.

Possiamo ora ridurre il numero di termini Hamiltoniani misurati utilizzando una tecnica di shifting [\[4\]](#references).
Dividiamo l'Hamiltoniana come:

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

dove $T$ è scelto in modo tale che lo stato di riferimento sia il suo autostato,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Then,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Here,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

è l'elemento della matrice Hamiltoniana shiftata.
Pertanto, dobbiamo misurare solo $X\otimes (H-T)$ e $Y\otimes (H-T)$.
Il contributo di $T$ viene ricostruito classicamente utilizzando l'elemento della matrice di overlap $\mathcal{S}_{0d}$ già misurato.

In questo esempio, una scelta naturale è la parte diagonale dell'Hamiltoniana di Heisenberg,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

Poiché lo stato di riferimento è uno stato della base computazionale, è un autostato di ogni termine $Z_iZ_{i+1}$.

Tuttavia, una scelta più vantaggiosa è includere non solo i termini diagonali $ZZ$, ma anche i termini $XX+YY$ che annichilano lo stato di riferimento.

Per ogni coppia vicina, l'operatore $XX+YY$ soddisfa

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

and

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

Pertanto, il termine $XX+YY$ contribuisce solo quando i due qubit vicini hanno occupazioni diverse nella stringa binaria di riferimento.
Se entrambi i qubit sono $0$ o entrambi $1$, il termine annichila lo stato di riferimento e può anch'esso essere shiftato fuori.

Sia $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, dove $z_i \in \{0,1\}$.
Quindi, possiamo scegliere
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Questo operatore soddisfa ancora

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

perché i termini $ZZ$ agiscono diagonalmente su $|\psi_0\rangle$, mentre i termini shiftati $XX+YY$ danno zero.
L'autovalore corrispondente è quindi determinato solo dai termini $ZZ$,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

Con questa scelta, l'Hamiltoniana shiftata diventa:
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Di conseguenza, è necessario misurare solo gli archi con occupazioni diverse nello stato di riferimento.
Tutti i termini $ZZ$ e tutti i termini $XX+YY$ inattivi sono ricostruiti tramite il contributo di overlap $\tau \mathcal{S}_{0d}$, oppure danno contributo zero per costruzione.

Questo fornisce un'osservabile più piccola rispetto allo shifting solo della parte diagonale.
In particolare, per uno stato di riferimento della base computazionale con un'eccitazione localizzata, solo gli archi adiacenti all'eccitazione rimangono in $H-T$.
Pertanto, il numero di termini di Pauli in $X\otimes(H-T)$ e $Y\otimes(H-T)$ può essere sostanzialmente ridotto, mentre l'elemento di matrice ricostruito
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

rimane esattamente lo stesso.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau

obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, shift_tau = (
    make_reduced_heisenberg_observables(ref_bitstring)
)

print("Observable: Re shifted H_0d")
print(obs_x_shifted_hamiltonian)
print()

print("Observable: Im shifted H_0d")
print(obs_y_shifted_hamiltonian)

]

    "Im shifted H_0d",
```

### Step 2: Ottimizzare il problema per l'esecuzione su hardware quantistico {#step-2-optimize-problem-for-quantum-hardware-execution}

Ora trasformiamo il circuito astratto di extended-swap-test in un template orientato all'hardware.
Prima di ciò, ottimizziamo ulteriormente il circuito prima a livello astratto.

#### Confrontare l'ordinamento dei termini Hamiltoniani {#compare-hamiltonian-term-ordering}

Innanzitutto, confrontiamo diversi ordinamenti dei termini di Pauli nell'Hamiltoniana di Heisenberg per la simulazione Hamiltoniana.
L'Hamiltoniana stessa rimane invariata, ma l'ordinamento influisce sul modo in cui viene generato il circuito a formula prodotto e su quanto la struttura può essere parallelizzata nel circuito.
Ad esempio, l'ordinamento ingenuo elenca tutti i termini $XX$ tra primi vicini, poi tutti i termini $YY$, poi tutti i termini $ZZ$.
Questo pone archi adiacenti come $(0,1)$ e $(1,2)$ vicini tra loro, quindi non possono essere eseguiti in parallelo.
L'ordinamento pari-poi-dispari visita prima gli archi pari disgiunti, seguiti dagli archi dispari, il che espone livelli paralleli a due qubit.
L'ordinamento raggruppato per archi pari-dispari va un passo oltre: per ogni arco, mantiene insieme i termini locali $XX$, $YY$ e $ZZ$, pur visitando ancora gli archi pari prima di quelli dispari.
Ci aspettiamo che gli ordinamenti pari-poi-dispari e raggruppato per archi pari-dispari riducano la profondità del circuito esponendo livelli paralleli a due qubit, e che l'ordinamento raggruppato per archi riduca inoltre l'errore di Trotter perché l'interazione locale a due qubit sullo stesso arco viene gestita come un blocco compatto.

![Pauli evolutions with different term ordering](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

L'ordinamento Hamiltoniano influisce anche sull'errore di Trotter.
Se poniamo termini non commutanti vicini tra loro, le transizioni di base si verificano più spesso, il che induce più errore di Trotter.
Raggruppando i termini che richiedono la stessa trasformazione della base di Pauli, si possono evitare cambi di base ridondanti.

Qui, il confronto utilizza il tempo di evoluzione più grande che compare nelle stime di Krylov della prima riga,
$t_{\max} = (r-1)\Delta t,$
utilizzando la stessa condizione di transpilazione.

Per misurare l'errore di Trotter, utilizziamo l'**infedeltà di processo** tra il circuito Trotterizzato e l'evoluzione Hamiltoniana esatta,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
where $d=2^n$ is the dimension of the Hilbert space.

Questa diagnostica utilizza matrici dense, quindi è adatta a questo piccolo esempio a 12 qubit ma non è pensata come subroutine scalabile.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

def build_numeric_evolution_circuit(
    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:
    """Build a numeric circuit for exp(-i H t) with a chosen synthesis rule."""
    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

print("Precomputing the exact evolution operator... ", end="")
exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### Rimuovere la porta di evoluzione temporale controllata {#remove-the-controlled-time-evolution-gate}

Nell'extended swap test, controllare l'evoluzione temporale con un singolo qubit ancilla richiede che l'ancilla controlli molte porte in tutto il sistema.
Questo può introdurre un notevole overhead di routing e, nel peggiore dei casi, richiede effettivamente una connettività all-to-one.
Per evitare ciò, è possibile un'ulteriore ottimizzazione sostituendo la porta di evoluzione temporale controllata con una versione senza controllo, sfruttando la simmetria dell'Hamiltoniana.
Osserviamo il seguente circuito.

![circuit optimization](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

Qui, $B_{\rm ref}$ prepara lo stato di riferimento, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

Invece di preparare prima $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$ e poi applicare $U(t)$ solo sul ramo $|1\rangle$, il circuito prepara direttamente i due rami come

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

where

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

Il circuito applica prima una porta di Hadamard all'ancilla e prepara lo stato di riferimento solo sul ramo $|1\rangle$:

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Quindi l'operatore di evoluzione temporale non controllato viene applicato a entrambi i rami:

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Poiché l'Hamiltoniana conserva il numero di eccitazioni, possiamo vedere che $|0^n\rangle$ è il suo autostato, e quindi
l'operatore di evoluzione accumula solo una fase sotto l'Hamiltoniana:
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Therefore,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Successivamente, $B_{\rm ref}$ viene applicato solo sul ramo $|0\rangle$.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

A questo punto, i due rami hanno una fase relativa aggiuntiva. Per rimuoverla, applichiamo la porta di fase dell'ancilla

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

Questo trasforma lo stato come

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Quindi, a meno di una fase globale irrilevante, abbiamo finalmente preparato

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

Nel prossimo blocco di codice, implementiamo questo circuito senza controllo.


### Step 3: Eseguire utilizzando le primitive di Qiskit {#step-3-execute-using-qiskit-primitives}

Per ciascun $d$, stimiamo quattro valori di aspettazione: $X\otimes I$, $Y\otimes I$, $X\otimes (H-T)$ e $Y\otimes (H-T)$. ### Step 4: Post-elaborazione e restituzione del risultato in formato classico desiderato {#step-4-post-process-and-return-result-in-desired-classical-format}
Dopo aver stimato le matrici proiettate, regolarizziamo e risolviamo il GEVP
$$
\begin{equation*}
\mathcal{H}\mathbf{c} = E\mathcal{S}\mathbf{c}.
\end{equation*}
$$
Il più piccolo autovalore generalizzato fornisce la stima KQD dell'energia dello stato fondamentale.

## Appendice: Il punto di vista della funzione Hamiltoniana (filtro spettrale) {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

Il workflow principale ha presentato la KQD in modo operativo: costruire una base di Krylov da stati evoluti in tempo reale, stimare le matrici proiettate $\mathcal{H}$ e $\mathcal{S}$, e risolvere il GEVP.
Questa appendice rivisita lo *stesso* calcolo da un'angolazione complementare che spiega **perché** la KQD funziona: il punto di vista della *funzione Hamiltoniana*, ovvero il *filtro spettrale* [\[3\]](#references), [\[5\]](#references).
Riutilizza il modello a 12 qubit, il passo temporale $\Delta t$, e la soluzione di Krylov già ottenuta sopra; non è richiesta alcuna nuova esecuzione di circuiti.

### Lo stato di riferimento come distribuzione di energia {#the-reference-state-as-an-energy-distribution}

Sia l'Hamiltoniana con la decomposizione agli autovalori

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

con autostati energetici $|E_m\rangle$.
Ogni stato di riferimento può essere espanso in questa autobase,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

quindi porta un **peso spettrale** $p_m=|a_m|^2$ a ciascuna energia $E_m$.
L'energia di riferimento è la media di questa distribuzione, $\langle H\rangle_{0}=\sum_m p_m E_m$.

L'autodecomposizione di un'Hamiltoniana generale a $n$ qubit ha un costo esponenziale, quindi questa rappresentazione è solo diagnostica, e *non* fa parte dell'algoritmo.
Qui, tuttavia, possiamo calcolarla in modo economico per lo *stesso* problema con $n=12$: l'Hamiltoniana di Heisenberg conserva il numero totale di eccitazioni, e il riferimento $|000001000000\rangle$ porta una singola eccitazione, quindi tutto il suo contenuto spettrale vive nel sottospazio a singola eccitazione, la cui dimensione cresce solo linearmente con $n$.
Riutilizziamo quindi il blocco esatto a singola eccitazione (già usato sopra come benchmark) e leggiamo la distribuzione di riferimento $\{(E_m, p_m)\}$ all'interno di quel sottospazio.

```python
# Exact single-excitation-subspace decomposition of the reference state.
# This reuses make_heisenberg_hamiltonian / _basis_state_transition_amplitude_sparse
# and the n=12 `hamiltonian` and `ref_bitstring` defined in the small-scale example.
single_excitation_states = [1 << k for k in range(num_qubits)]

h_single = np.array(
    [
        [
            _basis_state_transition_amplitude_sparse(hamiltonian, bra, ket)
            for ket in single_excitation_states
        ]
        for bra in single_excitation_states
    ]
)
h_single = 0.5 * (h_single + h_single.conj().T)

subspace_evals, subspace_evecs = la.eigh(h_single)
subspace_evals = np.real(subspace_evals)

ref_position = single_excitation_states.index(int(ref_bitstring, 2))
ref_in_subspace = np.zeros(num_qubits, dtype=complex)
ref_in_subspace[ref_position] = 1.0

# Amplitudes and spectral weights of the reference in the energy eigenbasis.
ref_eigen_amplitudes = subspace_evecs.conj().T @ ref_in_subspace
ref_spectral_weights = np.abs(ref_eigen_amplitudes) ** 2

print(f"Subspace ground-state energy:         {subspace_evals[0]:.6f}")
print(
    f"Reference energy (sum p_m E_m):       {np.sum(ref_spectral_weights * subspace_evals):.6f}"
```

### KQD apprende un filtro che rimodella questa distribuzione {#kqd-learns-a-filter-that-reshapes-this-distribution}

Una **funzione Hamiltoniana** $f(H)$ è definita tramite il calcolo spettrale,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

ovvero, in altre parole, una somma pesata di autoproiettori.
Applicarla al riferimento rimodella ciascuna ampiezza spettrale, $a_m \to a_m f(E_m)$:

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

Se $f$ fosse fortemente concentrata all'energia più bassa ($f(E_0)=1$ e $f(E_m)\approx 0$ altrimenti), allora $f(H)$ agirebbe come un proiettore sullo stato fondamentale, e l'output normalizzato sarebbe (vicino a) lo stato fondamentale.
Pertanto, un buon **filtro spettrale** passa-basso in energia è esattamente ciò che vogliamo.

KQD non prescrive $f$ in anticipo. Invece espande il filtro nella base dell'evoluzione temporale reale,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

una funzione *trigonometrica* dell'energia i cui coefficienti $\{c_\ell\}$ sono precisamente l'autovettore del GEVP risolto sopra.
Minimizzare il quoziente di Rayleigh $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ equivale quindi a *imparare* il filtro che meglio sopprime il peso degli stati eccitati del riferimento.
Una dimensione di Krylov $r$ maggiore dà al filtro più gradi di libertà e un picco più netto all'energia dello stato fondamentale.

L'helper qui sotto valuta questo filtro appreso su un asse energetico; lo applichiamo poi alla distribuzione di riferimento ottenuta sopra.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### Aumentare la dimensione di Krylov: flessibilità della funzione appresa {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

Ricorda che il filtro appreso è un polinomio trigonometrico nell'energia con $r$ coefficienti,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

La dimensione di Krylov $r$ è esattamente il numero di coefficienti liberi, quindi controlla la **flessibilità** della funzione.
Un $r$ piccolo può produrre solo un filtro ampio e variabile dolcemente, che lascia trapelare peso verso stati eccitati di bassa energia; quando $r$ aumenta, il filtro può formare un picco più stretto all'energia target e sopprimere in modo più aggressivo il peso residuo degli stati eccitati.
Questa è la controparte, in termini di filtro spettrale, della convergenza in energia osservata nell'esempio su piccola scala: al crescere di $r$, la distribuzione filtrata collassa sullo stato fondamentale del sottospazio e l'energia stimata diminuisce verso di esso.

Riutilizziamo le matrici proiettate già stimate sopra e risolviamo semplicemente il GEVP su ciascun blocco principale $r\times r$, quindi valutiamo e tracciamo il filtro corrispondente.

```python
# Sweep the Krylov dimension using the leading r x r blocks of the estimated matrices.
sweep_dims = [r for r in (2, 4, 6, 8, krylov_dim) if r <= krylov_dim]
sweep_dims = sorted(set(sweep_dims))

energy_grid = np.linspace(
    subspace_evals.min() - 0.5, subspace_evals.max() + 0.5, 800
)

sweep_cases = []
print(" r    retained    ground overlap    filtered energy")
print("--    --------    --------------    ---------------")
for r in sweep_dims:
    _, coeffs_r, retained_r = solve_thresholded_gevp(
        h_matrix_est[:r, :r],
        s_matrix_est[:r, :r],
        threshold=1e-12,
    )
    filter_on_spectrum_r = trigonometric_krylov_filter(
        coeffs_r, subspace_evals, dt
    )
    filtered_weights_r = filtered_spectral_weights(
        ref_spectral_weights, filter_on_spectrum_r
    )
    filtered_energy_r = float(np.sum(filtered_weights_r * subspace_evals))

    sweep_cases.append((r, coeffs_r, filtered_weights_r))
    print(
        f"{r:2d}    {retained_r:8d}    {filtered_weights_r[0]:14.4f}    {filtered_energy_r:15.6f}"
    )

print(f"\nSubspace ground-state energy (target): {subspace_evals[0]:.6f}")

# One panel per Krylov dimension: filtered spectrum (bars) + filter intensity (curve).
fig, axes = plt.subplots(
    len(sweep_cases),
    1,
    figsize=(8, 2.1 * len(sweep_cases)),
    sharex=True,
)
axes = np.atleast_1d(axes)

for idx, (ax, (r, coeffs_r, filtered_weights_r)) in enumerate(
    zip(axes, sweep_cases)
):
    visible = (ref_spectral_weights > 1e-4) | (filtered_weights_r > 1e-4)
    ax.bar(
        subspace_evals[visible],
        ref_spectral_weights[visible],
        width=0.18,
        alpha=0.35,
        color="C0",
        label="reference $p_m$" if idx == 0 else None,
    )
    ax.bar(
        subspace_evals[visible],
        filtered_weights_r[visible],
        width=0.14,
        alpha=0.9,
        color="C1",
        label="filtered weights" if idx == 0 else None,
    )

    filter_intensity_r = (
        np.abs(trigonometric_krylov_filter(coeffs_r, energy_grid, dt)) ** 2
    )
    filter_intensity_r /= filter_intensity_r.max()
    ax.plot(energy_grid, filter_intensity_r, color="k", linewidth=2)

    ax.axvline(subspace_evals[0], color="C3", linestyle="--", linewidth=1)
    ax.set_ylim(0, 1)
    ax.set_ylabel("weight")
    ax.legend(loc="upper right", title=f"$r={r}$")

axes[-1].set_xlabel("Energy eigenvalue $E_m$")
fig.suptitle(
    r"KQD-learned filter $|f_{\rm KQD}(E)|^2$ sharpening with Krylov dimension $r$",
    y=1.0,
)
fig.tight_layout()
plt.show()
```
