# Esame e badge {#exam-and-badge}

![A square badge stating the name of this course, foundational level, and issued by IBM Quantum&reg;.](/learning/images/courses/use-a-qc-today/exam/badge.avif)

## Sondaggio post-corso {#post-course-survey}

Congratulazioni per aver completato il corso "Usa un computer quantistico oggi" di IBM&reg;!

## Metti alla prova le tue conoscenze {#test-your-knowledge}

Dopo aver completato la lettura e le attività di questo corso, clicca sul pulsante qui sotto per navigare verso IBM Training, dove puoi sostenere l'esame per il badge di Usa un computer quantistico oggi.

L'esame consiste di 20 domande, e devi rispondere correttamente ad almeno 16 per superarlo. Al raggiungimento di un punteggio sufficiente, il tuo badge verrà inviato automaticamente all'email che hai usato per registrarti a IBM Training.

Assicurati di essere pronto a sostenere l'esame. Se non ottieni un punteggio sufficiente in due tentativi, l'esame viene temporaneamente bloccato.
