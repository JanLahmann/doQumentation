# Panoramica {#overview}

!["Hero image"](/learning/images/courses/use-a-qc-today/hero.svg)

Benvenuto in *Usa un computer quantistico oggi*! In questo corso inizierai subito a usare un computer quantistico e imparerai i principi fondamentali del quantum computing man mano che procedi.

Questo corso è pensato per i curiosi e per chi ha poco tempo. Non hai bisogno di una laurea in fisica o di anni di esperienza di programmazione. Se riesci a seguire un notebook e cliccare "Run," sei pronto.

## Esame {#exam}

Per ottenere il tuo badge per il corso "Usa un computer quantistico", sostieni l'esame su IBM&reg; Training. Questo esame è pensato per essere sostenuto dopo aver letto le lezioni di questo corso. Dopo aver superato l'esame, sarai avvisato da Credly di aver ottenuto un badge.
