# I-save ang iyong mga login credential {#save-your-login-credentials}
Kung gumagamit ka ng trusted na Python environment (tulad ng personal na laptop o workstation), maaari mong gamitin ang `save_account()` method para i-save ang iyong mga credential nang lokal, tapos gamitin ang mga ito para i-initialize ang serbisyo.

<Admonition type="note" title="Mga Tala">
      * Kung gumagamit ka ng pampublikong computer o ibang hindi trusted na environment, sundin ang mga instruksyon sa [I-initialize ang serbisyo sa isang hindi trusted na environment](/guides/cloud-setup-untrusted) sa halip.
      * Sundin ang [mga instruksyong ito](/guides/cloud-setup-rest-api) kung gusto mong kumonekta gamit ang REST API sa halip na Qiskit.
      * Kung kinakailangan, gamitin ang [impormasyong ito](/guides/quickstart-steps-org#firewall) para i-configure ang iyong firewall para ma-access ang mga IBM Quantum API endpoint.
</Admonition>

## Bago ka magsimula {#before-you-begin}

1. Tiyaking nasa aktibong Python environment ka na may [`qiskit` at `qiskit-ibm-runtime` packages na naka-install](/guides/install-qiskit#local).

1. I-activate ang Python virtual environment at patakbuhin ang Python sa iyong virtual environment.

1. Mag-login sa [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Hanapin ang iyong mga access credential {#find-your-access-credentials}

1. Tiyaking napili ang tamang account at rehiyon sa account switcher sa header.

1. Hanapin ang iyong API key. Mula sa [dashboard](https://quantum.cloud.ibm.com/), gumawa ng iyong API key, tapos kopyahin ito sa isang ligtas na lugar para magamit mo ito para sa authentication. Tandaan na maaari mong gamitin ang parehong API key para kumonekta sa anumang rehiyon.

1. Opsyonal: Hanapin ang instance na gusto mong gamitin mula sa pahina ng [Instances](https://quantum.cloud.ibm.com/instances). I-hover ang cursor sa CRN nito, i-click ang icon para kopyahin ito, tapos i-save sa ligtas na lugar para magamit mo ito para matukoy ang instance.


<span id="cloud-save"></span>

## I-save ang iyong mga access credential {#save-your-access-credentials}

I-save ang iyong mga credential sa pamamagitan ng pagpapatakbo ng angkop na code nang isang beses bawat account na gusto mong i-save. Pagkatapos i-save ang iyong mga credential, i-load ang mga ito sa pamamagitan ng pagsunod sa mga hakbang sa [I-initialize ang IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### I-save ang mga credential na nag-a-access sa isang partikular na instance: {#save-credentials-that-access-a-specific-instance}
Kung mayroon kang maraming instance at gusto mong madaling sabihin sa Quantum Compute kung aling instance ang gagamitin, mag-save ng mga credential na naglalaman ng instance CRN.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### I-save ang mga credential para sa awtomatikong pagpili ng instance: {#save-credentials-for-automatic-instance-selection}
Kung hindi ka magbibigay ng instance CRN at ipapasa ang mga credential na ito sa Quantum Compute, pipiliin para sa iyo ang angkop na instance batay sa mga tinukoy na opsyon.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Halimbawa 2 {#example-2}
Ang halimbawang ito ay nagse-save ng mga credential para sa awtomatikong pagpili ng instance. Titingnan lang ng Quantum Compute ang mga premium instance sa rehiyong EU na available sa account. Ang mga credential na ito ang magiging bagong default.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Tingnan ang mga na-save na credential {#view-saved-credentials}

Para makita ang lahat ng credential na na-save mo, patakbuhin ang `service.saved_accounts()`. Tandaan na kung nag-save ka ng default na mga credential at hindi mo pinangalanan ang mga ito, ang pangalan nila ay `default-ibm-quantum-platform`. Kung pinangalanan mo ang iyong default na mga credential, makikita mo ang `"is_default_account": true` sa output.

## Mga Konsiderasyon {#considerations}

* Kung nagse-save ka ng maraming account, gamitin ang parameter na `name` para makilala ang mga ito.

* Ang mga credential ay nase-save sa `$HOME/.qiskit/qiskit-ibm.json`. Huwag manu-manong i-edit ang file na ito.

* Kung hindi mo ise-save ang iyong mga credential, kailangan mong tukuyin ang mga ito sa bawat beses na magsisimula ka ng bagong session (pag-instantiate ng IBM Quantum Compute Service).

* Kung manu-mano mong tinukoy ang iyong mga credential, hindi gagamitin ang na-save na account.
