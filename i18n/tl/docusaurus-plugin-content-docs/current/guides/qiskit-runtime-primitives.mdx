# Panimula sa mga IBM Quantum primitive {#introduction-to-ibm-quantum-primitives}

Ang mga primitive ay nilikha para gawing mas simple ang mga pinakakaraniwang gawain para sa mga quantum computer: ang pag-sample ng mga quantum state at pagkalkula ng mga expectation value. Ang unang IBM Quantum primitives ([`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) at [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)) ay mga implementasyon ng Qiskit [primitives base classes](/guides/primitives). Nagbibigay sila ng mas sopistikadong implementasyon (halimbawa, sa pamamagitan ng pagsasama ng error mitigation) bilang isang cloud-based na serbisyo at ginagamit para ma-access ang IBM Quantum&reg; hardware.

Ang pinakabagong IBM Quantum primitive, [Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor) (na nasa beta), ay nagbibigay ng lower-level interface na nagbibigay ng higit na visibility at control nang hindi isinasakripisyo ang performance. 
Inilalantad din ng `Executor` ang **mga karagdagang kakayahan na hindi inaalok ng Sampler**, tulad ng mga karagdagang twirling group at twirling para sa mga circuit na may fractional gates. Sumangguni sa [Migrate from Sampler to Executor](/guides/migrate-from-sampler-to-executor) para sa karagdagang impormasyon kung dapat mag-migrate sa `Executor`.
