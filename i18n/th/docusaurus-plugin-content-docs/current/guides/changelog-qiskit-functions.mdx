# Qiskit Functions {#qiskit-functions}

<span id="new-methods"></span>

## กรกฎาคม 2026 {#july-2026}

- การตรวจสอบล่วงหน้าแบบใหม่และเมธอด `backend` ใหม่ใน Qiskit Functions v0.17.0: เมธอดใหม่ใน `qiskit-ibm-catalog` ช่วยให้คุณตรวจสอบความจุของ runtime และการเข้าถึง backend ก่อนที่จะรัน และ `run()` ตอนนี้ตรวจสอบทั้งสองอย่างก่อนที่จะส่งงาน


  - **มีอะไรใหม่**

    - เมื่อคุณเรียก `run()` บนฟังก์ชัน บริการจะตรวจสอบสามสิ่งก่อน: ว่าอินสแตนซ์ของคุณมีความจุ runtime ว่าคุณสามารถเข้าถึง backend ที่ระบุได้ และว่ามี backend อย่างน้อยหนึ่งตัวพร้อมใช้งาน หากมีสิ่งใดผิดพลาด คุณจะได้รับข้อความข้อผิดพลาดที่ชัดเจนทันทีแทนที่จะต้องรอในคิว


      คุณสามารถตรวจสอบทรัพยากรเหล่านี้ด้วยตนเองได้ตลอดเวลา:

      - ตรวจสอบความจุ runtime ที่เหลือของคุณด้วย `usage()`

      - แสดงรายการ backend ที่อินสแตนซ์ของคุณสามารถเข้าถึงได้ด้วย `backends()`

      - ค้นหา backend ตัวเดียวและยืนยันการเข้าถึงด้วย `backend()`

      - ค้นหา backend ที่มีงานค้างอยู่น้อยที่สุดด้วย `least_busy()`


  - **กรณีการใช้งานทั่วไป**

    - ตรวจสอบความจุที่เหลือของคุณก่อนงานชุดใหญ่ และข้ามการรันหากมีความจุไม่เพียงพอที่จะทำให้เสร็จ

    - เลือก backend ในโค้ดแทนการฝังชื่อไว้ตายตัว

    - ล้มเหลวได้อย่างรวดเร็วใน pipeline และ notebook แทนที่จะรอในคิว


  - **เริ่มต้นใช้งาน**


    - ก่อนอื่นให้แน่ใจว่าคุณกำลังใช้ `qiskit-ibm-catalog` เวอร์ชันล่าสุด:


      ```bash
      pip install --upgrade qiskit-ibm-catalog
      ```

    - จากนั้นดู[เอกสาร](/guides/functions-get-started)สำหรับข้อมูลเพิ่มเติมและตัวอย่าง

#### 16 พฤษภาคม 2025 {#16-may-2025}
- ในอีกไม่กี่สัปดาห์ข้างหน้า ทุกฟังก์ชันจะให้ข้อมูลรายละเอียดเพื่อช่วยให้คุณรัน ดีบัก และวิเคราะห์เวิร์กโฟลว์ของคุณ ซึ่งรวมถึง:


  - เมื่องานล้มเหลว คุณสามารถใช้ `job.error_message()` เพื่อค้นหารหัสข้อผิดพลาดและข้อความเฉพาะที่ช่วยให้คุณดีบักเวิร์กโฟลว์ของคุณได้

  - `job.status()` จะให้ข้อมูลเพิ่มเติมเกี่ยวกับสิ่งที่กำลังเกิดขึ้นในขณะที่ Function อยู่ในสถานะ `RUNNING` รวมถึง:

    - `RUNNING: MAPPING`

    - `RUNNING: OPTIMIZING_FOR_HARDWARE`

    - `RUNNING: WAITING_FOR_QPU`

    - `RUNNING: EXECUTING_QPU`

### 2024 {#2024}

#### 16 กันยายน 2024 {#16-september-2024}
- ขอแนะนำ Qiskit Functions พรีวิว สำหรับผู้ใช้ IBM Quantum Premium Plan หากต้องการเริ่มต้นใช้งาน ให้ `pip install qiskit-ibm-catalog` และสำรวจ[เอกสาร Qiskit Functions](/guides/functions) ด้วย Qiskit Functions Catalog client คุณสามารถส่งงานไปยังบริการนามธรรมที่ออกแบบมาเพื่อเร่งงานวิจัยของคุณได้ ลงชื่อเข้าใช้ด้วยข้อมูลรับรอง IBM Quantum Platform ที่มีอยู่ของคุณ


  Qiskit Functions Catalog พรีวิวให้สิทธิ์การเข้าถึงแก่ผู้ใช้ Premium Plan เพื่อสำรวจฟังก์ชันที่พร้อมใช้งาน รวมถึงฟังก์ชันที่เขียนโดย IBM และฟังก์ชันที่เขียนโดยสมาชิกอื่นๆ ในระบบนิเวศของเรา แคตตาล็อกประกอบด้วยฟังก์ชันสองประเภท: circuit functions และ application functions

    - **Circuit functions** มอบอินเทอร์เฟซที่เรียบง่ายสำหรับการรัน circuit โดยรับ circuit นามธรรมและ observable ที่ผู้ใช้ระบุเป็นอินพุต จากนั้นจัดการการสังเคราะห์ การหาค่าเหมาะที่สุด และการรัน ISA circuit ที่แทนค่า Circuit functions รวมความสามารถล่าสุดในด้าน transpilation การระงับข้อผิดพลาด และการบรรเทาข้อผิดพลาดเข้าไว้ด้วยกัน เพื่อให้ประสิทธิภาพระดับ utility เข้าถึงได้ทันทีโดยไม่ต้องปรับแต่งเพิ่มเติม สิ่งนี้ช่วยให้นักวิทยาศาสตร์เชิงคำนวณสามารถมุ่งเน้นไปที่การแมปปัญหาของตนเข้ากับ circuit แทนที่จะต้องสร้างรูปแบบสำหรับแต่ละปัญหาตั้งแต่ต้น


    - **Application functions** ครอบคลุมงานระดับสูงขึ้น เช่น การสำรวจอัลกอริทึมและกรณีการใช้งานเฉพาะโดเมน นักพัฒนาระดับองค์กรและนักวิทยาศาสตร์ข้อมูลอาจไม่มีความรู้พื้นฐานด้าน quantum information science สำหรับการทำงานกับ circuit และแทนที่จะเป็นเช่นนั้น พวกเขาต้องการนำความรู้เฉพาะโดเมนของตนมาพัฒนาอัลกอริทึมและแอปพลิเคชัน quantum computing ด้วย application functions ผู้ใช้สามารถป้อนอินพุตแบบคลาสสิกของตนและรับผลลัพธ์ เพื่อให้สามารถทดลองผนวก quantum เข้ากับเวิร์กโฟลว์เฉพาะโดเมนของตนได้ง่ายขึ้น


- ด้วยการเปิดตัว Qiskit Functions Catalog นักพัฒนา Premium Plan สามารถสำรวจ IBM Circuit function ได้ IBM Circuit function มีส่วนขยายล่าสุดที่ขับเคลื่อนด้วย AI สำหรับ Qiskit ในด้านการสังเคราะห์ circuit การหาค่าเหมาะที่สุด และการจัดตารางเวลา รวมถึงวิธีการบรรเทาข้อผิดพลาดขั้นสูงเพื่อให้ได้ค่าประมาณที่แม่นยำที่สุดเท่าที่จะเป็นไปได้ด้วยฮาร์ดแวร์ในปัจจุบัน


  ผู้ใช้สามารถซื้อสิทธิ์การใช้งานสำหรับฟังก์ชันต่อไปนี้ที่ร่วมสมทบโดยพาร์ทเนอร์ของเราที่ Q-CTRL, QEDMA และ Algorithmiq

- **Circuit functions**


  - Q-CTRL กำลังเปิดตัว circuit function ที่ใช้เทคนิคการควบคุม quantum ที่ขับเคลื่อนด้วย AI ซึ่งผู้ใช้สามารถขยายขนาดไปสู่ปัญหาที่ใหญ่ขึ้นได้สำเร็จ

  - Algorithmiq กำลังเปิดตัว circuit function ที่ใช้ TEM (tensor-network error mitigation) ซึ่งเป็นวิธีการบรรเทาข้อผิดพลาดสำหรับการได้มาซึ่งตัวประมาณด้วยจำนวน shot ที่น้อยกว่าวิธี PEC (probabilistic error cancellation)

  - QEDMA กำลังเปิดตัว circuit function ที่ใช้โพรโทคอลที่เป็นกรรมสิทธิ์เฉพาะสำหรับการระบุลักษณะการทำงานของ QPU ที่มีสัญญาณรบกวนอย่างมีประสิทธิภาพและแม่นยำ และใช้การระงับข้อผิดพลาดกับการบรรเทาข้อผิดพลาดโดยอิงจากข้อมูลการระบุลักษณะ


- **Application functions**


  - Q-CTRL กำลังเปิดตัวตัวแก้ปัญหาการหาค่าเหมาะที่สุด ซึ่งผู้ใช้สามารถส่งกราฟหรือ objective และรับค่าใช้จ่ายของคำตอบได้
