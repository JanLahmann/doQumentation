# ทำความเข้าใจความรับผิดชอบของคุณในการใช้ IBM Quantum Compute Service {#understanding-your-responsibilities-when-using-ibm-quantum-compute-service}

ตรวจสอบหัวข้อต่อไปนี้เพื่อดูความรับผิดชอบเฉพาะของคุณและของ IBM&reg; เมื่อคุณใช้ IBM Quantum Compute Service สำหรับข้อกำหนดการใช้งานโดยรวม ดู [Terms and Notices](https://cloud.ibm.com/docs/overview/terms-of-use?topic=overview-terms) สำหรับ IBM Cloud&reg;

## การจัดการเหตุการณ์และการดำเนินงาน {#incident-and-operations-management}

การจัดการเหตุการณ์และการดำเนินงานครอบคลุมงานต่าง ๆ เช่น การตรวจสอบ การจัดการเหตุการณ์ ความพร้อมใช้งานสูง การระบุปัญหา การกู้คืน และการสำรองและกู้คืนสถานะเต็มรูปแบบ

| Task | IBM responsibilities | Your responsibilities |
| --- | --- | --- |
|Infrastructure health management|<ul><li>Continuously deliver new features, updates, and bug fixes as needed in a transparent manner.</li><li>Provide notifications for planned maintenance, security bulletins, or unplanned outages.</li></ul> | <ul><li>[Set preferences to receive emails](https://cloud.ibm.com/user/notifications) about service notifications.</li><li>Monitor the [IBM Cloud status](https://cloud.ibm.com/status) page for general announcements.</li></ul> |
|Infrastructure health monitoring and notification| <ul><li>Remediate all infrastructure environment issues.</li><li> Notify customers of applicable incidents.</li></ul> | <ul><li> Ascertain the impact of each reported incident.</li><li>Engage [IBM Support](/guides/support) as required.</li></ul>|
|Maintain IBM Cloud high availability SLA| Operate IBM Quantum Compute Service in accordance with the [IBM Cloud Public Service Level Agreements](https://cloud.ibm.com/docs/overview?topic=overview-slas) (SLAs). | Follow high availability best practices. |

## การจัดการการเปลี่ยนแปลง {#change-management}

การจัดการการเปลี่ยนแปลงครอบคลุมงานต่าง ๆ เช่น การนำใช้งาน การกำหนดค่า การอัปเกรด การแพตช์ การเปลี่ยนแปลงการกำหนดค่า และการลบ

| งาน | ความรับผิดชอบของ IBM | ความรับผิดชอบของคุณ |
| --- | --- | --- |
| การอัปเกรดเวอร์ชันหลัก | ให้ความพร้อมและเครื่องมือสำหรับการอัปเดตเวอร์ชันหลัก | ย้ายไปยังเวอร์ชันที่รองรับก่อนสิ้นสุดการสนับสนุนสำหรับเวอร์ชันเก่า |
| การเปลี่ยนแปลงเวอร์ชัน API | กำหนดเวอร์ชัน REST APIs | ผสานรวมกับเวอร์ชัน REST APIs ที่ต้องการ |
| อัปเดต แก้ไข และฟีเจอร์ใหม่ | <ul><li>ให้การอัปเดตสม่ำเสมอ แก้ไขบั๊ก และฟีเจอร์ใหม่ อย่างโปร่งใสตามโมเดลการส่งมอบต่อเนื่อง</li><li>โพสต์การแจ้งเตือนสำหรับการเปลี่ยนแปลงที่ส่งผลต่อลูกค้า</li></ul> | <ul><li>ตั้งค่าการ[รับการแจ้งเตือนทางอีเมล](https://cloud.ibm.com/user/notifications) และติดตามหน้า [IBM Cloud status](https://cloud.ibm.com/status) สำหรับประกาศทั่วไป</li><li>อ่านการแจ้งเตือนที่ระบบสร้างขึ้นและ[ประกาศแพลตฟอร์ม](https://quantum.cloud.ibm.com/notifications) แล้วดำเนินการที่เหมาะสม</li></ul> |

## การจัดการข้อมูลระบุตัวตนและการเข้าถึง {#identity-and-access-management}

การจัดการข้อมูลระบุตัวตนและการเข้าถึงครอบคลุมงานต่าง ๆ เช่น การยืนยันตัวตน การอนุญาต การจัดการนโยบายการควบคุมการเข้าถึง และการอนุมัติ มอบ และเพิกถอนการเข้าถึง

| Task | IBM responsibilities | Your responsibilities |
| --- | --- | --- |
| Identity and access control | Provide the ability to manage and restrict access to resources through IBM Cloud. | Grant, revoke, and manage access to resources through [Cloud Identity and Access Management](/guides/access-groups) (IAM). |
| Service authentication | Ensure that only authenticated users have access to your IBM Quantum Compute Service and resources. | <ul><li>[Safeguard your API key](/guides/cloud-setup-untrusted#initialize-the-service-in-an-untrusted-environment) from unauthorized access.</li><li>Rotate and update your [API keys](https://cloud.ibm.com/iam/apikeys) according to your security policy requirements.</li></ul> |
| Observability | Allow integration of IBM Cloud Activity Tracker Event Routing to audit user actions. | Set up [IBM Cloud Activity Tracker Event Routing](https://cloud.ibm.com/docs/vmware-service?topic=vmware-service-at_events) or other functions to track user activity. |

## ความปลอดภัยและการปฏิบัติตามข้อบังคับ {#security-and-regulation-compliance}

ความปลอดภัยและการปฏิบัติตามข้อบังคับครอบคลุมงานต่าง ๆ เช่น การดำเนินการควบคุมความปลอดภัยและการรับรองการปฏิบัติตามข้อกำหนด

| งาน | ความรับผิดชอบของ IBM | ความรับผิดชอบของคุณ |
| --- | --- | --- |
| ทั่วไป | <ul><li>รักษาการควบคุมที่สอดคล้องกับมาตรฐานการปฏิบัติตามข้อกำหนดในอุตสาหกรรมต่าง ๆ</li><li>ตรวจสอบ แยก และกู้คืนการทำงานของบริการ</li><li>ตรวจสอบและรายงานสุขภาพของอินเทอร์เฟซบริการ</li></ul> | ตรวจสอบว่าไม่มีการให้ข้อมูลส่วนบุคคลหรือข้อมูลที่อยู่ภายใต้การควบคุม |
| ช่องโหว่ | ตรวจสอบเพื่อตรวจจับปัญหาช่องโหว่และการปฏิบัติตามข้อกำหนดด้านความปลอดภัย | <ul><li>รับทราบข้อมูลเกี่ยวกับช่องโหว่และปัญหาด้านความปลอดภัยที่อาจเกิดขึ้นผ่านประกาศด้านความปลอดภัยที่ให้แนวทางการแก้ไขที่เป็นไปได้</li><li>ตรวจสอบ[ส่วนความปลอดภัยของ Qiskit GitHub repository](https://github.com/Qiskit/qiskit/security) ช่องโหว่ด้านความปลอดภัยทั้งหมดจะถูกโพสต์ที่นั่น</li><li>ตรวจสอบ[เว็บไซต์ IBM Cloud status](https://cloud.ibm.com/status) เพื่อค้นหาประกาศและประกาศด้านความปลอดภัยเกี่ยวกับเหตุการณ์สำคัญที่ส่งผลต่อแพลตฟอร์ม IBM Cloud โครงสร้างพื้นฐาน และบริการหลัก</li></ul> |
| การเข้ารหัส | เข้ารหัสข้อมูลเมื่อส่งผ่านเครือข่ายสาธารณะและภายในเครือข่ายศูนย์ข้อมูลส่วนตัวของ Cloud Service วิธีการเข้ารหัส เช่น HTTPS และ TLS ใช้เพื่อปกป้องข้อมูลในขณะเคลื่อนย้าย | ตรวจสอบตามความจำเป็นว่าการเชื่อมต่อของคุณมีการเข้ารหัสแบบ end-to-end |
| ความปลอดภัย | <ul><li>ตรวจสอบความปลอดภัยของข้อมูลบนดิสก์และข้อมูลในขณะเคลื่อนย้ายภายในโครงสร้างพื้นฐานของตน</li><li>ให้บริการที่ปลอดภัยซึ่งสอดคล้องกับมาตรฐานสำคัญ</li></ul> | จำกัด[การเข้าถึงของผู้ใช้](/guides/access-groups) ไปยังทรัพยากรและกลุ่มทรัพยากรที่เหมาะสม |

## การกู้คืนระบบจากภัยพิบัติ {#disaster-recovery}

| Task | IBM responsibilities | Your responsibilities |
| --- | --- | --- |
| General | Restore or rebuild the provisioning environments and resources in the affected regions. | <ul><li>Monitor instance and resource states.</li><li>Provision new IBM Quantum Compute Service [instances](/guides/instances) in an alternate region, if available.</li></ul> |
| Recovery of services | Automatically recover and restore IBM Quantum Compute Service capabilities to normal operations. | Resubmit any impacted jobs following recovery. |
| Backup of user configuration data | IBM is not responsible for backup of user configuration data. | Backup of any configuration data, as needed. |
| Backup and recovery of workloads | IBM is not responsible for backup or recovery of user workload data. | Backup and recovery of your workloads, as needed. |
