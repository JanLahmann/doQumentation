*หากต้องการดูบันทึกการเผยแพร่สำหรับทุกเวอร์ชัน โปรดเยี่ยมชม[บันทึกการเผยแพร่ของ Qiskit Transpiler Service client](https://docs.quantum.ibm.com/api/qiskit-ibm-transpiler/release-notes)*

## การอัปเดตก่อนหน้านี้ {#previous-updates}

- Qiskit Transpiler Service client v0.3.0


  - Qiskit Transpiler Service ใช้ประโยชน์จากทรัพยากร IBM Cloud&reg; เพื่อมอบความสามารถ transpilation ล่าสุดจาก Qiskit SDK ให้แก่ผู้ใช้ โดยมี Python library ที่ช่วยให้ผู้ใช้สามารถผสานรวมบริการนี้เข้ากับรูปแบบและเวิร์กโฟลว์ Qiskit ปัจจุบันของตนได้อย่างราบรื่น และที่สำคัญที่สุดอาจเป็นการที่บริการนี้เชิญชวนให้ผู้ใช้ทดลองใช้ transpiler pass ที่ขับเคลื่อนด้วย AI แบบใหม่และปรับปรุงแล้ว ซึ่งเป็นเครื่องมือล้ำสมัยที่อาจเร็วกว่าและให้ผลลัพธ์ดีกว่าวิธี transpilation แบบดั้งเดิม อ่าน[บล็อก](https://www.ibm.com/quantum/blog/ai-transpiler-passes)เพื่อดูข้อมูลเพิ่มเติม
