# แนะนำ IBM Quantum primitives {#introduction-to-ibm-quantum-primitives}

Primitives ถูกสร้างขึ้นเพื่อทำให้งานที่พบบ่อยที่สุดสำหรับคอมพิวเตอร์ควอนตัมง่ายขึ้น ได้แก่ การสุ่มตัวอย่างสถานะควอนตัมและการคำนวณค่าความคาดหวัง IBM Quantum primitives ([`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) และ [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)) คือการ implement Qiskit [primitives base classes](/guides/primitives) ซึ่งให้ implementation ที่ซับซ้อนกว่า (เช่น การรวม error mitigation) ในรูปแบบบริการบนคลาวด์ และใช้เพื่อเข้าถึงฮาร์ดแวร์ IBM Quantum&reg;

IBM Quantum primitive ตัวล่าสุด [Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor) (ซึ่งอยู่ในสถานะเบต้า) มอบอินเทอร์เฟซระดับต่ำที่ให้ทัศนวิสัยและการควบคุมมากขึ้นโดยไม่เสียสละประสิทธิภาพ 
`Executor` ยังเปิดให้ใช้ **ความสามารถเพิ่มเติมที่ Sampler ไม่มี** เช่น twirling groups เพิ่มเติมและ twirling สำหรับวงจรที่มี fractional gates ดู [Migrate from Sampler to Executor](/guides/migrate-from-sampler-to-executor) สำหรับข้อมูลเพิ่มเติมว่าควรย้ายไปใช้ `Executor` หรือไม่
