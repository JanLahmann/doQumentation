# IBM Quantum Compute client v0.46.0 {#ibm-quantum-compute-client-v0460}

## เมษายน 2026 {#april-2026}

<span id="executor-primitive"></span>
- **Introducing the Executor primitive**: We're excited to announce the release of the new `Executor` primitive and a new version of the noise-learning helper class, `NoiseLearnerV3`, both of which were first previewed at QDC 2025.

  ร่วมกับ [Samplomatic](https://qiskit.github.io/samplomatic/index.html) ทั้งสองประกอบกันเป็น [directed execution model](/guides/directed-execution-model) ซึ่งให้ความโปร่งใสและการควบคุมอย่างเต็มที่เพื่อปรับแต่ง workflow การบรรเทาข้อผิดพลาดของคุณ ตัวอย่างเช่น tutorial [Probabilistic error cancellation with shaded lightcones](https://qiskit.github.io/qiskit-addon-slc/tutorials/01_getting_started.html) แสดงให้เห็นว่าโมเดลนี้ถูกใช้เพื่อผสมผสานเทคนิคขั้นสูง รวมถึง shaded lightcones, probabilistic error cancellation (PEC), Twirled Readout Error eXtinction (TREX) และ [measurement-based postselection](/guides/post-selection) เพื่อปรับปรุงคุณภาพของผลลัพธ์เพิ่มเติมได้อย่างไร

  หากคุณต้องการระดับ abstraction ที่สูงกว่านี้ [`EstimatorV2`](/guides/estimator-noise-management) ใน Qiskit Runtime ยังคงมีเทคนิคการบรรเทาและระงับข้อผิดพลาดในตัวหลายอย่าง ซึ่งคุณสามารถปรับแต่งได้ง่ายๆ โดยใช้ตัวเลือก [`resilience_level`](/guides/estimator-noise-management#resilience-level)

  หากต้องการเรียนรู้เพิ่มเติม ดูคู่มือต่อไปนี้:

    - [Executor quickstart](/guides/get-started-with-executor)

    - [Noise learning helper](/guides/noise-learning)


  ฟีเจอร์ใหม่ทั้งสองนี้อยู่ในสถานะเบต้าและต้องการ `qiskit-ibm-runtime` เวอร์ชัน 0.47.0 หรือสูงกว่า
