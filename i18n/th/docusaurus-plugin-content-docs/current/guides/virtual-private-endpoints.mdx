# ใช้ virtual private endpoints สำหรับ VPC เพื่อเชื่อมต่อกับ IBM Quantum Platform แบบส่วนตัว {#use-virtual-private-endpoints-for-vpc-to-privately-connect-to-ibm-quantum-platform}

ใช้ Virtual Private Endpoints (VPE) สำหรับ [Virtual Private Cloud (VPC)](https://cloud.ibm.com/docs/vpc) เพื่อเชื่อมต่อกับ IBM Quantum&reg; จากเครือข่าย VPC ของคุณ การเชื่อมต่อใช้ IP address ที่คุณระบุ ซึ่งจัดสรรมาจาก subnet ภายใน VPC ของคุณ

VPE คือ virtual IP interface ที่ผูกกับ endpoint gateway ที่สร้างขึ้นตามบริการแต่ละรายการ endpoint gateway เป็นฟังก์ชันเสมือนที่ขยายขนาดได้แนวนอน มีความซ้ำซ้อนและพร้อมใช้งานสูง และครอบคลุมทุก availability zone ของ VPC ของคุณ endpoint gateway ช่วยให้สามารถสื่อสารระหว่าง virtual server instance ภายใน VPC กับบริการ IBM Cloud&reg; บน private backbone ได้ VPE สำหรับ VPC ช่วยให้คุณควบคุมการกำหนดที่อยู่ส่วนตัวทั้งหมดภายใน cloud ของคุณได้ ดูข้อมูลเพิ่มเติมได้ที่ [About virtual private endpoint gateways](https://cloud.ibm.com/docs/vpc?topic=vpc-about-vpe)

ไม่ว่าคุณจะใช้ VPE หรือไม่ การสื่อสารภายในทั้งหมดในเครือข่ายของ IBM Quantum Platform จะใช้การเชื่อมต่อแบบส่วนตัวเสมอ แทนที่จะเป็นอินเทอร์เน็ตสาธารณะ

การเชื่อมต่อของคุณกับ IBM Quantum Platform เองจะเป็นแบบสาธารณะหรือแบบส่วนตัวขึ้นอยู่กับว่าคุณใช้ VPE หรือไม่ การเชื่อมต่อผ่าน public endpoint จะส่งข้อมูล request และ response ทั้งหมดผ่านอินเทอร์เน็ตสาธารณะ การเชื่อมต่อผ่าน VPE จะเก็บ traffic นั้นไว้บนเครือข่ายส่วนตัวแทน

VPE รองรับเฉพาะ IBM Quantum Platform API และ SDK ตามที่อธิบายในหัวข้อต่อไปนี้ เว็บไซต์ IBM Quantum Platform ไม่รองรับ VPE และสามารถเข้าถึงได้ผ่านเครือข่ายสาธารณะเท่านั้น

## ก่อนเริ่มต้น {#before-you-begin}

ก่อนกำหนดเป้าหมาย VPE สำหรับ IBM Quantum Platform ให้ทำตามขั้นตอนต่อไปนี้:

* [สร้าง Virtual Private Cloud](https://cloud.ibm.com/docs/vpc?topic=vpc-getting-started)

* [วางแผนโทโปโลยีเครือข่าย](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-planning-considerations) สำหรับการเชื่อมต่อกับ VPE

* [ตั้งค่า access controls](https://cloud.ibm.com/docs/vpc?topic=vpc-configure-acls-sgs-endpoint-gateways) สำหรับ VPE ของคุณ

* ทำความเข้าใจ [ข้อจำกัดของ service](https://cloud.ibm.com/docs/vpc?topic=vpc-limitations)

* ทำความเข้าใจวิธี [ดูรายละเอียด VPE](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-viewing-details-of-an-endpoint-gateway)


## ตั้งค่า VPE สำหรับ IBM Quantum Platform {#set-up-a-vpe-for-ibm-quantum-platform}

มีหลายวิธีในการสร้าง VPE gateway ถ้าใช้ [CLI](https://cloud.ibm.com/docs/vpc?topic=vpc-vpc-reference&interface=cli#vpe-clis) หรือ [API](https://cloud.ibm.com/apidocs/vpc/latest#create-endpoint-gateway) คุณต้องระบุ [Cloud Resource Name (CRN)](https://cloud.ibm.com/docs/account?topic=account-crn) ของ region ที่ต้องการเชื่อมต่อกับ IBM Quantum Platform ดูตารางต่อไปนี้สำหรับ region และ CRN ที่พร้อมใช้งาน

| Region | Plans   | Fully Qualified Domain Name (FQDN) | Cloud Resource Name (CRN) |
|-----------------|-----------------|-----------------|-----------------|
| `us-east` | `Standard` | `private.us-east.quantum.cloud.ibm.com` | `crn:v1:bluemix:public:quantum-computing:us-east:::endpoint:private.us-east.quantum.cloud.ibm.com` |
| `eu-de` | `Standard` | `private.eu-de.quantum.cloud.ibm.com` | `crn:v1:bluemix:public:quantum-computing:eu-de:::endpoint:private.eu-de.quantum.cloud.ibm.com` |

### การกำหนดค่า endpoint gateway {#configuring-an-endpoint-gateway}

ในการกำหนดค่า VPE gateway ให้ทำตามขั้นตอนเหล่านี้:

1. แสดงรายการบริการที่พร้อมใช้งาน รวมถึงบริการโครงสร้างพื้นฐาน IBM Cloud ที่พร้อมใช้งาน (โดยค่าเริ่มต้น) สำหรับผู้ใช้ VPC ทุกคน

1. [สร้าง endpoint gateway](https://cloud.ibm.com/docs/vpc?topic=vpc-ordering-endpoint-gateway) สำหรับ IBM Quantum Platform ที่ต้องการให้เข้าถึงได้แบบส่วนตัวใน VPC

1. [ผูก reserved IP address](https://cloud.ibm.com/docs/vpc?topic=vpc-bind-unbind-reserved-ip) กับ endpoint gateway

1. [ดู VPE gateway ที่สร้างขึ้น](https://cloud.ibm.com/docs/vpc?topic=vpc-vpe-viewing-details-of-an-endpoint-gateway) ที่เชื่อมโยงกับ IBM Quantum Platform


ตอนนี้ virtual server instance ใน VPC ของคุณสามารถเข้าถึง IBM Quantum Platform instance ของคุณแบบส่วนตัวได้แล้ว

## ใช้ VPE กับ IBM Quantum Platform {#use-your-vpe-for-ibm-quantum-platform}

หลังสร้าง endpoint gateway สำหรับ IBM Quantum Platform แล้ว ให้ทำตามขั้นตอนเหล่านี้:

### ใช้ VPE กับ `qiskit-ibm-runtime` (Python SDK) {#use-the-vpe-with-qiskit-ibm-runtime-python-sdk}

<Admonition type="note">
VPE รองรับ `qiskit-ibm-runtime` v0.24.0 ขึ้นไป
</Admonition>

เมื่อสร้าง instance ของ `QiskitRuntimeService` ให้ระบุ `private_endpoint=True`

```python
# For `token`, use the 44-character API_KEY you created 
# and saved from the IBM Quantum Platform Home dashboard
service = QiskitRuntimeService(token="your-API_KEY", 
                              instance="INSTANCE_CRN",
                              channel="ibm_cloud",
                              private_endpoint=True)
```

### ใช้ VPE กับ IBM Quantum API {#use-the-vpe-with-the-ibm-quantum-api}

หลังจากสร้าง endpoint gateway สำหรับ IBM Quantum Platform แล้ว ให้ใช้ fully qualified domain name (FQDN) ของ service endpoint สำหรับ region เป้าหมายจาก[ตารางก่อนหน้า](#set-up-a-vpe-for-ibm-quantum-platform)

```bash
  curl -X POST \
  https://private.us-east.quantum.cloud.ibm.com/api/v1/jobs \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Service-CRN: $SERVICE_INSTANCE_CRN" \
  -d '{
    "backend": "backend",
    "program_id": "sampler"
  }'
```
