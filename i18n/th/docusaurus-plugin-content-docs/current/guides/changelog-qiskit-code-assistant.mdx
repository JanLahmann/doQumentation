# Qiskit Code Assistant {#qiskit-code-assistant}

<span id="qca-sunset"></span>

## 29 พฤษภาคม 2026 {#29-may-2026}
- **บริการ Qiskit Code Assistant ถูกยกเลิกแล้ว** - บริการเวอร์ชันพรีวิวถูกยกเลิก และส่วนขยาย Visual Studio Code กับ JupyterLab ถูกเก็บเข้าคลังแล้ว


  จากความคิดเห็นและรูปแบบการใช้งาน พบว่าผู้ใช้จำนวนมากขึ้นรัน Qiskit Code Assistant models แบบโลคัลและทำงานในระบบผสานรวมของ editor ที่เป็นส่วนหนึ่งของขั้นตอนการพัฒนาอยู่แล้ว

  Qiskit Code Assistant models ยังคงพร้อมใช้งานสำหรับการใช้แบบโลคัล ดูเอกสาร [Qiskit Code Assistant](/guides/qiskit-code-assistant) เพื่อดูข้อมูลเพิ่มเติม
