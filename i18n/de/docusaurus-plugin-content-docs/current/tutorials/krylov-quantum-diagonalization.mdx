## Hintergrund {#background}

Dieses Tutorial zeigt, wie du den Krylov-Quantendiagonalisierungsalgorithmus (KQD) im Rahmen von Qiskit-Mustern implementierst.
Du wirst zunächst die Theorie hinter dem Algorithmus kennenlernen und anschließend eine Demonstration seiner Ausführung auf einer QPU sehen.

Die Abschätzung der Niedrigenergie-Eigenschaften von Vielteilchen-Hamiltonoperatoren ist eine zentrale Aufgabe der Quantensimulation.
Grundzustandsenergien und niedrig liegende Anregungen stehen beispielsweise in direktem Zusammenhang mit chemischer Stabilität, magnetischer Ordnung, Quantenphasenübergängen und dem Materialverhalten.
Auf einem klassischen Computer wächst die Dimension des Hilbertraums exponentiell mit der Anzahl der Orbitale oder Spins, sodass eine direkte Diagonalisierung schnell unpraktikabel wird.

Es gibt mehrere Quantencomputing-Ansätze für dieses Problem.
Near-Term-Variationsmethoden wie der [Variational Quantum Eigensolver (VQE)](/tutorials/spin-chain-vqe) verwenden relativ flache parametrisierte Schaltungen, benötigen aber eine nichtlineare klassische Optimierungsschleife mit vielen Auswertungen von Quantenschaltungen.
Am anderen Ende bietet die [Quantenphasenschätzung (QPE)](https://arxiv.org/abs/quant-ph/0604193) einen direkteren Weg zur Eigenwertschätzung mit strengen Garantien, aber die Standard-QPE erfordert lange kohärente Schaltungen und eignet sich vor allem für fehlertolerante Quantencomputer.
KQD liegt zwischen diesen beiden Ansätzen: Es nutzt Echtzeit-Hamiltonian-Evolution wie bei phasenschätzungsbasierten Algorithmen, ersetzt aber die vollständige Phasenschätzung durch ein kompaktes projiziertes Eigenwertproblem, das klassisch gelöst werden kann.

Betrachte einen $n$-Qubit-Hamiltonoperator $H$ und einen Referenzzustand $\lvert \psi_{0}\rangle$.
Die KQD-Methode konstruiert einen Krylov-Unterraum aus in Echtzeit entwickelten Zuständen,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

wobei $r$ die Krylov-Dimension und $\Delta t$ der Zeitschritt ist.
Jeder Zustand im Krylov-Unterraum wird dann als Linearkombination dieser Basiszustände dargestellt,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
wobei der Nenner den Zustand normiert.

Mit einfacher Algebra lässt sich zeigen, dass sich die entsprechende Energie als Rayleigh-Quotient schreiben lässt,

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

Hier sind die Matrizen $\mathcal{S}$ und $\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

definieren die projizierten Überlappungs- und Hamilton-Matrizen.
Ihre Einträge werden mittels Quantenschaltungsmessungen geschätzt.

Wir wollen den Koeffizienten $\mathbf{c}$ finden, der das Minimum von $E(\mathbf{c})$ ergibt:

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

Nach dem Rayleigh-Ritz-Theorem ist diese Minimierung äquivalent zur Lösung des verallgemeinerten Eigenwertproblems (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

Beachte, dass die Dimension $r$ klein genug sein kann, damit ein klassischer Computer das GEVP lösen kann.

Dies ist dasselbe Variationsprinzip, das bei der klassischen Unterraumdiagonalisierung verwendet wird, aber hier werden die Basiszustände durch Quanten-Zeitentwicklung erzeugt.
Im Vergleich zu VQE erfordert KQD in der Regel tiefere Schaltungen, da es auf Echtzeitentwicklung beruht.
Im Gegenzug vermeidet KQD nichtlineare Parameteroptimierung und iterative Ausführung auf Quantenhardware und verbessert sich systematisch, wenn der projizierte Unterraum vergrößert wird.
Der Algorithmus wurde in großem Maßstab auf existierender Quantenhardware demonstriert [\[2\]](#references), und seine Leistung kann mit beweisbaren Garantien analysiert werden [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter
from qiskit.circuit.library import PauliEvolutionGate
from qiskit.primitives import StatevectorEstimator
from qiskit.quantum_info import Operator, SparsePauliOp
from qiskit.synthesis import LieTrotter, SuzukiTrotter
from qiskit.transpiler import PassManager, Layout
from qiskit.transpiler.passes import CommutativeOptimization
from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### Die Parameter für den Algorithmus festlegen {#set-the-parameters-for-the-algorithm}

Basierend auf den oberen Schranken für die Hamiltonian-Norm schlägt Referenz [\[1\]](#references) heuristisch den Zeitschritt $\Delta t$ als $\pi/\|H\|$ vor.
Da die Spektralnorm $\|H\|$ schwer zu berechnen ist, verwenden wir stattdessen ihre obere Schranke:

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ Matrix, Norm leicht zu berechnen}} = 3(n-1).
\end{equation*}
$$

Wir setzen die Krylov-Dimension auf $r=10$ und die Anzahl der Trotter-Schritte pro Zeitschritt auf $5$: ein groß genug gewählter Krylov-Raum, um das niedrig liegende Spektrum aufzulösen, während die tiefste Schaltung ($t_{\max}=(r-1)\Delta t$) noch praktikabel bleibt, sowie genügend Trotter-Schritte, um den Diskretisierungsfehler bei dieser tiefsten Schaltung klein zu halten.

#### Schaltung erstellen {#build-circuit}

Hier bauen wir die Schaltungen zur Schätzung der Matrixelemente $\mathcal{H}_{k\ell}$ und $\mathcal{S}_{k\ell}$.
Da alle Potenzen von $H$ kommutieren, gilt
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Solche Matrizen, deren Elemente auf diese Weise von den Indexdifferenzen abhängen, werden *Toeplitz*-Matrizen genannt und lassen sich aus den Elementen der ersten Zeile rekonstruieren, indiziert durch $d=\ell-k$.

Hier stellen wir die Schaltung namens **Extended-Swap-Test** vor, die
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
vorbereitet, wobei $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$ ist.

#### Extended-Swap-Test-Schaltung [\[3\]](#references) {#extended-swap-test-circuit-3references}

Die Schaltung bereitet zunächst den Referenzzustand im Systemregister vor, während sich das Ancilla-Qubit in $|0\rangle$ befindet:

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

Anschließend erzeugt die Anwendung eines Hadamard-Gatters auf das Ancilla-Qubit eine kohärente Superposition zweier Zweige:

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Schließlich wird das kontrollierte Zeitentwicklungsgatter angewendet:

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

nur wenn sich das Ancilla-Qubit im $|1\rangle$-Zweig befindet. Daher gilt:

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Im nächsten Codeblock implementieren wir:
$$
\begin{equation*}
|\Psi(t)\rangle = \frac{|0\rangle|\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}},
\end{equation*}
$$
was im Ausführungsschritt als $t=d\Delta t$ für $d=1,\cdots r-1$ zugewiesen wird.

```python
ancilla = 0
system_qubits = list(range(1, num_qubits + 1))

extended_swap_test = QuantumCircuit(num_qubits + 1)

# Append state preparation part
extended_swap_test = extended_swap_test.compose(qc_ref, system_qubits)

# Prepare the coherent branch label, (|0> + |1>) / sqrt(2).
extended_swap_test.h(ancilla)

# Apply U(t) only to the |1> branch of the ancilla.
extended_swap_test.append(
    controlled_evolution_gate, [ancilla] + system_qubits

# Decompose once more for visualization so that control bullets are visible.
display(extended_swap_test.draw("mpl", fold=-1))
```

#### Observablen {#observables}

Für jede hermitesche Systemobservable $O$ legen wir hier die zu berechnenden Observablen fest:

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Das liegt daran, dass $O=I$ das Überlappungselement $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$ liefert, während $O=H$ das Hamiltonian-Element $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$ liefert.

Mit $X=|0\rangle\langle 1|+|1\rangle\langle 0|$ ergibt sich

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

Analog ergibt sich mit $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

Daher gilt
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Schließlich müssen wir für jeden Zustand $|\Psi_{0d}\rangle$ Folgendes messen:
$$
\begin{align*}
X \otimes I \text{ for } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ for } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ for } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ for } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

Für die Schätzung der $\mathcal{H}$-Matrixelemente ist die Anzahl der Pauli-Terme viel größer als für die $\mathcal{S}$-Matrixelemente.

Wir können nun die Anzahl der gemessenen Hamilton-Terme reduzieren, indem wir eine Verschiebungstechnik verwenden [\[4\]](#references).
Wir zerlegen den Hamiltonian wie folgt:

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

wobei $T$ so gewählt wird, dass der Referenzzustand sein Eigenzustand ist,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Dann,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Hier,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

ist das verschobene Hamilton-Matrixelement.
Daher müssen wir nur $X\otimes (H-T)$ und $Y\otimes (H-T)$ messen.
Der Beitrag von $T$ wird klassisch anhand des bereits gemessenen Überlapp-Matrixelements $\mathcal{S}_{0d}$ rekonstruiert.

In diesem Beispiel ist eine naheliegende Wahl der diagonale Teil des Heisenberg-Hamiltonians,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

Da der Referenzzustand ein Zustand der Rechenbasis ist, ist er ein Eigenzustand jedes $Z_iZ_{i+1}$-Terms.

Eine vorteilhaftere Wahl besteht jedoch darin, nicht nur die diagonalen $ZZ$-Terme, sondern auch die $XX+YY$-Terme einzubeziehen, die den Referenzzustand annihilieren.

Für jedes benachbarte Paar erfüllt der Operator $XX+YY$

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

und

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

Daher trägt der $XX+YY$-Term nur bei, wenn die beiden benachbarten Qubits im Referenz-Bitstring unterschiedliche Besetzungen haben.
Sind beide Qubits entweder $0$ oder $1$, annihiliert der Term den Referenzzustand und kann ebenfalls herausverschoben werden.

Sei $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, wobei $z_i \in \{0,1\}$.
Damit können wir wählen
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Dieser Operator erfüllt weiterhin

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

weil die $ZZ$-Terme diagonal auf $|\psi_0\rangle$ wirken, während die verschobenen $XX+YY$-Terme null ergeben.
Der zugehörige Eigenwert wird daher nur durch die $ZZ$-Terme bestimmt,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

Mit dieser Wahl wird der verschobene Hamiltonian zu:
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Infolgedessen müssen nur die Kanten mit unterschiedlichen Besetzungen im Referenzzustand gemessen werden.
Alle $ZZ$-Terme und alle inaktiven $XX+YY$-Terme werden über den Überlapp-Beitrag $\tau \mathcal{S}_{0d}$ rekonstruiert oder liefern konstruktionsbedingt einen Beitrag von null.

Dies ergibt eine kleinere Observable, als nur den diagonalen Teil zu verschieben.
Insbesondere bleiben bei einem Referenzzustand der Rechenbasis mit einer lokalisierten Anregung nur die an die Anregung angrenzenden Kanten in $H-T$ erhalten.
Daher kann die Anzahl der Pauli-Terme in $X\otimes(H-T)$ und $Y\otimes(H-T)$ erheblich reduziert werden, während das rekonstruierte Matrixelement
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

genau gleich bleibt.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau

obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, shift_tau = (
    make_reduced_heisenberg_observables(ref_bitstring)
)

print("Observable: Re shifted H_0d")
print(obs_x_shifted_hamiltonian)
print()

]
```

### Schritt 2: Problem für die Ausführung auf Quantenhardware optimieren {#step-2-optimize-problem-for-quantum-hardware-execution}

Jetzt wandeln wir den abstrakten Extended-Swap-Test-Circuit in eine hardwareorientierte Vorlage um.
Zuvor optimieren wir den Circuit zunächst weiter auf abstrakter Ebene.

#### Vergleich der Hamiltonian-Term-Reihenfolge {#compare-hamiltonian-term-ordering}

Zunächst vergleichen wir verschiedene Reihenfolgen der Pauli-Terme im Heisenberg-Hamiltonian für die Hamiltonian-Simulation.
Der Hamiltonian selbst bleibt unverändert, aber die Reihenfolge beeinflusst, wie der Produktformel-Circuit erzeugt wird und wie stark die Struktur im Circuit parallelisiert werden kann.
Die naive Reihenfolge listet beispielsweise zunächst alle nächste-Nachbar-$XX$-Terme, dann alle $YY$-Terme und dann alle $ZZ$-Terme auf.
Dadurch liegen benachbarte Kanten wie $(0,1)$ und $(1,2)$ direkt nebeneinander, sodass sie nicht parallel ausgeführt werden können.
Die Even-then-odd-Reihenfolge besucht zunächst disjunkte gerade Kanten, gefolgt von den ungeraden Kanten, wodurch parallele Zwei-Qubit-Schichten entstehen.
Die Even-odd-edge-grouped-Reihenfolge geht noch einen Schritt weiter: Für jede Kante werden die lokalen $XX$-, $YY$- und $ZZ$-Terme zusammengehalten, wobei weiterhin gerade Kanten vor ungeraden besucht werden.
Wir erwarten, dass die Even-then-odd- und die Even-odd-edge-grouped-Reihenfolge die Circuit-Tiefe verringern, indem sie parallele Zwei-Qubit-Schichten offenlegen, und dass die edge-grouped-Reihenfolge zusätzlich den Trotter-Fehler verringert, da die lokale Zwei-Qubit-Wechselwirkung auf derselben Kante als kompakter Block behandelt wird.

![Pauli-Entwicklungen mit unterschiedlicher Term-Reihenfolge](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

Die Hamiltonian-Reihenfolge beeinflusst auch den Trotter-Fehler.
Wenn wir nicht kommutierende Terme nebeneinander platzieren, treten die Basiswechsel häufiger auf, was zu einem größeren Trotter-Fehler führt.
Durch die Gruppierung von Termen, die dieselbe Pauli-Basistransformation erfordern, können redundante Basiswechsel vermieden werden.

Hier verwendet der Vergleich die größte Entwicklungszeit, die in den Krylov-Schätzungen der ersten Zeile auftritt,
$t_{\max} = (r-1)\Delta t,$
unter Verwendung derselben Transpilierungsbedingung.

Um den Trotter-Fehler zu messen, verwenden wir die **Prozess-Infidelity** zwischen der trotterisierten Schaltung und der exakten Hamilton-Zeitentwicklung,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
wobei $d=2^n$ die Dimension des Hilbertraums ist.

Diese Diagnostik verwendet dichte Matrizen und eignet sich daher für dieses kleine 12-Qubit-Beispiel, ist aber nicht als skalierbare Subroutine gedacht.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:

    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

print("Precomputing the exact evolution operator... ", end="")
exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### Entfernen des kontrollierten Zeitentwicklungs-Gates {#remove-the-controlled-time-evolution-gate}

Im Extended-Swap-Test erfordert die Steuerung der Zeitentwicklung mit einem einzelnen Ancilla-Qubit, dass das Ancilla-Qubit viele Gates im gesamten System steuert.
Dies kann erheblichen Routing-Overhead verursachen und im schlimmsten Fall praktisch eine All-to-One-Konnektivität erfordern.
Um dies zu vermeiden, ist eine weitere Optimierung möglich, indem das kontrollierte Zeitentwicklungs-Gate durch eine kontrollfreie Version ersetzt wird, die die Symmetrie des Hamiltonians ausnutzt.
Betrachten wir den folgenden Circuit.

![Circuit-Optimierung](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

Hier bereitet $B_{\rm ref}$ den Referenzzustand vor, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

Anstatt zunächst $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$ vorzubereiten und dann $U(t)$ nur auf den $|1\rangle$-Zweig anzuwenden, bereitet der Circuit die beiden Zweige direkt vor als

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

wobei

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

Der Circuit wendet zunächst ein Hadamard-Gate auf das Ancilla-Qubit an und bereitet den Referenzzustand nur auf dem $|1\rangle$-Zweig vor:

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Anschließend wird der unkontrollierte Zeitentwicklungsoperator auf beide Zweige angewendet:

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Da der Hamiltonian die Anregungszahl erhält, sehen wir, dass $|0^n\rangle$ sein Eigenzustand ist, und der Zeitentwicklungsoperator unter dem Hamiltonian somit nur eine Phase akkumuliert:
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Daher,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Als Nächstes wird $B_{\rm ref}$ nur auf den $|0\rangle$-Zweig angewendet.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

An dieser Stelle weisen die beiden Zweige eine zusätzliche relative Phase auf. Um sie zu entfernen, wenden wir das Ancilla-Phasen-Gate an

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

Dies transformiert den Zustand wie folgt

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Somit haben wir bis auf eine irrelevante globale Phase schließlich vorbereitet

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

Im nächsten Code-Block implementieren wir diesen kontrollfreien Circuit.


### Schritt 3: Ausführung mit Qiskit-Primitiven {#step-3-execute-using-qiskit-primitives}

Der nächste Schritt besteht darin, denselben parametrisierten Circuit für mehrere Werte von $d$ einzureichen. Für jedes $d$ schätzen wir vier Erwartungswerte: $X\otimes I$, $Y\otimes I$, $X\otimes (H-T)$ und $Y\otimes (H-T)$. Diese vier Zahlen werden dann zu den komplexen Elementen der ersten Zeile $\mathcal{S}_{0d}$ und $\mathcal{H}_{0d}$ kombiniert.

### Schritt 4: Nachbearbeitung und Rückgabe des Ergebnisses im gewünschten klassischen Format {#step-4-post-process-and-return-result-in-desired-classical-format}
Nach der Schätzung der projizierten Matrizen regularisieren wir und lösen das GEVP
$$
\begin{equation*}
\mathcal{H}\mathbf{c} = E\mathcal{S}\mathbf{c}.
\end{equation*}
$$
Der kleinste verallgemeinerte Eigenwert liefert die KQD-Schätzung der Grundzustandsenergie.

## Anhang: Die Hamiltonian-Funktions-(Spektralfilter-)Sichtweise {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

Der Hauptworkflow stellte KQD operativ vor: Aufbau einer Krylov-Basis aus zeitentwickelten Zuständen, Schätzung der projizierten Matrizen $\mathcal{H}$ und $\mathcal{S}$ und Lösung des GEVP.
Dieser Anhang betrachtet *dieselbe* Berechnung aus einem ergänzenden Blickwinkel, der erklärt, **warum** KQD funktioniert: die *Hamiltonian-Funktions*- bzw. *Spektralfilter*-Sichtweise [\[3\]](#references), [\[5\]](#references).
Er nutzt das 12-Qubit-Modell, den Zeitschritt $\Delta t$ und die oben bereits erhaltene Krylov-Lösung erneut; es ist keine neue Circuit-Ausführung erforderlich.

### Der Referenzzustand als Energieverteilung {#the-reference-state-as-an-energy-distribution}

Der Hamiltonian habe die Eigenzerlegung

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

mit Energie-Eigenzuständen $|E_m\rangle$.
Jeder Referenzzustand kann in dieser Eigenbasis entwickelt werden,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

sodass er bei jeder Energie $E_m$ ein **spektrales Gewicht** $p_m=|a_m|^2$ trägt.
Die Referenzenergie ist der Mittelwert dieser Verteilung, $\langle H\rangle_{0}=\sum_m p_m E_m$.

Die Eigenzerlegung eines allgemeinen $n$-Qubit-Hamiltonians ist exponentiell aufwendig, sodass dieses Bild nur eine Diagnostik ist, die *nicht* Teil des Algorithmus ist.
Hier können wir sie jedoch für das *gleiche* $n=12$-Problem kostengünstig berechnen: Der Heisenberg-Hamiltonian erhält die Gesamtanregungszahl, und der Referenzzustand $|000001000000\rangle$ trägt eine einzelne Anregung, sodass sein gesamter spektraler Inhalt im Einzelanregungs-Unterraum liegt, dessen Dimension nur linear mit $n$ wächst.
Wir nutzen daher den exakten Einzelanregungs-Block (der oben bereits als Benchmark verwendet wurde) erneut und lesen die Referenzverteilung $\{(E_m, p_m)\}$ innerhalb dieses Unterraums ab.


### KQD lernt einen Filter, der diese Verteilung umformt {#kqd-learns-a-filter-that-reshapes-this-distribution}

Eine **Hamiltonian-Funktion** $f(H)$ wird über Spektralkalkül definiert,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

mit anderen Worten eine gewichtete Summe von Eigenprojektoren.
Wendet man sie auf die Referenz an, wird jede spektrale Amplitude umgeformt, $a_m \to a_m f(E_m)$:

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

Wäre $f$ scharf bei der niedrigsten Energie konzentriert ($f(E_0)=1$ und ansonsten $f(E_m)\approx 0$), würde $f(H)$ als Grundzustandsprojektor wirken, und die normierte Ausgabe wäre (nahezu) der Grundzustand.
Ein guter Tiefpass-**Spektralfilter** in der Energie ist daher genau das, was wir wollen.

KQD schreibt $f$ nicht im Voraus vor. Stattdessen entwickelt es den Filter in der Echtzeit-Entwicklungsbasis,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

eine *trigonometrische* Funktion der Energie, deren Koeffizienten $\{c_\ell\}$ genau dem oben gelösten GEVP-Eigenvektor entsprechen.
Die Minimierung des Rayleigh-Quotienten $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ entspricht daher dem *Lernen* des Filters, der das Gewicht der angeregten Zustände in der Referenz am besten unterdrückt.
Eine größere Krylov-Dimension $r$ verleiht dem Filter mehr Freiheitsgrade und eine schärfere Spitze bei der Grundzustandsenergie.

Der folgende Helfer wertet diesen gelernten Filter auf einer Energieachse aus; wir wenden ihn dann auf die oben erhaltene Referenzverteilung an.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### Erhöhung der Krylov-Dimension: Flexibilität der gelernten Funktion {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

Erinnern wir uns, dass der gelernte Filter ein trigonometrisches Polynom in der Energie mit $r$ Koeffizienten ist,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

Die Krylov-Dimension $r$ entspricht genau der Anzahl der freien Koeffizienten und steuert somit die **Flexibilität** der Funktion.
Ein kleines $r$ kann nur einen breiten, sanft variierenden Filter erzeugen, der Gewicht in tiefliegende angeregte Zustände durchsickern lässt; wenn $r$ zunimmt, kann der Filter eine schmalere Spitze bei der Zielenergie bilden und das verbleibende Gewicht der angeregten Zustände stärker unterdrücken.
Dies ist das Spektralfilter-Gegenstück zur im kleinskaligen Beispiel beobachteten Energiekonvergenz: Mit wachsendem $r$ kollabiert die gefilterte Verteilung auf den Grundzustand des Unterraums, und die geschätzte Energie nähert sich diesem an.

Wir nutzen die oben bereits geschätzten projizierten Matrizen erneut und lösen einfach das GEVP für jeden führenden $r\times r$-Block, um dann den entsprechenden Filter auszuwerten und darzustellen.

```python
# Sweep the Krylov dimension using the leading r x r blocks of the estimated matrices.
sweep_dims = [r for r in (2, 4, 6, 8, krylov_dim) if r <= krylov_dim]
sweep_dims = sorted(set(sweep_dims))

energy_grid = np.linspace(
    subspace_evals.min() - 0.5, subspace_evals.max() + 0.5, 800
)

sweep_cases = []
print(" r    retained    ground overlap    filtered energy")
print("--    --------    --------------    ---------------")
for r in sweep_dims:
    _, coeffs_r, retained_r = solve_thresholded_gevp(
        h_matrix_est[:r, :r],
        s_matrix_est[:r, :r],
        threshold=1e-12,
    )
    filter_on_spectrum_r = trigonometric_krylov_filter(
        coeffs_r, subspace_evals, dt
    )
    filtered_weights_r = filtered_spectral_weights(
        ref_spectral_weights, filter_on_spectrum_r
    )
    filtered_energy_r = float(np.sum(filtered_weights_r * subspace_evals))

    sweep_cases.append((r, coeffs_r, filtered_weights_r))
    print(
        f"{r:2d}    {retained_r:8d}    {filtered_weights_r[0]:14.4f}    {filtered_energy_r:15.6f}"
    )

print(f"\nSubspace ground-state energy (target): {subspace_evals[0]:.6f}")

# One panel per Krylov dimension: filtered spectrum (bars) + filter intensity (curve).
fig, axes = plt.subplots(
    len(sweep_cases),
    1,
    figsize=(8, 2.1 * len(sweep_cases)),
    sharex=True,
)
axes = np.atleast_1d(axes)

for idx, (ax, (r, coeffs_r, filtered_weights_r)) in enumerate(
    zip(axes, sweep_cases)
):
    visible = (ref_spectral_weights > 1e-4) | (filtered_weights_r > 1e-4)
    ax.bar(
        subspace_evals[visible],
        ref_spectral_weights[visible],
        width=0.18,
        alpha=0.35,
        color="C0",
        label="reference $p_m$" if idx == 0 else None,
    )
    ax.bar(
        subspace_evals[visible],
        filtered_weights_r[visible],
        width=0.14,
        alpha=0.9,
        color="C1",
        label="filtered weights" if idx == 0 else None,
    )

    filter_intensity_r = (
        np.abs(trigonometric_krylov_filter(coeffs_r, energy_grid, dt)) ** 2
    )
    filter_intensity_r /= filter_intensity_r.max()
    ax.plot(energy_grid, filter_intensity_r, color="k", linewidth=2)

    ax.axvline(subspace_evals[0], color="C3", linestyle="--", linewidth=1)
    ax.set_ylim(0, 1)
    ax.set_ylabel("weight")
    ax.legend(loc="upper right", title=f"$r={r}$")

axes[-1].set_xlabel("Energy eigenvalue $E_m$")
fig.suptitle(
    r"KQD-learned filter $|f_{\rm KQD}(E)|^2$ sharpening with Krylov dimension $r$",
    y=1.0,
)
fig.tight_layout()
plt.show()
```
