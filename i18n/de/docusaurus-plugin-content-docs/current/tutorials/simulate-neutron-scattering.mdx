## Hintergrund {#background}

In diesem Tutorial reproduzieren wir die Ergebnisse von [Lee et al., arXiv:2603.15608](https://arxiv.org/abs/2603.15608).

### Inelastische Neutronenstreuung und der dynamische Strukturfaktor {#inelastic-neutron-scattering-and-the-dynamical-structure-factor}

Inelastische Neutronenstreuung (INS) ist eine der leistungsfähigsten experimentellen Sonden für magnetische Anregungen in Quantenmaterialien. Wenn ein Strahl thermischer oder kalter Neutronen auf einen Kristall trifft, tauschen einzelne Neutronen sowohl Impuls $\mathbf{q}$ als auch Energie $\omega$ mit dem magnetischen Subsystem aus. Die gemessene Streuintensität ist proportional zum dynamischen Strukturfaktor (DSF),

$$S^{\alpha\beta}(q,\omega) = \sum_{j} e^{-iq\,j}\int_{-\infty}^{\infty} dt\; e^{i\omega t}\, \langle S_0^{\alpha}(0)\, S_j^{\beta}(t)\rangle,$$

der die vollständigen Raum-Zeit-Korrelationen der Spin-Freiheitsgrade kodiert.

### KCuF$_3$: ein kanonischer Luttinger-Flüssigkeits-Magnet {#kcuf-3-a-canonical-luttinger-liquid-magnet}

Kaliumkupferfluorid (KCuF$_3$) ist ein quasi-eindimensionaler Antiferromagnet, in dem Ketten von Spin-$\frac{1}{2}$-Cu$^{2+}$-Ionen über einen Nächste-Nachbar-Heisenberg-Austausch $J$ wechselwirken, während die Kopplung zwischen den Ketten nur $\sim 2.7\%$ von $J$ beträgt. Bei $T = 6\;\mathrm{K}$, wo INS-Daten vorliegen, wird das Spektrum von fraktionalisierten Spinon-Anregungen dominiert, die charakteristisch für eine Tomonaga-Luttinger-Flüssigkeit sind. Da die Intrachain-Dynamik gut durch den eindimensionalen Spin-$\frac{1}{2}$-XXZ-Hamiltonian am isotropen Punkt ($\epsilon = 1$) beschrieben wird,

$$H = J\sum_{i}\left[S_i^Z S_{i+1}^Z + \epsilon\left(S_i^X S_{i+1}^X + S_i^Y S_{i+1}^Y\right)\right],$$

KCuF$_3$ dient als idealer Benchmark für Quantensimulation: Der Hamiltonian ist einfach genug, um auf einem Quantenprozessor implementiert zu werden, dennoch ist der Grundzustand stark verschränkt und das Anregungsspektrum weist ein breites Zwei-Spinon-Kontinuum auf.

Hinweis: Dieses Tutorial setzt $J = 1$ als Energieeinheit und übernimmt die Normierung $H = J\sum_i[\ldots]$, was dem lokalen Hamiltonian $H_\mathrm{loc} = J(S^X S^X + S^Y S^Y + S^Z S^Z)$ entspricht, der in der Circuit-Implementierung des Papers verwendet wird (Abb. S3 der Zusatzinformationen). Der vollständige Hamiltonian des Papers (Gl. 3) trägt einen zusätzlichen Gesamtfaktor 2, sodass das $J$ des Papers doppelt so groß ist wie das hier verwendete $J$.

### Was wir simulieren und messen {#what-we-simulate-and-measure}

Die physikalische Größe, die wir berechnen, ist die **retardierte Green'sche Funktion** (RGF), definiert als die zeitabhängige Spin-Spin-Korrelationsfunktion

$$G^R_{\alpha,\beta}(j, j_c, t) = -\frac{i}{2}\,\langle\psi_{\mathrm{GS}}|\,S_j^\alpha(t)\,S_{j_c}^\beta(0) - S_{j_c}^\beta(0)\,S_j^\alpha(t)\,|\psi_{\mathrm{GS}}\rangle,$$

Dabei ist $j_c$ eine Referenzstelle (das Kettenzentrum) und $S_j^\alpha(t) = e^{iHt}S_j^\alpha e^{-iHt}$ der Spinoperator im Heisenberg-Bild. In diesem Tutorial konzentrieren wir uns auf die $zz$-Komponente ($\alpha = \beta = z$). Auf einem Quantencomputer wird auf die RGF zugegriffen, indem der Grundzustand vorbereitet, eine lokale Störung bei $j_c$ angewendet, der gestörte Zustand zeitlich entwickelt und der Einzel-Qubit-Erwartungswert $\langle\sigma_j^z\rangle$ an jeder Stelle $j$ für jeden Zeitschritt gemessen wird. Die entscheidende Erkenntnis ist, dass jedes $\langle\sigma_j^z\rangle$ die Abweichung von der Grundzustandsmagnetisierung liefert; da der isotrope Heisenberg-Antiferromagnet eine verschwindende Netto-Magnetisierung pro Stelle hat ($\langle\sigma_j^z\rangle_\mathrm{GS} = 0$), ergibt der rohe Messwert direkt $G^R(j, j_c, t)$ ohne explizite Subtraktion.

Indem wir $G^R(j, j_c, t)$ über alle Stellen und Zeitschritte hinweg sammeln, stellen wir einen zweidimensionalen Datensatz zusammen, der dann sowohl räumlich als auch zeitlich per Fourier-Transformation in den **dynamischen Strukturfaktor** $S(q,\omega)$ umgewandelt wird. Der DSF ist die Größe, die in einem INS-Experiment direkt gemessen wird: Er zeigt uns, welche magnetischen Anregungen bei jedem Impuls $q$ und jeder Energie $\omega$ existieren. Für die isotrope Heisenberg-Kette ist das exakte Anregungsspektrum ein **Zwei-Spinon-Kontinuum**, ein breites Band von Streuintensität, dessen Form als strenger Ende-zu-Ende-Benchmark für die Quantensimulation dient: Es validiert gleichzeitig die Grundzustandsvorbereitung, die Störung, die Trotter-Zeitentwicklung und das Messprotokoll.

### Quantensimulations-Workflow {#quantum-simulation-workflow}

Der Workflow spiegelt die Physik eines INS-Ereignisses wider. Wir (1) bereiten den Vielteilchen-Grundzustand $|\psi_{\mathrm{GS}}\rangle$ auf $n$ Qubits vor, (2) wenden eine lokale Spin-Flip-Störung $U_{j_c} = \frac{1}{\sqrt{2}}(I - i\sigma^z_{j_c})$ am Kettenzentrum an, um den Spin-Transfer des Neutrons nachzubilden, (3) entwickeln unter $H$ für diskrete Zeitschritte mittels Trotterisierung zweiter Ordnung, und (4) messen $\langle\sigma_i^z\rangle$ an jedem Qubit bei jedem Schritt, um die RGF zu erhalten. Eine zweidimensionale diskrete Fourier-Transformation liefert dann den DSF $S(q,\omega)$.

Die Observable, die wir bei jedem Zeitschritt messen, ist $\sigma_i^z$ auf jedem Qubit $i$. In Qiskit wird dies als Liste von `SparsePauliOp`-Operatoren dargestellt: ein Einzel-Qubit-$Z$, eingebettet in die $n$-Qubit-Identitätskette für jede Stelle. Diese Observablen werden einmal pro Probleminstanz während des Problem-Mapping-Schritts (Schritt 1) konstruiert und für jeden Circuit auf dieser Skala wiederverwendet.

### Approximatives Quantenkompilieren (AQC) {#approximate-quantum-compiling-aqc}

Tiefe Trotter-Circuits können mit **approximativem Quantenkompilieren (AQC)** komprimiert werden, wobei die ersten mehreren Trotter-Schichten durch einen kürzeren parametrisierten Ansatz ersetzt werden, dessen Parameter klassisch optimiert werden, um die Fidelity auf MPS-Ebene mit dem ursprünglichen tiefen Circuit zu maximieren. Die verbleibenden Trotter-Schritte werden exakt angehängt, wodurch ein „gemischter“ AQC + Trotter-Circuit mit deutlich weniger Zwei-Qubit-Gates entsteht.

### MPS-Simulation {#mps-simulation}

Für ein eindimensionales System können Matrix-Produkt-Zustand-Methoden (MPS) sowohl die Grundzustandsvorbereitung (mit der Dichtematrix-Renormierungsgruppe, DMRG) als auch die Zeitentwicklung auf Circuit-Ebene effizient simulieren. Durch die Steuerung der Bindungsdimension $\chi$ wägen wir Genauigkeit gegen Rechenaufwand ab. In diesem Tutorial verwenden wir MPS-Simulation innerhalb von `qiskit-addon-aqc-tensor`, um hochpräzise AQC-Ansätze zu berechnen, die die tiefen Trotter-Circuits für die Hardware-Ausführung komprimieren.

```python
def xxz_hamiltonian_mpo(
    n_qubits: int, interaction: float = 1.0, anisotropy: float = 1.0
) -> qtn.MatrixProductOperator:
    """1D XXZ Hamiltonian as a quimb MPO.

    Builds the Hamiltonian using ``qtn.SpinHam1D``.

    Args:
        n_qubits: Number of sites.
        interaction: Overall interaction strength (J in the paper).
        anisotropy: XY/Z anisotropy (ε in the paper). ``ε = 1`` is the
            isotropic Heisenberg point; ``ε = 0`` is the Ising limit.

    Returns:
        The Hamiltonian as a matrix product operator.
    """
    builder = qtn.SpinHam1D(S=1 / 2)
    builder += interaction * anisotropy * 0.5, "+", "-"
    builder += interaction * anisotropy * 0.5, "-", "+"
    builder += interaction, "Z", "Z"
    return builder.build_mpo(L=n_qubits)

def build_ground_state_ansatz(n_qubits: int, n_layers: int) -> QuantumCircuit:
    """Hamiltonian variational ansatz (HVA) circuit for ground-state preparation.

    Starts from a product of singlet pairs and applies alternating
    odd/even layers of parameterized XXZ pair-evolution gates.

    The returned circuit is parameterized: it carries a ``ParameterVector``
    named ``"theta"`` of length ``2 * n_layers`` whose values must be
    assigned (e.g. via ``circuit.assign_parameters``) before simulation.
    Element ``2 * r`` is the odd-layer angle and element ``2 * r + 1`` is the
    even-layer angle of layer ``r``.

    Args:
        n_qubits: Number of qubits (must be even).
        n_layers: Number of HVA layers.

    Returns:
        The parameterized HVA preparation circuit.
    """
    theta = ParameterVector("theta", 2 * n_layers)
    circuit = QuantumCircuit(n_qubits)
    # Initial singlet product state
    for i in range(n_qubits // 2):
        circuit.x(2 * i)
        circuit.x(2 * i + 1)
        circuit.h(2 * i + 1)
        circuit.cx(2 * i + 1, 2 * i)
    # Variational layers: each pair gate is exp(-i theta (XX+YY+ZZ)/2)
    pair_ham = SparsePauliOp(
        ["XX", "YY", "ZZ"], coeffs=[0.5, 0.5, 0.5]
    )  # H_pair (HVA form)
    for r in range(n_layers):
        for i in range(1, (n_qubits + 1) // 2):  # odd layer
            circuit.append(
                PauliEvolutionGate(pair_ham, time=theta[2 * r]),
                [2 * i - 1, 2 * i],
            )
        for i in range(n_qubits // 2):  # even layer
            circuit.append(
                PauliEvolutionGate(pair_ham, time=theta[2 * r + 1]),
                [2 * i, 2 * i + 1],
            )
    return circuit

def optimize_ground_state_ansatz(
    ansatz: QuantumCircuit,
    x0: NDArray[np.floating],
    target_mps: qtn.MatrixProductState,
    *,
    max_bond: int | None = None,
    cutoff: float = 1e-10,
    method: str = "COBYQA",
    options: dict | None = None,
) -> scipy.optimize.OptimizeResult:
    """Optimize HVA parameters by maximizing fidelity with a target MPS.

    The HVA circuit is simulated as a matrix product state with the given
    bond-dimension truncation, and the parameters are optimized to maximize
    the state fidelity ``|<psi_HVA | target_mps>|**2`` with the DMRG ground
    state. Both states are normalized, so the minimized objective is the
    infidelity ``1 - |<psi_HVA | target_mps>|**2``.

    Args:
        ansatz: Parameterized HVA circuit from ``build_ground_state_ansatz``.
            The length of ``x0`` must equal ``ansatz.num_parameters``.
        x0: Initial parameters.
        target_mps: Target MPS (DMRG ground state) to maximize fidelity with.
        max_bond: Maximum MPS bond dimension during gate application.
        cutoff: Singular-value cutoff during gate application.
        method: ``scipy.optimize.minimize`` method.
        options: Options dict forwarded to ``scipy.optimize.minimize``.

    Returns:
        The Scipy OptimizeResult.
    """

    def infidelity(params: NDArray[np.floating]) -> float:
        circuit = ansatz.assign_parameters(params)
        circuit_mps = quimb_circuit(
            circuit.decompose(["PauliEvolution"]),
            quimb_circuit_class=qtn.CircuitMPS,
            max_bond=max_bond,
            cutoff=cutoff,
        )
        return 1 - abs(circuit_mps.psi.H @ target_mps) ** 2

    return scipy.optimize.minimize(
        infidelity, np.asarray(x0), method=method, options=options
    )

def trotter_evolution(
    qubits: Sequence[Qubit],
    interaction: float,
    anisotropy: float,
    time_step: float,
    n_steps: int,
) -> Iterator[CircuitInstruction]:
    """Second-order Trotter steps of the XXZ pair Hamiltonian.

    While the paper used a hand-optimized circuit for the Trotter steps, we use
    PauliEvolutionGate here for simplicity and generality. The final two-qubit gate
    count and gate depth are equivalent when transpiled with ``optimization_level=3``.

    Args:
        qubits: Qubits to act on (length ``n_qubits``).
        interaction: Overall interaction strength (J in the paper).
        anisotropy: XY/Z anisotropy (ε in the paper). ``ε = 1`` is the
            isotropic Heisenberg point; ``ε = 0`` is the Ising limit.
        time_step: Per-step Trotter time.
        n_steps: Number of Trotter steps.

    Yields:
        ``CircuitInstruction``s implementing the Trotter steps.
    """
    if n_steps == 0:
        return
    n_qubits = len(qubits)
    pair_ham = SparsePauliOp(
        ["XX", "YY", "ZZ"],
        coeffs=[
            0.25 * interaction * anisotropy,
            0.25 * interaction * anisotropy,
            0.25 * interaction,
        ],
    )
    half_evo = PauliEvolutionGate(pair_ham, time=time_step / 2)
    full_evo = PauliEvolutionGate(pair_ham, time=time_step)
    for i in range(n_qubits // 2):  # half even layer
        yield CircuitInstruction(half_evo, (qubits[2 * i], qubits[2 * i + 1]))
    for i in range(n_qubits // 2 - 1):  # full odd layer
        yield CircuitInstruction(
            full_evo, (qubits[2 * i + 1], qubits[2 * i + 2])
        )
    for _ in range(n_steps - 1):  # interior steps
        for i in range(n_qubits // 2):
            yield CircuitInstruction(
                full_evo, (qubits[2 * i], qubits[2 * i + 1])
            )
        for i in range(n_qubits // 2 - 1):
            yield CircuitInstruction(
                full_evo, (qubits[2 * i + 1], qubits[2 * i + 2])
            )
    for i in range(n_qubits // 2):  # half even layer
        yield CircuitInstruction(half_evo, (qubits[2 * i], qubits[2 * i + 1]))

def get_dsf(
    n_qubits: int,
    rgf_mat: NDArray[np.floating],
    time_step: float,
    n_steps: int,
    n_points_momentum: int,
    n_points_frequency: int,
) -> NDArray[np.floating]:
    """Compute the dynamical structure factor from the retarded Green's function.

    Uses the center-site approximation and a discrete Fourier transform.
    The result is symmetrized about the momentum axis and clipped to
    non-negative values, ready for plotting.

    Args:
        n_qubits: Number of qubits (sites).
        rgf_mat: RGF matrix of shape ``(n_steps, n_qubits)``.
        time_step: Trotter time-step size.
        n_steps: Number of time steps.
        n_points_momentum: Number of momentum points.
        n_points_frequency: Number of frequency points.

    Returns:
        DSF array of shape ``(n_points_frequency, n_points_momentum)``,
        symmetrized about the momentum axis and clipped to non-negative values.
    """
    max_frequency = np.pi / time_step
    momentum_range = np.linspace(0, 2 * np.pi, n_points_momentum)
    frequency_range = np.linspace(0, max_frequency, n_points_frequency)
    result = np.zeros((frequency_range.shape[0], momentum_range.shape[0]))
    center = n_qubits // 2 - 1
    for iw, w in enumerate(frequency_range):
        exponent = np.exp(1j * w * time_step * np.arange(1, n_steps + 1))
        # S = sigma/2, so two spin operators contribute a factor of (1/2)(1/2) = 1/4.
        rgf_omega = (
            np.dot(rgf_mat.T, exponent) * time_step / 4
        )  # S(omega): time Fourier slice of the Green's function
        for iq, q in enumerate(momentum_range):
            momentum_phases = np.exp(
                -1j * q * np.arange(-center, center + 2, 1)
            )
            result[iw, iq] = np.imag(np.dot(rgf_omega, momentum_phases))
    result = -(result + result[:, ::-1]) / 2
    result = np.clip(result, a_min=0, a_max=None)
    return result

def plot_dsf(
    dsf: NDArray[np.floating],
    time_step: float,
    n_points_momentum: int,
    n_points_frequency: int,
    title: str | None = None,
) -> None:
    """Heat-map of the dynamical structure factor.

    Args:
        dsf: DSF array of shape ``(n_points_frequency, n_points_momentum)``.
        time_step: Trotter time-step size.
        n_points_momentum: Number of momentum points.
        n_points_frequency: Number of frequency points.
        title: Optional plot title.
    """
    max_frequency = np.pi / time_step
    momentum_range = np.linspace(0, 2 * np.pi, n_points_momentum)
    frequency_range = np.linspace(0, max_frequency, n_points_frequency)
    x, y = np.meshgrid(momentum_range, frequency_range)
    fig, ax = plt.subplots(figsize=(8, 5))
    c = ax.pcolormesh(x, y, dsf / np.max(dsf), cmap="viridis", shading="auto")
    fig.colorbar(c, ax=ax, label="Normalized intensity")
    ax.set_ylim(0, 3.6)
    ax.set_xlim(0, 2 * np.pi)
    ax.set_xlabel(r"$q$", fontsize=16)
    ax.set_ylabel(r"$\tilde{\omega} = \omega / J$", fontsize=16)
    ax.set_xticks([0, np.pi / 2, np.pi, 3 * np.pi / 2, 2 * np.pi])
    ax.set_xticklabels(["0", r"$\pi/2$", r"$\pi$", r"$3\pi/2$", r"$2\pi$"])
    if title:
        ax.set_title(title, fontsize=14)
    plt.tight_layout()
    plt.show()

def plot_rgf(
    n_qubits: int,
    rgf_mat: NDArray[np.floating],
    time_step: float,
    n_steps: int,
    title: str | None = None,
) -> None:
    """Heat-map of the retarded Green's function in real space and time.

    Args:
        n_qubits: Number of qubits (sites).
        rgf_mat: RGF matrix of shape ``(n_steps, n_qubits)``.
        time_step: Trotter time-step size.
        n_steps: Number of time steps.
        title: Optional plot title.
    """
    fig, ax = plt.subplots(figsize=(8, 6))
    qubit_axis = np.arange(n_qubits)
    t_axis = np.arange(1, n_steps + 1) * time_step
    x, y = np.meshgrid(qubit_axis, t_axis)
    c = ax.pcolormesh(
        x,
        y,
        np.real(rgf_mat),
        cmap="RdBu",
        vmax=0.5,
        vmin=-0.5,
        shading="auto",
    )
    fig.colorbar(c, ax=ax, label=r"Re $G^R(j, j_c, t)$")
    ax.set_xlabel("Qubit", fontsize=16)
    ax.xaxis.set_major_locator(
        plt.matplotlib.ticker.MaxNLocator(integer=True)
    )
    ax.set_ylabel(r"Time", fontsize=16)
    if title:
        ax.set_title(title, fontsize=14)
    plt.tight_layout()
    plt.show()
```

### Schritt 1: Klassische Eingaben auf ein Quantenproblem abbilden {#step-1-map-classical-inputs-to-a-quantum-problem}

Wir beginnen damit, das physikalische Modell zu definieren und die Quanten-Circuits zu konstruieren.

**Hamiltonian.** KCuF$_3$ wird durch den 1D-XXZ-Hamiltonian am isotropen Punkt modelliert ($J = 1$, $\epsilon = 1$, wobei $J = 1$ als Energieeinheit gesetzt wird).

**Grundzustand.** Wir verwenden einen Hamiltonian-Variational-Ansatz(HVA)-Circuit, `build_ground_state_ansatz`, als Grundzustandsvorbereitungs-Circuit. Die HVA-Parameter werden klassisch optimiert, indem die Zustandsfidelity $|\langle\psi_{\mathrm{HVA}}(\theta)|\psi_{\mathrm{DMRG}}\rangle|^2$ mit dem DMRG-Grundzustands-MPS maximiert wird, wobei der HVA-Zustand ausgewertet wird, indem der Circuit mit quimbs `CircuitMPS` als Matrix-Produkt-Zustand simuliert wird. Wir verwenden `scipy.optimize.minimize` für die Optimierung. Die Energie $\langle H \rangle$ des optimierten Ansatzes wird ebenfalls zu Referenzzwecken berechnet.

**Trotter-Gates.** Jeder Wechselwirkungsterm zwischen nächsten Nachbarn $e^{-i\Delta t\, H_{\mathrm{pair}}}$ mit $H_{\mathrm{pair}} = (J/4)(XX + YY + ZZ)$ wird mit `PauliEvolutionGate(H_pair, time=time_step)` konstruiert. Qiskit synthetisiert dies während der Transpilation in die optimale Drei-CNOT-Zerlegung.

**Störung.** Ein $R_z(\pi/2)$-Gate auf dem zentralen Qubit implementiert $U_{j_c} = \frac{1}{\sqrt{2}}(I - i\sigma^z_{j_c})$ und ahmt den lokalen Spin-Flip nach, der durch ein gestreutes Neutron erzeugt wird.

**Observablen.** Wir konstruieren für jeden Qubit-Platz ein $\sigma^z$-Observable. Diese `SparsePauliOp`-Objekte werden in Schritt 3 an die Estimator-Primitive übergeben, um $\langle\sigma_i^z\rangle$ zu jedem Zeitschritt zu extrahieren.

```python

        circuit.qubits, interaction, anisotropy, time_step, t
```

### Schritt 2: Problem für die Ausführung auf Quantenhardware optimieren {#step-2-optimize-problem-for-quantum-hardware-execution}

Für reale Hardware wären die obigen Trotter-Circuits zu tief. **Approximate Quantum Compiling (AQC)** löst dieses Problem, indem die ersten $k$ Trotter-Schichten (einschließlich des Grundzustands-Circuits) durch einen kürzeren parametrisierten Ansatz ersetzt werden, der so optimiert ist, dass die Fidelity auf MPS-Ebene mit dem ursprünglichen tiefen Circuit maximiert wird. Die verbleibenden Trotter-Schritte werden exakt angehängt, wodurch ein flacherer „AQC + Trotter"-Circuit entsteht.

Um Ausdrucksstärke gegen Circuit-Tiefe abzuwägen, werden zwei Ansätze verwendet: Ein **einschichtiger Ansatz** (erzeugt aus einem einzigen Trotter-Schritt) komprimiert die frühesten Zeitschritte, und ein tieferer **zweischichtiger Ansatz** (erzeugt aus zwei Trotter-Schritten) komprimiert die nächsten Schritte, bei denen eine höhere Fidelity benötigt wird.

Der AQC-Workflow besteht aus vier Teilschritten:

1. **Ziel-Circuits erstellen** &mdash; die ersten $k_1 + k_2$ Circuits aus Schritt 1 dienen direkt als AQC-Ziele.

2. **Ziel-MPS berechnen** &mdash; simuliere jeden Ziel-Circuit als Matrixproduktzustand mit `quimb.tensor.CircuitMPS`.

3. **Ansätze erzeugen und optimieren** &mdash; `generate_ansatz_from_circuit` erstellt einen einschichtigen und einen zweischichtigen parametrisierten Ansatz; die Parameter werden mit L-BFGS-B unter Verwendung von JAX-beschleunigten Gradienten optimiert, um $1 - |\langle\psi_{\mathrm{ansatz}}|\psi_{\mathrm{target}}\rangle|^2$ zu minimieren. Die ersten $k_1$ Schritte verwenden den einschichtigen Ansatz und die nächsten $k_2$ Schritte den zweischichtigen Ansatz; innerhalb jeder Stufe startet jeder Schritt mit den optimierten Parametern des vorherigen Schritts (Warmstart), und die Parameter werden an der Stufengrenze auf die Standardwerte der Stufe zurückgesetzt.

4. **Gemischte Circuits zusammenstellen** &mdash; für Zeitschritte jenseits des AQC-Checkpoints werden mit `trotter_evolution` exakte Trotter-Schichten an den optimierten zweischichtigen AQC-Circuit angehängt.


```python
# Number of time steps to compress into an AQC ansatz with one layer
aqc_n_steps_1 = 3
# Number of time steps to compress into an AQC ansatz with two layers
aqc_n_steps_2 = 2
aqc_n_steps_total = aqc_n_steps_1 + aqc_n_steps_2

# ── Step 2a: Target circuits (first aqc_n_steps_total circuits from Step 1) ──
target_circuits = {
    k: circuits[k - 1] for k in range(1, aqc_n_steps_total + 1)
}
# ── Step 2b: Compute target MPS ──
# Decompose PauliEvolutionGate to RXX/RYY/RZZ before passing to the AQC MPS
# backend, which does not understand PauliEvolutionGate natively.
aqc_sim = QuimbSimulator(
    quimb_circuit_factory=partial(
        qtn.CircuitMPS,
        gate_opts=dict(max_bond=mps_max_bond, cutoff=mps_cutoff),
    ),
    autodiff_backend="jax",
)
print("\nStep 2b — target MPS:")
target_mps = {}
for k in range(1, aqc_n_steps_total + 1):
    target_mps[k] = tensornetwork_from_circuit(
        target_circuits[k].decompose(["PauliEvolution"]), aqc_sim
    )
    print(f"  k={k}: max bond = {target_mps[k].psi.max_bond()}")

# ── Step 2c: Generate ansätze (one-layer and two-layer) and optimize parameters ──
ansatz_1, initial_params_1 = generate_ansatz_from_circuit(
    target_circuits[1].decompose(["PauliEvolution"]),
    qubits_initially_zero=True,
)
initial_params_1 = np.array(initial_params_1)
ansatz_2, initial_params_2 = generate_ansatz_from_circuit(
    target_circuits[2].decompose(["PauliEvolution"]),
    qubits_initially_zero=True,
)
initial_params_2 = np.array(initial_params_2)
print(
    f"\nStep 2c — one-layer ansatz: {ansatz_1.num_parameters} parameters, "
    f"2q depth (uniform basis) = {uniform_2q_depth(ansatz_1)}"
)
print(
    f"Step 2c — two-layer ansatz: {ansatz_2.num_parameters} parameters, "
    f"2q depth (uniform basis) = {uniform_2q_depth(ansatz_2)}"
)

aqc_circuits = {}
aqc_params = {}
for k in range(1, aqc_n_steps_total + 1):
    if k <= aqc_n_steps_1:
        ansatz, base_params = ansatz_1, initial_params_1
    else:
        ansatz, base_params = ansatz_2, initial_params_2
    # Warm-start from the previous step only within the same stage
    same_stage = (k - 1 >= 1) and (
        (k - 1 <= aqc_n_steps_1) == (k <= aqc_n_steps_1)
    )
    x0 = aqc_params[k - 1] if same_stage else base_params
    obj = MaximizeStateFidelity(target_mps[k], ansatz, aqc_sim)
    t0 = timeit.default_timer()
    result = scipy.optimize.minimize(
        obj.loss_function,
        x0,
        method="L-BFGS-B",
        jac=True,
        options=dict(maxiter=100),
    )
    elapsed = timeit.default_timer() - t0
    aqc_params[k] = result.x
    aqc_circuits[k] = ansatz.assign_parameters(result.x)
    print(
        f"  k={k}: fidelity = {1 - result.fun:.4f}, "
        f"2q depth (uniform basis) = "
        f"{uniform_2q_depth(aqc_circuits[k])}, "
        f"{elapsed:.1f}s"
    )

# ── Step 2d: Assemble full circuit set (AQC + Trotter) ──
all_circuits = []
for k in range(1, aqc_n_steps_total + 1):
    all_circuits.append(aqc_circuits[k])
base = aqc_circuits[aqc_n_steps_total]
for k in range(1, n_steps - aqc_n_steps_total + 1):
    circuit = base.copy()
    for instr in trotter_evolution(
        circuit.qubits, interaction, anisotropy, time_step, k
    ):
        circuit.append(instr)
    all_circuits.append(circuit)

full_depths = [
    uniform_2q_depth(circuits[k - 1]) for k in range(1, n_steps + 1)
]
aqc_depths = [uniform_2q_depth(circuit) for circuit in all_circuits]
full_2q = [
    circuits[k - 1].decompose(["PauliEvolution"]).num_nonlocal_gates()
    for k in range(1, n_steps + 1)
]
aqc_2q = [
    circuit.decompose(["PauliEvolution"]).num_nonlocal_gates()
    for circuit in all_circuits
]
print(f"\nStep 2d — assembled {len(all_circuits)} circuits")
print(
    f"  At step {n_steps} (uniform basis): "
    f"Trotter 2q depth = {full_depths[-1]}, AQC+Trotter 2q depth = {aqc_depths[-1]}; "
    f"2q gates: Trotter = {full_2q[-1]}, AQC+Trotter = {aqc_2q[-1]}"
)

steps_axis = np.arange(1, n_steps + 1)
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(steps_axis, full_depths, "-o", color="black", label="Full Trotter")
ax.plot(
    steps_axis, aqc_depths, "-o", color="cadetblue", label="AQC + Trotter"
)
ax.set_xlabel("Trotter steps", fontsize=13)
ax.xaxis.set_major_locator(plt.matplotlib.ticker.MaxNLocator(integer=True))
ax.set_ylabel("2q gate depth (uniform basis)", fontsize=13)
ax.set_title(f"AQC circuit-depth reduction ({n_qubits} qubits)", fontsize=13)
ax.legend(fontsize=11)
plt.tight_layout()
plt.show()
```

## Großskalige Hardware-Ausführung {#large-scale-hardware-execution}

Wir skalieren nun auf **50 Qubits**. Bei diesem Umfang erreichen die Optimierungen niedrigere Fidelities als im kleinskaligen Beispiel: Die Fidelity des Grundzustands-Ansatzes sinkt auf etwa 0,65, und die AQC-Fidelities sinken bei den späteren Checkpoints auf etwa 0,7. Das ist zu erwarten, und du kannst diese Fidelities verbessern, indem du die Anzahl der Grundzustands-Ansatz-Schichten (`gs_n_layers`) oder die Anzahl der Optimierungsiterationen (`maxiter`) erhöhst, was zusätzliche klassische Rechenkosten verursacht. Beachte außerdem, dass die zweischichtigen AQC-Fidelities niedriger ausfallen als die einschichtigen. Das ist keine Verschlechterung: Spätere Zeitschritte erzeugen mehr Verschränkung und sind daher einfach schwerer zu komprimieren, weshalb für sie der ausdrucksstärkere zweischichtige Ansatz verwendet wird.

Die AQC-Optimierung kann außerdem mehrere Stunden klassische Rechenzeit in Anspruch nehmen (rund sechs Stunden im hier gezeigten Lauf, wobei der Großteil davon auf die zweischichtigen Checkpoints in Schritt 2c entfällt). Um die tatsächliche Laufzeit zu verkürzen, kannst du dieses Notebook auf leistungsfähigerer klassischer Hardware ausführen, etwa auf einem Hochleistungsrechensystem (HPC). Alternativ kannst du die Problemgröße verkleinern (zum Beispiel weniger Qubits oder weniger Zeitschritte); deine Ergebnisse werden sich dann von den hier gezeigten unterscheiden.

Der folgende Code folgt derselben vierschrittigen Struktur wie das kleinskalige Beispiel. Die HVA-Grundzustandsparameter werden erneut mithilfe von MPS-Simulation optimiert. Auf der QPU aktivieren wir Dynamical Decoupling (DD), Pauli-Twirling und Twirled Readout Error Extinction (TREX) zur Fehlerunterdrückung und -minderung. Die folgende Tabelle fasst zusammen, wie sich das großskalige Experiment vom kleinskaligen unterscheidet:

| &nbsp; | Kleiner Maßstab | Großer Maßstab |
|---|---|---|
| Qubits | 10 | 50 |
| Zeitschritte | 10 | 20 |
| AQC-Checkpoints (1-schichtig + 2-schichtig) | 3 + 2 = 5 | 6 + 4 = 10 |
| Grundzustands-Ansatz-Schichten | 3 | 5 |
| Maximale MPS-Bindungsdimension | 32 | 128 |
| Estimator | `StatevectorEstimator` | QPU mit DD, Pauli-Twirling und TREX |

```python
        f"{uniform_2q_depth(aqc_circuits[k])}, "
        f"{elapsed:.1f}s"
    )

all_circuits = []
for k in range(1, aqc_n_steps_total + 1):
    all_circuits.append(aqc_circuits[k])
base = aqc_circuits[aqc_n_steps_total]
for k in range(1, n_steps - aqc_n_steps_total + 1):
    circuit = base.copy()
    for instr in trotter_evolution(
        circuit.qubits, interaction, anisotropy, time_step, k
    ):
        circuit.append(instr)
    all_circuits.append(circuit)

full_depths = [
    uniform_2q_depth(circuits[k - 1]) for k in range(1, n_steps + 1)
]
aqc_depths = [uniform_2q_depth(circuit) for circuit in all_circuits]
full_2q = [
    circuits[k - 1].decompose(["PauliEvolution"]).num_nonlocal_gates()
    for k in range(1, n_steps + 1)
]
aqc_2q = [
    circuit.decompose(["PauliEvolution"]).num_nonlocal_gates()
    for circuit in all_circuits
]
print(f"\nStep 2d — assembled {len(all_circuits)} circuits")
print(
    f"  At step {n_steps} (uniform basis): "
    f"Trotter 2q depth = {full_depths[-1]}, AQC+Trotter 2q depth = {aqc_depths[-1]}; "
    f"2q gates: Trotter = {full_2q[-1]}, AQC+Trotter = {aqc_2q[-1]}"
)

steps_axis = np.arange(1, n_steps + 1)
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(steps_axis, full_depths, "-o", color="black", label="Full Trotter")
ax.plot(
    steps_axis, aqc_depths, "-o", color="cadetblue", label="AQC + Trotter"
)
ax.set_xlabel("Trotter steps", fontsize=13)
ax.xaxis.set_major_locator(plt.matplotlib.ticker.MaxNLocator(integer=True))
ax.set_ylabel("2q gate depth (uniform basis)", fontsize=13)
ax.set_title(f"AQC circuit-depth reduction ({n_qubits} qubits)", fontsize=13)
ax.legend(fontsize=11)
plt.tight_layout()
plt.show()

# ── Step 3: Execute on IBM Quantum hardware ───────────────────────────────────
# (replaces StatevectorEstimator)
service = QiskitRuntimeService()
backend = service.least_busy(
    min_num_qubits=n_qubits,
    operational=True,
    simulator=False,
    filters=lambda x: x.configuration().processor_type["family"] == "Heron",
)
print(f"Backend: {backend.name}")

pm = generate_preset_pass_manager(optimization_level=3, backend=backend)
isa_circuits = pm.run(all_circuits, num_processes=1)
isa_2q_depths = [
    isa_circuit.depth(lambda inst: inst.operation.num_qubits == 2)
    for isa_circuit in isa_circuits
]
print(
    f"Transpiled 2q depth (deepest, ISA on {backend.name}): "
    f"{max(isa_2q_depths)} "
    f"(2q gates: {max(isa_circuit.num_nonlocal_gates() for isa_circuit in isa_circuits)})"
)

estimator = Estimator(backend)
estimator.options.environment.job_tags = ["TUT_SNS"]
estimator.options.dynamical_decoupling.enable = True
estimator.options.dynamical_decoupling.sequence_type = "XY4"
estimator.options.twirling.enable_gates = True
estimator.options.twirling.num_randomizations = 1000
estimator.options.twirling.shots_per_randomization = 128
estimator.options.resilience.measure_mitigation = True
estimator.options.resilience.measure_noise_learning.num_randomizations = 32
estimator.options.resilience.measure_noise_learning.shots_per_randomization = 100

pubs = [
    (
        isa_circuit,
        [obs.apply_layout(isa_circuit.layout) for obs in observables],
    )
    for isa_circuit in isa_circuits
]
job = estimator.run(pubs)
print(f"Job ID: {job.job_id()}")

result = job.result()

# ── Step 4: Post-process ──────────────────────────────────────────────────────
rgf_mat = np.stack([pub_result.data.evs for pub_result in result])

n_points_momentum, n_points_frequency = 100, 100
spectrum = get_dsf(
    n_qubits,
    rgf_mat,
    time_step,
    n_steps,
    n_points_momentum,
    n_points_frequency,
)

plot_rgf(
    n_qubits,
    rgf_mat,
    time_step,
    n_steps,
    title=f"Retarded Green's function — {n_qubits} qubits (QPU)",
)
plot_dsf(
    spectrum,
    time_step,
    n_points_momentum,
    n_points_frequency,
    title=rf"KCuF$_3$ DSF — {n_qubits} qubits (QPU)"
    "\n(AQC + DD + Pauli twirling + TREX)",
)
```
