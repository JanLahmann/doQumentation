# Autorisierungsrollen {#authorization-roles}

Sieh dir die verfügbaren Rollen und die diesen zugeordneten Aktionen an, um die Zuweisung von Zugriffsrechten zu erleichtern. Weitere Informationen findest du unter [IAM-Rollen und -Aktionen](https://cloud.ibm.com/docs/iam?topic=iam-iam-service-roles-actions#service-roles-table155) in IBM Cloud&reg;.

## IBM Quantum Compute Service {#ibm-quantum-compute-service}

| Permission | Required by |
| -- | -- |
| `quantum-computing.account-analytics-filters.read` | Analysefilter abrufen (`GET /v1/analytics/filters`) |
| `quantum-computing.account-analytics-usage.read` | Nutzungsanalysen abrufen (`GET /v1/analytics/usage`) |
| `quantum-computing.account-analytics-usage.read` | Gruppierte Nutzungsanalysen abrufen (`GET /v1/analytics/usage_grouped`) |
| `quantum-computing.account-analytics-usage.read` | Nach Datum gruppierte Nutzungsanalysen abrufen (`GET /v1/analytics/usage_grouped_by_date`) |
| `quantum-computing.account-configuration.read` | Kontokonfiguration abrufen (`GET /v1/accounts/{id}`) |
| `quantum-computing.device.read` | Backend-Konfiguration abrufen (`GET /v1/backends/{id}/configuration`) |
| `quantum-computing.device.read` | Standardeinstellungen des Backends abrufen (`GET /v1/backends/{id}/defaults`) |
| `quantum-computing.device.read` | Backend-Eigenschaften abrufen (`GET /v1/backends/{id}/properties`) |
| `quantum-computing.device.read` | Backend-Status abrufen (`GET /v1/backends/{id}/status`) |
| `quantum-computing.device.read` | Eigene Backends auflisten (`GET /v1/backends`) |
| `quantum-computing.instance-usage.read` | Instanznutzung abrufen (`GET /v1/instances/usage`) |
| `quantum-computing.instance.configuration.read` | Instanzkonfiguration abrufen (`GET /v1/instances/configuration`) |
| `quantum-computing.instance.read` | Aktuelle Instanzdetails abrufen (`GET /v1/instance`) |
| `quantum-computing.job.cancel` | Einen Job abbrechen (`POST /v1/jobs/{id}/cancel`) |
| `quantum-computing.job.create` | Einen Job ausführen (`POST /v1/jobs`) |
| `quantum-computing.job.delete` | Einen Job löschen (`DELETE /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Job-Metriken abrufen (`GET /v1/jobs/{id}/metrics`) |
| `quantum-computing.job.read` | Job-Details auflisten (`GET /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Job-Protokolle auflisten (`GET /v1/jobs/{id}/logs`) |
| `quantum-computing.job.read` | Job-Ergebnisse auflisten (`GET /v1/jobs/{id}/results`) |
| `quantum-computing.job.read` | Jobs auflisten (`GET /v1/jobs`) |
| `quantum-computing.job.read` | Tags auflisten (`GET /v1/tags`) |
| `quantum-computing.session.create` | Eine Session erstellen (`POST /v1/sessions`) |
| `quantum-computing.session.read` | Eine Session abrufen (`GET /v1/sessions/{id}`) |
| `quantum-computing.session.update` | Job-Session schließen (`DELETE /v1/sessions/{id}/close`) |
| `quantum-computing.session.update` | Eine Session aktualisieren (`PATCH /v1/sessions/{id}`) |
| `quantum-computing.workload.list` | Workloads der Benutzerinstanz auflisten (`GET /v1/workloads`) |

## IBM Quantum System Service {#ibm-quantum-system-service}

| Permission | Required by |
| -- | -- |
| `quantum-computing.direct-access-backend-configuration.read` | Backend-Konfiguration abrufen (`GET /v1/backends/{backend-name}/configuration`) |
| `quantum-computing.direct-access-backend-properties.read` | Backend-Eigenschaften abrufen (`GET /v1/backends/{backend-name}/properties`) |
| `quantum-computing.direct-access-backend.list` | Liste der Backends abrufen (`GET /v1/backends`) |
| `quantum-computing.direct-access-backend.read` | Backend-Details abrufen (`GET /v1/backends/{backend-name}`) |
| `quantum-computing.direct-access-job.cancel` | Einen Job abbrechen (`POST /v1/jobs/{job-id}/cancel`) |
| `quantum-computing.direct-access-job.create` | Einen Job ausführen (`POST /v1/jobs`) |
| `quantum-computing.direct-access-job.delete` | Einen Job löschen (`DELETE /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-job.list` | Jobs abrufen (`GET /v1/jobs`) |
| `quantum-computing.direct-access-job.read` | Job anhand der ID abrufen (`GET /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-lane-configuration.list` | Lane-Konfiguration des Backends abrufen (`GET /v1/backends/{backend-name}/lanes`) |
