# Qiskit Code Assistant {#qiskit-code-assistant}

<span id="qca-sunset"></span>

## 29. Mai 2026 {#29-may-2026}
- **Qiskit Code Assistant Service eingestellt** – Der Preview-Service wurde eingestellt, und die Visual Studio Code- und JupyterLab-Erweiterungen wurden archiviert.


  Basierend auf Feedback und Nutzungsmustern führen immer mehr Benutzer Qiskit Code Assistant-Modelle lokal aus und arbeiten mit Editor-Integrationen, die bereits Teil ihres Entwicklungsworkflows sind.

  Die Modelle von Qiskit Code Assistant stehen weiterhin für die lokale Nutzung zur Verfügung. Weitere Informationen findest du in der Dokumentation zu [Qiskit Code Assistant](/guides/qiskit-code-assistant).
