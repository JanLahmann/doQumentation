# IBM Quantum Compute Client v0.46.0 {#ibm-quantum-compute-client-v0460}

## April 2026 {#april-2026}

<span id="executor-primitive"></span>
- **Introducing the Executor primitive**: We're excited to announce the release of the new `Executor` primitive and a new version of the noise-learning helper class, `NoiseLearnerV3`, both of which were first previewed at QDC 2025.

  Zusammen mit [Samplomatic](https://qiskit.github.io/samplomatic/index.html) bilden sie das [Directed Execution Model](/guides/directed-execution-model), das volle Transparenz und Kontrolle bietet, um deinen Fehlerminderungs-Workflow feinabzustimmen. Das Tutorial [Probabilistic error cancellation with shaded lightcones](https://qiskit.github.io/qiskit-addon-slc/tutorials/01_getting_started.html) zeigt beispielsweise, wie dieses Modell verwendet wird, um fortgeschrittene Techniken zu kombinieren, darunter Shaded Lightcones, Probabilistic Error Cancellation (PEC), Twirled Readout Error eXtinction (TREX) und [messungsbasierte Postselektion](/guides/post-selection), um die Ergebnisqualität weiter zu verbessern.

  Wenn du eine höhere Abstraktionsebene bevorzugst, bietet [`EstimatorV2`](/guides/estimator-noise-management) in Qiskit Runtime weiterhin mehrere integrierte Techniken zur Fehlerminderung und -unterdrückung, die du einfach über die Option [`resilience_level`](/guides/estimator-noise-management#resilience-level) anpassen kannst.

  Weitere Informationen findest du in den folgenden Leitfäden:

    - [Executor-Schnellstart](/guides/get-started-with-executor)

    - [Noise-Learning-Hilfsprogramm](/guides/noise-learning)


  Beide neuen Funktionen befinden sich derzeit in der Beta-Phase und erfordern `qiskit-ibm-runtime` Version 0.47.0 oder höher.
