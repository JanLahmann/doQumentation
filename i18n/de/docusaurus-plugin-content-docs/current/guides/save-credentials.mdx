# Zugangsdaten speichern {#save-your-login-credentials}
Wenn du in einer vertrauenswürdigen Python-Umgebung arbeitest (z. B. auf deinem persönlichen Laptop oder deiner Workstation), kannst du die Methode `save_account()` verwenden, um deine Zugangsdaten lokal zu speichern und sie anschließend zur Initialisierung des Dienstes zu nutzen.

<Admonition type="note" title="Hinweise">
      * Wenn du einen öffentlichen Computer oder eine andere nicht vertrauenswürdige Umgebung verwendest, folge stattdessen den Anweisungen unter [Den Dienst in einer nicht vertrauenswürdigen Umgebung initialisieren](/guides/cloud-setup-untrusted).
      * Folge [diesen Anweisungen](/guides/cloud-setup-rest-api), wenn du dich über die REST API statt über Qiskit verbinden möchtest.
      * Falls erforderlich, verwende [diese Informationen](/guides/quickstart-steps-org#firewall), um deine Firewall so zu konfigurieren, dass der Zugriff auf die IBM Quantum API-Endpunkte möglich ist.
</Admonition>

## Vorbereitung {#before-you-begin}

1. Stelle sicher, dass du in einer aktiven Python-Umgebung mit den [installierten Paketen `qiskit` und `qiskit-ibm-runtime`](/guides/install-qiskit#local) arbeitest.

1. Aktiviere die virtuelle Python-Umgebung und führe Python darin aus.

1. Melde dich bei [IBM Quantum Platform](https://quantum.cloud.ibm.com) an.


<span id="find-credentials"></span>

## Zugangsdaten finden {#find-your-access-credentials}

1. Stelle sicher, dass das richtige Konto und die richtige Region im Konto-Umschalter im Header ausgewählt sind.

1. Finde deinen API-Schlüssel. Erstelle deinen API-Schlüssel im [Dashboard](https://quantum.cloud.ibm.com/) und kopiere ihn an einen sicheren Ort, damit du ihn zur Authentifizierung verwenden kannst. Beachte, dass du denselben API-Schlüssel für die Verbindung zu jeder Region verwenden kannst.

1. Optional: Finde die Instanz, die du verwenden möchtest, auf der Seite [Instanzen](https://quantum.cloud.ibm.com/instances). Fahre mit der Maus über deren CRN, klicke auf das Symbol zum Kopieren und speichere sie an einem sicheren Ort, damit du sie zur Identifizierung der Instanz verwenden kannst.


<span id="cloud-save"></span>

## Zugangsdaten speichern {#save-your-access-credentials}

Speichere deine Zugangsdaten, indem du den entsprechenden Code einmal pro Konto ausführst, das du speichern möchtest. Lade deine gespeicherten Zugangsdaten anschließend, indem du die Schritte unter [IBM Quantum Compute Service initialisieren](/guides/initialize-account) befolgst.

<span id="save-instance"></span>

### Zugangsdaten für eine bestimmte Instanz speichern: {#save-credentials-that-access-a-specific-instance}
Wenn du mehrere Instanzen hast und Quantum Compute einfach mitteilen möchtest, welche Instanz verwendet werden soll, speichere Zugangsdaten, die einen Instanz-CRN enthalten.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Zugangsdaten für automatische Instanzauswahl speichern: {#save-credentials-for-automatic-instance-selection}
Wenn du keinen Instanz-CRN angibst und diese Zugangsdaten an Quantum Compute übergibst, wird automatisch eine geeignete Instanz für dich ausgewählt, basierend auf den angegebenen Optionen.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Beispiel 2 {#example-2}
Dieses Beispiel speichert Zugangsdaten für die automatische Instanzauswahl. Quantum Compute berücksichtigt dabei ausschließlich Premium-Instanzen in der EU-Region, die dem Konto zur Verfügung stehen. Diese Zugangsdaten werden zum neuen Standard.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Gespeicherte Zugangsdaten anzeigen {#view-saved-credentials}

Um alle gespeicherten Zugangsdaten anzuzeigen, führe `service.saved_accounts()` aus. Wenn du Standardzugangsdaten gespeichert hast, ohne ihnen einen Namen zu geben, heißen sie `default-ibm-quantum-platform`. Wenn du deinen Standardzugangsdaten einen Namen gegeben hast, wird `"is_default_account": true` in der Ausgabe angezeigt.

## Hinweise {#considerations}

* Wenn du mehrere Konten speicherst, verwende den Parameter `name`, um sie voneinander zu unterscheiden.

* Zugangsdaten werden unter `$HOME/.qiskit/qiskit-ibm.json` gespeichert. Bearbeite diese Datei nicht manuell.

* Wenn du deine Zugangsdaten nicht speicherst, musst du sie jedes Mal neu angeben, wenn du eine neue Sitzung startest (d. h. den IBM Quantum Compute Service instanziierst).

* Wenn du deine Zugangsdaten manuell angibst, werden gespeicherte Konten nicht verwendet.
