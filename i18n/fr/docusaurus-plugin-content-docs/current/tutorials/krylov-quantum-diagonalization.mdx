## Contexte {#background}

Ce tutoriel montre comment implémenter l'algorithme de diagonalisation quantique de Krylov (KQD) dans le cadre des modèles Qiskit. Tu apprendras d'abord la théorie sous-jacente à l'algorithme, puis tu verras une démonstration de son exécution sur un QPU.

Estimer les propriétés de basse énergie des hamiltoniens à plusieurs corps est une tâche centrale en simulation quantique.
Par exemple, les énergies de l'état fondamental et les excitations de basse énergie sont directement liées à la stabilité chimique, à l'ordre magnétique, aux transitions de phase quantiques et à la réponse des matériaux.
Sur un ordinateur classique, la dimension de l'espace de Hilbert croît exponentiellement avec le nombre d'orbitales ou de spins, de sorte que la diagonalisation directe devient rapidement impraticable.

Il existe plusieurs approches d'informatique quantique à ce problème.
Les méthodes variationnelles à court terme, comme le [solveur propre variationnel quantique (VQE)](/tutorials/spin-chain-vqe), utilisent des circuits paramétrés relativement peu profonds, mais elles nécessitent une boucle d'optimisation classique non linéaire avec de nombreuses évaluations de circuits quantiques. À l'autre extrémité, l'[estimation de phase quantique (QPE)](https://arxiv.org/abs/quant-ph/0604193) fournit une voie plus directe vers l'estimation de valeurs propres avec des garanties rigoureuses, mais la QPE standard nécessite de longs circuits cohérents et convient principalement aux ordinateurs quantiques tolérants aux pannes.
KQD se situe entre ces deux approches : elle utilise l'évolution hamiltonienne en temps réel, comme dans les algorithmes basés sur l'estimation de phase, mais remplace l'estimation de phase complète par un problème de valeurs propres projeté compact qui peut être résolu classiquement.

Considère un hamiltonien à $n$ qubits $H$ et un état de référence $\lvert \psi_{0}\rangle$.
La méthode KQD construit un sous-espace de Krylov à partir d'états évolués en temps réel,

$$
\begin{equation*}
\lvert \psi_\ell\rangle = e^{-i\ell\Delta t H}\lvert \psi_{0}\rangle,
\qquad
\ell = 0,1,\ldots,r-1,
\end{equation*}
$$

où $r$ est la dimension de Krylov et $\Delta t$ est le pas de temps.
Tout état du sous-espace de Krylov est alors représenté comme une combinaison linéaire de ces états de base,

$$
\begin{equation*}
\lvert \psi(\mathbf{c})\rangle
=
\frac{\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle}
{\left\|\sum_{\ell=0}^{r-1} c_\ell \lvert \psi_\ell\rangle\right\|},
\end{equation*}
$$
where the denominator normalizes the state.

Avec une algèbre simple, on peut voir que l'énergie correspondante s'écrit comme le quotient de Rayleigh,

$$
\begin{equation*}
E(\mathbf{c})
=\langle \psi(\mathbf{c})|H|\psi(\mathbf{c}) \rangle=
\frac{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert H\vert\psi_\ell\rangle
}{
\sum_{k,\ell} c_k^* c_\ell \langle \psi_k\vert\psi_\ell\rangle
}
=
\frac{
\mathbf{c}^{\dagger}\mathcal{H}\mathbf{c}
}{
\mathbf{c}^{\dagger}\mathcal{S}\mathbf{c}
}.
\end{equation*}
$$

Ici, les matrices $\mathcal{S}$ et $\mathcal{H}$,

$$
\begin{equation*}
\mathcal{S}_{k\ell}=\langle \psi_k\vert\psi_\ell\rangle,
\qquad
\mathcal{H}_{k\ell}=\langle \psi_k\vert H\vert\psi_\ell\rangle
\end{equation*}
$$

définissent les matrices de recouvrement et hamiltonien projetées.
Leurs éléments sont estimés à l'aide de mesures de circuits quantiques.

Notre objectif est de trouver le coefficient $\mathbf{c}$ qui donne le minimum $E(\mathbf{c})$ :

$$
\begin{equation*}
\min_{\mathbf{c}\neq \mathbf{0}} E(\mathbf{c}).
\end{equation*}
$$

D'après le théorème de Rayleigh-Ritz, cette minimisation équivaut à résoudre le problème aux valeurs propres généralisé (GEVP),

$$
\begin{equation*}
\mathcal{H}\mathbf{c}=E \mathcal{S}\mathbf{c}.
\end{equation*}
$$

Note que la dimension $r$ peut être assez petite pour qu'un ordinateur classique résolve le GEVP.

Il s'agit du même principe variationnel que celui utilisé dans la diagonalisation de sous-espace classique, mais ici les états de base sont générés par évolution temporelle quantique.
Comparé à VQE, KQD nécessite généralement des circuits plus profonds car il repose sur l'évolution en temps réel.
En contrepartie, KQD évite l'optimisation de paramètres non linéaire et l'exécution itérative sur matériel quantique, et il s'améliore systématiquement à mesure que le sous-espace projeté est agrandi.
L'algorithme a été démontré à grande échelle sur du matériel quantique existant [\[2\]](#references), et ses performances peuvent être analysées avec des garanties prouvables [\[1\]](#references).

```python
from __future__ import annotations

import warnings

import numpy as np
import pandas as pd
import scipy.linalg as la
import matplotlib.pyplot as plt

from qiskit import QuantumCircuit, transpile
from qiskit.circuit import Parameter

from qiskit.transpiler.preset_passmanagers import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService, EstimatorV2, Batch
from qiskit_ibm_runtime.fake_provider import FakeMarrakesh

warnings.filterwarnings("ignore")

def make_heisenberg_hamiltonian(
    num_qubits: int,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Make a Heisenberg Hamiltonian for a 1D chain of qubits with nearest-neighbor interactions."""
    terms: list[tuple[str, complex]] = []

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    for pauli in ("XX", "YY", "ZZ"):
        for q in range(num_qubits - 1):
            append_term(q, q + 1, pauli)
    return SparsePauliOp.from_list(terms).simplify()

def _basis_state_transition_amplitude_sparse(
    hamiltonian: SparsePauliOp,
    bra_state: int,
    ket_state: int,
) -> complex:
    """Evaluate <bra_state|H|ket_state> for computational-basis states."""
    num_qubits = hamiltonian.num_qubits
    amplitude = 0.0 + 0.0j
    for pauli, coeff in zip(hamiltonian.paulis, hamiltonian.coeffs):
        new_state = ket_state
        phase = 1.0 + 0.0j
        for q in range(num_qubits):
            x = bool(pauli.x[q])
            z = bool(pauli.z[q])
            if not x and not z:
                continue
            bit = (new_state >> q) & 1
            if x and z:
                # Y|0> = i|1>, Y|1> = -i|0>
                phase *= 1j if bit == 0 else -1j
                new_state ^= 1 << q
            elif x:
                new_state ^= 1 << q
            else:
                # Z|0> = |0>, Z|1> = -|1>
                if bit:
                    phase *= -1
        if new_state == bra_state:
            amplitude += coeff * phase
    return amplitude

def basis_state_expectation_sparse(
    hamiltonian: SparsePauliOp,
    bitstring: str,
) -> complex:
    """Evaluate <bitstring|H|bitstring>."""
    state = int(bitstring, 2)
    return _basis_state_transition_amplitude_sparse(
        hamiltonian,
        bra_state=state,
        ket_state=state,
    )

def diagonalize_single_1_subspace(
    hamiltonian: SparsePauliOp,
) -> np.ndarray:
    """Diagonalize the Hamiltonian projected onto the single-excitation subspace."""
    num_qubits = hamiltonian.num_qubits

    # Integer basis states |...010...>, with the excitation at qubit k.
    basis = [1 << k for k in range(num_qubits)]

    h_single = np.empty((num_qubits, num_qubits), dtype=complex)

    for row, bra_state in enumerate(basis):
        for col, ket_state in enumerate(basis):
            h_single[row, col] = _basis_state_transition_amplitude_sparse(
                hamiltonian,
                bra_state=bra_state,
                ket_state=ket_state,
            )
    # Remove floating-point-level asymmetry.
    h_single = 0.5 * (h_single + h_single.conj().T)
    evals, _ = np.linalg.eigh(h_single)
    return np.real(evals)

def simple_transpilation(circuit: QuantumCircuit) -> QuantumCircuit:
    """Transpilation to simplify the circuit"""
    pm = PassManager(
        [
            CommutativeOptimization(),
        ]
    )
    circuit = transpile(circuit, optimization_level=3)
    circuit = pm.run(circuit)
    return circuit

def summarize_circuit(circuit: QuantumCircuit) -> dict[str, int | str]:
    """Summarize the circuit with depth, size, and 2-qubit gate information."""
    two_qubit_total = sum(
        inst.operation.num_qubits == 2 for inst in circuit.data
    )
    two_qubit_depth = circuit.depth(lambda x: x[0].num_qubits == 2)
    return {
        "depth": circuit.depth(),
        "size": circuit.size(),
        "2q gates": two_qubit_total,
        "2q depth": two_qubit_depth,
    }

def solve_thresholded_gevp(
    h_matrix: np.ndarray,
    s_matrix: np.ndarray,
    threshold: float = 1e-10,
) -> tuple[float, np.ndarray, int]:
    """Solve H c = E S c using canonical orthogonalization of S."""
    s_vals, s_vecs = la.eigh(s_matrix)

    valid = s_vals > threshold
    if not np.any(valid):
        raise ValueError(
            "All overlap eigenvalues were removed by thresholding."
        )

    keep = valid

    orthogonalizer = s_vecs[:, keep] @ np.diag(1.0 / np.sqrt(s_vals[keep]))
    h_orth = orthogonalizer.conj().T @ h_matrix @ orthogonalizer
    h_orth = 0.5 * (h_orth + h_orth.conj().T)

    eigvals, eigvecs = la.eigh(h_orth)

    coeffs = orthogonalizer @ eigvecs[:, 0]
    normalization = np.sqrt(np.real(coeffs.conj().T @ s_matrix @ coeffs))
    coeffs /= normalization

    return float(np.real(eigvals[0])), coeffs, int(np.sum(keep))
```

#### Définition des paramètres de l'algorithme {#set-the-parameters-for-the-algorithm}

Sur la base des bornes supérieures de la norme du hamiltonien, la réf. [\[1\]](#references) suggère heuristiquement le pas de temps $\Delta t$ comme $\pi/\|H\|$.
Étant donné que la norme spectrale $\|H\|$ est difficile à calculer, nous utilisons à la place sa borne supérieure :

$$
\begin{equation*}
\|H\| \le \sum_{i=0}^{n-2}\underbrace{\|X_i X_{i+1}+Y_{i} Y_{i+1}+Z_{i} Z_{i+1}\|}_{4 \times 4 \text{ matrix, easy to calculate the norm}} = 3(n-1).
\end{equation*}
$$

Nous fixons la dimension de Krylov à $r=10$ et le nombre de pas de Trotter par pas de temps à $5$ : un espace de Krylov suffisamment grand pour résoudre le spectre de basse énergie tout en gardant le circuit le plus profond ($t_{\max}=(r-1)\Delta t$) abordable, et suffisamment de pas de Trotter pour maintenir une petite erreur de discrétisation à ce circuit le plus profond.

#### Construire le circuit {#build-circuit}

Ici, nous construisons les circuits pour estimer les éléments de matrice $\mathcal{H}_{k\ell}$ et $\mathcal{S}_{k\ell}$.
Étant donné que toutes les puissances de $H$ commutent, nous avons
$$
\begin{equation*}
\mathcal{H}_{k\ell}
=
\langle\psi_{0}|H e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{H}_{0,\ell-k},
\qquad
\mathcal{S}_{k\ell}
=
\langle\psi_{0}|e^{-i(\ell-k)\Delta tH}|\psi_{0}\rangle=\mathcal{S}_{0,\ell-k}.
\end{equation*}
$$
Such matrices where the elements depend on the index differences in this manner are called *Toeplitz* and can be reconstructed from first-row elements indexed by $d=\ell-k$.

Ici, nous présentons le circuit, appelé **test de swap étendu**, qui prépare
$$
\begin{equation*}
|\Phi_{0d}\rangle=
\frac{|0\rangle|\psi_0\rangle+|1\rangle|\psi_d\rangle}{\sqrt{2}},
\end{equation*}
$$
où $|\psi_d\rangle=e^{-id\Delta tH}|\psi_{0}\rangle$.

#### Circuit de test de swap étendu [\[3\]](#references) {#extended-swap-test-circuit-3references}

Le circuit prépare d'abord l'état de référence sur le registre système tandis que l'ancilla reste à $|0\rangle$ :

$$
\begin{equation*}
|0\rangle |0\rangle^{\otimes n}
\longrightarrow
|0\rangle |\psi_{0}\rangle .
\end{equation*}
$$

Ensuite, l'application d'une porte de Hadamard à l'ancilla crée une superposition cohérente de deux branches :

$$
\begin{equation*}
|0\rangle |\psi_0\rangle
\longrightarrow
\frac{|0\rangle + |1\rangle}{\sqrt{2}} |\psi_0\rangle
=
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Enfin, la porte d'évolution temporelle contrôlée s'applique :

$$
\begin{equation*}
U(t=d\Delta t) = e^{-id\Delta t H}
\end{equation*}
$$

uniquement lorsque l'ancilla est dans la branche $|1\rangle$. Par conséquent,

$$
\begin{equation*}
\frac{|0\rangle|\psi_0\rangle + |1\rangle|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle|\psi_0\rangle + |1\rangle U(d\Delta t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Dans le prochain bloc de code, nous implémentons :
$$
\begin{equation*}
|\Psi(t)\rangle = \frac{|0\rangle|\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}},
\end{equation*}
$$
qui sera assigné comme $t=d\Delta t$ pour $d=1,\cdots r-1$ à l'étape d'exécution.

```python
ancilla = 0
system_qubits = list(range(1, num_qubits + 1))

# Append state preparation part
```

#### Observables {#observables}

Pour tout observable hermitien du système $O$, nous fixons ici les observables à calculer :

$$
\begin{equation*}
z=\langle \psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Cela s'explique par le fait que $O=I$ donne l'élément de recouvrement $\mathcal{S}_{0d}=\langle\psi_0|\psi_d\rangle$, tandis que $O=H$ donne l'élément du hamiltonien $\mathcal{H}_{0d}=\langle\psi_0|H|\psi_d\rangle$.

En utilisant $X=|0\rangle\langle 1|+|1\rangle\langle 0|$, nous avons

$$
\begin{align*}
\langle \Psi_{0d}|X\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(X\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
\langle \psi_0|O|\psi_d\rangle
+
\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{z+z^*}{2}
=
\operatorname{Re} z.
\end{align*}
$$

De même, en utilisant $Y=-i|0\rangle\langle 1|+i|1\rangle\langle 0|$,

$$
\begin{align*}
\langle \Psi_{0d}|Y\otimes O| \Psi_{0d} \rangle
&=
\left(\frac{\langle0|\langle\psi_0| + \langle1| \langle\psi_d|}{\sqrt{2}}\right)(Y\otimes O)\left(\frac{|0\rangle|\psi_0\rangle + |1\rangle |\psi_d\rangle}{\sqrt{2}}\right) \\
&=
\frac{1}{2}
\left(
-i\langle \psi_0|O|\psi_d\rangle
+
i\langle \psi_d|O|\psi_0\rangle
\right) \\
&=
\frac{-iz+iz^*}{2}
=
\operatorname{Im} z.
\end{align*}
$$

Par conséquent, nous avons
$$
\begin{equation*}
\langle \Phi_{0d}|X\otimes O|\Phi_{0d}\rangle
=
\operatorname{Re}\langle\psi_0|O|\psi_d\rangle ,
\quad
\langle \Phi_{0d}|Y\otimes O|\Phi_{0d}\rangle
=
\operatorname{Im}\langle\psi_0|O|\psi_d\rangle .
\end{equation*}
$$

Enfin, pour chaque état $|\Psi_{0d}\rangle$, nous devons mesurer :
$$
\begin{align*}
X \otimes I \text{ for } \operatorname{Re}\mathcal{S}_{0d},\\
Y \otimes I \text{ for } \operatorname{Im}\mathcal{S}_{0d},\\
X \otimes H \text{ for } \operatorname{Re}\mathcal{H}_{0d},\\
Y \otimes H \text{ for } \operatorname{Im}\mathcal{H}_{0d}.\\
\end{align*}
$$

Pour l'estimation des éléments de matrice $\mathcal{H}$, le nombre de termes de Pauli est bien plus grand que celui des éléments de matrice $\mathcal{S}$.

Nous pouvons maintenant réduire le nombre de termes du hamiltonien mesurés en utilisant une technique de décalage [\[4\]](#references).
Nous décomposons le hamiltonien comme :

$$
\begin{equation*}
H = (H-T) + T,
\end{equation*}
$$

où $T$ est choisi de sorte que l'état de référence en soit l'état propre,

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle .
\end{equation*}
$$

Then,

$$
\begin{align*}
\mathcal{H}_{0d}
&=
\langle\psi_0|H|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\langle\psi_0|T|\psi_d\rangle \\
&=
\langle\psi_0|(H-T)|\psi_d\rangle
+
\tau \langle\psi_0|\psi_d\rangle \\
&=
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}.
\end{align*}
$$

Here,

$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
=
\langle\psi_0|(H-T)|\psi_d\rangle
\end{equation*}
$$

est l'élément de matrice du hamiltonien décalé.
Par conséquent, nous n'avons besoin de mesurer que $X\otimes (H-T)$ et $Y\otimes (H-T)$.
La contribution de $T$ est reconstruite classiquement à l'aide de l'élément de matrice de recouvrement déjà mesuré $\mathcal{S}_{0d}$.

Dans cet exemple, un choix naturel est la partie diagonale du hamiltonien de Heisenberg,

$$
\begin{equation*}
T
=
\sum_{i=0}^{n-2} Z_iZ_{i+1}.
\end{equation*}
$$

Étant donné que l'état de référence est un état de la base computationnelle, il s'agit d'un état propre de chaque terme $Z_iZ_{i+1}$.

Cependant, un choix plus avantageux consiste à inclure non seulement les termes diagonaux $ZZ$, mais aussi les termes $XX+YY$ qui annihilent l'état de référence.

Pour chaque paire voisine, l'opérateur $XX+YY$ satisfait

$$
\begin{equation*}
(XX+YY)|00\rangle = 0,
\qquad
(XX+YY)|11\rangle = 0,
\end{equation*}
$$

and

$$
\begin{equation*}
(XX+YY)|01\rangle = 2|10\rangle,
\qquad
(XX+YY)|10\rangle = 2|01\rangle .
\end{equation*}
$$

Par conséquent, le terme $XX+YY$ ne contribue que lorsque les deux qubits voisins ont des occupations différentes dans le bitstring de référence.
Si les deux qubits sont tous deux $0$ ou tous deux $1$, le terme annihile l'état de référence et peut également être décalé.

Soit $|\psi_{\rm ref}\rangle = |z_0\cdots z_{n-1}\rangle$, où $z_i \in \{0,1\}$.
Ainsi, nous pouvons choisir
$$
\begin{equation*}
T=\sum_{i=0}^{n-2} Z_iZ_{i+1}
+
\sum_{z_i={z_{i+1}}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

Cet opérateur satisfait toujours

$$
\begin{equation*}
T|\psi_0\rangle = \tau |\psi_0\rangle ,
\end{equation*}
$$

car les termes $ZZ$ agissent diagonalement sur $|\psi_0\rangle$, tandis que les termes décalés $XX+YY$ donnent zéro.
La valeur propre correspondante est donc déterminée uniquement par les termes $ZZ$,
$$
\begin{equation*}
\tau = \sum_{i=0}^{n-2}
(-1)^{z_i}
(-1)^{z_{i+1}} .
\end{equation*}
$$

Avec ce choix, le hamiltonien décalé devient :
$$
\begin{equation*}
H-T = \sum_{z_i\ne z_{i+1}}
\left(
X_iX_{i+1}
+
Y_iY_{i+1}
\right).
\end{equation*}
$$

En conséquence, seules les arêtes ayant des occupations différentes dans l'état de référence doivent être mesurées.
Tous les termes $ZZ$ et tous les termes $XX+YY$ inactifs sont reconstruits par le biais de la contribution de recouvrement $\tau \mathcal{S}_{0d}$, ou donnent une contribution nulle par construction.

Cela donne un observable plus petit que le décalage de la seule partie diagonale.
En particulier, pour un état de référence de la base computationnelle avec une excitation localisée, seules les arêtes adjacentes à l'excitation restent dans $H-T$.
Par conséquent, le nombre de termes de Pauli dans $X\otimes(H-T)$ et $Y\otimes(H-T)$ peut être considérablement réduit, tandis que l'élément de matrice reconstruit
$$
\begin{equation*}
\widetilde{\mathcal{H}}_{0d}
+
\tau \mathcal{S}_{0d}
\end{equation*}
$$

reste exactement le même.

```python
def make_reduced_heisenberg_observables(
    ref_bitstring: str,
    coupling: float = 1.0,
) -> tuple[SparsePauliOp, SparsePauliOp, float]:
    """Build X⊗(H-T), Y⊗(H-T), and tau."""
    n_qubits = len(ref_bitstring)

    shifted_terms: list[tuple[str, complex]] = []
    tau = 0.0

    def bit(q: int) -> str:
        return ref_bitstring[n_qubits - 1 - q]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * n_qubits
        label[n_qubits - 1 - q0] = pauli[0]
        label[n_qubits - 1 - q1] = pauli[1]
        shifted_terms.append(("".join(label), coupling))

    for q in range(n_qubits - 1):
        same_occupation = bit(q) == bit(q + 1)

        # ZZ contribution to tau
        tau += coupling * (1.0 if same_occupation else -1.0)

        # XX + YY survives only for opposite occupations.
        if not same_occupation:
            append_term(q, q + 1, "XX")
            append_term(q, q + 1, "YY")

    if shifted_terms:
        obs_x_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "X", coeff) for label, coeff in shifted_terms]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp.from_list(
            [(label + "Y", coeff) for label, coeff in shifted_terms]
        )
    else:
        obs_x_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "X", coeffs=[0.0]
        )
        obs_y_shifted_hamiltonian = SparsePauliOp(
            "I" * n_qubits + "Y", coeffs=[0.0]
        )

    return obs_x_shifted_hamiltonian, obs_y_shifted_hamiltonian, tau
```

### Étape 2 : Optimiser le problème pour l'exécution sur du matériel quantique {#step-2-optimize-problem-for-quantum-hardware-execution}

Nous transformons maintenant le circuit abstrait de test de swap étendu en un modèle orienté matériel.
Avant cela, nous optimisons d'abord davantage le circuit au niveau abstrait.

#### Comparer l'ordre des termes du hamiltonien {#compare-hamiltonian-term-ordering}

Tout d'abord, nous comparons différents ordres des termes de Pauli dans le hamiltonien de Heisenberg pour la simulation du hamiltonien.
Le hamiltonien lui-même reste inchangé, mais l'ordre affecte la façon dont le circuit à formule de produit est généré et la mesure dans laquelle la structure peut être parallélisée dans le circuit.
Par exemple, l'ordre naïf liste tous les termes $XX$ de plus proches voisins, puis tous les termes $YY$, puis tous les termes $ZZ$.
Cela place des arêtes adjacentes telles que $(0,1)$ et $(1,2)$ l'une à côté de l'autre, de sorte qu'elles ne peuvent pas être exécutées en parallèle.
L'ordre pair-puis-impair visite d'abord les arêtes paires disjointes, suivies des arêtes impaires, ce qui expose des couches à deux qubits parallèles.
L'ordre pair-impair groupé par arête va encore plus loin : pour chaque arête, il conserve ensemble les termes locaux $XX$, $YY$ et $ZZ$, tout en visitant toujours les arêtes paires avant les arêtes impaires.
Nous nous attendons à ce que les ordres pair-puis-impair et pair-impair groupé par arête réduisent la profondeur du circuit en exposant des couches à deux qubits parallèles, et à ce que l'ordre groupé par arête réduise en outre l'erreur de Trotter car l'interaction locale à deux qubits sur la même arête est traitée comme un bloc compact.

![Pauli evolutions with different term ordering](/docs/images/tutorials/krylov-quantum-diagonalization/ham_ordering.avif)

L'ordre du hamiltonien affecte également l'erreur de Trotter.
Si nous plaçons des termes non commutants l'un à côté de l'autre, les transitions de base se produisent plus souvent, ce qui induit davantage d'erreur de Trotter.
En regroupant les termes qui nécessitent la même transformation de base de Pauli, on peut éviter des changements de base redondants.

Ici, la comparaison utilise le temps d'évolution le plus grand qui apparaît dans les estimations de Krylov de première ligne,
$t_{\max} = (r-1)\Delta t,$
en utilisant la même condition de transpilation.

Afin de mesurer l'erreur de Trotter, nous utilisons l'**infidélité de processus** entre le circuit trotterisé et l'évolution exacte du hamiltonien,
$$
\begin{equation*}
\text{Infidelity}(U,V)
=
1-F(U,V)
=
1 - \frac{|\operatorname{Tr}(U^\dagger V)|^2}{d^2},
\end{equation*}
$$
where $d=2^n$ is the dimension of the Hilbert space.

Ce diagnostic utilise des matrices denses, il convient donc à ce petit exemple à 12 qubits mais n'est pas destiné à être une sous-routine évolutive.

```python
# The comparison uses the largest time that appears in the first-row Krylov estimates.
# Circuit depth does not depend on this numeric value, but the Trotter error does.
comparison_time = (krylov_dim - 1) * dt

def make_heisenberg_hamiltonian_ordered(
    num_qubits: int,
    ordering: str,
    coupling: float = 1.0,
) -> SparsePauliOp:
    """Return the same Heisenberg Hamiltonian with a specified term ordering."""
    terms: list[tuple[str, complex]] = []
    even_edges = [(q, q + 1) for q in range(0, num_qubits - 1, 2)]
    odd_edges = [(q, q + 1) for q in range(1, num_qubits - 1, 2)]

    def append_term(q0: int, q1: int, pauli: str):
        label = ["I"] * num_qubits
        label[num_qubits - 1 - q0] = pauli[0]
        label[num_qubits - 1 - q1] = pauli[1]
        terms.append(("".join(label), coupling))

    if ordering == "naive":
        for pauli in ("XX", "YY", "ZZ"):
            for q in range(num_qubits - 1):
                append_term(q, q + 1, pauli)
    elif ordering == "even-then-odd":
        for pauli in ("XX", "YY", "ZZ"):
            for q0, q1 in even_edges + odd_edges:
                append_term(q0, q1, pauli)
    elif ordering == "even-odd edge-grouped":
        for q0, q1 in even_edges + odd_edges:
            for pauli in ("XX", "YY", "ZZ"):
                append_term(q0, q1, pauli)
    else:
        raise ValueError(f"Unknown ordering: {ordering}")

    return SparsePauliOp.from_list(terms).simplify()

def build_numeric_evolution_circuit(
    hamiltonian: SparsePauliOp,
    synthesis,
    time_value: float,
    **synthesis_kwargs,
) -> QuantumCircuit:
    """Build a numeric circuit for exp(-i H t) with a chosen synthesis rule."""
    evolution_gate = PauliEvolutionGate(
        hamiltonian,
        time=time_value,
        synthesis=synthesis(**synthesis_kwargs),
    )
    circuit = QuantumCircuit(hamiltonian.num_qubits)
    circuit.append(evolution_gate, range(hamiltonian.num_qubits))
    return circuit

def process_infidelity(
    circuit: QuantumCircuit,
    exact_matrix: np.ndarray,
) -> float:
    """Return 1 - |Tr(U_circuit† U_exact) / d|²."""
    circuit_matrix = np.asarray(Operator(circuit).data)
    dim = circuit_matrix.shape[0]
    normalized_trace = np.vdot(circuit_matrix, exact_matrix) / dim
    fidelity = np.abs(normalized_trace) ** 2
    return float(np.clip(1.0 - fidelity, 0.0, 1.0))

hamiltonians_by_ordering = {
    ordering: make_heisenberg_hamiltonian_ordered(
        num_qubits, ordering, coupling=1.0
    )
    for ordering in ["naive", "even-then-odd", "even-odd edge-grouped"]
}

print(f"Comparison time: {comparison_time}\n")

for order_name, ham_ordered in hamiltonians_by_ordering.items():
    print(f"{order_name}:")
    print([op for op, _ in ham_ordered.to_list()])
    print()

print("Precomputing the exact evolution operator... ", end="")
exact_matrix = la.expm(-1j * comparison_time * hamiltonian.to_matrix())
print("Done")
```

#### Supprimer la porte d'évolution temporelle contrôlée {#remove-the-controlled-time-evolution-gate}

Dans le test de swap étendu, contrôler l'évolution temporelle avec un seul qubit ancilla exige que l'ancilla contrôle de nombreuses portes à travers le système.
Cela peut introduire une surcharge de routage substantielle et, dans le pire des cas, nécessite effectivement une connectivité de tous vers un.
Pour éviter cela, une optimisation supplémentaire est possible en remplaçant la porte d'évolution temporelle contrôlée par une version sans contrôle, en exploitant la symétrie du hamiltonien.
Observons le circuit suivant.

![circuit optimization](/docs/images/tutorials/krylov-quantum-diagonalization/circuit_opt.avif)

Ici, $B_{\rm ref}$ prépare l'état de référence, $B_{\rm ref}|0^n\rangle = |\psi_{0}\rangle$.

Au lieu de préparer d'abord $\frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)|\psi_0\rangle$ puis d'appliquer $U(t)$ uniquement sur la branche $|1\rangle$, le circuit prépare directement les deux branches comme

$$
\begin{equation*}
|0\rangle|\psi_0\rangle
\quad \text{and} \quad
|1\rangle|\psi_d\rangle ,
\end{equation*}
$$

where

$$
\begin{equation*}
|\psi_d\rangle = U(d\Delta t)|\psi_0\rangle .
\end{equation*}
$$

Le circuit applique d'abord une porte de Hadamard à l'ancilla et prépare l'état de référence uniquement sur la branche $|1\rangle$ :

$$
\begin{equation*}
|0\rangle |0^n\rangle
\longrightarrow
\frac{|0\rangle |0^n\rangle + |1\rangle B_{\rm ref}|0^n\rangle}{\sqrt{2}}
=
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Ensuite, l'opérateur d'évolution temporelle non contrôlé est appliqué aux deux branches :

$$
\begin{equation*}
\frac{|0\rangle |0^n\rangle + |1\rangle |\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Étant donné que le hamiltonien préserve le nombre d'excitations, nous pouvons voir que $|0^n\rangle$ en est l'état propre, et donc
l'opérateur d'évolution n'accumule qu'une phase sous le hamiltonien :
$$
\begin{equation*}
U(t)|0^n\rangle
=
e^{-iE_{\rm vac}t}|0^n\rangle .
\end{equation*}
$$

Therefore,

$$
\begin{equation*}
\frac{|0\rangle U(t)|0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
=
\frac{e^{-iE_{\rm vac}t}|0\rangle |0^n\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Ensuite, $B_{\rm ref}$ est appliqué uniquement sur la branche $|0\rangle$.

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

À ce stade, les deux branches ont une phase relative supplémentaire. Pour la supprimer, nous appliquons la porte de phase de l'ancilla

$$
\begin{equation*}
P(-E_{\rm vac}t)
=
\begin{pmatrix}
1 & 0 \\
0 & e^{-iE_{\rm vac}t}
\end{pmatrix}.
\end{equation*}
$$

Cela transforme l'état comme

$$
\begin{equation*}
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle + |1\rangle U(t)|\psi_0\rangle}{\sqrt{2}}
\longrightarrow
\frac{e^{-iE_{\rm vac}t}|0\rangle |\psi_0\rangle
+
e^{-iE_{\rm vac}t}|1\rangle U(t)|\psi_0\rangle}{\sqrt{2}} .
\end{equation*}
$$

Ainsi, à une phase globale non pertinente près, nous avons finalement préparé

$$
\begin{equation*}
|\Phi_{0d}\rangle
=
\frac{
|0\rangle|\psi_0\rangle
+
|1\rangle U(t)|\psi_0\rangle
}{\sqrt{2}} .
\end{equation*}
$$

Dans le prochain bloc de code, nous implémentons ce circuit sans contrôle.


### Étape 3 : Exécuter à l'aide des primitives Qiskit {#step-3-execute-using-qiskit-primitives}

L'étape suivante consiste à soumettre le même circuit paramétré pour plusieurs valeurs de $d$. Pour chaque $d$, nous estimons quatre valeurs d'espérance : $X\otimes I$, $Y\otimes I$, $X\otimes (H-T)$ et $Y\otimes (H-T)$. Ces quatre nombres sont ensuite combinés en les éléments complexes de première ligne $\mathcal{S}_{0d}$ et $\mathcal{H}_{0d}$.

### Étape 4 : Post-traitement et renvoi du résultat dans le format classique souhaité {#step-4-post-process-and-return-result-in-desired-classical-format}
Après avoir estimé les matrices projetées, nous régularisons et résolvons le GEVP
$$
\begin{equation*}
\mathcal{H}\mathbf{c} = E\mathcal{S}\mathbf{c}.
\end{equation*}
$$
La plus petite valeur propre généralisée donne l'estimation KQD de l'énergie de l'état fondamental.


## Annexe : le point de vue de la fonction-hamiltonienne (filtre spectral) {#appendix-the-hamiltonian-function-spectral-filter-viewpoint}

Le flux de travail principal a présenté KQD de manière opérationnelle : construire une base de Krylov à partir d'états évolués en temps réel, estimer les matrices projetées $\mathcal{H}$ et $\mathcal{S}$, et résoudre le GEVP.
Cette annexe revisite le *même* calcul sous un angle complémentaire qui explique **pourquoi** KQD fonctionne : le point de vue de la *fonction-hamiltonienne*, ou du *filtre spectral* [\[3\]](#references), [\[5\]](#references).
Elle réutilise le modèle à 12 qubits, le pas de temps $\Delta t$, et la solution de Krylov déjà obtenue ci-dessus ; aucune nouvelle exécution de circuit n'est requise.

### L'état de référence comme distribution d'énergie {#the-reference-state-as-an-energy-distribution}

Soit le hamiltonien ayant la décomposition en valeurs propres

$$
\begin{equation*}
H=\sum_{m} E_m\,|E_m\rangle\!\langle E_m|,
\qquad E_0\le E_1\le\cdots,
\end{equation*}
$$

avec des états propres d'énergie $|E_m\rangle$.
Tout état de référence peut être développé dans cette base propre,

$$
\begin{equation*}
|\psi_{0}\rangle=\sum_m a_m\,|E_m\rangle,
\qquad a_m=\langle E_m|\psi_{0}\rangle,
\end{equation*}
$$

il porte donc un **poids spectral** $p_m=|a_m|^2$ à chaque énergie $E_m$.
L'énergie de référence est la moyenne de cette distribution, $\langle H\rangle_{0}=\sum_m p_m E_m$.

La décomposition en valeurs propres d'un hamiltonien général à $n$ qubits est exponentiellement coûteuse, donc cette image n'est qu'un diagnostic, qui ne fait *pas* partie de l'algorithme.
Ici, cependant, nous pouvons la calculer à moindre coût pour le *même* problème $n=12$ : le hamiltonien de Heisenberg conserve le nombre total d'excitations, et la référence $|000001000000\rangle$ porte une seule excitation, de sorte que tout son contenu spectral se trouve dans le sous-espace à excitation unique dont la dimension croît uniquement de manière linéaire avec $n$.
Nous réutilisons donc le bloc exact à excitation unique (déjà utilisé ci-dessus comme référence) et lisons la distribution de référence $\{(E_m, p_m)\}$ dans ce sous-espace.

```python
# Exact single-excitation-subspace decomposition of the reference state.

# and the n=12 `hamiltonian` and `ref_bitstring` defined in the small-scale example.

    [

            _basis_state_transition_amplitude_sparse(hamiltonian, bra, ket)
            for ket in single_excitation_states

        for bra in single_excitation_states
```

### KQD apprend un filtre qui remodèle cette distribution {#kqd-learns-a-filter-that-reshapes-this-distribution}

Une **fonction-hamiltonienne** $f(H)$ est définie par le calcul spectral,

$$
\begin{equation*}
f(H)=\sum_m f(E_m)\,|E_m\rangle\!\langle E_m|,
\end{equation*}
$$

ou, en d'autres termes, une somme pondérée de projecteurs propres.
Son application à la référence remodèle chaque amplitude spectrale, $a_m \to a_m f(E_m)$ :

$$
\begin{equation*}
f(H)\,|\psi_{0}\rangle=\sum_m a_m\,f(E_m)\,|E_m\rangle .
\end{equation*}
$$

Si $f$ était fortement piqué à l'énergie la plus basse ($f(E_0)=1$ et $f(E_m)\approx 0$ sinon), alors $f(H)$ agirait comme un projecteur d'état fondamental, et la sortie normalisée serait (proche de) l'état fondamental.
Par conséquent, un bon **filtre spectral** passe-bas en énergie est exactement ce que nous voulons.

KQD ne prescrit pas $f$ à l'avance. Il développe plutôt le filtre dans la base d'évolution en temps réel,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E},
\end{equation*}
$$

une fonction *trigonométrique* de l'énergie dont les coefficients $\{c_\ell\}$ sont précisément le vecteur propre du GEVP résolu ci-dessus.
Minimiser le quotient de Rayleigh $\mathbf{c}^\dagger\mathcal{H}\mathbf{c}/\mathbf{c}^\dagger\mathcal{S}\mathbf{c}$ revient donc à *apprendre* le filtre qui supprime le mieux le poids des états excités de la référence.
Une dimension de Krylov $r$ plus grande donne au filtre plus de degrés de liberté et un pic plus net à l'énergie de l'état fondamental.

La fonction d'aide ci-dessous évalue ce filtre appris sur un axe d'énergie ; nous l'appliquons ensuite à la distribution de référence obtenue ci-dessus.

```python
def trigonometric_krylov_filter(
    coeffs: np.ndarray,
    energies: np.ndarray,
    time_step: float,
) -> np.ndarray:
    """Evaluate the learned Krylov filter f(E) = sum_l c_l exp(-i l dt E)."""
    values = np.zeros_like(energies, dtype=complex)
    for ell, coeff in enumerate(coeffs):
        values += coeff * np.exp(-1j * ell * time_step * energies)
    return values

def filtered_spectral_weights(
    weights: np.ndarray,
    filter_values: np.ndarray,
) -> np.ndarray:
    """Reshape spectral weights by |f(E)|^2 and renormalize."""
    reshaped = weights * np.abs(filter_values) ** 2
    return reshaped / np.sum(reshaped)

# Recover the KQD coefficients from the already-estimated projected matrices.
# The shift only moves H by tau * S, so it does not change the GEVP eigenvector;
# we solve at the full Krylov dimension used in the small-scale example.
_, kqd_coeffs, _ = solve_thresholded_gevp(
    h_matrix_est,
    s_matrix_est,
    threshold=1e-12,
)

filter_on_spectrum = trigonometric_krylov_filter(
    kqd_coeffs, subspace_evals, dt
)
filtered_weights = filtered_spectral_weights(
    ref_spectral_weights, filter_on_spectrum
)

print(f"Ground-state overlap  (reference): {ref_spectral_weights[0]:.4f}")
print(f"Ground-state overlap  (filtered):  {filtered_weights[0]:.4f}")
print(
    f"Mean energy           (reference): {np.sum(ref_spectral_weights * subspace_evals):.6f}"
)
print(
    f"Mean energy           (filtered):  {np.sum(filtered_weights * subspace_evals):.6f}"
)
```

### Augmenter la dimension de Krylov : flexibilité de la fonction apprise {#increasing-the-krylov-dimension-flexibility-of-the-learned-function}

Rappelons que le filtre appris est un polynôme trigonométrique en énergie avec $r$ coefficients,

$$
\begin{equation*}
f_{\rm KQD}(E)=\sum_{\ell=0}^{r-1} c_\ell\, e^{-i\ell\Delta t E}.
\end{equation*}
$$

La dimension de Krylov $r$ est exactement le nombre de coefficients libres, elle contrôle donc la **flexibilité** de la fonction.
Un petit $r$ ne peut produire qu'un filtre large et variant doucement qui laisse fuir du poids vers les états excités de basse énergie ; lorsque $r$ augmente, le filtre peut former un pic plus étroit à l'énergie cible et supprimer plus agressivement le poids restant des états excités.
C'est le pendant en filtre spectral de la convergence d'énergie observée dans l'exemple à petite échelle : à mesure que $r$ augmente, la distribution filtrée s'effondre vers l'état fondamental du sous-espace et l'énergie estimée diminue vers celui-ci.

Nous réutilisons les matrices projetées déjà estimées ci-dessus et résolvons simplement le GEVP à chaque bloc principal $r\times r$, puis évaluons et traçons le filtre correspondant.

```python
# Sweep the Krylov dimension using the leading r x r blocks of the estimated matrices.
sweep_dims = [r for r in (2, 4, 6, 8, krylov_dim) if r <= krylov_dim]
sweep_dims = sorted(set(sweep_dims))

energy_grid = np.linspace(
    subspace_evals.min() - 0.5, subspace_evals.max() + 0.5, 800
)

sweep_cases = []
print(" r    retained    ground overlap    filtered energy")
print("--    --------    --------------    ---------------")
for r in sweep_dims:
    _, coeffs_r, retained_r = solve_thresholded_gevp(
        h_matrix_est[:r, :r],
        s_matrix_est[:r, :r],
        threshold=1e-12,
    )
    filter_on_spectrum_r = trigonometric_krylov_filter(
        coeffs_r, subspace_evals, dt
    )
    filtered_weights_r = filtered_spectral_weights(
        ref_spectral_weights, filter_on_spectrum_r
    )
    filtered_energy_r = float(np.sum(filtered_weights_r * subspace_evals))

    sweep_cases.append((r, coeffs_r, filtered_weights_r))
    print(
        f"{r:2d}    {retained_r:8d}    {filtered_weights_r[0]:14.4f}    {filtered_energy_r:15.6f}"
    )

print(f"\nSubspace ground-state energy (target): {subspace_evals[0]:.6f}")

# One panel per Krylov dimension: filtered spectrum (bars) + filter intensity (curve).
fig, axes = plt.subplots(
    len(sweep_cases),
    1,
    figsize=(8, 2.1 * len(sweep_cases)),
    sharex=True,
)
axes = np.atleast_1d(axes)

for idx, (ax, (r, coeffs_r, filtered_weights_r)) in enumerate(
    zip(axes, sweep_cases)
):
    visible = (ref_spectral_weights > 1e-4) | (filtered_weights_r > 1e-4)
    ax.bar(
        subspace_evals[visible],
        ref_spectral_weights[visible],
        width=0.18,
        alpha=0.35,
        color="C0",
        label="reference $p_m$" if idx == 0 else None,
    )
    ax.bar(
        subspace_evals[visible],
        filtered_weights_r[visible],
        width=0.14,
        alpha=0.9,
        color="C1",
        label="filtered weights" if idx == 0 else None,
    )

    filter_intensity_r = (
        np.abs(trigonometric_krylov_filter(coeffs_r, energy_grid, dt)) ** 2
    )
    filter_intensity_r /= filter_intensity_r.max()
    ax.plot(energy_grid, filter_intensity_r, color="k", linewidth=2)

    ax.axvline(subspace_evals[0], color="C3", linestyle="--", linewidth=1)
    ax.set_ylim(0, 1)
    ax.set_ylabel("weight")
    ax.legend(loc="upper right", title=f"$r={r}$")

axes[-1].set_xlabel("Energy eigenvalue $E_m$")
fig.suptitle(
    r"KQD-learned filter $|f_{\rm KQD}(E)|^2$ sharpening with Krylov dimension $r$",
    y=1.0,
)
fig.tight_layout()
plt.show()
```
