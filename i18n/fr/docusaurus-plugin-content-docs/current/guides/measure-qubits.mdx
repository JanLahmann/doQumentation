To get information about a qubit's state, you can _measure_ it onto a [classical bit](https://docs.quantum.ibm.com/api/qiskit/circuit#qiskit.circuit.Clbit). In Qiskit, measurements are performed in the computational basis, that is, the single-qubit Pauli-$Z$ basis. Therefore, a measurement yields 0 or 1, depending on the overlap with the Pauli-$Z$ eigenstates $|0\rangle$ and $|1\rangle$:

$$
|q\rangle \xrightarrow{measure}\begin{cases}
      0 (\text{outcome}+1), \text{with probability } p_0=|\langle q|0\rangle|^{2}\text{,} \\
      1 (\text{outcome}-1), \text{with probability } p_1=|\langle q|1\rangle|^{2}\text{.}
    \end{cases}
$$

## Appliquer une mesure à un circuit {#apply-a-measurement-to-a-circuit}

Il existe plusieurs façons d'appliquer des mesures à un circuit :

### Méthode `QuantumCircuit.measure` {#quantumcircuitmeasure-method}

Utilise la méthode [`measure`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#measure) pour mesurer un [`QuantumCircuit`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#quantumcircuit-class).

Exemples :


```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(5, 5)
qc.x(0)
qc.x(1)
qc.x(4)
qc.measure(
    range(5), range(5)
)  #  Measures all qubits into the corresponding clbit.
```

### Classe `Measure` {#measure-class}

La classe Qiskit [Measure](https://docs.quantum.ibm.com/api/qiskit/circuit#qiskit.circuit.Measure) mesure les qubits spécifiés.

```python
from qiskit.circuit import Measure

qc = QuantumCircuit(3, 1)
qc.x([0, 1])
qc.append(Measure(), [0], [0])  # measure qubit 0 into clbit 0
```

### Méthode `QuantumCircuit.measure_all` {#quantumcircuitmeasure-all-method}

Pour mesurer tous les qubits dans les bits classiques correspondants, utilise la méthode [`measure_all`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#measure_all). Par défaut, cette méthode ajoute de nouveaux bits classiques dans un `ClassicalRegister` pour stocker ces mesures.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3, 1)
qc.x([0, 2])
qc.measure_all()  # Measure all qubits.
```

### Méthode `QuantumCircuit.measure_active` {#quantumcircuitmeasure-active-method}

Pour mesurer tous les qubits qui ne sont pas inactifs, utilise la méthode [`measure_active`](https://docs.quantum.ibm.com/api/qiskit/qiskit.circuit.QuantumCircuit#measure_active). Cette méthode crée un nouveau `ClassicalRegister` dont la taille est égale au nombre de qubits non inactifs mesurés.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3, 1)
qc.x([0, 2])
qc.measure_active()  # Measure qubits that are not idle, that is, qubits 0 and 2.
```
