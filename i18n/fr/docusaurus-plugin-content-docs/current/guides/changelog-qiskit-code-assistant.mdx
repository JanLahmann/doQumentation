# Qiskit Code Assistant {#qiskit-code-assistant}

<span id="qca-sunset"></span>

## 29 mai 2026 {#29-may-2026}
- **Service Qiskit Code Assistant abandonné** - Le service en aperçu a été abandonné et les extensions Visual Studio Code et JupyterLab ont été archivées.


  D'après les retours et les habitudes d'utilisation, de plus en plus d'utilisateurs exécutent les modèles Qiskit Code Assistant localement et travaillent avec des intégrations d'éditeur qui font déjà partie de leur workflow de développement.

  Les modèles Qiskit Code Assistant restent disponibles pour une utilisation locale. Consulte la documentation [Qiskit Code Assistant](/guides/qiskit-code-assistant) pour plus d'informations.

## Mises à jour précédentes {#previous-updates}
