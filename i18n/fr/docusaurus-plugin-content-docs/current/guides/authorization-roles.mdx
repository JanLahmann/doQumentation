# Rôles d'autorisation {#authorization-roles}

Consulte les rôles disponibles et les actions associées à chacun pour t'aider à attribuer les accès. Voir [Rôles et actions IAM](https://cloud.ibm.com/docs/iam?topic=iam-iam-service-roles-actions#service-roles-table155) sur IBM Cloud&reg; pour plus d'informations.

## IBM Quantum Compute Service {#ibm-quantum-compute-service}

| Autorisation | Requise par |
| -- | -- |
| `quantum-computing.account-analytics-filters.read` | Obtenir les filtres d'analytique (`GET /v1/analytics/filters`) |
| `quantum-computing.account-analytics-usage.read` | Obtenir l'analytique d'utilisation (`GET /v1/analytics/usage`) |
| `quantum-computing.account-analytics-usage.read` | Obtenir l'analytique d'utilisation groupée (`GET /v1/analytics/usage_grouped`) |
| `quantum-computing.account-analytics-usage.read` | Obtenir l'analytique d'utilisation groupée par date (`GET /v1/analytics/usage_grouped_by_date`) |
| `quantum-computing.account-configuration.read` | Obtenir la configuration du compte (`GET /v1/accounts/{id}`) |
| `quantum-computing.device.read` | Obtenir la configuration du backend (`GET /v1/backends/{id}/configuration`) |
| `quantum-computing.device.read` | Obtenir les paramètres par défaut du backend (`GET /v1/backends/{id}/defaults`) |
| `quantum-computing.device.read` | Obtenir les propriétés du backend (`GET /v1/backends/{id}/properties`) |
| `quantum-computing.device.read` | Obtenir le statut du backend (`GET /v1/backends/{id}/status`) |
| `quantum-computing.device.read` | Répertorier tes backends (`GET /v1/backends`) |
| `quantum-computing.instance-usage.read` | Obtenir l'utilisation de l'instance (`GET /v1/instances/usage`) |
| `quantum-computing.instance.configuration.read` | Obtenir la configuration de l'instance (`GET /v1/instances/configuration`) |
| `quantum-computing.instance.read` | Obtenir les détails de l'instance actuelle (`GET /v1/instance`) |
| `quantum-computing.job.cancel` | Annuler un job (`POST /v1/jobs/{id}/cancel`) |
| `quantum-computing.job.create` | Exécuter un job (`POST /v1/jobs`) |
| `quantum-computing.job.delete` | Supprimer un job (`DELETE /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Obtenir les métriques du job (`GET /v1/jobs/{id}/metrics`) |
| `quantum-computing.job.read` | Répertorier les détails du job (`GET /v1/jobs/{id}`) |
| `quantum-computing.job.read` | Répertorier les journaux du job (`GET /v1/jobs/{id}/logs`) |
| `quantum-computing.job.read` | Répertorier les résultats du job (`GET /v1/jobs/{id}/results`) |
| `quantum-computing.job.read` | Répertorier les jobs (`GET /v1/jobs`) |
| `quantum-computing.job.read` | Répertorier les tags (`GET /v1/tags`) |
| `quantum-computing.session.create` | Créer une session (`POST /v1/sessions`) |
| `quantum-computing.session.read` | Obtenir une session (`GET /v1/sessions/{id}`) |
| `quantum-computing.session.update` | Fermer la session du job (`DELETE /v1/sessions/{id}/close`) |
| `quantum-computing.session.update` | Mettre à jour une session (`PATCH /v1/sessions/{id}`) |
| `quantum-computing.workload.list` | Répertorier les charges de travail de l'instance utilisateur (`GET /v1/workloads`) |

## IBM Quantum System Service {#ibm-quantum-system-service}

| Autorisation | Requise par |
| -- | -- |
| `quantum-computing.direct-access-backend-configuration.read` | Obtenir la configuration du backend (`GET /v1/backends/{backend-name}/configuration`) |
| `quantum-computing.direct-access-backend-properties.read` | Obtenir les propriétés du backend (`GET /v1/backends/{backend-name}/properties`) |
| `quantum-computing.direct-access-backend.list` | Obtenir la liste des backends (`GET /v1/backends`) |
| `quantum-computing.direct-access-backend.read` | Obtenir les détails du backend (`GET /v1/backends/{backend-name}`) |
| `quantum-computing.direct-access-job.cancel` | Annuler un job (`POST /v1/jobs/{job-id}/cancel`) |
| `quantum-computing.direct-access-job.create` | Exécuter un job (`POST /v1/jobs`) |
| `quantum-computing.direct-access-job.delete` | Supprimer un job (`DELETE /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-job.list` | Obtenir les jobs (`GET /v1/jobs`) |
| `quantum-computing.direct-access-job.read` | Obtenir un job par ID (`GET /v1/jobs/{job-id}`) |
| `quantum-computing.direct-access-lane-configuration.list` | Obtenir la configuration des voies (lanes) du backend (`GET /v1/backends/{backend-name}/lanes`) |
