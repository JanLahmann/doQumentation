# Sauvegarder tes identifiants de connexion {#save-your-login-credentials}
Si tu travailles dans un environnement Python de confiance (par exemple sur un ordinateur portable personnel ou un poste de travail), tu peux utiliser la méthode `save_account()` pour sauvegarder tes identifiants localement, puis les utiliser pour initialiser le service.

<Admonition type="note" title="Remarques">
      * Si tu utilises un ordinateur public ou tout autre environnement non fiable, suis plutôt les instructions de la page [Initialiser le service dans un environnement non fiable](/guides/cloud-setup-untrusted).
      * Suis [ces instructions](/guides/cloud-setup-rest-api) si tu souhaites te connecter via l'API REST plutôt qu'en utilisant Qiskit.
      * Si nécessaire, utilise [ces informations](/guides/quickstart-steps-org#firewall) pour configurer ton pare-feu et autoriser l'accès aux points de terminaison de l'API IBM Quantum.
</Admonition>

## Avant de commencer {#before-you-begin}

1. Assure-toi de travailler dans un environnement Python actif avec les [packages `qiskit` et `qiskit-ibm-runtime` installés](/guides/install-qiskit#local).

1. Active l'environnement virtuel Python et exécute Python dans cet environnement.

1. Connecte-toi à [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Trouver tes identifiants d'accès {#find-your-access-credentials}

1. Assure-toi que le bon compte et la bonne région sont sélectionnés dans le sélecteur de compte dans l'en-tête.

1. Trouve ta clé API. Depuis le [tableau de bord](https://quantum.cloud.ibm.com/), crée ta clé API, puis copie-la dans un emplacement sécurisé afin de pouvoir l'utiliser pour l'authentification. Note que tu peux utiliser la même clé API pour te connecter à n'importe quelle région.

1. Facultatif : Trouve l'instance que tu souhaites utiliser depuis la page [Instances](https://quantum.cloud.ibm.com/instances). Survole son CRN, clique sur l'icône pour le copier, puis sauvegarde-le dans un emplacement sécurisé afin de pouvoir l'utiliser pour identifier l'instance.


<span id="cloud-save"></span>

## Sauvegarder tes identifiants d'accès {#save-your-access-credentials}

Sauvegarde tes identifiants en exécutant le code approprié une fois par compte que tu souhaites enregistrer. Après avoir sauvegardé tes identifiants, charge-les en suivant les étapes de la page [Initialiser IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Sauvegarder des identifiants qui accèdent à une instance spécifique : {#save-credentials-that-access-a-specific-instance}
Si tu as plusieurs instances et que tu veux indiquer facilement à Quantum Compute laquelle utiliser, sauvegarde des identifiants incluant un CRN d'instance.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Sauvegarder des identifiants pour la sélection automatique d'instance : {#save-credentials-for-automatic-instance-selection}
Si tu ne fournis pas de CRN d'instance et que tu transmets ces identifiants à Quantum Compute, une instance appropriée sera automatiquement choisie pour toi en fonction des options spécifiées.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Exemple 2 {#example-2}
Cet exemple sauvegarde des identifiants pour la sélection automatique d'instance. Quantum Compute ne prendra en compte que les instances premium dans la région EU disponibles pour le compte. Ces identifiants deviennent le nouveau défaut.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Voir les identifiants sauvegardés {#view-saved-credentials}

Pour voir tous les identifiants que tu as sauvegardés, exécute `service.saved_accounts()`. Note que si tu as sauvegardé des identifiants par défaut sans les nommer, ils portent le nom `default-ibm-quantum-platform`. Si tu as nommé tes identifiants par défaut, tu verras `"is_default_account": true` dans le résultat.

## Considérations {#considerations}

* Si tu sauvegardes plusieurs comptes, utilise le paramètre `name` pour les différencier.

* Les identifiants sont sauvegardés dans `$HOME/.qiskit/qiskit-ibm.json`. Ne modifie pas ce fichier manuellement.

* Si tu ne sauvegardes pas tes identifiants, tu devras les spécifier à chaque fois que tu démarres une nouvelle session (instanciation d'IBM Quantum Compute Service).

* Si tu spécifies manuellement tes identifiants, un compte sauvegardé ne sera pas utilisé.
