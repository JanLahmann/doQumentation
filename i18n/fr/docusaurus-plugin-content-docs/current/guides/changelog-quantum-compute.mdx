# Client IBM Quantum Compute v0.46.0 {#ibm-quantum-compute-client-v0460}

## Avril 2026 {#april-2026}

<span id="executor-primitive"></span>
- **Introducing the Executor primitive**: We're excited to announce the release of the new `Executor` primitive and a new version of the noise-learning helper class, `NoiseLearnerV3`, both of which were first previewed at QDC 2025.

  Avec [Samplomatic](https://qiskit.github.io/samplomatic/index.html), ils constituent le [modèle d'exécution dirigée](/guides/directed-execution-model), qui offre une transparence et un contrôle complets pour affiner ton flux de travail d'atténuation d'erreur. Le tutoriel [Annulation d'erreur probabiliste avec des cônes de lumière ombrés](https://qiskit.github.io/qiskit-addon-slc/tutorials/01_getting_started.html), par exemple, démontre comment ce modèle est utilisé pour combiner des techniques avancées, notamment les cônes de lumière ombrés, l'annulation d'erreur probabiliste (PEC), l'extinction d'erreur de lecture par embrouillage (TREX) et la [post-sélection basée sur les mesures](/guides/post-selection), afin d'améliorer encore la qualité des résultats.

  Si tu préfères un niveau d'abstraction plus élevé, [`EstimatorV2`](/guides/estimator-noise-management) dans Qiskit Runtime continue de fournir plusieurs techniques intégrées d'atténuation et de suppression d'erreur, que tu peux facilement ajuster à l'aide de l'option [`resilience_level`](/guides/estimator-noise-management#resilience-level).

  Pour en savoir plus, consulte les guides suivants :

    - [Démarrage rapide avec Executor](/guides/get-started-with-executor)

    - [Assistant d'apprentissage du bruit](/guides/noise-learning)


  Ces deux nouvelles fonctionnalités sont actuellement en version bêta et nécessitent `qiskit-ibm-runtime` version 0.47.0 ou supérieure.
