# Збережи свої облікові дані {#save-your-login-credentials}
Якщо ти працюєш у довіреному середовищі Python (наприклад, на особистому ноутбуці або робочій станції), можна скористатися методом `save_account()`, щоб зберегти облікові дані локально, а потім використовувати їх для ініціалізації сервісу.

<Admonition type="note" title="Примітки">
      * Якщо ти використовуєш публічний комп'ютер або інше ненадійне середовище, дотримуйся інструкцій у [Ініціалізація сервісу в ненадійному середовищі](/guides/cloud-setup-untrusted).
      * Дотримуйся [цих інструкцій](/guides/cloud-setup-rest-api), якщо хочеш підключитися через REST API, а не через Qiskit.
      * За потреби скористайся [цією інформацією](/guides/quickstart-steps-org#firewall), щоб налаштувати брандмауер для доступу до точок API IBM Quantum.
</Admonition>

## Перш ніж почати {#before-you-begin}

1. Переконайся, що працюєш у активному середовищі Python із встановленими [`qiskit` та `qiskit-ibm-runtime` пакетами](/guides/install-qiskit#local).

1. Активуй віртуальне середовище Python і запусти Python у ньому.

1. Увійди в [IBM Quantum Platform](https://quantum.cloud.ibm.com).


<span id="find-credentials"></span>

## Знайди свої облікові дані для доступу {#find-your-access-credentials}

1. Переконайся, що у перемикачі облікових записів у шапці обрано правильний акаунт і регіон.

1. Знайди свій API-ключ. На [головній сторінці](https://quantum.cloud.ibm.com/) створи API-ключ, скопіюй його в надійне місце — він знадобиться для автентифікації. Зверни увагу: один і той самий API-ключ можна використовувати для підключення до будь-якого регіону.

1. Необов'язково: знайди потрібний інстанс на сторінці [Instances](https://quantum.cloud.ibm.com/instances). Наведи курсор на його CRN, клацни іконку копіювання та збережи значення в надійному місці — воно знадобиться для ідентифікації інстансу.


<span id="cloud-save"></span>

## Збережи свої облікові дані для доступу {#save-your-access-credentials}

Збережи облікові дані, запустивши відповідний код один раз для кожного акаунта, який хочеш зберегти. Після збереження завантаж їх, дотримуючись кроків у [Ініціалізація IBM Quantum Compute Service](/guides/initialize-account).

<span id="save-instance"></span>

### Збережи облікові дані для доступу до конкретного інстансу: {#save-credentials-that-access-a-specific-instance}
Якщо у тебе кілька інстансів і ти хочеш легко вказати Quantum Compute, який із них використовувати, збережи облікові дані з CRN інстансу.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your-api-key>", 
      name="<account-name>", # Optional
      instance="<IBM Cloud CRN or instance name>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
    ```

<span id="auto-select"></span>

### Збережи облікові дані для автоматичного вибору інстансу: {#save-credentials-for-automatic-instance-selection}
Якщо не вказати CRN інстансу і передати ці облікові дані в Quantum Compute, відповідний інстанс буде обрано автоматично на основі вказаних параметрів.

    ```python
    from qiskit_ibm_runtime import QiskitRuntimeService

    QiskitRuntimeService.save_account(
      # For `token`, use the 44-character API_KEY you created 
      # and saved from the IBM Quantum Platform Home dashboard:
      token="<your=api-key>", 
      name="<account-name>", # Optional
      instance="<instance-to-use>", # Optional
      plans_preference="<plan_types>", # Optional
      region="<region>", # Optional
      tags="<instance-tags>", # Optional
      set_as_default=True, # Optional
      overwrite=True, # Optional
    )
   ```

### Available options {#available-options}

- **`token`**: IBM Cloud API key. Your token is confidential. Do not share your token in public code.
- **`instance`**: Optionally specify the instance to use through its IBM Cloud CRN or instance name.
- **`plans_preference`**: Optionally set the types of plans to prioritize. This is ignored if the instance is specified. Available options are `open`, `pay-as-you-go`, `flex`, `premium`, and `on-prem`. Instances of a certain plan type are excluded if the plan name is not specified. For example, if [`open`] is passed in, only Open Plan instances are available. This is ignored if `instance` is specified.
- **`region`**: Optionally set the region to use. Accepted values are `us-east` and `eu-de`. This is ignored if `instance` is specified.
- **`tags`**: Optionally specify the instance's tags. Accepts a list of tag name strings. This is ignored if `instance` is specified.
- **`name`**: Optionally name this set of account credentials.
- **`set_as_default`**: Set the value to `True` to save these as your default credentials. If you save only one account, it is automatically set as the default.
- **`overwrite`**: Set this value to `True` to update your default credentials.

## Examples {#examples}

### Example 1 {#example-1}
This example saves credentials for specific instances, which allow open and premium access.  The open credentials are set as the default.

```python
from qiskit_ibm_runtime import QiskitRuntimeService

QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_premium_instance>",
                                  name="premium")
QiskitRuntimeService.save_account(token="<API_TOKEN>", 
                                  instance="<CRN_for_open_instance>",
                                  name="open", set_as_default=True)
 ```

### Приклад 2 {#example-2}
У цьому прикладі зберігаються облікові дані для автоматичного вибору інстансу. Quantum Compute розглядатиме лише premium-інстанси в регіоні EU, доступні для цього акаунта. Ці облікові дані стають новими стандартними.

```python
QiskitRuntimeService.save_account(
    token="your-api-key",
    set_as_default=True,
    overwrite = True,

    # Set instance "filters" instead of specifying the instance:
    region="eu-de",
    plans_preference=["premium"]
  )
 ```

## Переглянь збережені облікові дані {#view-saved-credentials}

Щоб переглянути всі збережені облікові дані, виконай `service.saved_accounts()`. Зверни увагу: якщо ти зберіг стандартні облікові дані і не давав їм імені, вони матимуть назву `default-ibm-quantum-platform`. Якщо ти назвав свої стандартні облікові дані, у виводі побачиш `"is_default_account": true`.

## Важливі моменти {#considerations}

* Якщо зберігаєш кілька акаунтів, використовуй параметр `name`, щоб відрізняти їх.

* Облікові дані зберігаються у `$HOME/.qiskit/qiskit-ibm.json`. Не редагуй цей файл вручну.

* Якщо не збережеш облікові дані, їх потрібно буде вказувати щоразу при старті нової сесії (ініціалізації IBM Quantum Compute Service).

* Якщо вказати облікові дані вручну, збережений акаунт використовуватися не буде.
