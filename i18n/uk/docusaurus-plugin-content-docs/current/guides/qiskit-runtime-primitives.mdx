# Вступ до примітивів IBM Quantum {#introduction-to-ibm-quantum-primitives}

Примітиви були створені для спрощення найпоширеніших завдань квантових комп'ютерів: а саме, вибірки квантових станів та обчислення очікуваних значень. Перші примітиви IBM Quantum ([`EstimatorV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/estimator-v2) та [`SamplerV2`](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/sampler-v2)) — це реалізації базових класів [примітивів Qiskit](/guides/primitives). Вони надають більш досконалу реалізацію (наприклад, включаючи пом'якшення помилок) як хмарний сервіс і використовуються для доступу до апаратного забезпечення IBM Quantum&reg;.

Найновіший примітив IBM Quantum, [Executor](https://docs.quantum.ibm.com/api/qiskit-ibm-runtime/executor) (який перебуває в бета-версії), надає нижчорівневий інтерфейс, що дає більше видимості та контролю без втрати продуктивності. 
`Executor` також надає **додаткові можливості, яких немає в Sampler**, такі як додаткові групи твірлінгу та твірлінг для схем з дробовими гейтами. Дивись [Перехід від Sampler до Executor](/guides/migrate-from-sampler-to-executor) для отримання додаткової інформації про те, чи варто переходити на `Executor`.
