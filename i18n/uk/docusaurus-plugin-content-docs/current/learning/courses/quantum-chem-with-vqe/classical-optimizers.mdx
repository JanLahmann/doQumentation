## Програмування класичного оптимізатора {#coding-a-classical-optimizer}

У попередніх уроках ти навчився будувати гамільтоніан, придатний для квантового комп'ютера, і створювати варіаційну схему. Ти також дізнався, що варіаційна схема (або анзац) містить параметри, які потрібно варіювати, а оптимальний вибір параметрів — той, що дає найнижчу можливу цільову функцію або енергію. Таким чином, задача зводиться до пошуку в просторі параметрів оптимального набору. Більшу частину роботи з класичними оптимізаторами вже зроблено за нас: відмінні оптимізатори доступні з кількох джерел.

У цьому уроці ти дізнаєшся:
- Як класичні оптимізатори вписуються в розрахунок VQE
- Які класичні оптимізатори доступні в SciPy
- Які оптимізатори __ще__ недоступні через SciPy і як тимчасово доповнити їх за допомогою `qiskit.algorithms`
- Які параметри доступні для цих оптимізаторів і що вони означають з точки зору квантових обчислень

[SciPy](https://scipy.org/) — це безкоштовна бібліотека Python з відкритим кодом, що містить пакети для різних областей наукових обчислень, зокрема оптимізації. Зокрема, SciPy має пакет оптимізації, що включає [minimize](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.minimize.html):

```from scipy.optimize import minimize```
This minimize function has several arguments, but the most relevant arguments for quantum chemistry are:
- The cost function (`cost_func`). This is related to the Hamiltonian, but also includes some complexities, such as determining the expectation value by using Estimator, and in the case of excited state calculations, might include orthogonality conditions.
- An initial state (x0) for the system, often the Hartree Fock state
- Other arguments, including arguments of the cost function itself
- The method set to the classical optimizer you select
- Options for the classical optimizer (not to be confused with Session options discussed in the next section)

Нижче наведено приклад коду. Тут ми обмежимо наше обговорення двома останніми аргументами.

```minimize(
    cost_func,
    x0,
    args=(ansatz, hamiltonian, estimator),
    method="cobyla",
    options={"maxiter": 200})

```
SciPy має документацію щодо всіх доступних методів minimize. Ось кілька примітних прикладів, всі з яких є методами мінімізації скалярної функції однієї або кількох змінних:
- [cobyla](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-cobyla.html#optimize-minimize-cobyla): алгоритм оптимізації за допомогою лінійної апроксимації (COBYLA).
- [slsqp](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-slsqp.html#optimize-minimize-slsqp): послідовне квадратичне програмування з обмеженнями (SLSQP).
- [nelder-mead](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-neldermead.html#optimize-minimize-neldermead) алгоритм Нелдера-Міда.

Більшість доступних класичних алгоритмів оптимізації є локальними мінімізаторами, у тому сенсі, що вони використовують різні методи для пошуку локальних мінімумів, але не гарантують знаходження глобальних мінімумів. Деякі класичні оптимізатори явно оцінюють градієнти та використовують їх для знаходження локальних мінімумів. Інші можуть використовувати послідовні лінійні або квадратичні апроксимації цільової функції для знаходження мінімумів.

Ці алгоритми мають кілька спільних опцій, але з тонкими відмінностями. Наприклад, усі мають опцію вказати максимальну кількість ітерацій за допомогою запису `'maxiter': 200`, як показано вище. Усі мають певну опцію, що вказує інший критерій зупинки на основі значень функції або змінних, хоча ці критерії дещо відрізняються для різних алгоритмів. COBYLA, наприклад, дозволяє вказати допуск (наприклад, `'tol': 0.0001`), що є нижньою межею "довірчої області". Для порівняння, SLSQP дозволяє вказати мету щодо точності функції, використаної в критерії зупинки ('ftol'). Nelder-Mead дозволяє вказати допуск щодо різниці між послідовними здогадками параметра ($x$) (xatol) або допуск щодо різниці між послідовними значеннями, отриманими для функції вартості $f(x)$ (fatol) (або обидва).
Повний список доступних алгоритмів та опцій дивись у [документації SciPy щодо minimize](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.minimize.html).
