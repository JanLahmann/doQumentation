Ось реалізація протоколу квантової телепортації у вигляді квантової схеми.

```python
qubit = QuantumRegister(1, "Q")
ebit0 = QuantumRegister(1, "A")
ebit1 = QuantumRegister(1, "B")
a = ClassicalRegister(1, "a")
b = ClassicalRegister(1, "b")

protocol = QuantumCircuit(qubit, ebit0, ebit1, a, b)

# Prepare ebit used for teleportation
protocol.h(ebit0)
protocol.cx(ebit0, ebit1)
protocol.barrier()

# Alice's operations
protocol.cx(qubit, ebit0)
protocol.h(qubit)
protocol.barrier()

# Alice measures and sends classical bits to Bob
protocol.measure(ebit0, a)
protocol.measure(qubit, b)
protocol.barrier()

# Bob uses the classical bits to conditionally apply gates
with protocol.if_test((a, 1)):
    protocol.x(ebit1)
with protocol.if_test((b, 1)):
    protocol.z(ebit1)

display(protocol.draw(output="mpl"))
```

У схемі використовується кілька можливостей Qiskit, яких ми ще не бачили в попередніх уроках: функції `barrier` та `if_test`.
Функція `barrier` створює візуальне розділення, що робить діаграму схеми більш читабельною, а також забороняє Qiskit виконувати різноманітні спрощення та оптимізації через бар'єр під час компіляції, коли схеми запускаються на реальному обладнанні.
Функція `if_test` застосовує операцію умовно — залежно від значення класичного біта або регістра.

Спочатку схема ініціалізує $(\mathsf{A},\mathsf{B})$ у стан $\vert \phi^+\rangle$ (що не є частиною самого протоколу), потім виконуються операції Аліси, потім її вимірювання, і нарешті — операції Боба.
Щоб перевірити правильність роботи протоколу, ми застосуємо випадково згенерований однокубітний вентиль до ініціалізованого стану $\vert 0\rangle$ кубіта $\mathsf{Q}$, отримавши таким чином випадковий квантовий вектор стану для телепортації. Застосувавши інверсію (тобто спряжено-транспоновану матрицю) цього вентиля до $\mathsf{B}$ після виконання протоколу, ми можемо перевірити, що стан було телепортовано, вимірявши та переконавшись, що він повернувся до стану $\vert 0\rangle$.

Спочатку ми випадково оберемо унітарний вентиль для кубіта.

## Надщільне кодування {#superdense-coding}

Надщільне кодування — це протокол, який, у певному сенсі, досягає мети, комплементарної до телепортації.
Замість того щоб передавати один кубіт за допомогою двох класичних бітів зв'язку (ціною одного е-біта заплутаності), він дозволяє передавати два класичних біти за допомогою одного кубіта квантового зв'язку (знову ж таки, ціною одного е-біта заплутаності).

Детальніше: є відправник (Аліса) і одержувач (Боб), які розділяють один е-біт заплутаності.
Відповідно до угод, прийнятих у цьому уроці, це означає, що Аліса тримає кубіт $\mathsf{A}$, Боб тримає кубіт $\mathsf{B}$, і разом пара $(\mathsf{A},\mathsf{B})$ перебуває у стані $\vert\phi^+\rangle$.
Аліса хоче передати Бобу два класичних біти, які ми позначимо як $c$ і $d$, і зробить це, надіславши йому один кубіт.

Можна вважати, що це досягнення менш вражаюче, ніж те, чого досягає телепортація.
Надсилання кубітів, найімовірніше, буде значно складнішим, ніж надсилання класичних бітів у найближчому майбутньому, тому обмін одним кубітом квантового зв'язку на два класичних біти — та ще й ціною е-біта — навряд чи здається вартим того.
Однак це не означає, що надщільне кодування нецікаве — навпаки, воно дуже навіть цікаве.

Відповідно до теми уроку, одна з причин, чому надщільне кодування цікаве, полягає в тому, що воно демонструє конкретне і (в контексті теорії інформації) досить разюче використання заплутаності.
Відома теорема в квантовій теорії інформації, відома як *теорема Голєво*, стверджує, що без спільного заплутаного стану неможливо передати більше одного біта класичної інформації, надіславши один кубіт.
(Теорема Голєво є більш загальною за це.
Її точне формулювання технічне й потребує пояснень, але це один із її наслідків.)
Отже, завдяки надщільному кодуванню спільна заплутаність фактично дозволяє *подвоїти* пропускну здатність класичної інформації при надсиланні кубітів.

### Протокол {#protocol}

Наступна діаграма квантової схеми описує протокол надщільного кодування:

![Схема надщільного кодування](/learning/images/courses/basics-of-quantum-information/entanglement-in-action/qiskit-implementation/superdense-coding.avif)

Словами, ось що робить Аліса:

1. Якщо $d=1$, Аліса застосовує вентиль $Z$ до свого кубіта $\mathsf{A}$ (а якщо $d=0$ — не застосовує).


2. Якщо $c=1$, Аліса застосовує вентиль $X$ до свого кубіта $\mathsf{A}$ (а якщо $c=0$ — не застосовує).


Після цього Аліса надсилає свій кубіт $\mathsf{A}$ Бобу.

Коли Боб отримує кубіт $\mathsf{A}$, він спочатку застосовує вентиль controlled-NOT, де $\mathsf{A}$ є контрольним, а $\mathsf{B}$ — цільовим, а потім застосовує вентиль Адамара до $\mathsf{A}$.
Потім він вимірює $\mathsf{B}$, щоб отримати $c$, і $\mathsf{A}$, щоб отримати $d$, — в обох випадках за допомогою вимірювань у стандартному базисі.

### Аналіз {#analysis}

Ідея цього протоколу проста:
Аліса фактично обирає, в якому стані Белла вона хотіла б перебувати разом із Бобом,
надсилає Бобу свій кубіт, і Боб вимірює, щоб визначити, який стан Белла обрала Аліса.

Тобто спочатку вони розділяють $\vert\phi^+\rangle,$ і залежно від бітів $c$ та $d,$ Аліса або залишає цей стан незмінним, або переводить його в один із інших станів Белла, застосовуючи $\mathbb{I},$ $X,$ $Z,$ або $XZ$ до свого кубіта
$\mathsf{A}.$

$$
\begin{aligned}
(\mathbb{I} \otimes \mathbb{I}) \vert \phi^+ \rangle & = \vert \phi^+\rangle \\
(\mathbb{I} \otimes Z) \vert \phi^+ \rangle & = \vert \phi^-\rangle \\
(\mathbb{I} \otimes X) \vert \phi^+ \rangle & = \vert \psi^+\rangle \\
(\mathbb{I} \otimes XZ) \vert \phi^+ \rangle & = \vert \psi^-\rangle
\end{aligned}
$$

Дії Боба мають такий вплив на чотири стани Белла:

$$
\begin{aligned}
\vert \phi^+\rangle & \mapsto \vert 00\rangle\\
\vert \phi^-\rangle & \mapsto \vert 01\rangle\\
\vert \psi^+\rangle & \mapsto \vert 10\rangle\\
\vert \psi^-\rangle & \mapsto -\vert 11\rangle\\
\end{aligned}
$$

Це можна перевірити безпосередньо, обчислюючи результати операцій Боба над цими станами по одному.

Отже, коли Боб виконує свої вимірювання, він може визначити, який стан Белла обрала Аліса.
Перевірка правильності роботи протоколу зводиться до розгляду кожного випадку:

 - Якщо $cd = 00$, то стан $(\mathsf{B},\mathsf{A})$ на момент отримання Бобом $\mathsf{A}$ дорівнює $\vert \phi^+\rangle$. Він перетворює цей стан на $\vert 00\rangle$ і отримує $cd = 00$.


 - Якщо $cd = 01$, то стан $(\mathsf{B},\mathsf{A})$ на момент отримання Бобом $\mathsf{A}$ дорівнює $\vert \phi^-\rangle$. Він перетворює цей стан на $\vert 01\rangle$ і отримує $cd = 01$.


 - Якщо $cd = 10$, то стан $(\mathsf{B},\mathsf{A})$ на момент отримання Бобом $\mathsf{A}$ дорівнює $\vert \psi^+\rangle$. Він перетворює цей стан на $\vert 10\rangle$ і отримує $cd = 10$.


 - Якщо $cd = 11$, то стан $(\mathsf{B},\mathsf{A})$ на момент отримання Бобом $\mathsf{A}$ дорівнює $\vert \psi^-\rangle$. Він перетворює цей стан на $-\vert 11\rangle$ і отримує $cd = 11$. (Фазовий множник мінус один тут жодного впливу не має.)


### Реалізація надщільного кодування {#superdense-coding-implementation}

Ось проста реалізація надщільного кодування, де ми задаємо схему залежно від бітів, які потрібно передати. Спочатку оберемо два біти для передачі. (Пізніше ми оберемо їх випадково, але поки що зробимо довільний вибір.)

```python
c = "1"
d = "0"
```

Тепер побудуємо схему відповідно. Тут ми дозволимо Qiskit використовувати стандартні назви для кубітів: $\mathsf{q}_0$ для верхнього кубіта та $\mathsf{q}_1$ для нижнього.

```python
protocol = QuantumCircuit(2)

# Prepare ebit used for superdense coding
protocol.h(0)
protocol.cx(0, 1)
protocol.barrier()

# Alice's operations
if d == "1":
    protocol.z(0)
if c == "1":
    protocol.x(0)
protocol.barrier()

# Bob's actions
protocol.cx(0, 1)
protocol.h(0)
protocol.measure_all()

display(protocol.draw(output="mpl"))
```

```python
test.measure(ebit0, Bob_d)
```

### Реалізація в Qiskit {#qiskit-implementation}

Гру CHSH разом із описаною вище квантовою стратегією можна реалізувати в Qiskit таким чином.

По-перше, ось визначення самої гри, яке приймає довільну стратегію як аргумент.

```python
def chsh_game(strategy):
    # This function runs the CHSH game, using the strategy (a function
    # from two bits to two bits), returning 1 for a win and 0 for a loss.

    # Choose x and y randomly
    x, y = random.randint(0, 1), random.randint(0, 1)

    # Use the strategy to determine a and b
    a, b = strategy(x, y)

    # Decide if the strategy wins or loses
    if (a != b) == (x & y):
        return 1  # Win
    return 0  # Lose
```

Тепер створимо функцію, що генерує схему залежно від питань для Аліси та Боба. Для простоти залишимо кубітам стандартні імена, а для дій Аліси та Боба використаємо вбудований вентиль $R_y(\theta)$.

```python
def chsh_circuit(x, y):
    # This function creates a `QuantumCircuit` implementing the quantum
    # strategy described above (including the e-bit preparation).

    qc = QuantumCircuit(2, 2)

    # Prepare an e-bit
    qc.h(0)
    qc.cx(0, 1)
    qc.barrier()

    # Alice's actions
    if x == 0:
        qc.ry(0, 0)
    else:
        qc.ry(-pi / 2, 0)
    qc.measure(0, 0)

    # Bob's actions
    if y == 0:
        qc.ry(-pi / 4, 1)
    else:
        qc.ry(pi / 4, 1)
    qc.measure(1, 1)

    return qc
```

Ось чотири можливі схеми залежно від того, які питання ставляться.

Тепер створимо завдання за допомогою симулятора Aer, що запускає схему один раз для заданої пари вхідних значень $(x,y)$.

```python
def quantum_strategy(x, y):
    # This function runs the appropriate quantum circuit defined above
    # one time and returns the measurement results

    # Setting `shots=1` to run the circuit once
    result = AerSimulator().run(chsh_circuit(x, y), shots=1).result()
    statistics = result.get_counts()

    # Determine the output bits and return them
    bits = list(statistics.keys())[0]
    a, b = bits[0], bits[1]
    return a, b
```

Також можна визначити класичну стратегію й перевірити, наскільки добре вона працює.
Це лише одна стратегія — інші можна перевірити, змінивши код, — але вона належить до оптимальних класичних стратегій.

```python
def classical_strategy(x, y):
    # This function implements just one example of an optimal classical
    # strategy for the CHSH game. Other classical strategies can be
    # implemented by changing the bit values assigned to a and b.

    # Alice's answer
    if x == 0:
        a = 0
    elif x == 1:
        a = 1

    # Bob's answer
    if y == 0:
        b = 1
    elif y == 1:
        b = 0

    return a, b
```

Знову зіграємо в гру 1000 разів, щоб побачити, наскільки вона ефективна.

```python
NUM_GAMES = 1000
TOTAL_SCORE = 0

    TOTAL_SCORE += chsh_game(classical_strategy)
```
