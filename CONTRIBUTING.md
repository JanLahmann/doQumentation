# Contributing to doQumentation

Thank you for helping. Pick the path that fits:

| You want to… | Go to |
|---|---|
| Report a wrong or awkward translation (no tools needed) | [Wrong or awkward translation](https://github.com/JanLahmann/doQumentation/issues/new?template=translation-report.yml) |
| Report a broken page, link, search or setting | [Site bug](https://github.com/JanLahmann/doQumentation/issues/new?template=site-bug.yml) |
| Report code that does not run on the site | [Code does not run](https://github.com/JanLahmann/doQumentation/issues/new?template=execution-error.yml) |
| Fix a mistake in the English tutorial or course content | Upstream: [Qiskit/documentation](https://github.com/Qiskit/documentation/issues). `docs/` here is generated from it. |
| Review a whole language with Claude Code | [CONTRIBUTING-NOW.md](CONTRIBUTING-NOW.md), then [CONTRIBUTING-REVIEWS.md](CONTRIBUTING-REVIEWS.md) |
| Translate newly synced content | [CONTRIBUTING-TRANSLATIONS.md](CONTRIBUTING-TRANSLATIONS.md) |
| Change the site's code | README → Development. Pull requests welcome; please do not edit `docs/` or `i18n/*/po/` by hand. |
